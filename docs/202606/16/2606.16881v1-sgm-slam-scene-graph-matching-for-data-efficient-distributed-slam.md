## 摘要
我们提出了一种数据高效的分布式同时定位与地图构建（SLAM）框架，专为配备LiDAR、相机和惯性传感器的机器人团队设计。该框架利用场景图匹配来识别机器人间的测量约束。与先前依赖特征级匹配的方法不同，我们的框架是首个仅使用物体标签和质心进行场景图匹配的方法。我们的方法通过融合RGB-LiDAR点云来构建场景图，生成语义分割点云层和离散有界物体层，以配合估计的机器人轨迹。场景图匹配是通过与相邻机器人交换和匹配物体数据来协作完成的。为了最大化通信效率，我们采用了多步数据交换和优化过程。我们通过仿真以及由腿式机器人在室内外环境中收集的真实世界数据集，展示了我们方法的有效性和效率。

## Abstract
We introduce a data-efficient distributed Simultaneous Localization and Mapping (SLAM) framework designed for a team of robots equipped with LiDAR, cameras, and inertial sensors. Our framework uses scene graph matching to identify inter-robot measurement constraints. Unlike prior approaches that rely on feature-level matching, our framework is the first to perform scene graph matching using only object labels and centroids. Our approach constructs a scene graph by using fused RGB-LiDAR point clouds to generate both a semantically segmented point cloud layer, and a layer of discrete bounded objects, to accompany estimated robot trajectories. Scene graph matching is performed collaboratively through exchanging and matching object data with neighboring robots. To maximize communication efficiency, we utilize a multi-step data exchange and optimization process. We demonstrate the effectiveness and efficiency of our approach using both simulation and real-world datasets collected by legged robots in indoor and outdoor environments.

### 2. 方法论
- **核心思想**：
  - 每个机器人通过融合 RGB 图像与 LiDAR 点云，构建**多层级场景图**（包括关键帧层、物体层、语义点云层）。
  - 机器人间仅交换轻量级的**物体数据**（ID、类型、质心坐标），利用图匹配算法在物体层进行匹配，得到候选重叠物体。
  - 根据匹配物体对估计机器人间的初始相对变换（简化为 2D 刚体变换），再通过稀疏物体点云的 ICP 精化，生成 inter-robot 约束，加入局部因子图中进行优化。
- **关键技术细节**：
  1. **场景图构建**（Sec. 4.1）：
     - 图像语义分割（Oneformer） → 将语义标签投影到 LiDAR 点云 → 聚类为物体 → 构建物体层（全连接图，边权为欧氏距离）。
     - 物体跨帧匹配通过求解线性分配问题（LAP，匈牙利算法），最小化质心距离。
  2. **场景图匹配**（Sec. 4.2）：
     - 将本地物体图与邻居物体图视为两个全连接图，匹配形式化为**二次分配问题（QAP）**，通过谱松弛求解（特征向量取正解），再转化为 LAP 得到二元分配。
     - 边权重比较使用指数衰减函数 \(d_e(e_{ij}, e_{mn}) = \exp(-\mu|w_{ij}-w_{mn}|)\)；顶点比较仅依赖语义标签（0/1）。
  3. **相对变换估计**（Sec. 4.3）：
     - 假设物体共面，将问题简化为 2D 刚体变换估计（大于 3 个非共线物体）。
  4. **通信策略**（Sec. 4.5）：
     - 高频交换物体数据（仅 7-18 KB/次），匹配成功后按需请求压缩点云（约 19 KB/帧），大幅降低带宽占用。

### 5. 实验数量与充分性

### 6. 主要结论与发现
- 提出的 **SGM-SLAM** 在室内外数据集上均显著优于基于描述子的方法（Swarm-SC / Swarm-CP），特别是在低重叠和视角变化大的场景下优势明显。
- 仅使用物体标签和质心即可实现**稳健**的 inter-robot 数据关联，**通信量极低**（物体数据每次仅 ~8-18 KB，点云按需传输）。
- 仿真表明，即使存在物体位置误差（±1m）和少量语义标签错误（≤9 个），仍能保持 >95% 的成功率；但当仅 4 个重叠物体时成功率下降至 65%。
- 本方法首次证明了**不依赖特征描述子**的场景图匹配在分布式 SLAM 中的可行性，为数据受限环境下的多机器人协作提供了新思路。

### 7. 优点
- **数据高效**：仅交换轻量级语义-几何信息，大幅降低通信负载，适合低带宽或长任务场景。
- **视角鲁棒**：基于物体级别的图匹配，对视角变化、光照变化、场景重复不敏感。
- **无需外部先验**：不依赖 GPS、预先标定或固定形状匹配，拓展到未知环境。
- **层次化场景图**：便于人类理解和后续 LLM 集成，支持更高级的语义推理。
- **实时性能**：即使在 35 物体规模下，图匹配时间仅约 200 ms，满足在线需求。

### 8. 不足与局限
- **实验覆盖有限**：真实世界仅两个场景（室内外各一），且机器人平台单一（LiDAR 为固态式 Livox mid-360），未验证在更大型、更多机器人、更复杂环境（如森林、地下）下的表现。
- **物体检测质量依赖**：分割和聚类质量直接决定匹配性能；若物体检测失效（如严重遮挡、动态物体），系统鲁棒性将下降。
- **平面假设**：相对变换估计假设物体共面（简化为 2D），在地形起伏大的环境（如楼梯、野外）可能引入误差。
- **对比范围不足**：仅与 Swarm-SLAM 的两种变体对比，未与 Kimera-Multi、Multi S-graphs 等更经典的分布式场景图 SLAM 方法比较。
- **缺少消融实验**：未单独分析每个模块（如 QAP vs 简单最近邻、物体数量影响、ICP 精化贡献）的贡献；未讨论物体类别的选择对结果的影响。
- **真值局限性**：使用 COLMAP 而非高精度运动捕捉或 RTK-GPS，且只重建了特征丰富区域，部分轨迹可能无真值对比。
- **通信分析**仅基于模拟无线通信，未在实际低带宽网络下测试延迟和丢包影响。
