## 摘要
在执行长时程视觉操作任务的机器人会观察到高维图像，但成功的计划依赖于与动作相关的事实：当前能做什么以及之后会发生什么变化。一个有用的规划表示应丢弃无关视觉细节，同时保留动作的适用性和效果。经典任务规划器通过具有前提条件和效果的符号操作符来利用这种结构，但从原始视觉经验中获取这种表示仍然具有挑战性。我们研究了一种视觉任务规划设定，其中机器人仅接收图像转换：当前图像、执行的高级动作以及结果图像。在测试时，给定起始图像和目标图像，机器人必须生成一系列达到目标的高级动作。为了解决这个问题，我们引入了STRIPS-WM，一个直接从视觉转换中学习基于图像的STRIPS风格世界模型的框架。STRIPS-WM首先从图像中诱导出一个有限抽象转换图，然后学习潜在的二元谓词和每个动作标签的一个基础命题操作符。学习到的操作符形成一个具有稀疏前提条件和添加/删除效果的符号动作模型。最后，将学习到的谓词提炼到视觉编码器中，使得能够直接从新的起始和目标图像进行经典规划。在视觉重排任务上的实验表明，STRIPS-WM在图像到计划成功率上优于测试的视觉展开、潜在图搜索和潜在符号基准方法。

## Abstract
Robots performing long-horizon visual manipulation observe high-dimensional images, but successful plans depend on action-relevant facts: what can be done now and what changes afterward. A useful planning representation should discard irrelevant visual details while preserving action applicability and effects. Classical task planners exploit this structure through symbolic operators with preconditions and effects, but obtaining such representations from raw visual experience remains challenging. We study a visual task-planning setting in which a robot receives only image transitions: the current image, executed high-level action, and the resulting image. At test time, given a start image and a goal image, the robot must produce a sequence of high-level actions that reaches the goal. To address this problem, we introduce STRIPS-WM, a framework for learning image-grounded STRIPS-style world models directly from visual transitions. STRIPS-WM first induces a finite abstract transition graph from images, then learns latent binary predicates and one grounded propositional operator per action label. The learned operators form a symbolic action model with sparse preconditions and add/delete effects. Finally, the learned predicates are distilled into a visual encoder, enabling classical planning directly from novel start and goal images. Experiments on visual rearrangement tasks show that STRIPS-WM improves image-to-plan success over the tested visual rollout, latent graph-search and latent-symbolic baselines.

## 1. 核心问题与整体含义（研究动机和背景）

- **问题**：机器人通过高维图像感知环境，但长时程操作任务的高层规划依赖于与动作相关的抽象事实（如哪些动作当前可执行、执行后改变什么）。直接在像素空间预测未来图像代价高且包含大量无关细节，而经典任务规划（如STRIPS）使用符号谓词和带有前提/效果的算子，能够高效搜索。但是，从原始视觉经验中自动学习这种符号世界模型仍是一个挑战。
- **背景**：现有方法如基于重建的视觉规划（预测像素）或连续潜在空间规划（缺乏逻辑结构）在长时程任务中表现不佳。另一些符号学习方法需要物体级输入或手工谓词，不适合直接处理图像。
- **目标**：提出一个框架，仅从图像-动作-图像转移数据（无物体标签、无手工谓词、无符号状态）中学习一个基于图像的命题STRIPS世界模型，使得测试时给定起始和目标图像，能用经典规划器生成动作序列。

## 2. 方法论：核心思想、关键技术细节、算法流程

**核心思想**：分三个阶段，逐步从原始图像过渡到符号规划模型。

1. **阶段1：构建图像基础任务图（Image-Grounded Task Graph）**

   - 训练损失包括：动态预测L2损失、逆模型交叉熵损失、承诺损失、数据增强一致性损失、预测分离损失（减少潜在非确定性）。

2. **阶段2：从任务图学习STRIPS算子和谓词（CP-SAT优化）**

## 6. 主要结论与发现

- **STRIPS-WM能在仅有图像转移数据时学习到正确的命题STRIPS世界模型**。在BlocksWorld上实现了零松弛重建（表1），在DinnerTable和真实域也接近完美重构（转移松弛为0，应用松弛很小）。

- **谓词表示比平坦图搜索更鲁棒**：能合并过分割节点并修复不一致（图4）。

## 7. 优点

- **端到端从图像学习可规划符号模型**：无需物体标注、无需手工定义谓词或符号状态，仅需图像-动作-图像三元组。  
- **三阶段架构清晰**：用JEPA学习离散抽象图 → 用CP-SAT学习语义算子 → 蒸馏到视觉判断器，各阶段可独立验证。  
- **理论保证强**：零松弛时精确匹配图，且任意可行解产生标准STRIPS算子（定理10）。  
- **规划性能突出**：尤其长时程任务上显著优于基于潜在前向预测或平坦图搜索的方法。  
- **有效地结合了神经表示和符号优化**：编码器提取离散码字，组合优化恢复逻辑结构。

## 8. 不足与局限

- **假设确定性世界和STRIPS动态**：无法处理随机转移、部分可观察或隐藏状态。  
- **任务图质量和覆盖依赖**：若视觉抽象产生过分割或遗漏转移，CP-SAT可能引入松弛或学到错误前提；覆盖不充分导致负证据不可靠。  
- **未支持分层的或一阶逻辑**：学到的算子是无参数命题形式，不能组合泛化到新物体或动作参数；与Konidaris等技能-符号不同，无法迁移到不同物体数量。  
- **实验范围有限**：仅在三个相对较小领域（最大101个状态、70个动作）测试，未在更大或更复杂环境（多机器人、连续动作）验证。缺少对算法鲁棒性的系统分析（如不同FSQ维度、量化噪声、训练数据规模的影响）。  
- **计算开销未充分讨论**：CP-SAT阶段可能需要较长时间（每个候选谓语维度300秒），且视觉编码器训练超参数依赖扫查。
