## 摘要
世界动作模型（WAM）已成为具身智能的一种新型强大范式，能够学习与动作相关的视觉动态，显著增强泛化能力和鲁棒性。然而，现有的WAM在长期机器人操作中仍难以处理与任务相关的记忆。为了解决这一问题，我们提出了HiMem-WAM，一种分层记忆门控WAM，它集成了以运动为中心的潜在动作、高级技能潜在向量以及边界触发的记忆更新。具体来说，我们开发了一个分层潜在动作框架，联合学习低级运动和高级技能潜在向量，提供了结构化的时间抽象。同时，一个边界感知的记忆门在预测的技能转换处写入紧凑的任务状态，使得无需在测试时生成未来视频或光流估计即可进行因果推理。在LIBERO、LIBERO-PLUS、RMBench以及真实世界任务上的评估表明，HiMem-WAM的分层潜在向量提高了部署扰动下的鲁棒性，并且记忆模块显著有益于依赖记忆的长期操作。

## Abstract
World Action Models (WAMs) have emerged as a new powerful paradigm for embodied intelligence, learning action-relevant visual dynamics that significantly enhance generalization and robustness. However, existing WAMs still struggle with task-relevant memory in long-horizon robotic manipulation. To address this, we present HiMem-WAM, a Hierarchical Memory-Gated WAM that integrates motion-centric latent actions, high-level skill latents, and boundary-triggered memory updates. Specifically, we develop a hierarchical latent action framework that jointly learns low-level motion and high-level skill latents, providing structured temporal abstraction. Meanwhile, a boundary-aware memory gate writes compact task states at predicted skill transitions, enabling causal inference without test-time generation of future video or optical flow estimation. Evaluated on LIBERO, LIBERO-PLUS, RMBench and real-world tasks, HiMem-WAM shows that hierarchical latents improve robustness under deployment perturbations, and the memory module substantially benefits memory-dependent long-horizon manipulation.

- **背景**：视觉-语言-动作模型（VLA）依赖端到端动作预测，对部署扰动（光照、视角变化）鲁棒性不足；而WAM虽能学习动作相关的视觉动态，但在长程任务中效率低下。现有改进（如MotuBrain、LingBot-VA、FFDC）仍缺少对低层运动到高层技能的分层抽象和跨技能边界的显式记忆保留能力。
- **整体含义**：HiMem-WAM旨在通过分层记忆门控机制，连接短时运动执行与长时任务状态保留，实现因果推理（无需测试时生成未来视频或光流），提升长程操作的鲁棒性和记忆依赖任务的成功率。

## 2. 方法论
### 核心思想
- 将策略分解为三个层次：**高层技能潜在变量**（skill latent）选择当前子任务，**低层潜在动作块**（low-level latent action chunk）展开短期运动，**动作解码器**将潜在动作映射为具体控制指令。
- 引入**边界触发的记忆门控模块**：仅在预测的技能转换处写入紧凑的任务状态，读取时检索历史上下文以调节当前决策，实现稀疏、事件驱动的记忆更新。

### 关键技术细节
1. **低层潜在动作（Low-Level Latent Actions）**
   - 使用DPFlow提取多视图光流Φ_t，结合RGB、深度、语言、本体感受构成上下文c_t。
   - 训练变分词器（Variational Tokenizer）编码c_t得到低层潜在动作z^l_t，通过重建光流和（若有动作标签）辅助动作对齐进行训练：
     \[
     \mathcal{L}_l = \|\hat{\Phi}_t - \Phi_t\|_1 + \lambda_a I_t^{\text{act}} \|\hat{a}_t - a_t\|_2^2 + \beta D_{\text{KL}}(q_\phi(z^l_t | c_t) \| \mathcal{N}(0,I))
     \]
   - 训练后冻结分词器，离线提取所有轨迹的低层潜在序列Z^l。

2. **高层技能潜在（High-Level Skill Latents）**
   - 对低层潜在序列Z^l进行层次化动态分块：通过边界预测器（boundary predictor）标记新段落的开始，每段通过注意力池化得到下一层潜在向量。
   - 经过H层后得到技能序列Z^h = (z^h_1, ..., z^h_S)，并展开回原始时间步得到每个时间步的技能目标\bar{z}^h_t和边界标签\bar{b}_t。
   - 训练损失包括下一潜在预测、运动重建、边界比例约束和连续性损失，以学习有意义的技能边界。

3. **记忆门控模块（Memory-Gated Module）**
   - 编码当前状态x_t = E_θ(o_t, p_t, ℓ)，从外部记忆库M_t中检索上下文c^m_t = Attn(W_q x_t, W_k M_t, W_v M_t)。
   - **读门**：α^r_t = σ(G_r(x_t, c^m_t))，形成记忆适应状态\tilde{x}_t = x_t + α^r_t W_m c^m_t。
   - **规划器**（Qwen3-VL-4B-Instruct）从\tilde{x}_t预测当前技能\hat{z}^h_t和边界得分\hat{b}_t。
   - **执行器**从\tilde{x}_t和\hat{z}^h_t预测低层潜在动作块\hat{Z}^l_{t:t+K-1}，解码器映射为可执行动作。
   - **写门**：α^w_t = σ(G_w(\tilde{x}_t, \hat{z}^h_t, \hat{b}_t))，当α^w_t > η时，将候选记忆令牌γ_t写入记忆库，实现稀疏更新。
   - 训练时写门受边界标签\bar{b}_t的BCE监督，读门通过下游损失和L1稀疏正则化学习。

### 训练流程（三阶段）
- **Stage I**：训练低层潜在动作分词器（使用光流和动作标签）。
- **Stage II**：冻结分词器，学习技能潜在，预训练规划器和执行器（无记忆），损失：MSE(技能)+MSE(潜在动作块)+BCE(边界)。
- **Stage III**：激活记忆门控模块，在动作标记数据上微调完整策略，损失：动作损失 + 规划损失 + 执行损失 + 边界损失 + 门控损失（含写门BCE和读/写门L1稀疏项）。
