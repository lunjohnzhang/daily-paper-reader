## 摘要
移动操作机器人需要当前、可查询、具有语义意义且能在边缘计算约束下使用的世界模型。本技术报告提出KRVF，一种面向边缘移动操作的源感知语义体素世界表示。与主要优化全局几何保真度的以重建为中心的映射管线不同，KRVF将局部世界状态表示为任务导向的体素，编码占用、颜色、语义证据、时间新鲜度和证据来源。该表示将测量的占用与语义先验假设分离，使得在深度失效的情况下能够进行对象推理，而不会静默破坏持久几何结构。KRVF还通过渲染地图先验深度进行修复，闭合了映射与感知之间的反馈循环，并为语义对象和抓取候选提供了任务级查询操作符。本报告正式定义了KRVF表示，并记录了将在线RGB-D观测转化为面向任务的机器人记忆的ROS 2实现。

## Abstract
Mobile manipulators need world models that are current, queryable, semantically meaningful, and usable under edge-compute constraints. This technical report presents KRVF, a source-aware semantic voxel world representation for edge mobile manipulation. Unlike reconstruction-centric mapping pipelines that primarily optimize global geometric fidelity, KRVF represents local world state as task-oriented voxels that encode occupancy, color, semantic evidence, temporal freshness, and evidence source. The representation separates measured occupancy from semantic-prior hypotheses, enabling depth-failure-aware object reasoning without silently corrupting persistent geometry. KRVF also closes a feedback loop between mapping and sensing by rendering map-prior depth for repair, and exposes task-level query operators for semantic objects and grasp candidates. The report formalizes the KRVF representation and documents a ROS 2 implementation that turns online RGB-D observations into a task-facing robot memory.

# KRVF论文总结

## 1. 核心问题与整体含义（研究动机和背景）
- **问题**：移动操作机器人需要在边缘硬件（低功耗、有限算力）上构建世界模型，但传统以重建为中心的映射管线（如TSDF、OctoMap）侧重于全局几何保真度，缺乏任务导向性，无法满足机器人对低延迟、可查询、语义丰富的世界状态的需求。尤其是深度传感器在透明、反光、高光泽、暗色或薄物体上经常失效，导致几何观测不完整或错误，而纯粹的语义检测又会将错误假设写入地图。
- **动机**：机器人需要知道一个区域“为什么被占据”、“证据是否仍然新鲜”、“能否支持操作”，而不是仅仅知道“是否被占据”。因此需要一种源感知、可查询、支持假设与观测分离的表示。
- **背景**：现有工作如OctoMap、RTAB-Map、SemanticFusion等，要么忽略语义，要么将语义与几何混为一谈。KRVF旨在填补“感知与操作之间的表示层”空白，提供任务级查询接口。

## 2. 方法论
### 核心思想
- KRVF将世界表示为**源感知语义体素场**，每个体素不仅存储占用概率，还编码**颜色、语义证据、观测置信度、时间新鲜度和证据来源**（测量/修复/假设）。
- 明确区分**测量占用层**(\(K_{\text{obs}}\))与**语义先验假设层**(\(K_{\text{hyp}}\))，假设不会静默地覆盖测量几何。
- 建立**地图-感知反馈循环**：将当前体素地图渲染为深度先验，用于修复缺失或不可靠深度，修复后的观测带置信度标签回注到地图。
- 提供**任务级查询算子**：语义对象查询（\(Q_{\text{obj}}\)）和抓取候选查询（\(Q_{\text{grasp}}\)），直接输出对象ID、边界框、中心、稳定性评分以及顶部、腰部、侧边等抓取姿态。

### 关键技术细节
- **体素状态定义**：\(v_i = (l_i, c_i, s_i, q_i, \tau_i, \eta_i)\)，分别为对数几率、外观、语义、置信度、时间戳、证据类型。
- **源加权证据融合**：占用更新时加入置信度因子 \(q_t\)，\( \Delta l_i = q_t \cdot L_{\text{hit}}(z_t, x_t, v_i) \)。低置信度观测不产生激进的几何更新。
- **语义门控逆传感器模型**：物理深度可信时主导更新，深度缺失但语义存在时创建假设体素，不破坏持久几何。
- **假设生命周期**：\(h_i \xrightarrow{\text{TTL}} \varnothing\)，若未刷新则过期。未来可升级为测量（\(h_i \xrightarrow{z_t \text{ valid}} o_i\)）。
- **动态清除**：稳定体素需要多次连续miss才衰减（\(m_{\text{required}}\)依赖局部支撑），孤立噪声快速消失。
- **阴影壳防护**：基于颜色比较拒绝光照产生的暗色重复表面。
- **颜色稳定性**：持久颜色冻结，仅当重复证据支持时才更新。
- **候选体素晋升**：候选体素在足够证据下晋升为稳定体素。

### 算法流程（文字描述）
1. 输入：同步RGB-D图像、相机标定、TF/位姿变换。
2. 有效深度点反投影到3D，变换到世界帧，插入分块稀疏体素地图。
3. 每个体素融合占用、颜色、置信度、时间戳；保守射线投射更新自由空间证据。
4. 语义桥接节点：2D检测（如YOLO）通过深度采样、剔除不稳定边缘，仅更新存在占用的体素；深度缺失时创建假设体素层。
5. 地图先验深度修复：当前体素地图渲染为深度先验，与当前受损深度结合（颜色插值、平面拟合、时间滤波）得到修复深度，带置信度标签重新融合回地图。
6. 输出：高频率活动局部地图、低频率持久地图、假设层、语义对象数组、抓取候选标记等，通过ROS服务/动作接口供行为树或操作管线查询。

## 6. 主要结论与发现
- KRVF成功实现了**源感知世界表示**：能够区分观测几何、语义假设、修复深度和自由空间，并在深度失效时通过假设层保留任务信息，同时不污染持久几何。
- **地图-感知反馈循环**（深度先验修复）在概念上可行，但未在实验中单独验证其提升效果。
- **任务级查询接口**（对象/抓取）使得行为树和操作管线可以直接消费世界模型，无需解析原始点云。

## 7. 优点
- **源意识**：明确记录证据来源（观测/假设/修复），提高可调试性和信任度。
- **假设与观测分离**：防止语义误检长期污染地图，同时利用语义支持操纵决策。
- **反馈循环**：地图作为先验帮助修复传感器失效，形成闭环感知。
- **任务导向**：直接提供对象和抓取查询，降低下游模块复杂度。
- **解耦设计**：映射核心与检测、操作、行为树分离，便于移植到不同RGB-D机器人平台。
- **轻量级**：适用于边缘计算（稀疏体素、频控发布、按需更新）。

## 8. 不足与局限
- **依赖外部位姿**：不解决SLAM/定位，需要TF/里程计提供精度足够的位姿。
