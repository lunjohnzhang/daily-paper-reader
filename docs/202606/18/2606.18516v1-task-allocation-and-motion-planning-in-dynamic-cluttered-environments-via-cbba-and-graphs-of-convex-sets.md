## 摘要
在杂乱、动态环境中的多智能体任务规划需要将任务分配给智能体，同时确定通过环境的、安全且省时的轨迹。当任务为动态（如会合目标）时，分配决策不仅取决于哪个智能体最适合该任务，还取决于何时何地能到达该任务。本文提出了解决此问题的方法，该方法将用于轨迹优化的凸集图（GCS）与用于分布式任务分配的基于共识的捆绑算法（CBBA）相结合。在我们的方法中，GCS通过使用时间扩展（3D+时间）配置空间来找到通过动态环境的最优轨迹。同时，CBBA协调跨智能体的任务分配，使在移动环境中能够做出明智的决策。然后，我们将分配与规划相连接，使智能体能够在3D+时间配置空间中避免碰撞，并为任务完成提供准确的时间估计。我们在带有静态和动态任务的模拟杂乱环境中展示了我们方法的有效性。

## Abstract
Multi-agent task planning in cluttered, dynamic environments requires assigning tasks to agents while simultaneously determining safe, time-efficient trajectories through the environment. When tasks are dynamic, such as rendezvous objectives, allocation decisions depend not only on which agent is best suited for a task, but also on when and where that task can be reached. This paper presents a solution to this problem, which combines Graphs of Convex Sets (GCS) for trajectory optimization with the Consensus-Based Bundle Algorithm (CBBA) for distributed task allocation. In our approach, GCS finds optimal trajectories through dynamic environments using a time-extended (3D+time) configuration space. At the same time, CBBA coordinates task assignments across agents, enabling informed decision-making in a moving environment. We then connect allocation and planning to allow the agents to avoid collisions in the 3D+time configuration space and provide accurate time estimates for task completion. We demonstrate the effectiveness of our approach in simulated cluttered environments with static and dynamic tasks.

- **研究动机**：运动规划在任务分配中扮演关键角色。当环境中存在密集障碍物、狭窄通道以及时变因素时，任务的执行成本和可行性必须与分配方案精确耦合。已有的Consensus-Based Bundle Algorithm (CBBA) 通常使用简化的距离或时间模型进行投标，无法反映真实的轨迹约束；而Graphs of Convex Sets (GCS) 能高效求解最优轨迹但尚未与分布式任务分配深度集成。
- **整体含义**：本文提出将CBBA与空间-时间GCS (ST-GCS) 相结合，使投标过程直接基于轨迹优化结果，从而得到由轨迹可行性驱动的、更真实的分配方案，并支持动态任务（如移动会合点）。

## 2. 方法论：核心思想、关键技术细节
- **核心思想**：在CBBA的贪婪捆绑构建阶段，智能体评估候选任务插入时，不再使用几何距离或名义旅行时间作为投标值，而是求解对应的ST-GCS轨迹优化问题，将轨迹代价转化为路径得分，从而反映障碍物几何、动态障碍、速度限制和任务时序等真实约束。
- **关键技术细节**：
  - **ST-GCS (3D+time)**：将时间作为显式优化维度，每个轨迹点表示为四维状态 (x, y, z, τ)。运动约束包括最大速度 (Lorentz锥形式) 和因果性约束（时间严格递增）。轨迹使用Bézier曲线参数化，段内通过控制点约束确保证碰撞避免。
  - **任务建模**：静态任务通过固定区域约束表示；动态任务通过线性时变不等式 (A x_f ≤ b) 刻画，其中A矩阵包含任务速度分量，使得最终区域随时间移动。
  - **投标计算**：对于候选路径 p_i ⊕_k j，智能体求解各段ST-GCS，得出总代价 G，路径得分 S(p) = - Σ G（最小化代价）。若某段不可行，该路径得分为 -∞，从而不可行插入不会赢得投标。
  - **CBBA集成**：保持标准CBBA的贪婪构建和共识流程，但投标值 c_{ij} 由ST-GCS代价的最大边际改进决定。之前计算的段代价可缓存重用，减少重复求解。
- **算法流程**（文字说明）：
  1. 每个智能体独立进行贪婪捆绑构建：对每个未分配任务 j，尝试所有可插入位置 k，用ST-GCS计算候选路径得分与当前路径得分的差值（边际得分），取最大值作为投标 c_{ij}。
  2. 若 c_{ij} 超过智能体已知的当前胜出投标 y_{ij}，则该任务可被竞争。智能体选择使 c_{ij} h_{ij} 最大的任务加入捆绑，更新胜出信息和路径。
  3. 所有智能体完成后，进入共识阶段：交换投标和胜出者信息，通过冲突消解规则更新本地信息，重复直到收敛。
