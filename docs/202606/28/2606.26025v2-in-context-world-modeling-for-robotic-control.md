## 摘要
现代视觉-语言-动作（VLA）模型通常难以泛化到新的设置，例如改变相机视角或机器人形态，因为它们通常仅以当前观察和语言指令为条件。由于忽略了作为变量的底层系统配置，这些模型隐式假设了训练过程中遇到的固定执行上下文，从而需要对任何新环境进行数据密集型的微调。在这项工作中，我们引入了上下文世界建模（ICWM），一个将系统辨识视为上下文自适应问题的框架。ICWM使机器人策略能够从短历史的自生成、任务无关交互中自主推断关键系统变量。与使用示范来指定执行什么任务的传统上下文学习不同，ICWM利用上下文窗口来理解系统如何运行。通过在任务执行前处理这些交互，模型隐式捕捉当前系统的世界动态，从而无需参数更新即可适应新配置。在仿真和真实世界机器人平台上的大量实验表明，ICWM在新型相机视角上显著优于标准VLA基线。

## Abstract
Modern Vision-Language-Action (VLA) models often fail to generalize to novel setups, such as altered camera viewpoints or robot morphologies, because they are typically conditioned only on current observations and language instructions. By ignoring the underlying system configuration as a variable, these models implicitly assume a fixed execution context encountered during training, necessitating data-intensive fine-tuning for any new environment. In this work, we introduce In-Context World Modeling (ICWM), a framework that treats system identification as an in-context adaptation problem. ICWM enables robot policies to autonomously infer essential system variables from a short history of self-generated, task-agnostic interactions. Unlike traditional In-Context Learning that uses demonstrations to specify what task to perform, ICWM leverages the context window to understand how the system operates. By processing these interactions before task execution, the model implicitly captures the world dynamics of the current system, enabling adaptation to novel configurations without parameter updates. Extensive experiments in simulation and on real-world robot platforms demonstrate that ICWM significantly outperforms standard VLA baselines on novel camera viewpoints.

## 1. 核心问题与整体含义（研究动机和背景）

- 当前VLA模型（如RT-2、OpenVLA、π0等）的标准公式为 `πθ(at | ot, l)`，仅以当前观测和语言指令为条件，**隐式假设系统配置ψ（如相机视角、机器人形态、关节偏移等）在训练和部署中固定不变**。
- 当部署时配置发生偏移（如新相机角度、更改的连杆长度），模型无法自动恢复正确的观测-动作对应关系，性能严重下降。即便使用多视角训练，几何外推仍是一个开放挑战。
- 现有解决方案（如场景微调）需要人工干预和数据密集型重训练，违背通用部署目标。而现有的上下文学习方法仅将上下文作为“行为规范”（做什么），而非“系统辨识”（系统如何运行）。
- **本文核心洞察**：将泛化失败重新解释为**测试时的系统辨识问题**，并借鉴人类通过短暂随机探索建立内部世界模型的能力，提出ICWM框架，使VLA模型在无需参数更新和任务示范的情况下，通过自生成的、任务无关的交互上下文隐式推断当前系统动态，从而适应新配置。

## 2. 方法论：核心思想、关键技术细节

### 核心思想
- ICWM将系统辨识转换为**上下文适应问题**。在任务执行前，机器人执行一段简短、随机、任务无关的探索动作（self-probing），记录产生的视觉状态-动作-下一视觉状态三元组 `(o_s, a, o_e)`，将这些片段作为上下文前缀 `T`。
- 策略条件化变为 `πθ(at | Ψ(T), ot, l)`，其中 `Ψ(T)` 从交互历史中隐式恢复当前系统配置ψ的表示。这一过程完全隐式，不引入额外参数，也不依赖任何任务特定示范或奖励信号。

### 关键技术细节
1. **隐式世界建模**：利用Transformer的序列建模能力，在处理任务查询前先行处理交互上下文，使模型从视觉-动作对应中提取时不变因果结构（如控制映射、相机视角）。
2. **训练**：模型在多种系统配置下收集的数据上训练。每个训练样本前附加N个任务无关交互片段（从数据池中随机采样，确保多样性）。损失函数为标准的负对数似然 `L = -log πθ(at | Ψ(T), ot, l)`。通过这种构造，模型必须学会从不同配置下的上下文中提取动力学信息，隐式地学习配置推断。
3. **测试时推理**：分为两个阶段：
   - **主动探测阶段**：机器人在安全的工作空间内执行N个随机探测动作（例如采样随机目标位姿，进行固定步长移动），记录起止帧和动作。这些动作不接触任务物体，不破坏初始状态。
   - **上下文执行阶段**：将收集的探测片段作为前缀一次性输入模型，Transformer首先处理这些上下文以构建配置感知的隐藏状态，然后处理任务查询 `(ot, l)` 并输出动作。整个过程无需梯度更新。
4. **参数共享**：`Ψ` 与VLA主网络共享参数，无需额外参数化世界模型。
5. **动作表示**：使用FAST动作分词器，动作块大小为5。N=5上下文片段在实验中使用。

### 公式与算法（文字说明）
- 标准VLA：`πθ(at | ot, l)` → 隐式假设ψ固定。
- 理想策略：`π*_θ(at | ot, l, ψ)` → 需要显式ψ。
- ICWM：`πθ(at | Ψ(T), ot, l)`，其中T = 自生成的任务无关交互历史，Ψ隐式从T中恢复ψ。
- 训练时采用相同公式，只是T来自训练数据池；测试时T来自实时探测。
- 主动探测：随机采样N个目标位姿，执行动作ai，得到`(osi, ai, oei)`，形成T。

## 3. 实验设计

## 7. 优点

- **方法创新性**：将上下文学习从“行为规范”重新定义为“系统辨识”，利用最少的任务无关交互来隐式恢复系统动力学，这是之前工作未探索的视角。
- **实际高效**：无需参数更新、无需任务示范、无需外部标定，仅需几秒随机探索即可在线适应，极大降低部署成本。
- **框架通用性**：扩展性良好，不仅适用于视角变化，还适用于语义场景变化和机器人形态变化（运动学修改），表明学到了真正的动力学而非单一模式。
- **实验设计严谨**：通过消融、错误上下文、多次探测策略、t-SNE可视化等多维度验证了方法内部机制，排除了死记硬背或捷径学习的可能性。
- **实际可行性**：在真实UR5e平台上成功验证，且探测过程安全（不接触任务物体），延迟在可接受范围内。

## 8. 不足与局限

- **探测阶段需要物理交互**：虽然只有几秒（5-6秒），但在某些高风险环境或初始状态不可变动的情况下可能不适用。不过作者指出探测可一次完成并被复用。
- **困难视角性能仍有限**：在135°视角上所有方法均表现很差（OOD场景下ICWM仅2.2%），说明当视角导致严重遮挡或场景裁剪时，仅靠简短上下文可能不足。需要更鲁棒的感知或更长的上下文。
- **缺少与在线调整方法的直接比较**：如meta-learning、在线适应等（但作者指出这些方法需要任务奖励或梯度更新，设定不同）。
- **训练数据需要多配置**：ICWM假设训练数据覆盖多种系统配置（多视角、多变体），虽然可以通过数据增强或域随机化实现，但完全单一配置训练后无法直接执行ICWM（见6.1节训练必要性实验）。这限制了在完全不变化数据上的应用。
- **未测试大规模跨躯干泛化**：只测试了同一机器人不同视角和部分运动学变化（如垫片、连杆缩放），未验证到完全不同的机器人（如机械臂A到B）的零样本泛化。
- **统计报告不够细**：缺少多次随机种子的方差或置信区间，使得结果的可靠性判断受限于单次测试。真实实验每条件25次，尚可但略低。
- **探测策略选择未深度优化**：四种策略虽都有效，但没有系统地研究最优采样策略或所需上下文数量N的敏感度（仅使用N=5）。
- **对外部干扰的鲁棒性**：语义实验中仅测试了静态干扰物和纹理，未考虑动态干扰或其他场景变化（如光照、遮挡）。
