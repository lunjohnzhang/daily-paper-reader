## 摘要
双机器人协作能够完成单机器人无法触及的有效载荷任务，例如跨环境协作搬运物体和执行协调交接。数据获取是训练这些系统的主要瓶颈。为此，我们提出了DUET，一个用于移动操作的双机器人学习框架。为了实现高效的数据收集，我们创建了一个统一的双体同步虚拟现实遥操作系统，用于域内异构机器人数据收集。我们进一步开发了一个互补的跟踪管道，记录人-人协作和协作移动操作先验知识。为了实现高效学习，我们引入了一种基于动作分块变换器（Action Chunking Transformer）的架构，该架构首先在人-人高效演示上预训练协作策略，然后在最少的真实机器人遥操作轨迹上进行微调。我们开发了一个包含四个协作任务的基准测试，使用Unitree G1人形机器人和Dexmate Vega1移动操作器评估我们的框架。结果表明，利用人类先验知识不仅在任务性能上优于仅使用机器人数据训练的基线方法，而且减少了数据收集所需的总人力。我们的人类数据收集管道平均比遥操作快5.4倍，但在所有任务上，我们的表现与仅使用机器人数据训练的策略相当或更好。我们的项目页面位于https://zhaoy37.github.io/Duet/。

## Abstract
Dual-robot collaboration enables tasks that exceed the reach and payload of a single robot, such as collaboratively transporting objects across environments and executing coordinated handovers. Data acquisition is the primary bottleneck for training these systems. To this end, we introduce DUET, a dual-robot learning framework for mobile manipulation. For efficient data collection, we create a unified dual-embodiment synchronized VR-based teleoperation system for in-domain heterogeneous robot data collection. We further develop a complementary tracking pipeline that records human-human coordination and collaborative mobile manipulation priors. To allow efficient learning, we introduce an Action Chunking Transformer based architecture that first pretrains collaborative policies on efficient human-human demonstrations, before finetuning them on a minimal set of real-robot teleoperation trajectories. We develop a benchmark of four collaborative tasks to evaluate our framework using a Unitree G1 humanoid and a Dexmate Vega1 mobile manipulator. The results demonstrate that harnessing human priors not only yields superior task performance compared to baselines trained only on robot data, but also reduces the total human effort required for data collection. Our human data collection pipeline achieves 5.4x acceleration on average from teleoperation, but we perform equally or better than robot-only data trained policies across all tasks. Our project page is available at https://zhaoy37.github.io/Duet/.

## 1. 核心问题与整体含义

- **研究动机**：双机器人协作能完成单机器人无法胜任的任务（如搬运大件、协调手递手），但训练此类系统的主要瓶颈是数据获取——异构双机器人的演示采集通常需要复杂设置和大量人工操作。
- **整体目标**：提出一个高效的数据收集与学习框架，降低对昂贵机器人遥操作数据的依赖，利用廉价的人-人协作数据作为先验，实现双机器人视觉运动策略的有效学习。

## 2. 方法论

### 核心思想
通过两阶段训练结合两种数据源：第一阶段利用低成本、高效率的人-人协作演示（经3D姿态提取）预训练一个共享的视觉运动策略主干；第二阶段用少量的真实机器人遥操作轨迹对策略进行微调，弥合人-机器人之间的体态差异。

### 关键技术细节
- **双操作员VR遥操作系统**（Section 3.1）：
  - 两个操作员分别通过PICO VR头显和控制器控制异构机器人对（Unitree G1人形机器人 + Dexmate Vega1移动操作器）。
  - G1使用SONIC框架进行全身运动跟踪，Vega1使用通用运动重定向（GMR）和自定义底层控制（指数移动平均平滑）。
  - 异步日志（10 Hz），通过Chrony NTP服务器同步主机时钟实现离线对齐。
  - 视觉反馈：G1: RealSense 1920×1080 @30Hz；Vega1: ZED 2560×720 @30Hz。

- **人-人协作数据采集管道**（Section 3.2）：
  - 三台摄像机：每人一个头/颈部摄像机 + 一个主摄像机（固定第三视角）。
  - 使用YOLO检测人体，SAM 3D Body提取3D网格和关键点（mhr70格式）。
  - 深度校准：将SAM预测网格与主摄像机的深度流融合，通过两阶段鲁棒估计恢复公制尺度。
  - 提取9个3D关键点（27维/人）和骨盆速度，经掩码加权移动平均滤波。

- **集体训练架构**（Section 3.3）：
  - 基于Action Chunking Transformer（ACT）[11]，采用双头设计：位姿头（pose head）和关节空间头（joint head）。
  - 输入：每个智能体的历史自我中心RGB图像序列 + 姿态状态（57维，包含G1和Vega1各27维关键点以及Vega1移动基座速度3维）。
  - 共享的位姿空间：人类姿态重定中心到头部，机器人姿态转换成相对于头部链节的坐标。
  - 训练流程：
    - **阶段1**：仅在人-人数据上预训练整个网络（包括CVAE编码器和解码器），只激活位姿头。
    - **阶段2**：用机器人数据微调所有权重，关节空间头随机初始化后从头训练。
    - 推理时，CVAE编码器被绕过，潜变量设为0。

## 3. 实验设计

- **数据集/场景**：自建基准，包含四个协作任务，均在真实物理硬件上执行：
  - T1 垃圾收集（不对称时空协调，G1扫垃圾入Vega1动态持有的袋子）
  - T2 盒子整理（协作视觉+长时程，G1清理工作台，Vega1传递盒子并由G1纠正）
  - T3 板倾斜（协作操作+平衡，共同倾斜白板使物品滑入容器）
  - T4 玩偶传递（协调手递手，Vega1抓住玩偶传给G1）

- **硬件平台**：Unitree G1人形机器人 + Dexmate Vega1移动操作器（异构对）。

- **对比方法**：
  - **DUET**（60个人类演示 + 30条机器人轨迹）
  - **Robot-only (50)**：仅用50条机器人数据训练（无人类预训练）
  - **Robot-only (30)**：仅用30条机器人数据训练

  - 每个任务的标准化得分（0~1分），基于子任务完成度。
  - 成功率（所有子任务均完成的比例）。
  - 数据收集效率：平摊收集时间（AT，获取10条成功轨迹的平均耗时）。
  - 收集努力：E = N_H*AT_H + N_R*AT_R。

## 6. 主要结论与发现

1. **人类预训练提升性能**：DUET（60人类+30机器人）在四个任务上的成功率和平均得分均优于或等于仅用50条机器人数据训练的基线，尽管使用的机器人数据更少。
2. **数据收集效率显著提升**：人类演示的平摊收集时间平均比遥操作快5.4倍（228.4秒 vs 39.9-64.4秒）。
3. **减少总人力投入**：计算收集努力（E），DUET所需总时间明显少于50条机器人数据基线（例如T1: 200.95分钟 vs 268.42分钟）。
4. **零样本泛化能力**：在视觉和物理分布偏移（不同颜色的盒子、覆盖黑板）下，DUET仍能成功完成任务。

## 7. 优点

- **创新性**：首次将人-人协作先验用于双机器人学习，通过两阶段训练有效弥合体态差距。
- **实用性**：提供了完整的双机器人数据采集方案（VR遥操作+人体演示管道），开源数据集与代码（声明将发布）。
- **效率**：人类演示管道可快速规模化，避开机器人硬件瓶颈和认知负担。
- **模块化**：ACT架构可被其他骨干网络替代，框架具有通用性。
- **硬件无关性**：遥操作系统设计为硬件无关，支持热插拔不同机器人平台。

## 8. 不足与局限

- **模型探索有限**：仅测试了ACT一种架构，未尝试其他SOTA视觉运动策略（如Diffusion Policy、RT-2）。
- **体态与团队规模限制**：仅验证了一种异构对（G1+Vega1），未扩展到同构或更多机器人的场景。
- **实验样本量偏小**：每个条件仅10次试验，可能不足以证明统计显著性；缺乏重复训练稳定性分析。
- **OOD评估不充分**：仅做定性展示，无定量成功率或分数。
- **遥操作系统本身仍有改进空间**：依赖两个人类操作员同时工作，认知负荷仍较高；数据后处理（姿态提取、校准）存在误差传播风险。
- **数据采集中存在假设**：人类数据的速度缩放因子（1.5倍）和旋转矩阵固定设计可能限制迁移到新任务的方向变化。
