## 摘要
多智能体系统的模型预测覆盖控制运行在紧张的通信和计算预算下，这要求它在优化负载与对变化的空间优先级的响应能力之间取得平衡。在固定事件阈值下，更新率会随运行条件变化，使得规定的平均更新预算难以维持。我们提出阈值自适应的事件触发模型预测控制（MPC），它根据目标平均周期与最近事件间间隔之间的差成比例地在线调整阈值。我们证明了经验平均更新周期收敛到任意可行的规定目标，并建立了累积平均的依赖于初始化的单侧界。一个非线性基准示例说明了这些预算保证。然后，我们将该机制应用于覆盖MPC，使用一种能够捕捉机器人运动与空间重要性变化的任务感知统计量。在一个五智能体移动密度研究中，自适应策略平均使用204.7次全局MPC更新，目标为200，而使用相同统计量和初始阈值的固定阈值策略为266.7次。与更新次数完全匹配的周期性调度相比，它还降低了覆盖代价。这些结果表明了直接的平均预算调节以及MPC更新的有效任务相关调度。

## Abstract
Model predictive coverage control for multi-agent systems operates under tight communication and computation budgets, which requires it to balance the load of optimization against responsiveness to varying spatial priorities. With a fixed event threshold, the update rate varies with operating conditions, making a prescribed average update budget difficult to maintain. We propose threshold-adaptive event-triggered model predictive control (MPC), which adjusts the threshold online in proportion to the difference between the target average period and the latest inter-event interval. We prove convergence of the empirical average update period to any feasible prescribed target and establish initialization-dependent one-sided bounds on the cumulative average. A nonlinear benchmark illustrates these budget guarantees. We then apply the mechanism to coverage MPC using a task-aware statistic that captures robot motion and changes in spatial importance. In a five-agent moving-density study, the adaptive policy uses 204.7 global MPC updates on average against a target of 200, compared with 266.7 for a fixed-threshold policy using the same statistic and initial threshold. It also reduces coverage cost relative to periodic schedules with exactly matched update counts. These results demonstrate direct average-budget regulation and effective task-dependent scheduling of MPC updates.
