## 摘要
在多机器人操作中，一个动作的价值取决于队友如何响应。我们提出 CARE（协作动作—响应信念估计，Cooperative Action-Response Belief Estimation），一个从局部历史中学习团队响应信念的框架。一个预测性信念编码器对交互进行表征，并以标称动作为条件。匹配的反应式延续与重放延续将每个候选动作的直接优势与队友适应所贡献的效用分离开来。一个以候选动作为条件的读出模块与总优势一起学习该响应分布，校准后的选择则选择备选动作或保留标称动作。我们的分析刻画了响应何时会改变偏好动作，以及预测误差和来源误差如何限制可恢复的收益。在表示、候选提议和数据固定时，显式响应监督相比通过分支效用学习相同信息，能够改善候选排序并降低选择遗憾。这种收益集中在队友适应会改变偏好动作的决策上。在 RoboFactory、MARS Control Track 以及物理协作任务上，CARE 在评估的策略中取得了最高平均成功率，将能力较强的标称策略与选择性协调调整相结合。总之，这些结果表明 CARE 能将队友适应的预测转化为有效的去中心化动作选择。项目主页：https://jeong-zju.github.io/care/.

## Abstract
In multi-robot manipulation, an action's value depends on how teammates respond. We present \method{} (Cooperative Action--Response Belief Estimation), a framework for learning \emph{team-response beliefs} from local history. A predictive belief encoder represents the interaction and conditions a nominal action. Matched reactive and replay continuations separate each candidate's direct advantage from the utility contributed by teammate adaptation. A candidate-conditioned readout learns this response distribution alongside total advantage, and calibrated selection chooses an alternative or retains the nominal action. Our analysis characterizes when response changes the preferred action and how prediction and source errors limit the recoverable gain. With the representation, proposals, and data fixed, explicit response supervision improves candidate ranking and reduces selection regret relative to learning the same information through branch utilities. The benefit is concentrated in decisions where teammate adaptation changes the preferred action. Across RoboFactory, the MARS Control Track, and physical collaboration tasks, CARE achieves the highest average success among the evaluated policies, combining a capable nominal policy with selective coordination adjustments. Together, these results show that CARE turns predictions of teammate adaptation into effective decentralized action selection. Project page: https://jeong-zju.github.io/care/.
