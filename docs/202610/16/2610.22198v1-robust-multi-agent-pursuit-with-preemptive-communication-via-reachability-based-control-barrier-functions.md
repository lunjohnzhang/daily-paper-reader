## 摘要
安全的多智能体协调通常假设现实世界中部署的资源受限机器人无法提供的东西：连续、完美的状态共享。鲁棒控制策略必须辅以鲁棒的通信策略，才能实现韧性部署。在这项工作中，我们提出了一种统一的控制/通信策略，该策略提供安全控制以保证间歇通信下的智能体间安全，并在追逃场景中证明了其有效性。每个智能体根据最近接收到的状态信息计算相邻智能体的可达集，然后基于控制屏障函数求解安全控制输入，以确保智能体避免碰撞。我们证明，只要通信陈旧度保持有界，就能保证智能体间避免碰撞。随着状态传输之间可达集膨胀，每个智能体基于刻画不确定性风险和运动学风险的新指标，推断何时向相邻智能体抢占式发送其状态信息。我们实现并仿真了多种追逃场景，并表明与周期性和事件触发基线相比，抢占式通信将消息减少了77.5%，且碰撞为零。

## Abstract
Safe multi-agent coordination typically assumes what real-world, deployed, resource-constrained robots cannot provide: continuous, perfect state sharing. Robust control strategies must be complemented with robust communication strategies to deliver resilient deployments. In this work, we propose a unified control/communication strategy that provides safe control to guarantee inter-agent safety under intermittent communication and demonstrate its effectiveness in a pursuit-evasion scenario. Each agent computes the reachable set of neighboring agents based on the last state information received, then solves for a safe control input based on control barrier functions to ensure agents avoid collision. We prove that inter-agent collision avoidance is guaranteed provided communication staleness remains bounded. As the reachable set inflates between state transmissions, each agent reasons about when to preemptively transmit its state information to neighboring agents based on novel metrics characterizing uncertainty risk and kinematic risk. We implement and simulate a variety of pursuit-evasion scenarios and show that preemptive communication reduces messages by 77.5% compared to periodic and event-triggered baselines with zero collisions.

## 2. 方法论

### 2.1 系统建模与问题设定

- 系统包含 $n_p$ 个追捕者（Pursuer）与 $n_e$ 个逃逸者（Evader），在 $\mathbb{R}^3$ 中运动；状态 $x=[p^\top, v^\top]^\top$，动力学 $\dot{x}=[v^\top, u^\top]^\top$。
- 约束：$\|v_i\|\le v_{max}$，$\|u_i\|\le u_{max}$；逃逸者加速度有界。
- 每个追捕者 $i$ 维护对邻居 $j$ 的**最后接收状态** $\xi_{ji}$ 及其**陈旧度** $\tau_{ji}=t-t_{ji}$。
- 假设：追捕者-逃逸者配对固定且已知，由匈牙利算法（Hungarian algorithm）计算；通信为理想化的有向成对网络；设置**心跳机制**（heartbeat）限制最大通信间隔。

### 2.2 可达性分析（Reachability）

- 由于缺少邻居 $j$ 的连续状态，$i$ 对 $j$ 的当前状态做**过近似**预测：
  - $\hat{p}_j(t)=p_j(t_{ji})+v_j(t_{ji})\tau_{ji}$（刻意省略控制输入项以减小预测误差与可达集体积）
  - $\hat{v}_j(t)=v_j(t_{ji})$
- 以 $\hat{p}_j$ 为中心构造**球状可达集** $S_j(t)=\{q: \|q-\hat{p}_j(t)\|\le r(\tau_{ji})\}$，半径
  $$r(\tau_{ji})=\tfrac{1}{2}u_{max}\tau_{ji}^2$$
  即半径随陈旧度**二次增长**，收到新状态时归零。
- **引理 1（包含性）**：$p_j(t)\in S_j(t),\ \forall t\ge t_{ji}$（通过对加速度二次积分并用三角不等式证明误差上界恰为 $r$）。

### 2.3 基于可达性的控制屏障函数

- **硬约束——追捕者间安全**：$\|p_i-p_j\|\ge d_{safe}$。由于 $p_j$ 未知，用可达集与预测位置构造屏障函数
  $$h_{ij}(x_i,t)=\|p_i(t)-\hat{p}_j(t)\|^2-\tilde{r}_j(\tau_{ji})^2,\quad \tilde{r}=r+d_{safe}$$
  即要求 $i$ 位于 $j$ 的**膨胀球之外**至少 $d_{safe}$。
- **软约束——感知范围维持**：$\|p_i-p_{e_i}\|\le \kappa$，屏障函数 $h_{ie_i}=\kappa^2-\|p_i-p_{e_i}\|^2$，通过松弛变量 $\delta\ge0$ 与惩罚权重 $w_s\gg1$ **软性执行**，确保追捕者间安全优先于感知范围维持。
- **高阶 CBF（HOCBF）**：两个屏障函数相对阶均为 2，故引入辅助函数 $\psi$ 与 $\omega$：
  $$\omega_{ij}=\ddot{h}_{ij}+k_1\dot{h}_{ij}+k_0h_{ij}\ge0,\qquad \omega_{ie_i}=\ddot{h}_{ie_i}+k_3\dot{h}_{ie_i}+k_2h_{ie_i}\ge0$$
  其中 $k_0=a_0a_1,\ k_1=a_0+a_1$（及对应 $k_2,k_3$），并要求 $k_1^2>4k_0$、$k_3^2>4k_2$。
- **QP 控制器**：每个控制周期求解
  $$\min_{u_i,\delta\ge0}\ \|u_i-u_{i,nom}\|^2+w_s\delta^2\quad \text{s.t.}\ \omega_{ij}\ge0\ \forall j\ne i,\ \ \omega_{ie_i}+\delta\ge0,\ \ \|u_i\|\le u_{max}$$
  其中 $u_{i,nom}$ 指向所分配逃逸者。

### 2.4 安全性证明（定理 1）

- **Step 1–2**：由 $\dot\psi+a_1\psi\ge0$ 与 $\dot h+a_0h\ge0$ 的微分不等式积分，得 $\psi\ge\psi(0)e^{-a_1t}\ge0$、$h\ge h(0)e^{-a_0t}\ge0$。
- **Step 3**：由 $h_{ij}\ge0$ 得 $\|p_i-\hat{p}_j\|\ge\tilde r$，结合引理 1 的 $\|p_j-\hat{p}_j\|\le r$ 与三角不等式，得 $\|p_i-p_j\|\ge\tilde r-r=d_{safe}$。
- **Step 4–5**：在每个通信事件 $t_k$ 处 $\tau_{ji}=0$、$r(0)=0$、$\tilde r=d_{safe}$，预测误差为零，故 $h_{ij}(t_k)\ge0$ 成立；再由连续性对区间逐段归纳，最终 $\forall t\ge0$ 均满足 $\|p_i-p_j\|\ge d_{safe}$。
- **关键推论（Remark 1）**：安全性的前提是 QP（17）始终**可行**；而 $\tau$ 增大使可达集膨胀、控制权限缩小，威胁可行性。这正是需要抢占式通信的动机。

### 2.5 抢占式通信机制

- **触发准则**：追捕者 $i$ 在
  $$\rho_{ij}\ge P \quad\text{或}\quad \tau_{ij}\ge T$$
  时向 $j$ 发送状态。$P\in[0,1)$ 为风险阈值（越小越保守），$T$ 为心跳上限（保证陈旧度有限、可检测通信失效）。
- **综合风险评分**：$\rho_{ij}=1-(1-\rho_k)(1-\rho_u)$，即不确定性风险或运动学风险任一较高时，整体风险即升高。
- **不确定性风险**（衡量 $j$ 对 $i$ 的感知不确定度）：
  $$\rho_u=\frac{r_i(\tau_{ij})}{r_i(\tau_{ij})+d_{ij}}$$
  可达集半径相对预测间距越大，$\rho_u\to1$。
- **运动学风险**（衡量相对运动趋势）：
  $$\rho_k=1-\prod_{n\in\{d,v,u\}}(1-\beta_n\gamma_n),\quad \beta_n\in[0,1)$$
  其中邻近风险 $\gamma_d=1-\big(\frac{d_{ij}-d_{safe}}{d_{ij}}\big)^2$；速度接近风险 $\gamma_v=\max\big(0,-\frac{n_{ij}^\top v_{ij}}{2v_{max}}\big)$；控制输入接近风险 $\gamma_u=\max\big(0,-\frac{n_{ij}^\top u_{ij}}{2u_{max}}\big)$。权重满足 $\beta_d>\beta_v>\beta_u$，体现"当前邻近 > 预期轨迹"的重要性排序。
- **前提限制**：该策略假设**同构执行能力**；异构系统需按智能体各自的执行约束调整 $\gamma_v,\gamma_u$。

## 6. 主要结论与发现

- **通信效率**：抢占式策略在所有强制安全的策略中通信开销最低。
  - 相比 **Full**：每智能体每秒消息少 **29.03×**，总消息量减少 **96.5%**；
  - 相比 **Periodic 1 Hz**：总消息量减少 **64.1%**（消息率低 3.26×）；
  - 相比 **Periodic 5 Hz**：总消息量减少 **90.77%**（消息率低 10.96×）；
  - 相比 **Event Triggered**：消息率低 **4.78×**，总消息量减少 **79.43%**；
  - 相比周期与事件触发基线合计：**减少 77.5%**；相比全部基线合计：**减少 82.2%**。
- **安全性**：所有通信策略均实现**零智能体间碰撞**，验证了可达性 HOCBF-QP 控制器在信息大幅削减下仍具鲁棒安全保证；不通信时碰撞不可避免，且碰撞数随智能体密度上升（10 → 80 → 100）。
- **任务性能无损**：总捕获时间与各通信基线相差不到 1 秒，说明 82.2% 的通信削减**不带来显著任务代价**。
- **可扩展性**：Full/Periodic/Event-Triggered 的通信率随智能体数量增长而上升（受智能体对数量或自状态变化频率驱动），而抢占式机制的通信率由**态势风险**驱动，规模增长时表现更优。
- **通信分布特征**：消息并非均匀分布，而是**集中在碰撞风险高或邻居需要信息的时刻**，即通信被真正重构为安全机制。

## 7. 优点

- **统一设计视角**：将控制（可达性 HOCBF-QP）与通信（抢占式触发）纳入同一安全框架协同设计，而非分别优化，回应了"控制/通信割裂导致部署脆弱"的痛点。
- **触发逻辑的反转具有新意**：从"自状态阈值触发"转为"预测邻居是否需要信息"，配合**不确定性风险 + 运动学风险**双指标，使通信直接服务于安全保证的维持（QP 可行性）。
- **形式化保证扎实**：定理 1 通过微分不等式积分 + 三角不等式 + 通信事件处的归纳论证，
