# A Physics-Informed Collision Learning Framework for Collaborative Robot Motion Generation 

Chen Cai and Steven Liu 

Abstract —Close-proximity multi-arm manipulation requires collision models that are both geometrically accurate and differ-entiable enough for real-time optimization. Classical geometry checkers provide reliable distances but are difficult to use inside gradient-based model predictive control, while conservative proxy models can restrict tightly coupled motion. We present PI-UDF, a physics-informed unified differentiable framework for body-to-body collision distance prediction between articulated robots. PI-UDF combines analytical forward kinematics with learnable link-geometry embeddings and a shared residual network to predict pairwise inter-arm distances directly from robot configurations. To improve safety-critical fidelity, we combine quota-driven boundary mining with an asymmetric boundary-crossing penalty that emphasizes false-safe sign errors near the collision boundary. The learned distance field is integrated into nonlinear MPC as a differentiable inter-arm clearance term. We validate the framework on a real dual-Franka platform through high-speed close-proximity 14-DoF dual-arm swapping, sustained single-arm dynamic evasion, and dynamic-evasion planning configurations with frozen, predicted, and target-switching treatments of the moving arm. Hardware experiments and offline Drake/FCL replay show that PI-UDF provides a differentiable inter-arm clearance estimate suitable for closed-loop collision-aware col-laborative robot motion generation. 

Index Terms —Collaborative robots, collision avoidance, dif-ferentiable collision detection, model predictive control, motion planning, robot learning. 

I. INTRODUCTION Close-proximity multi-arm manipulation requires multiple robots to move through tight shared workspaces while main-taining continuous inter-arm clearance. Classical mesh-based checkers such as FCL [1] provide reliable geometry queries for offline validation, but their discrete and non-smooth computa-tions are difficult to embed in gradient-based model predictive control. Real-time controllers often replace full geometry with simplified convex proxies; for example, distributed MPC can approximate robot links by line segments and ellipsoids [2]. These proxies reduce computation, but their inflated clearances can restrict tightly coupled motion and cause deadlock-like behavior in dense workspaces [3]. Signed distance fields provide a continuous clearance signal and gradients that are useful for optimization-based collision avoidance. Neural SDF variants extend this idea to robot configuration spaces; for example, Neural-JSDF uses MLPs for joint-space distance fields [4], while Bernstein-polynomial representations improve storage efficiency [5]. For multi-arm planning, treating one moving arm as a set of query points for the other arm requires dense online point sampling or proxy-shape approximations. Both choices scale poorly with link complexity and weaken the geometry signal available to a closed-loop optimizer. What is needed is a compact, differentiable body-to-body distance model that reasons directly over robot configurations. PairwiseNet [6] is an important step toward direct link-pair distance learning. It decomposes the global collision problem into pairwise subproblems and conditions a shared regressor on pairwise relative transforms and point-cloud-derived shape descriptors, thereby avoiding dense online point sampling during planning. Our framework builds on this established pairwise relative-pose factorization and focuses its contribution on the co-design of geometry representation, boundary-focused supervision, and differentiable integration into downstream motion generation. Boundary-focused data acquisition has also been studied for high-DoF collision-distance learning. Kim and Park [7] itera-tively update a fixed-size configuration dataset with samples near the current model’s global collision boundary and use a redundant link- SE (3) n representation to improve distance learning. Their approach is model-in-the-loop: the learned collision boundary guides subsequent data generation. In con-trast, our retained-set construction is driven by ground-truth coverage deficits over link-pair classes and distance zones, rather than by the boundary of an intermediate model. Against this background, we propose the Physics-Informed Unified Differentiable Framework (PI-UDF), a compact frame-work for body-to-body collision distance learning between articulated robots. PI-UDF provides a differentiable collision-distance representation that can be queried by downstream motion-generation modules; in this work, we instantiate this interface within nonlinear MPC. The model conditions ashared residual regressor on FK-derived relative poses and task-optimized link embeddings learned end-to-end from signed-distance supervision. PI-UDF further combines pair-level boundary mining with an asymmetric Boundary-Crossing Penalty that emphasizes false-safe prediction errors. The contributions of this work are threefold:

B. Unified Dual-Stream Architecture 

To instantiate the pairwise regressor in Eq. (4), PI-UDF uses a unified dual-stream architecture, as shown in Fig. 2. The network input is composed of an explicit pose descriptor derived from the analytical relative transform Tij (q), and an implicit geometry descriptor obtained from learnable link-embedding tables. The two descriptors are fused by a shared residual regressor to predict the pairwise signed distance ˆdij .

Explicit pose stream. For each inter-arm link pair (i, j ), the relative pose Tij (q) ∈ SE (3) is already provided by Eq. (2). We convert it into a vector representation 

vpose = ϕ(Tij ) ∈ R12 ,

where ϕ(·) flattens the rotation matrix and translation vector of 

Tij . This descriptor exposes the relative spatial configuration of the two links directly to the network, instead of requiring the network to infer forward kinematics from joint angles. Because the predictor uses only Tij , it is invariant to a common rigid transformation applied to both links. 

Implicit geometry stream. The link geometries G1,i and 

G2,j are fixed for a given robot model and therefore need not be encoded from point clouds during inference. We represent them using robot-specific learnable embedding tables 

E(r) ∈ RLr ×m, r ∈ { 1, 2},

where Lr is the number of modeled links of robot r, and 

m = 32 in our implementation. For a query pair (i, j ), the geometry descriptors are obtained by table lookup: 

e1,i = E(1) [i], e2,j = E(2) [j],

and concatenated as 

vgeo = [ e1,i ; e2,j ] ∈ R2m.

These embedding rows are initialized randomly and optimized jointly with the distance regressor using the collision-distance supervision. Thus, the learned descriptors are not intended to reconstruct visual shape, but to encode geometry features that are useful for signed distance prediction. During inference, this geometry stream reduces to constant-time indexing. Identical robots may share the same embedding table, while heteroge-neous robot pairs can be represented by robot-specific tables without changing the shared regressor architecture. C. Safety-Aware Training Pipeline 

Representative neural collision-learning methods rely on broad configuration-space sampling [3], [6], while PairwiseNet additionally adopts a standard symmetric regression objective [6]. In a 14-DoF dual-arm system, however, contact and near-contact configurations occupy only a small, structured subset of the joint space. Uniform q-sampling therefore produces predominantly far-field data and severely underrepresents the boundary interactions most relevant to closed-loop safety. We refer to this imbalance as the Sparsity Trap .Model-in-the-loop active learning has previously addressed this sparsity by iteratively updating a fixed-size dataset with configurations sampled near the learned global collision boundary [7]. Our objective differs in two respects. First, PI-UDF is supervised on pairwise distances rather than a single global configuration-level label. Second, our mining rule is based on ground-truth coverage deficits over link-pair classes and distance zones, without repeatedly estimating and resampling around an intermediate model boundary. The imbalance is amplified at the link-pair level be-cause each configuration induces many d⋆ij labels: a globally safe configuration may contain informative near-field pairs, whereas a boundary configuration may contain only one or two critical pairs. PI-UDF therefore retains physically valid whole configurations while performing mining and supervision at the link-pair level. Its Safety-Aware Training Pipeline combines class-zone quota-driven active mining with an asymmetric boundary-crossing loss, reflecting that neither all samples nor all errors are equally important. 4

Uni-form sampling passively accepts most far-field configurations, whereas our active generator retains a candidate configuration only when its induced link-pair distances improve the coverage of underrepresented boundary regions. Specifically, candidate configurations are proposed in joint space and evaluated over the canonical inter-arm link-pair set P. Each pairwise query is assigned to one of four distance zones: 

W1 : d⋆ij ≤ 0 (penetration) ,W2 : 0 < d ⋆ij ≤ 5 cm (near-field) ,W3 : 5 cm < d ⋆ij ≤ 20 cm (mid-field) ,W4 : d⋆ij > 20 cm (far-field) .

For each link-pair class and each zone, we maintain a prescribed coverage quota. A candidate configuration is re-tained if at least one of its link-pair queries contributes to an underrepresented class-zone bucket; otherwise it is rejected. This converts the fixed configuration budget into a boundary-enriched set of pairwise supervision signals. In practice, higher priority is assigned to kinematically relevant and historically under-covered pairs, such as distal forearm, wrist, and end-effector interactions, because these pairs dominate close-proximity collaborative manipulation. Retaining a configuration preserves labels for all canonical inter-arm link pairs. Thus, a configuration accepted because one pair lies near contact also supplies mid- and far-field labels for the remaining pairs, preserving global calibration. Mini-batches are sampled from the resulting class-zone buckets, while Fig. 3 summarizes the retained set at the configuration level through D⋆(q).

A. Experimental Setup and Training Settings 

To rigorously evaluate the proposed framework, we structure our experiments to assess both system-level safety and the underlying architectural choices. 

1) Target System: As illustrated in Fig. 1(a), we evalu-ate PI-UDF on a fixed-cell dual-arm system consisting of two 7-DoF Franka Emika Panda arms with a fixed relative base placement (inter-base offset 1.16 m , opposing orienta-tions [0 , π ] rad). This setup matches the intended deployment scenario of many industrial collaborative workcells, where the robot bases are calibrated once and remain fixed during operation. This choice should be distinguished from the original goal of PairwiseNet [6], which targets generalized collision detec-tion across varying multi-arm layouts. Although the analytical relative transform already includes the robot-base placement, training across multiple layouts would be required to cover the resulting relative-pose distribution. Here we focus on the calibrated fixed-cell deployment. This fixed-cell setting allows us to evaluate whether a compact pairwise differentiable distance model can provide accurate near-boundary distances and gradients for downstream motion planning. 

2) Training Datasets: We compare uniform and active datasets under the same budget of 100 k retained dual-arm configurations. The uniform set follows the joint-space sam-pling used in our PairwiseNet reproduction, whereas the active set is constructed using the class-zone quota rule in Sec. II-C. B. Implementation and Baselines 1) Experimental Infrastructure: All data generation, train-ing, and evaluation procedures were executed on a stan-dard workstation equipped with an Intel Core i7-12700 CPU (2.10 GHz, 12 cores), 64 GB DDR4 RAM, and an NVIDIA GeForce RTX 5080 GPU. The proposed PI-UDF and all baseline models were implemented in PyTorch. For training, we generally utilize the Adam optimizer with a learning rate of 1 × 10 −4 and a batch size of 512 . Unless stated otherwise, BCP-trained variants use η = 5 .0, (λW1 , λ W2 , λ W3 , λ W4 ) = (1 .5, 1.0, 0.5, 0.1) , and balanced 4:4:4:4 zone sampling. 

2) Baseline Variants: We use PairwiseNet [6] as the primary pairwise-learning baseline. Because pretrained geometry-encoder weights were unavailable, we trained the point-cloud encoders for the same Franka link geometries using the authors’ public pipeline and froze them during subsequent distance-regressor training. All PairwiseNet results below therefore denote a budget-matched fixed-cell reproduction on the same fixed-base dual-Franka setup. We evaluate the following variants:

> •

3) Held-Out Static and Dynamic Test Sets: To rigorously evaluate the models’ worst-case safety performance and prac-tical reliability, we construct two distinct test domains. First, we generate a Static Safety-Critical Test Set via rejection sampling from an independently sampled dual-arm configurations not used during training. We filter randomly drawn dual-arm configurations to enforce a strict quota: 30% true collisions ( d ≤ 0), 50% near-collisions ( 0 < d ≤ 5 cm), and 20% safe states in terms of minimum inter-arm collision distance. The final static set comprises 2,000 accepted con-figurations (yielding 110,000 valid inter-arm link-pair evalua-tions), with ground-truth signed distances computed via Drake (FCL/GJK) [8]. Second, to assess temporal consistency, we define a Dy-namic Trajectory Test Set using a high-speed dual-arm ”swap-ping” motion. By continuously evaluating the raw predicted clearance ˆD(qt) against the Drake/FCL reference D⋆(qt), we rigorously benchmark their point-wise accuracy and robustness against prediction chattering. 

C. Comparative Evaluation on Held-Out Test Sets 

Building upon the held-out test sets defined previously, we benchmark the model performance across several metrics:  

> •

RMSE (cm): The root mean-squared error (RMSE) between the estimated and actual collision distances.  

> •

SC-MAE (cm): Safety-Critical Mean Absolute Error targets precision exclusively within the narrow near-field and collision zones ( d < 5 cm).  

> •

FNR (%): The False Negative Rate represents the fre-quency of predicting a physically colliding state ( d∗ ≤ 0)as safe ( d > 0).  

> •

AUC: Area Under the ROC Curve. Evaluates the over-all classification capability of distinguishing safe versus colliding states across all continuous thresholds. 

Evaluation on the Static Safety-Critical Test Set: Table I and Fig. 4 detail the models’ performance on the static test set, offering insights into the efficacy of our specific methodological contributions: 

Dataset Quality and Sparsity Trap: Under the reproduced uniform-data setting, PairwiseNet yields an FNR of 100% ,with its predicted density mass shifted erroneously into the false-safe positive region (Fig. 4). Retraining the same regres-sor on the active dataset reduces the FNR to 16 .47% , isolating the effect of boundary-oriented data coverage. 

Loss Formulation and Safety: When comparing models at an equal training budget of 50 epochs, PairwiseNet (Re-trained) and PI-UDF achieve highly comparable SC-MAE ( 2.38 cm vs. 

2.33 cm). This suggests that our enriched dataset levels the playing field for near-field precision. Yet, PI-UDF achieves a substantially lower FNR ( 6.83% vs. 16 .47% ). This safety advantage is consistent with the proposed Boundary-Crossing Penalty (BCP), which amplifies false-safe boundary errors, i.e., predicting positive clearance when the ground-truth pair is in contact or penetration. Compared with the symmetric loss used by the re-trained PairwiseNet regressor, BCP therefore reduces hazardous sign errors while preserving comparable near-field accuracy. 

Global Regression vs. Training Efficiency: Because BCP and the zone weights place less emphasis on far-field errors than on boundary errors, one might expect PI-UDF’s global RMSE to degrade. PI-UDF (50 ep) maintains a RMSE of 

3.32 cm, closely trailing the larger PairwiseNet trained for 

1.5× longer (75 ep, RMSE 3.08 cm). As observed in the far right of Fig. 4, PI-UDF still closely approximates the ground-truth density in the safe zone( d > 20 cm). This confirms that our framework attains competitive global regression and lowest FNR among the compared models, without requiring a massive pre-trained geometric encoder or exhaustive training cycles. 

Continuous Dynamic Trajectory Tracking: Static metrics alone cannot guarantee the temporal consistency required for closed-loop control. We evaluate continuous predictions during a high-speed swapping maneuver in Fig. 5. PI-UDF maintains a smooth, continuous prediction profile that tightly overlaps with the ground-truth collision trend across all spatial zones, exhibiting minimal error in near field. The PairwiseNet (Re-trained, 75 ep) baseline also demonstrates similar trend tracking. In contrast, while the modestly trained PairwiseNet (Re-trained, 50 ep) manages to capture the general motion trend, it exhibits noticeably larger predictive errors. 

End-to-End Architectural Efficiency: Table I further high-lights the computational benefit of the unified PI-UDF de-sign. PairwiseNet relies on a frozen point-cloud encoder with 0.81 M parameters in addition to its trainable regressor, whereas PI-UDF trains a compact 0.11 M parameter model end-to-end. Because the geometry representation is learned jointly with the distance regression objective and reused across all link pairs, PI-UDF avoids both online geometric encoding and link-specific expert networks. At the same 50-epoch train-ing budget, this compact model achieves a lower FNR than the re-trained PairwiseNet baseline while reducing training time from 138 min to 27.8 min.

1) Impact of Activation Function (SiLU vs. ReLU): For fixed link embeddings, a ReLU regressor is piecewise affine in its network input. After composition with the analytical FK map, activation-boundary crossings can still induce abrupt changes in the joint-space gradient ∇q ˆd. SiLU replaces this hard gating with a smooth transition. Such derivative regularity is relevant to methods based on repeated local linearization, including SLSQP [9] and iSAM2 [10], since abrupt gradient changes can reduce the fidelity of local models and quasi-Newton updates [11]. A smooth activation alone, however, does not guarantee solver convergence. We quantify this behavior using the model-level gradient roughness Rg in Eq. 8 along the fixed L4–L5 collision-crossing trajectory. Comparing the matched PI-UDF (ReLU) 

and PI-UDF (Base) variants, ReLU worsens RMSE from 

3.316 to 3.635 cm and FNR from 6.83% to 7.52% , while SC-MAE remains comparable. It also increases Rg from 

2.14 × 10 −3 to 9.83 × 10 −3 (4.6×). Fig. 6 shows the cor-responding staircase-like directional derivative and localized input-gradient spikes. We therefore use SiLU in the deployed model. ReLU’s zero derivative for negative pre-activations may also leave units persistently inactive [12]. SiLU avoids an identi-cally zero negative branch, providing a secondary motivation for signed-distance regression; our activation choice is based primarily on the matched empirical comparison above.

3) Training Strategy: Boundary Fine-Tuning and HNM: 

While PI-UDF (Base) establishes good accuracy-safety bal-ance, its collision-awareness can be further customized via targeted late-stage training interventions. Rather than changing the architecture or increasing the computational budget, these stage-wise strategies modify the data distribution or loss objective after the initial epochs. Crucially, the total training epochs remains strictly constant across all variants, ensuring that performance gains stem entirely from the intervention mechanisms rather than extended training time. As shown in Table II and Fig. 7, standard boundary fine-tuning (PI-UDF (FT) ) – achieved by shifting the batch sampling distribution heavily toward contact boundaries ( |d| <

5 cm) – improves both primary metrics, reducing RMSE to 

3.148 cm and FNR to 6.69% . Alternatively, Hard Negative Mining ( PI-UDF (HNM) ) alters the loss landscape by explic-itly up-weighting missed deep-collision configurations, i.e., false-safe predictions in penetration states. This heightened penalty further drives the FNR down to 6.37% , albeit intro-ducing a slight conservative bias that marginally increases the global RMSE to 3.298 cm. In summary, we present PI-UDF not merely as a static architecture, but as an adaptable framework. While the Base configuration serves as a strong default, the FT and HNM strategies demonstrate that practitioners can seamlessly steer the network in later epochs to satisfy specific deployment criteria. For instance, tasks demanding high spatial precision in tight clearances can leverage FT to maximize global accuracy, whereas highly safety-critical applications can employ HNM to enforce stronger collision conservatism and suppress false-safe predictions. 2) Real-Time-Oriented JIT-Compiled NMPC Implementa-tion: Solving the NMPC problem requires repeated evaluation of PI-UDF and its derivatives along the prediction horizon. Directly coupling deep-learning models with external nonlin-ear programming solvers can introduce callback latency, host-device transfer overhead, and Python Global Interpreter Lock (GIL) bottlenecks, which may limit the achievable planning frequency in closed-loop control [14]. To reduce these overheads, we port the trained PI-UDF model to a functional JAX implementation and express the for-ward kinematics, PI-UDF inference, soft-min collision aggre-gation, and L-BFGS-B optimization loop in a single JAX/XLA pipeline. The resulting end-to-end JIT-compiled computation graph enables automatic differentiation through the full NMPC objective and amortizes runtime overhead across repeated closed-loop solves [15], [16]. In hardware, the compiled planner is paired with a command interpolation layer that converts each optimized joint trajectory into high-rate references for the low-level robot controllers. A. Hardware Setup and Evaluation Protocol 

Building on the model evaluation and NMPC formulation of Secs. III–IV, we evaluate PI-UDF as a differentiable safety primitive for closed-loop dual-arm hardware control. All ex-periments are conducted on a dual Franka Emika Panda system with a fixed relative base placement; the two arms share a common workspace and therefore require continuous inter-arm collision reasoning during execution. We instantiate the controller in two forms: a centralized 14-DoF dual-arm NMPC for tightly coupled swapping, where both robots are optimized jointly, and a single-arm evasion NMPC, where R1 tracks a task target while avoiding R2. In the evasion tasks, R2 is treated as an externally generated moving body rather than a jointly optimized agent. Depending on the operating mode, future R2 samples are either supplied to the prediction horizon or R2 is frozen at its current pose. All hardware controllers run on a centralized workstation running Ubuntu 22.04 with PREEMPT-RT, equipped with an AMD Threadripper 3960X CPU and an NVIDIA RTX A5000 GPU. The high-speed dual-arm swapping controller uses a 200 ms planning period and passes the optimized joint trajectory through a 100 Hz command-interpolation interface, while the low-level Franka controllers run at 1 kHz . The dynamic-evasion controllers use a 100 ms planning period with the same 100 Hz interpolation interface. Solve-time variability is treated as an implementation diagnostic rather than a hard real-time guarantee. In all hardware experiments, PI-UDF is queried online to provide pairwise inter-arm distances and gradients. The NMPC objective uses the smooth aggregate eDα(q) from Eq. (9), whereas the plots and tables report the raw predicted minimum 

ˆD(q) defined in Eq. (5). The nominal operating threshold is set according to the con-trol architecture. Centralized dual-arm swapping uses dsafe =5 cm , since both arms are jointly optimized over a self-consistent 14-DoF horizon. Single-arm dynamic evasion uses the more conservative value dsafe = 10 cm , since only R1

is optimized while R2 is externally generated. In both cases, 

dsafe defines the operating clearance of the differentiable soft cost rather than a hard collision constraint. For post-hoc geometry validation, Drake/FCL [8] is eval-uated offline on the logged current configurations of both arms to obtain the reference D⋆(q); it is never queried by the online controller. In the dynamic-evasion mode study, future 

R2 samples affect only the NMPC prediction horizon and are not used in the reported per-time-step PI-UDF–Drake/FCL clearance comparisons. D. Dynamic-Evasion Operating Modes 

We finally evaluate the PI-UDF-NMPC framework under several real-time motion-planning configurations for dynamic evasion. The goal is not to isolate a single MPC design choice, but to test whether the learned differentiable distance field remains reliable when integrated with different horizon and task-target formulations. In particular, the moving R2 arm can be treated as a frozen obstacle in the horizon, predicted over the horizon using its scripted future trajectory, or combined with online target switching for R1 as the interaction region changes. These differences affect how the NMPC predicts and optimizes future motion; the clearance values reported in Table III and Fig. 10 are evaluated at the current logged system configurations. This work presented PI-UDF, a compact differentiable body-to-body clearance model that combines FK-derived rela-tive poses, task-optimized link embeddings, and safety-aware boundary learning. Model-level experiments showed compet-itive global accuracy, the lowest FNR among the compared models, and substantially lower training cost than the re-trained PairwiseNet baseline. Integrated into NMPC, PI-UDF supported high-speed close-proximity 14-DoF swapping and sustained dynamic evasion on real dual-Franka hardware. Offline Drake/FCL replay con-firmed the reported current-state clearance behavior. Future work will address uncertainty-aware motion prediction, solver robustness, and generalization across robot layouts and mor-phologies.
