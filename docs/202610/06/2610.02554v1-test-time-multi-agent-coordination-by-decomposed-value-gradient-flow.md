## 摘要
离线多智能体强化学习（MARL）面临一个长期存在的权衡。具有表现力的生成式策略能够表示数据中的多模态协调，但无法区分高价值区域；而价值优化策略利用学习到的 Q 函数，却将多模态坍缩为单一主导模态。单个智能体的模态坍缩会破坏联合协调，而各智能体同时漂移则可能将联合策略推向动作空间中的未见区域。我们提出通过最优统一传输实现可扩展协调（SCOUT），这是首个通过测试时动作细化将生成式基础模型与学习到的价值函数相结合的离线 MARL 框架。SCOUT 训练两个解耦组件：流匹配行为先验和分解价值函数。在测试时，它通过 Stein 变分梯度下降将行为样本输运至高价值区域。传输步数控制自适应测试时扩展，取代固定的正则化系数。在个体-全局-最大（IGM）原则下，我们证明联合软价值差距的一个单项 KL 界，该界随传输收敛而消失，并带有与 IGM 违背程度成正比且不可约的加性残差。在实证中，SCOUT 在离散和连续离线 MARL 基准上取得最佳平均性能，并在所有离线到在线配置中带来性能提升。

## Abstract
Offline multi-agent reinforcement learning (MARL) faces a persistent trade-off. Expressive generative policies can represent multi-modal coordination in the data, but cannot distinguish high-value regions, while value-optimized policies exploit the learned Q-function but collapse the multi-modal into a single dominant mode. A single agent's mode collapse can break joint coordination, and simultaneous drift across agents can push the joint policy into unseen regions of the action space. We propose scalable coordination via optimal unified transport (SCOUT), the first offline MARL framework to combine a generative foundation model with a learned value function through test-time action refinement. SCOUT trains two decoupled components: a flow-matching behavioral prior and a decomposed value function. At test-time, it transports behavioral samples toward high-value regions via Stein variational gradient descent. The number of transport steps controls adaptive test-time scaling, replacing a fixed regularization coefficient. Under the individual-global-max (IGM) principle, we prove a single-term KL bound on the joint soft-value gap that vanishes as transport converges, with an irreducible additive residual proportional to the IGM violation. Empirically, SCOUT achieves the best average performance across discrete and continuous offline MARL benchmarks and yields performance improvements in all offline-to-online configurations.

## 2. 方法论
- **核心思想**：不显式参数化用于值最大化的策略，而是把行为策略作为基础先验，在测试时对采样动作进行细化；细化步数 \(L\) 取代固定正则化系数，成为自适应测试时缩放预算。
- **训练两个解耦组件**：
  - **流匹配行为先验**：每个智能体学习速度场 \(v_{w_i}\)，沿线性路径 \(x_t=(1-t)x_0+t a_i\) 拟合行为分布，损失为 \(\|v_{w_i}(t,o_i,x_t)-(a_i-x_0)\|^2\)。推理时用 Euler 积分生成候选动作。
  - **分解值函数**：采用加性 VDN 式分解 \(Q_{\text{tot}}(o,a)=\sum_i Q_{\theta_i}(o_i,a_i)\)，满足 IGM 原则；TD 目标中的下一状态动作通过 refinement 得到，使每个智能体的梯度继承联合信用信号。
- **测试时动作 refinement**：
  - 每个智能体从行为流策略采样 \(P\) 个动作粒子。
  - 使用 Stein 变分梯度下降（SVGD）进行 \(L\) 步输运，更新包含两项：
    - 核平滑值梯度项：\(\frac{1}{\alpha}k(a_j,a)\nabla_{a_j}Q_i\)，推动粒子走向高 \(Q_i\) 区域。
    - 排斥项：\(\nabla_{a_j}k(a_j,a)\)，防止粒子坍缩，保留多模态。
  - 核函数为 RBF，带宽用中位数自适应；更新后做 clip。
  - 离散动作空间在 logit 空间进行 refinement，对 softmax 加权 Q 值自动微分。
  - 最后每个智能体选择最高 \(Q_i\) 的粒子执行。
- **测试时缩放**：
  - \(L=0\)：退化为从行为策略采样并 best-of-P 选择。
  - \(L=L_{\text{train}}\)：匹配训练条件。
  - \(L>L_{\text{train}}\)：当 Q 函数泛化良好时，可额外提升协调强度。
- **理论分析**：
  - 假设全局 Q 可分解为 \(Q_{\text{tot}}=\sum_i Q_i+\Delta\)，且 \(\|\Delta\|_\infty\le\delta\)。
  - 定理 4.2 给出软值差距上界：  
    \(0\le J_{\text{soft}}(\pi^*_{\text{joint}})-J_{\text{soft}}(\tilde\pi_L)\le \alpha \mathrm{KL}(\tilde\pi_L\|\prod_i\pi_i^*)+4\delta\)。  
    其中 KL 输运误差随 \(L\to\infty\) 在理想 SVGD 下消失，\(4\delta\) 来自 IGM 违背。
  - 命题 4.3 表明，分解输运近似联合 best-of-P；当 \(\Delta=0\) 时每智能体选择联合最优，当 \(\|\Delta\|_\infty\le\delta\) 时差距不超过 \(2\delta\)。
