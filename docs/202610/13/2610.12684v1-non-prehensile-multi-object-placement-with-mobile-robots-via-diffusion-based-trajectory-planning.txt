# Non-Prehensile Multi-Object Placement with Mobile Robots via Diffusion-Based Trajectory Planning 

Lance Pharand 1, Megnath Ramesh, Mark Chiu, Yash Vardhan Pant, Stephen L. Smith 

Abstract — Non-prehensile manipulation with mobile robots has primarily targeted placement in coarse goal regions. Precision placement has been studied with manipulators on benchmarks such as Push-T, where an omnidirectional end effector can readily re-approach an object from any side. For a mobile robot, correcting the same placement errors may require wide repositioning maneuvers around the object. We formalize multi-object pushing with a mobile robot as a multi-target assignment problem at tight tolerances. We propose a diffusion planner with a causal factorization: each robot denoising step is followed by an object step conditioned on the current clean robot estimate. This factorization allows us to sample multiple object outcomes for a single robot plan, capturing the multi-modality of pushing. We also design a set of pushing-specific costs for mobile robots, used for both guidance and best-of-

N sampling at inference. On Push-T, our planner attains the highest success rate of the methods we compare, while having the lowest rate of implausible object motion. Across three multi-box pushing environments resembling warehouse scenarios, it raises the fraction of boxes placed by 21 .5 percentage points over an unguided baseline, and replans 1.8× faster than a planner that denoises the two trajectories together. Lastly, we deploy the guided planner on a TurtleBot 3 Burger with object shapes absent from the training data, where it places 85 .0% of objects within tolerance against Diffusion Policy’s 37 .5% .

I. I NTRODUCTION 

In this work, we focus on the problem of multi-object pushing with a mobile robot. Formally, this is a multi-target assignment problem, where each object must be placed inside a tight target configuration (Fig. 1). Successfully solving this problem would make mobile robots viable for warehouse tasks where they must push boxes or pallets to precise positions for downstream automation to take over. Precision pushing has been studied in the manipulator setting, where Push-T [1], [2] is a popular benchmark [3], [4]. Here, a robot with a circular end-effector must push a T-shaped block onto a goal pose, with success requiring near-complete overlap. In contrast, existing non-prehensile manipulation (NPM) work with mobile robots [5], [6], [7] only requires the object to land inside a target zone much larger than the object itself. Two properties of the mobile robot setting make pushing an object to within a small tolerance of a target harder than it is in the manipulator setting. First, mobile robots typically have non-holonomic dynamics and cannot move

sideways. Second, the robot’s contact face is typically a non-prehensile bumper fixed to the front, so changing the side of the object being pushed requires a wide reposition. Both aspects make it difficult to perform the small corrections needed to bring an object within a tight tolerance of its target. In contrast, the end effector in Push-T can move sideways, is omnidirectional, and can re-approach the object from any side. Planners and policies for the studied setting must account for the difficulty of these corrections, but existing mobile robot NPM methods are evaluated in settings where this is not necessary. Diffusion-based planners have shown promise in solving difficult pushing problems [3], [4]. Diffusion planners that predict object motion typically denoise the robot and object trajectories simultaneously [8], which can yield object mo-tion that is implausible given the robot’s actions. We instead factorize the joint trajectory distribution into a robot trajec-tory prior and an object trajectory conditional. Each robot denoising step is followed by an object step conditioned on the current clean robot estimate (Fig. 2). As a result, guidance can be evaluated on a predicted object outcome that is a response to the current robot plan, and its gradient is backpropagated through that response to improve the robot plan. The Causal factorization also lets us sample several object outcomes for a single robot plan, which is beneficial as pushing is multimodal [9]. Our main contributions are: 1) We formulate and evaluate multi-object placement by a mobile robot under tight spatial tolerances, requiring each object’s footprint to lie within its target region and previously completed placements to remain undisturbed. We assess how placement tolerance affects execution success across multiple environments. 2) We propose a diffusion-based planner that uses a Causal arXiv:2610.12684v1 [cs.RO] 8 Oct 2026 factorization of trajectory denoising for non-prehensile pushing. With this, each robot denoising step is followed by an object step that is conditioned on the current clean robot estimate. We also propose a guidance formulation for this factorization, together with a set of differentiable cost terms tailored to mobile robot pushing. In this work, our evaluation spans the Push-T task, three unseen mobile robot pushing environments, and a hardware deployment on a TurtleBot 3 Burger, with analysis of the planner’s capabilities and limitations. 

A. Related Works a) Diffusion models for planning: Diffusion-based tra-jectory planners have been applied to both short and long-horizon tasks, both of which arise in NPM. At short horizons, the planner samples a trajectory, executes a portion of it, and then replans [1], [3]. Long horizon settings instead tend to rely on trajectory stitching, where a full plan is com-posed from sub-trajectories already present in the training distribution [8], [10]. Closest to our proposed factorization is MBA [11], which also splits robot and object denoising into two phases. However, MBA fully denoises the object trajectory first and conditions the robot denoising on that finished prediction, whereas our phases alternate within each denoising step. Diffusion Forcing [12] also orders denoising, but through per-token noise levels rather than separate phases, resolving lower-noise tokens first. Unlike our method, most of these planners do not apply guidance at inference, which can limit their ability to adapt to task settings outside their training distribution at deployment. 

b) Guidance in diffusion models: Guidance is applied to diffusion models across many domains such as image generation [13], [14], [15], autonomous driving, and robotics. Diffuser [16] steers plans by nudging the denoising process along the gradient of a learned return predictor. However, the performance of this learned model on novel scenes is dependent on its training distribution. Diffusion-ES [17] skips gradient-based guidance entirely. Instead, it samples trajectories from an unconditional diffusion model, scores them with a reward function, and projects elites back onto the data manifold. This keeps the trajectory distribution broader and improves robustness, but the search across iterations is expensive. Diffusion Planner [18] is a transformer-based driving planner that relies on hand-designed energy functions at inference, eliminating the need for an auxiliary model. Our work builds upon this concept in two ways. First, we extend these energy functions to have asymmetric penalties for precision pushing tasks. Second, we add a per-term gradient rescaling that lets each term’s contribution be tuned independent of its native scale and units. 

c) Pushing tasks: Diffusion-based trajectory planners have been applied to pushing in non-precision settings, beyond just Push-T. CompDiffuser [8] reports encouraging results on AntSoccer, where a quadruped agent pushes a ball to a goal location, and HeRD [7] demonstrates similar gains in a multi-object box environment. Precision has instead been pursued through reinforcement learning by [19], who train a recurrent policy that pushes single objects to within 1 cm of the goal. To the best of our knowledge, no diffusion-based planner targets multi-object NPM with a mobile robot at tight tolerances. II. P RELIMINARIES

B. Gradient-based guidance: DPS 

Test time guidance steers a trained diffusion model toward samples consistent with an auxiliary signal y without retrain-ing. Following [16], [18], let y ∈ { 0, 1} be an indicator variable with likelihood p(y=1 | x0) ∝ e−C (x0), where 

C(x0) is a cost associated with x0. The reverse process should then sample from the conditional p(xt | y) rather than the unconditional prior. The corresponding posterior score decomposes by Bayes’ rule as ∇xt log p(xt | y) = 

∇xt log p(xt) + ∇xt log p(y | xt). The first term is the prior score, given by the trained ϵθ (Sec. II-A). The second is the guidance term, which is intractable because y depends on the clean x0 rather than the noised xt. We therefore require an approximation of the guidance term to estimate the posterior score. For this, we use diffusion posterior sampling (DPS) [25] which can directly estimate the guidance expectation 

Ex0∼p(x0|xt)[p(y | x0)] . DPS replaces it with the point estimate p(y | ˆx0(xt)) by evaluating at the Tweedie posterior mean (Eq. (1)). As a result, the guidance term becomes 

∇xt log p(y | ˆx0(xt)) , which is tractable. III. P ROBLEM FORMULATION

B. Goal-conditioned guidance 

For mobile robot pushing tasks, we train the planners to imitate expert demonstrations that avoid both overshooting placement and poor pushing approaches. Despite this, the planner still overshoots at inference, as the denoising objec-tive never penalizes it (Sec. V-B). To penalize overshoots, we design a cost function C over predicted trajectories. It is composed of multiple terms (Sec. IV-D), each penalizing a distinct undesirable outcome in pushing such as overshoot, collision, or a poor initial approach. A key property of the Causal design is the chain in Eq. 2, where the gradient of the guidance function is allowed to flow back to the noisy robot trajectory. The result is more successful placements (Sec. V).

In this section, we evaluate the Causal planner against baselines on non-prehensile tasks, starting with Push-T in simulation. We then run simulated and real-world multi-object pushing experiments with a mobile robot, applying the cost terms of Sec. IV-D in both guidance and best-of-N

A. Push-T Experiments a) Task and Data: In Push-T [1][2], the objective is to align the gray T-block to a green goal region by pushing with a blue cylindrical end effector (see Table II). In the simulation experiments, the cylindrical pusher has a 2D state, while the block state is represented by eight keypoints, each with a 2D state. No image information is used as condi-tioning, and the goal pose is identical in every episode. The success criteria is defined as the T-block achieving at least 95% intersection-over-union (IoU) within 300 environment steps. We refer to the IoU value as coverage throughout this work. The pusht keypoints dataset from Hugging Face was used for training our models. 

b) Metrics: SR denotes success rate, with Wilson 95% confidence intervals shown below each entry. Max and Final are the mean per-episode maximum and terminal coverage, aggregated over all episodes regardless of success. Steps is the mean number of environment steps to completion, computed on successful episodes only, since failures always exhaust the 300 -step cap. The Motion Fidelity metrics are new to the Push-T setting. Contact consistency (CC) mea-sures how often a predicted block trajectory moves despite the pusher not touching it. A step is contact-free if the pusher-to-block surface distance exceeds a small distance threshold, and is violated if the block’s mean per-keypoint displacement over that step exceeds 2 distance units. Object-motion error (OME) is the ℓ2 distance between the predicted and actual block-centroid displacement at the end of each executed action chunk. 

c) Baselines and ablation design: Because the Causal factorization is designed to predict object motion, we first evaluate with best-of-N sampling, selecting the robot tra-jectory whose predicted object trajectory ends closest to the goal. This defers Diffusion Policy [1] to Sec. V-B, since it denoises only the robot trajectory. We instead use Diffusion Forcing [12], which denoises both trajectories and emphasizes causality. We implement its transformer variant, moving the per-token noise schedule from the temporal axis to our two trajectories. Each object token is held at a noise level no lower than the robot tokens, so the object is never resolved ahead of the robot motion producing it.

Bumping it afterward would be unsafe and stall the pipeline, so we end the trial as soon as any placed box is disturbed. Boxes are 8 cm per side, and each target is the box footprint inflated by a tolerance δ ∈ { 4, 2} cm. Training data consists of roughly 500 human teleoperation episodes at δ = 2

cm, with any episode that bumped a placed box discarded. We evaluate the planners on three environments that share structural elements with the training data, but never appear in their exact configurations. We use the TSP planner to assign boxes to subtasks throughout the experiments. Lastly, all diffusion models are only given a local ego-centric crop when it comes to info on nearby objects. 

b) Metrics: Our primary success metric is the Box Placement Fraction , or BPF. It records the average fraction of boxes placed within their target configurations across all episodes. We prefer this fractional measure over binary episode success because trials end the instant any placed box is disturbed, a rule that mirrors the real-world requirement that each box remain at its target after placement. Binary success would collapse 7 of 8 placed and 0 of 8 placed into the same zero, while BPF preserves credit for place-ments completed before the failure. e) Latency: The Causal factorization uses two decoder passes per denoising step, so the DDIM reduction makes the two methods match at 100 decoder passes per replan. However, when averaged across environments and toler-ances, Causal Best-of-16 replans in 2812 ms against Joint’s 

5088 ms, a 1.8× reduction. Two mechanisms produce this gap. Causal skips object denoising on non-pushing replans (i.e., navigation), so 49% of its replans use only 50 decoder passes and cost 1812 ms, rather than the 3776 ms a replan costs when it denoises an object as well. Both methods run 100 decoder passes on a replan that requires denoising an object, but not the same passes. The first pass of each Causal denoising step runs over the robot trajectory alone. As a result, this pass skips the spatial self-attention block and halves the query length of the cross-attention blocks. In contrast, every Joint denoising step runs on both trajectories, so Joint never gets a cheaper pass. Causal’s two passes per denoising step cost 75 ms against Joint’s 51 ms, but it wins on total replan cost by running half as many steps. 

f) Guidance versus conditioning: This is an important comparison, and it is reported in Table III, where guidance (Causal w/ MC DPS) gives an 8.1-point BPF gain on average and up to 18.8 points over Diffusion Policy, an unguided baseline. All models condition on scene occupancy, placed boxes, goal pose, and push direction via cross-attention, and train only on demonstrations in which no box was overshot. Yet, the unguided planners still overshoot, and we demonstrate this in a plan-only test. In each of 50 Pallet Staging episodes, we pause at the last replan step that still determines the first box placement, draw 50 plans from that identical state, and record the predicted along-axis placement error e∥ at the end of the horizon. Despite no overshooting trajectory in training, 3.6% of the 2500 unguided plans land more than 1 cm past the goal and 0.64% more than 2 cm. At identical state and initial noise, guidance drops these to 

2.6% and 0.20% , respectively. 

g) OOD Robot Demo: We recreate a portion of the Cross-Dock Staging environment from Table III and deploy the Causal w/ MC DPS model without fine-tuning it (Fig. 1). i) Limitations and Future Work: Our hardware demon-stration relies on an overhead camera tracking AprilTags on the robot and each box, which supplies the global pose estimates that the planner conditions on. An onboard camera deployment is not a drop-in replacement. During a push, the box occludes the goal tag on the floor, so the robot loses sight of the goal precisely when the stopping decision must be made. Closing this gap is the goal of future work. In addition, the binary success rates are low across Table III, ranging from 7% to 37% for Causal Best-of-16. Full task success requires placing every box within tolerance without disturbing any earlier placement, and a trial is considered a failure the instant one is disturbed. The difficulty also com-pounds with each placement, as every box placed narrows the c-space for the robot. VI. C ONCLUSION 

We formalized multi-object pushing as a multi-target assignment problem for a mobile robot, and proposed a diffusion-based planner with a Causal factorization: each robot denoising step is followed by an object step condi-tioned on the current clean robot estimate. This makes the predicted object motion a response to the robot plan, and exposes the object trajectory as a conditional that we can sample repeatedly. On Push-T, our model attains the highest success rate, 10 .7 percentage points over the closest baseline, while having the lowest rate of implausible object motion. Across three new multi-box pushing environments, Causal best-of-16 lifts placement by 21 .5 BPF points on average and up to 30 .9 over an unguided baseline, while matching a joint denoiser on placement performance and replanning 1.8×

faster. Lastly, on a TurtleBot 3 Burger, our guided Causal planner places 85 .0% of objects with geometries absent from training, against 37 .5% for Diffusion Policy. REFERENCES [1] C. Chi, Z. Xu, S.
