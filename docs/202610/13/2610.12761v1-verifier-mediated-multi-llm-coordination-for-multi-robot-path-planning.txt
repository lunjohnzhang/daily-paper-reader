Abstract — Foundation models are increasingly used for high-level multi-robot task planning, yet independently generated symbolic plans can become jointly infeasible after geometric grounding because of shared spatial and temporal constraints. We study execution-aware coordination of large-language-model (LLM) planners for multi-robot navigation. We compare a centralized architecture, in which one LLM jointly reasons over the robot team, with a decentralized multi-LLM architec-ture in which each robot independently proposes a task plan. A geometric verifier grounds the candidate plans into robot trajectories, detects predicted inter-robot conflicts, and converts conflict information into structured feedback for targeted re-planning. This verifier-mediated architecture separates seman-tic task reasoning from execution-level feasibility while enabling iterative coordination among LLM planners. Experiments in CARLA and on Crazyflie aerial robots evaluate coordination performance as task complexity increases and characterize the trade-offs between centralized reasoning, decentralized verifier-mediated coordination, and physical executability. 

Index Terms— Large language models, multi-robot systems, multi-agent planning, decentralized coordination, foundation models, robot navigation, path planning 

I. I NTRODUCTION 

Foundation models provide a flexible interface for seman-tic reasoning, task decomposition, and high-level planning in robotic systems. In multi-robot settings, however, a plan that is individually meaningful for each robot may still be jointly infeasible after geometric grounding. Independently generated routes can intersect in space and time, violate shared workspace constraints, or create execution conflicts that are not apparent at the symbolic planning level. These failures motivate an execution-aware coordination mech-anism between foundation-model reasoning and physical robot motion. A key architectural question is whether multi-robot foundation-model planning should be centralized or decentralized. A centralized planner can reason over the com-plete team state and generate coordinated plans jointly, but its context and decision space grow with team and task complex-ity. In contrast, decentralized planners provide modularity and local reasoning, but they require an explicit coordination mechanism to resolve conflicts between independently gener-ated plans. Recent multi-robot LLM frameworks coordinate robot teams through centralized or decentralized symbolic reasoning and inter-agent communication [1], [2]. However, such symbolic coordination does not by itself ensure that the resulting plans remain physically feasible after geometric grounding. This work studies verifier-mediated multi-LLM coordi-nation . Each robot-level LLM proposes a symbolic task plan, which is grounded into an executable trajectory by a geometric planning layer. A shared execution-level verifier evaluates the grounded trajectories for obstacle and inter-robot conflicts. When a conflict is predicted, the verifier converts the failure into structured feedback —including the affected agents, conflict location, and conflict time—and returns this information to the appropriate LLM planner for targeted replanning. This creates a closed coordination loop between foundation-model reasoning and robot execution without requiring unrestricted natural-language negotiation. The framework is illustrated in Fig. 1. III. M ULTI -R OBOT EVALUATION 

A. CARLA Experiments 

We first evaluate the proposed centralized and decen-tralized multi-LLM planning architectures in CARLA [3] using a structured road-network graph (shown in Fig. 2). We evaluate two environment representations: raw coordinate descriptions and a neighbor-list representation. In the raw-coordinate representation, the environment is provided to the LLM through the serialized geometric positions of the graph nodes. In the neighbor-list representation, each node vi ∈ V 

is instead described by its adjacent nodes, N (vi) = {vj :(vi, v j ) ∈ E} , thereby explicitly encoding the admissible graph connectivity. We consider a two-agent multi-target navigation problem. Each agent begins at an assigned start node, visits all designated target points in any order, and returns to its start node. The agents share the road network and must avoid inter-agent conflicts during execution. To evaluate increasing task complexity, we consider target sets of size |W| ∈ { 2, 5, 9} nodes. We compare centralized and decentralized planning under the same task conditions. In the centralized architecture, a single LLM jointly generates plans for both agents. In the decentralized architecture, each robot is assigned an indepen-dent LLM planner that reasons over its own task and tentative trajectory. Coordination is achieved through iterative verifier-mediated replanning as described in Section II. At the end of each planning iteration, the agents exchange their tentative paths, which are evaluated by a prediction-based collision checker using a time-indexed distance criterion (cf. (4)). If an inter-agent conflict is detected, the predicted conflict location and time index are communicated to the corresponding LLM, which replans its trajectory while the other agent retains its current plan (cf. (5)). This process is repeated until no predicted inter-agent conflict is detected. Performance is evaluated using three primary metrics: (i) expected success time, defined as the average planning time over successful trials; (ii) expected successful path length, defined as the average path length over successful trials; and (iii) expected planning time, defined as the average planning time over all trials. For decentralized planning, the reported planning time is averaged across the two LLM planners. Fig. 3 highlights the trade-off between centralized and de-centralized LLM coordination as task complexity increases. For smaller target sets, centralized planning incurs lower planning overhead, whereas the performance gap narrows for larger target sets as decentralized planning benefits from its modular structure. The results also show that the environ-ment representation matters: neighbor-list inputs consistently produce graph-valid routes with path lengths comparable to centralized planning, while raw-coordinate inputs provide greater geometric flexibility but are more susceptible to invalid waypoint generation. 

B. Insights from CARLA Experiments 

The CARLA experiments reveal several system-level trade-offs in foundation-model-based multi-robot planning. First, centralized planning is computationally efficient for the two-agent tasks considered here because a single LLM reasons jointly over the complete multi-agent state and can account for inter-agent interactions during plan generation. In contrast, decentralized planning introduces additional communication and replanning overhead through verifier-mediated coordination. As task complexity increases, how-ever, the performance gap between the two architectures becomes smaller, suggesting that the additional coordination overhead of decentralized planning is partially offset by its modular planning structure. Second, the environment representation provided to the LLM has a significant effect on planning reliability. The neighbor-list representation consistently produces graph-valid feasible routes with similar path lengths across the two planning architectures, whereas coordinate-based de-scriptions occasionally produce shorter trajectories but are more susceptible to invalid or out-of-map waypoints. This illustrates a trade-off between geometric flexibility and sym-bolic validity. Finally, collision-free task completion became more dif-ficult as the number of target points increased, consistent with longer trajectories, larger waypoint-ordering spaces, and more frequent inter-agent conflicts. These factors also increase the difficulty of resolving conflicts through iterative replanning, highlighting the importance of explicit execution-level feasibility checking. 

C. Crazyflie Cross-Platform Evaluation 

We next evaluate whether the planning–verification– execution interface transfers from ground vehicles to aerial robots through both Crazyflie [4] simulation and physical hardware experiments. In simulation, two quadrotors are assigned distinct navigation tasks, and the same central-ized/decentralized planning architectures are used to gen-erate trajectories satisfying the verifier’s predicted inter-agent separation criterion. The geometric verifier evaluates synchronized inter-agent distances and triggers replanning when a predicted conflict is detected. On physical hardware, we deploy the same symbolic-to-geometric planning pipeline for obstacle-aware navigation of a single Crazyflie. D. Insights from Crazyflie Experiments 

The Crazyflie experiments provide complementary evi-dence of both multi-robot coordination and cross-platform transfer. In simulation, the verifier-mediated architecture enables two independently tasked quadrotors to coordinate through trajectory-level conflict checking and replanning, demonstrating that the proposed interface is not specific to the CARLA road-network setting. The physical experiments further show that the same symbolic-to-geometric planning and feasibility pipeline can be deployed on real aerial hard-ware despite tracking errors, actuator dynamics, localiza-tion uncertainty, and external disturbances. Together, these results highlight the modularity of separating foundation-model reasoning from execution-level feasibility evaluation: the high-level planning architecture can be retained across robot embodiments while the geometric grounding and exe-cution layers are adapted to the underlying platform. In the present implementation, the verifier operates as an execution-level feasibility checker for predicted trajectory conflicts; extending this interface with uncertainty-aware or formally certified safety mechanisms provides a natural direction for future work. IV. C ONCLUSION 

We presented a verifier-mediated architecture for coordi-nating foundation-model planners in multi-robot navigation. The approach separates high-level semantic reasoning from execution-level feasibility: centralized or decentralized LLM planners propose robot-level task plans, while a geomet-ric verifier evaluates the grounded trajectories and returns structured conflict information for targeted replanning. This formulation provides a concrete interface between decentral-ized foundation-model reasoning and execution-aware multi-robot coordination. CARLA experiments study coordina-tion performance under increasing task complexity, while Crazyflie experiments demonstrate transfer of the planning– verification–execution interface to aerial robot navigation. Ongoing work includes extending the framework to larger robot teams, richer communication policies, uncertainty-aware verification, and multi-robot hardware deployment. ACKNOWLEDGMENT
