## 摘要
在无信号交叉口协调自主车辆仍然是多智能体强化学习（MARL）系统面临的关键挑战，这些系统通常难以处理组合动作空间、依赖于特权信息或采用刚性的智能体设计。我们提出了主智能体原型计划系统（MAPS），这是一种分层深度强化学习（DRL）架构，其中集中式主智能体生成一个紧凑的连续嵌入，称为原型计划，用于编码全局协调策略。分散的工作智能体将该嵌入与局部观测相结合，执行车辆特定的控制，将策略意图与战术执行解耦，并使得每个模块能够独立优化。作为对这种协调机制的概念验证评估，我们在HighwayEnv中的72种交叉口配置下测试了MAPS。MAPS实现了无碰撞导航，同时显著降低了平均旅行时间，优于现有最先进的基线方法。学习到的原型计划还表现出强大的泛化能力：一个使用三个智能体训练的系统在零样本部署到五个智能体场景时达到了94%的成功率，证实了基于原型计划的分层学习为多车辆协调提供了有前景的框架。

## Abstract
Coordinating autonomous vehicles at unsignalized intersections remains a critical challenge for multi-agent reinforcement learning (MARL) systems, which typically struggle with combinatorial action spaces, reliance on privileged information, or rigid agent designs. We propose Master-Agent Proto-plan System (MAPS), a hierarchical deep reinforcement learning (DRL) architecture in which a centralized Master agent generates a compact, continuous embedding, denoted as proto-plan, that encodes a global coordination strategy. Decentralized Worker agents integrate this embedding with local observations to execute vehicle-specific control, decoupling strategic intent from tactical execution and enabling independent optimization of each module.   As a proof-of-concept evaluation of this coordination mechanism, we test MAPS across 72 intersection configurations in HighwayEnv. MAPS achieves collision-free navigation while significantly reducing average travel time, outperforming state-of-the-art baselines. The learned proto-plans further exhibit robust generalization: a system trained with three agents achieves a 94% success rate when deployed zero-shot to five-agent scenarios, confirming that proto-plan-based hierarchical learning provides a promising framework for multi-vehicle coordination.

## 2. 方法论：核心思想、关键技术细节

### 核心思想
- **分层控制**：集中式Master agent观测全局交通状态，生成一个d维连续嵌入向量（proto-plan）；分散式Worker agent各自结合proto-plan与本地观测，选择车辆特定动作。
- **解耦协调与控制**：Master负责策略意图，Worker负责战术执行，双方可独立优化。
- **CTDE范式**：集中训练（Master拥有全局信息），分散执行（Worker仅依赖本地观测+proto-plan）。

### 关键技术细节
- **状态空间**：
  - Master状态：所有车辆的坐标和速度拼接（4N维），固定最大Nmax，不足时零填充。
  - Worker状态：自身4维运动学 + d维proto-plan（d=4）。
- **动作空间**：
  - Master连续动作：输出d维proto-plan（tanh激活，值域[-1,1]）。
  - Worker离散动作：{加速，减速}，目标速度改变±5 m/s，底层控制器执行。
- **奖励设计**：
  - Worker奖励：成功穿越（+50），碰撞（-300），每步惩罚（-5）。碰撞惩罚远大于成功奖励和步罚，体现安全优先。
  - Master奖励：取所有未到达车辆Worker奖励的最小值（最大化最差个体），防止牺牲个别车辆。
- **网络架构**：Woker用4层全连接（64,32,16,8），Master用3层（128,256,128），输出tanh生成proto-plan。所有Worker共享参数。
- **训练算法**：Proximal Policy Optimization (PPO)。采用“交替冻结”训练：首个周期联合更新，后续周期交替冻结Master或Worker，减少非平稳性。
- **增量训练泛化**：Master输入层固定为Nmax=5，训练分两阶段：阶段1用1个学习agent训练，阶段2增加至3个agent继续训练，然后零样本测试5个agent。

### 训练流程（算法1简述）
1. 初始化Master和Worker策略，rollout缓冲区。
2. 循环多个周期：每个周期内执行多次episode收集经验，根据周期奇偶性决定更新Master或Worker（首周期联合更新）。
3. 评估时去除探索噪声，确定性执行。

## 3. 实验设计

### 数据集/场景

- **场景**：18个基础场景，每个旋转4个朝向（0°,90°,180°,270°），共72种不同交叉口配置。场景设计保证可解且非平凡（存在冲突轨迹）。
- **车辆配置**：每episode 5辆车，其中3辆由MAPS学习agent控制，2辆匀速背景车（20 m/s）。初始位置距交叉口0~75 m，初速20 m/s。

## 7. 优点

- **新颖架构**：用连续潜在嵌入（proto-plan）替代离散命令，避免动作空间组合爆炸，通信开销恒定O(d)。
- **解耦设计**：主智能体吸收协调复杂度，Worker保持智能体数量无关，支持零样本泛化。
- **无特权信息**：仅需位置、速度等基本运动学状态，不依赖未来轨迹或专家演示。
- **消融深入**：系统验证了proto-plan的必要性、嵌入维度敏感性和可解释性（PCA空间分离安全/危险状态）。
