## 摘要
开放智能体系统（OASYS）在现实世界中日益普遍，其中智能体集合和任务集合随时间不可预测地变化。这种开放性，包括智能体开放性（AO）和任务开放性（TO），对通常假设固定状态和动作空间的多智能体强化学习（MARL）构成了根本性挑战。现有方法仅部分解决了开放性问题：填充和掩码方法引入了人为边界，而最近的基于图或超图的方法处理了一个维度的开放性，但仍依赖于限制性假设。在本文中，我们引入了面向智能体与任务开放性的指针学习器（PLATO），这是一种基于指针网络的actor与集中式图神经网络（GNN）critic相结合的方法，在集中训练与分散执行范式下使用多智能体近端策略优化进行训练。我们的基于指针的actor直接在当前任务集上输出分布。这直接支持了变化动作空间，无需掩码或重新训练。我们的GNN critic将智能体-任务交互编码为一个随任务和智能体构成而改变形状的图。这些组件共同考虑了AO和TO，且不受现有方法的有界性限制。我们在任务与智能体开放马尔可夫博弈（TaAgO-MG）中形式化了PLATO，扩展了先前的任务开放公式，并证明了其在由此产生的无界状态和动作空间上是良定义的。我们使用开放智能体系统评估方法倡议（MOASEI）的野火抑制领域评估PLATO，这是一个为开放多智能体系统评估而设计的环境，我们展示了强劲的性能以及比OASYS中最先进的基线更一致的零样本泛化能力。

## Abstract
Open agent systems (OASYS) are increasingly prevalent in real-world domains where the sets of agents and tasks change unpredictably over time. Such openness, including agent openness (AO) and task openness (TO), poses a fundamental challenge to multi-agent reinforcement learning (MARL), which typically assumes fixed state and action spaces. Existing methods address openness only partially: padding and masking approaches introduce artificial bounds, while recent graph-based or hypergraph methods handle one dimension of openness but still depend on restrictive assumptions. In this paper, we introduce Pointer Learner for Agent and Task Openness (PLATO), a pointer-network-based actor combined with a centralized graph neural network (GNN) critic, trained with multi-agent proximal policy optimization under a centralized training and decentralized execution paradigm. Our pointer-based actor outputs distributions directly over the current task set. This directly supports changing action spaces without masking or retraining. Our GNN critic encodes agent-task interactions as a graph that changes shape with task and agent composition. Together, these components consider AO and TO without the boundedness of existing approaches. We formalize PLATO in a Task-and-Agent-Open Markov Game (TaAgO-MG), extending prior task-open formulations, and prove it is well-defined over the resulting unbounded state and action spaces. We evaluate PLATO with the Methods for Open Agent Systems Evaluation Initiative (MOASEI) wildfire suppression domain, an environment designed for open multi-agent system evaluation, and we demonstrate strong performance and more consistent zero-shot generalization than state-of-the-art baselines in OASYS.

- **问题背景**：开放智能体系统（OASYS）中，智能体集合（Agent Openness, AO）和任务集合（Task Openness, TO）会动态变化（如智能体加入/离开、任务出现/消失），而传统多智能体强化学习（MARL）方法通常假设固定状态和动作空间，无法直接处理这种开放特性。
- **现有方法局限**：填充（padding）和掩码（masking）方法引入人工边界；图/超图方法虽能处理部分开放性，但仍依赖固定边界假设或仅处理单一维度（如MOHITO仅处理TO，DGN/DICG隐含限制）。
- **研究目标**：提出一种能同时联合处理AO和TO、且不依赖固定边界或重新训练的MARL算法，保证在无界状态-动作空间上良定义，并实现高效的零样本泛化。

## 2. 论文提出的方法论

- **核心思想**：利用**指针网络**（Pointer Network）机制，使actor的策略输出直接基于当前任务集合进行“内容指向”，而非固定索引分类；结合**图神经网络（GNN）** critic将开放全局状态建模为动态二部图，实现集中训练分散执行（CTDE）。
- **关键技术细节**：
  - **指针Actor（Pointer Actor）**：
    - 预处理：将智能体观测分解为智能体特征矩阵和任务特征矩阵。
    - 智能体编码：对当前智能体集合计算统计量（均值、方差、最小值、最大值）得到定长向量，经MLP生成**查询向量（query）**。
    - 任务编码：对每个任务独立编码得到**键向量（key）**，再加上一个NO-OP键。
    - 指针解码：利用加性注意力计算查询与每个键的兼容性得分，经softmax输出当前任务集上的概率分布（支持动态变化）。关键性质：置换不变性（Lemma 1）。
  - **GNN Critic**：
    - 将全局状态建模为**二部图 G_t = ⟨X_t, N_t, E_t⟩**，其中节点分别表示任务和智能体，边表示可能的交互（智能体-任务之间）。
    - 使用GCN进行消息传递（2层+跳跃连接），平均池化聚合节点信息，最后通过MLP输出状态价值 V(s)。
    - 支持动态变化的节点数量，无需固定尺寸输入。
  - **训练**：使用MAPPO（Multi-Agent PPO）框架，critic集中训练，actor分散执行。损失函数为PPO裁剪目标+价值回归损失，优势估计采用GAE。训练复杂度 O(|N_t|² + |N_t||X_t|)（Theorem 2）。
  - **形式化模型**：提出**TaAgO-MG**（Task-and-Agent-Open Markov Game），扩展TaO-MG，包含生成器Ψ处理智能集合和任务集合的动态变化。并证明PLATO在无界空间上是良定义的（Theorem 1）和置换不变的。

## 3. 实验设计

- **领域与环境**：使用MOASEI（Methods for Open Agent Systems Evaluation Initiative）中的**野火抑制（Wildfire Suppression）** 领域。网格大小包括 2×3、3×3、4×4。
- **四种开放性设置（Setup S0–S3）**：
  - S0：封闭基线（无火灾蔓延，无随机点火，无限灭火剂）。
  - S1：仅内生TO（火灾蔓延概率0.6，灭火剂补给成功率1.0）。
  - S2：仅外生TO（随机点火概率0.6，补给成功率0.8）。
  - S3：联合AO+TO（蔓延+点火各0.6，补给成功率0.6，部分智能体初始灭火剂不均）。
- **对比基线**：
  - **智能基线**：DGN、DICG、MOHITO（分别代表图卷积、隐式协调图、超图方法）。
  - **启发式基线**：NOOP（始终选择无动作）、Random（均匀随机选择）、Weakest（优先扑灭最小火灾）、Strongest（优先扑灭最大火灾）。
- **评估指标**：
  - 性能：**Episode Return**（平均累计回报）。
  - 效率：**Reward per Fight**（每次扑灭动作的平均奖励）。
  - 辅助指标：NOOP%（空闲率）、Burnouts（火灾自燃次数）、Putouts（扑灭次数）。
- **零样本泛化测试**：将在小网格（2×3）上训练的策略直接部署到更大网格（3×3、4×4）；将在3×3上训练的策略部署到4×4和5×5上测试，评估未见过构型下的泛化能力。

- **实验规模**：涵盖了3种网格尺寸、4种开放性设置、8种方法（3种智能基线+4种启发式+PLATO），以及零样本泛化（2个训练源×3个目标网格）。此外进行了**消融实验**（4种PLATO变体：MLP/LSTM编码器 × 加性/点积注意力），在每个设置和网格上均报告150个评估episode（50个种子×3个检查点）。

## 6. 论文的主要结论与发现

- **主要结果**：
  - PLATO在联合开放设置（S2、S3）下，在3×3和4×4网格上获得**统计显著的最高Episode Return**，在小网格2×3上S1-S3也显著领先。
  - 在Reward per Fight指标上，PLATO在多数开放设置下显著优于基线（如4×4 S2、S3）。
  - 零样本泛化：PLATO在从2×3迁移至3×3/4×4，以及从3×3迁移至5×5时，在S1-S3上表现**最一致且最强**，而MOHITO在强开放性下表现崩溃（负回报），DGN/DICG泛化能力不稳定。
- **消融分析**：
  - LSTM+加性注意力组合在**联合AO+TO的零样本泛化**（S3）下显著优于其他变体。
  - MLP+点积注意力在简单封闭零样本（S0）下更好。
  - 没有一种编码器或计分器在所有设置上绝对占优，两者存在交互。
- **理论保证**：证明了PLATO的actor和critic在无界智能体-任务空间上置换不变且良定义。
