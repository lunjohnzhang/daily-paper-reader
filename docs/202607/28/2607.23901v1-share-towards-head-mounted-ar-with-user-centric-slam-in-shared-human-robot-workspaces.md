## 摘要
在共享物理空间中，使用增强现实（AR）界面的人机协作（HRC）依赖于同步定位与地图构建（SLAM）。现有的多智能体SLAM系统依赖于边缘服务器来整合多个资源受限智能体的视觉观测结果，执行计算，并调度对其局部地图的更新。然而，边缘服务器对所有智能体一视同仁，忽略了异构HRC智能体（机器人和头戴式AR用户）根本不同的延迟需求。这种统一的资源分配通常导致用户操作的高延迟，因为它无法满足AR的严格延迟要求。在这项工作中，我们设计、实现并评估了SHARE，一个以用户为中心的SLAM系统，它在保持机器人精确跟踪性能的同时，战略性地优先考虑AR用户体验。SHARE为HRC智能体构建了首个此类体验模型，并自适应地调整传输优先级以匹配该模型。为了减少端到端延迟，SHARE利用共享人机工作空间中智能体获取的视觉特征的冗余性，来减少边缘处理带来的计算时间。在商业AR头显和地面机器人上的实际部署实现了AR用户平均13.22毫秒的延迟（相比基线降低43.3%），同时保持亚厘米级的跟踪精度。用户研究进一步揭示了用户感知方面的统计显著改善。

## Abstract
Human-Robot Collaboration (HRC) in shared physical spaces using Augmented Reality (AR) interfaces is powered by Simultaneous Localization and Mapping (SLAM). Existing multi-agent SLAM systems rely on an edge server to combine visual findings of multiple resource-constrained agents, perform computation, and schedule updates to their local maps. However, the edge treats all agents uniformly and ignores the fundamentally different latency requirements of heterogeneous HRC agents: robots and head-mounted AR users. This uniform resource allocation often results in high lag for user manipulation, as it does not meet the stringent latency requirements of AR. In this work, we design, implement, and evaluate SHARE, a user-centric SLAM system that strategically prioritizes AR user experience while maintaining accurate tracking performance for robots. SHARE builds a first-of-its-kind experience model for HRC agents and adaptively adjusts transmission priorities to match it. To reduce end-to-end latency, SHARE leverages the redundancy of visual features acquired by agents in shared human-robot workspaces to reduce computation time induced by edge-based processing. Real-world deployment with commercial AR headsets and a ground robot achieves 13.22 ms average latency for AR users (43.3% reduction from baseline) while maintaining sub-2-centimeter tracking accuracy. User studies further reveal statistically significant improvements in user perception.

## 1. 核心问题与整体含义（研究动机和背景）

在共享物理空间中使用增强现实（AR）界面的人机协作（HRC）场景中，多智能体同步定位与地图构建（SLAM）系统是实现空间感知的基础。现有系统通常依赖边缘服务器协调多个资源受限的智能体（如机器人、AR头显）的视觉信息，但存在一个关键瓶颈：**边缘服务器对所有智能体一视同仁，忽略了异构HRC智能体（AR用户 vs 机器人）根本不同的延迟需求**。AR应用对延迟极其敏感（通常要求运动到光子延迟低于20 ms），而机器人控制可容忍数百毫秒的延迟。统一资源分配导致AR用户操作出现高延迟，严重损害用户体验。因此，本文研究如何降低AR-HRC场景下多智能体SLAM的延迟，同时保持良好跟踪精度。

## 2. 方法论：核心思想、关键技术细节

### 2.1 核心思想
提出 **SHARE** 系统：一个以用户为中心的SLAM系统，通过差异化策略优先保证AR用户的低延迟，同时利用机器人较高延迟容忍度的特性，并借助共享环境中视觉特征的冗余性减少计算开销。

### 2.2 关键技术细节

1. **代理特异性QoE建模**：为不同代理（AR用户和机器人）建立差异化质量体验模型。QoE定义为延迟和准确率的函数，但参数因代理类型而异：
   - AR服务：以延迟为中心，惩罚项为 \(P_i = d - d_0\)（\(d_0=20\) ms），边际贡献为准确率 \(Q_i = a\)。
   - 机器人服务：以准确率为中心，惩罚项为 \(P_i = a_0 - a\)（\(a_0=1\) cm），边际贡献为延迟的倒数 \(Q_i = (d + \theta_i)^{-1}\)。
   公式：\(QoE_i = e^{-\beta_i P_i} \cdot (1 - e^{-\gamma_i Q_i})\)。

2. **基于深度神经网络的SLAM误差实时估计**：由于无法实时获得地面真值轨迹，设计轻量级MobileNetV2架构，结合图像特征、点空间分布（PSD）矩阵和8维标量特征，预测每帧定位误差。训练使用pySLAM + SenseTime视觉SLAM数据集离线生成标签。

3. **PID调度管道**：将每个代理的QoE偏差作为误差信号，使用比例-积分-微分控制器动态调整帧传输率，以平衡即时QoE需求、补偿持续性能缺陷并预测未来需求。参数通过网格搜索确定（\(K_p=0.8, K_i=0.15, K_d=0.2\)）。

4. **视觉重叠计算与冗余合并消除**：利用各代理的6自由度位姿（仅约200字节）计算视锥重叠体积，采用点采样近似IoU。当重叠体积高时，以概率形式跳过冗余地图合并请求（仅合并信息最丰富的时刻），平均减少43.72%的合并操作。

整体系统结构：前端（代理侧）含DNN评估、本地跟踪；后端（边缘服务器）含QoE建模、PID调度、视觉重叠分析和全局地图后端（基于COVINS-G）。

## 6. 主要结论与发现

- SHARE在实地研究中实现AR用户平均延迟13.22 ms（比COVINS-G降低43.3%），低于20 ms阈值；机器人延迟约25 ms，仍可接受。

- 地图合并减少43.72%，几乎不影响精度。
- PID调度优于线性帧丢弃：更低延迟和更好精度。
- 用户研究中，SHARE在可预测性、响应性、可达性上均最优，65%参与者首选SHARE，无人将其选为最差。
- 统计检验显著（\(p<0.005\)）。
