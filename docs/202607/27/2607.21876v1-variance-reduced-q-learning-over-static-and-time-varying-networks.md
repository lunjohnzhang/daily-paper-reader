## 摘要
我们研究了一个涉及多个智能体的分布式强化学习问题，这些智能体与同一马尔可夫决策过程（MDP）进行交互。智能体可以通过网络交换信息，共同学习最优状态-动作价值函数。针对这一设定，我们提出了一种新颖的基于epoch的分布式Q学习算法，称为VRDQ，在每个epoch内，智能体局部估计贝尔曼最优性算子，并使用基于共识的协议扩散信息。对于静态和时变网络，我们建立了VRDQ的高概率有限时间收敛速率，该速率通过协作实现了线性加速。关键的是，我们证明样本复杂度中的这种加速仅需要̃O(1)的通信，大大优于先前工作中的通信成本。

## Abstract
We investigate a decentralized reinforcement learning problem involving multiple agents that interact with the same Markov Decision Process (MDP). The agents can exchange information over a network to collectively learn the optimal state-action value function. For this setting, we introduce a novel epoch-based distributed $Q$-learning algorithm called VRDQ, where within each epoch, agents locally estimate the Bellman optimality operator and diffuse information using a consensus-based protocol. For both static and time-varying networks, we establish high-probability finite-time convergence rates for VRDQ that enjoy linear speedups from collaboration. Crucially, we prove that such speedups in sample-complexity require only $\tilde{O}(1)$ communication, substantially improving upon the communication costs in prior work.

### 2. 方法论：核心思想、关键技术细节、算法流程
- **核心思想**：采用**epoch-based方差缩减**与**扩散（diffusion）** 相结合。
  - 智能体不再每个时间步都更新Q表，而是在每个epoch内收集H个样本，局部估计Bellman最优性算子（通过经验转移概率和平均奖励），获得低方差估计。
  - 在epoch的前L步并行执行平均共识（consensus）协议，扩散上一epoch的更新方向；其余时间用于采样估计。这种解耦使得估计误差与网络扩散误差可以独立分析。
- **关键技术细节**：
  - 在每个epoch k，每个智能体i收集H个独立样本，构造经验转移概率 \(\hat{P}_{i,k}\)，进而得到低方差Bellman算子估计 \(\hat{T}_{i,k}\)。
  - 初始化扩散变量 \(d_{i,k}^{(0)} = \hat{T}_{i,k-1} Q_{i,k}\)（\(Q_{i,k}\)为epoch k开始时的Q估计）。
  - 执行L步共识：\(d_{i,k}^{(\ell+1)} = \sum_{j\in N_i} W_{ij} d_{j,k}^{(\ell)}\)。
  - 更新Q估计：\(Q_{i,k+1} = (1-\alpha) Q_{i,k} + \alpha d_{i,k}^{(L)}\)。
- **参数选择**：步长 \(\alpha = \log(NT)/((1-\gamma)K)\)，epoch数 \(K = \lceil c_1 \log(NT)/(1-\gamma) \rceil\)，扩散步数 \(L = \lceil \log(c_2 N^{3/2}\sqrt{T}\sqrt{1-\gamma})/\log(1/\rho) \rceil\)。这些参数使通信次数仅为 \(\tilde{O}(\log^2(NT))\)。
