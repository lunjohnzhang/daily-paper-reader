## 摘要
部署在非结构化室外环境中的机器人通常依据部署前采集的场景重建进行规划，因为操作员无法在每次任务前重新测绘大型或偏远场地。因此，机器人必须使用假定地形不变的过时地图进行长期规划决策，即使环境物理变化可能使得先前可行的路线在执行时变得不安全或无法到达。我们提出了一种物理可行的世界模型，用于评估未来地形变化下机器人导航的“假设”查询。该系统通过基于物理的模拟增强重建的3D高斯溅射场景，生成同一环境的物理修改版本，而无需重新收集传感器数据或重建地图。然后，我们实现了一个地形感知规划器，它考虑世界模型模拟的物理事件、障碍物和变形。这使得机器人和人类操作员能够在承诺一条规划路线之前评估该路线是否仍然可行，特别是在条件变化后撤退或恢复可能变得不可能的受限环境中。我们在德克萨斯州中部的一个真实户外现场，使用模拟的多种严重程度的洪水对该系统进行了评估。我们在物理模拟干预下地形条件恶化时测量路线和任务可行性。结果表明，物理可行的世界模型揭示了仅在原始重建环境上规划时不明显的长期路线失败和重新规划行为，使机器人能够在部署前评估未来地形变化如何影响路线可行性。

## Abstract
Robots deployed in unstructured outdoor environments often plan from scene reconstructions collected before deployment because operators cannot remap large or remote sites before every mission. As a result, robots must make long-horizon planning decisions using stale maps that assume the terrain remains unchanged, even though physical changes to the environment may render previously feasible routes unsafe or unreachable at execution time. We present a physically viable world model for evaluating what-if queries for robot navigation under future terrain change. The system augments reconstructed 3D Gaussian splat scenes with physics-based simulation to generate physically modified versions of the same environment without recollecting sensor data or rebuilding the map. We then implement a terrain-aware planner that accounts for physical events, obstacles, and deformations that are simulated by the world model. This allows robots and human operators to evaluate whether planned routes remain feasible before committing to a planned route, particularly in constrained environments where retreat or recovery may become impossible once conditions change. We evaluate the system on a real outdoor field site in Central Texas using simulated flooding across multiple severity levels. We measure route and mission feasibility as terrain conditions deteriorate under physically simulated interventions. Our results show that physically viable world models expose long-horizon route failures and rerouting behavior that are not apparent when planning only on the original reconstructed environment, allowing robots to evaluate how future terrain changes may affect route feasibility before deployment.

## 2. 论文提出的方法论：核心思想、关键技术细节、公式与算法流程

### 核心思想
- 从单一静态重建场景出发，通过基于物质点法（Material Point Method, MPM）的物理仿真生成多种可能的未来环境状态（如不同洪水 severity、滑坡），从而为规划器提供“物理修改后的环境”。
- 规划器在修改后的环境中评估路线可行性，考虑物理障碍、变形和地面接触约束，输出物理上可实现的路径。

### 关键技术细节

#### a. 场景重建与地形模型
- 使用 3D 高斯泼溅（Gaussian Splatting）从无人机视频重建场景，得到高斯原语集合 \(\{(\mu_i, \Sigma_i, c_i, \alpha_i)\}\)。
- 通过几何滤波（基于垂直与水平尺寸比例、高度邻域偏差）分离地面高斯原语、障碍物原语和漂浮伪影。
- 将地面高斯原语分箱到二维网格中，每个格子取最大 z 值生成数字高程模型（DEM）\(h(x,y)\)；同时标记障碍物掩码 \(O\)。
- 得到初始 2D 占用地图 \(G_0\)。

#### b. 干预仿真
- 使用 MPM 对高斯泼溅场景进行物理仿真，支持流体（洪水）、颗粒材料（滑坡）、弹性体（树木）等不同本构模型。
- 每次仿真输出干预表面高度 \(h_{\text{int}}(x,y)\)，并根据涉水阈值 \(\tau_{\text{wade}}\) 定义不可通行掩码 \(M_i(x,y) = 1\) 当干预深度超过阈值。
- 导航表面 \(h_{\text{nav}}(x,y)\) 在可通行区域使用地形面，在实体沉积物上使用沉积表面。

#### c. 地形感知规划器
- 基于 FOCI 框架的 B 样条轨迹优化，拓展了以下组件：
  - **碰撞成本**：计算机器人高斯原语与场景高斯原语的解析重叠积分 \(C(x_k) = \sum_i \sum_j \mathcal{N}(\bar{\mu}_j; \mu_i, \Sigma_i + \bar{\Sigma}_j)\)。
  - **朝向对齐项**：惩罚偏航与速度方向偏差。
  - **地面接触约束**：轨迹状态必须位于导航表面上方固定垂直带内（\(h_{\text{nav}} + c \leq z \leq h_{\text{nav}} + c + b\)）。
  - **体素障碍物编码**：对不可通行掩码区域生成垂直柱状高斯原语，嵌入碰撞成本。
  - **图搜索初始化**：在 xy 平面扩展，限制 z 在导航表面附近，不可通行掩码作为硬障碍。
- 优化器使用 IPOPT 求解带约束非线性规划，速度和加速度约束通过 MINVO 基保证连续满足。

### 算法流程（文字说明）
1. 输入：原始 3D 高斯泼溅场景、起始点、目标点、一组物理干预参数（如水量）。
2. 对每种干预参数运行 MPM 仿真，得到修改后的场景。
3. 从修改后的场景投影出 DEM、不可通行掩码、导航表面。
4. 在图搜索阶段，使用不可通行掩码和地形约束生成初始路径。
5. 在轨迹优化阶段，使用高斯重叠碰撞成本、朝向约束、地面接触约束进行优化。
6. 输出优化后的轨迹，并投影到地形表面。
7. 对每个干预级别重复，评估路线是否可行、重绕成本、可达性损失。

## 3. 实验设计

### 数据集 / 场景
- **Central Texas Hill Country 户外现场**：约 500×500 ft 的陡峭石灰岩地形，内含冲沟和易洪水道。从无人机 4K 视频重建（约 21 分钟，500 帧训练），生成约 7M 高斯原语。人为模拟低、中、高三级洪水，加上干旱基线共 4 种条件。定义了 4 对起点-终点。
- **Alaska 村庄场景**：真实村庄道路交叉口，从无人机影像重建（634 帧，约 5M 高斯原语）。模拟一辆卡车在干燥和洪水条件下通过路口。通过 MPM 模拟洪水与车辆相互作用，观察卡车能否通过。
- **玩具沙箱场景**：人工构建的沙谷，中间有通道和四个障碍立方体。通过 MPM 模拟左右两侧山体滑坡，观察规划器能否绕过滑坡堆积物。

## 6. 论文的主要结论与发现

- **PVWM 能暴露静态规划无法发现的路线失效**：例如 Central Texas 中 Pair 3 在干旱时可行，但在高洪水下变得不可达；而静态干旱地图完全无法预知这一问题。
- **不同起点-终点对洪水响应模式不同**：有些始终可行（绕行成本随 severity 增加），有些出现硬阈值不可达。这为任务预筛选提供了依据。
- **地形感知规划器能正确处理物理干预产生的障碍**：搜索阶段禁止进入深度超过阈值的细胞，优化阶段通过体素障碍编码阻止轨迹穿过干预体积。
- **Alaska 场景表明，即使几何不变，物理交互（如水流影响车辆摩擦力）也能改变路线可行性**，静态重建无法捕捉此类效应。
- **沙箱场景展示了对假设性灾害（滑坡）的规划适应能力**，规划器能绕开仿真产生的堆积物。

## 7. 优点

- **创新性**：将物理仿真与 3D 场景重建结合，使机器人能够在不重新采集数据的前提下评估未来环境变化的影响，属于新颖的“物理增强世界模型”方向。
- **方法完整性**：从场景重建、物理仿真到路径优化的全流程设计，每个环节都有配套策略（如高斯原语滤波、地形跟随搜索、体素障碍编码）。
