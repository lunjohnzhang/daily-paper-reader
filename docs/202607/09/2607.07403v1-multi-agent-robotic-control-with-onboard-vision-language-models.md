## 摘要
视觉语言模型（VLM）和视觉语言动作（VLA）模型在机器人控制中展现出潜力，但在可解释性、泛化能力和计算需求方面面临重大挑战。本文提出了一种多智能体系统（MAS）架构，通过在机载硬件上部署专用智能体来克服这些限制——消除了对外部计算的依赖。该系统在模拟工业仓库中控制一个多用途自主移动机械臂，完成五类任务：安全检查、仓库维护、仓库搜索、包裹质量验证以及响应人类请求。全程使用紧凑型VLM（3-200亿参数），并应用微调以提高包裹检测精度。一种新颖的“Megamind”编排智能体缓解了较小模型在长时规划中固有的上下文保持问题。该系统在采用AMD Ryzen(TM) AI迷你PC的硬件在环仿真中进行了验证。结果表明，完全机载的MAS架构是云依赖部署的一种可行、经济高效的替代方案，并具有向真实世界迁移的强大潜力。仿真环境已在Apache 2.0许可下作为开源发布。

## Abstract
Vision Language Models (VLMs) and Vision Language Action (VLA) models have shown promise in robotic control. Yet, they face significant challenges regarding explainability, generalization, and compute requirements. This paper presents a Multi-Agent System (MAS) architecture that addresses these limitations by deploying specialized agents on onboard hardware - eliminating dependence on external compute. The system controls a multi-purpose autonomous mobile manipulator in a simulated industrial warehouse, fulfilling five task categories: safety inspection, warehouse maintenance, warehouse search, package quality verification, and responding to human requests. Compact VLMs (3-20B parameters) are used throughout, with fine-tuning applied to improve package inspection accuracy. A novel "Megamind" orchestration agent mitigates context retention issues inherent to long-horizon planning with smaller models. The system was validated in a hardware-in-the-loop simulation using an AMD Ryzen(TM) AI mini PC. Results demonstrate that a fully onboard MAS architecture is a viable, cost-efficient alternative to cloud-dependent deployments, with strong potential for real-world transfer. The simulation environment has been released as open source under the Apache 2.0 licence.

## 2. 论文提出的方法论：核心思想、关键技术细节

- **核心思想**：采用多智能体架构，每个智能体专注于特定子任务，由“Megamind”编排智能体进行顶层规划与任务调度。所有智能体共享一个微调后的紧凑型VLM（LFM2-VL-3B），并运行在机载AMD Ryzen AI迷你PC上，无需网络连接外部计算资源。

- **关键技术细节**：
  - **智能体划分**：
    - **Megamind（编排智能体）**：采用两状态自反馈循环。在“规划状态”中，根据当前机器人状态和任务队列选择下一个任务并委派；在“分析状态”中，评估任务是否成功，若不成功则生成纠正步骤并加入队列。此机制缓解了小模型在长时规划中的上下文丢失问题。
    - **Inspection智能体**：负责检查仓库异常（错位箱子、地面障碍、泄漏）。分为两步：VLM先描述图像并列出最多三个潜在问题；然后分类为可抓取箱子、可抓取垃圾、其他不可操作障碍或无关。对可抓取物体，从仿真获取3D位姿并输出结构化JSON给Megamind。
    - **Safety智能体**：持续合规监控。采用三阶段流水线：视觉阶段（VLM描述场景并识别最多三个安全隐患）、检索阶段（对每个隐患查询基于OSHA法规的FAISS向量数据库，并用Qwen3-Reranker重排序，只保留高相关文档）、推理阶段（VLM结合图像、描述和法规摘录判断是否违规，并输出法规ID、严重等级和理由）。对连续帧使用SSIM跳过相似帧以减少推理。
    - **MoveIt和Nav2智能体**：分别负责机械臂操作和导航的低层控制，通过RAI工具与ROS 2接口。
  - **VLM微调**：针对包裹质量检测（T4），发现基础检查点效果差（准确率76.7%）。因此构建仿真数据集，每张图标注anomaly/box_condition/safety_hazard三个属性。使用大教师模型Qwen3-256B-A22B生成合成文本描述，然后对LFM2-VL-3B微调一个epoch。微调后箱体条件标注准确率从76.7%提升至91.5%（F1从0.755到0.915），假阳性大幅降低。
  - **硬件在环（HIL）仿真**：使用O3DE仿真环境，搭配AMD Ryzen AI迷你PC（128GB统一内存，96GB分配给GPU）作为计算节点，运行完整智能体栈。
