## 摘要
开放智能体系统（OASYS）在现实领域日益普遍，其中智能体和任务集合随时间不可预测地变化。这种开放性，包括智能体开放性（AO）和任务开放性（TO），对通常假设固定状态和动作空间的多智能体强化学习（MARL）构成了根本性挑战。现有方法仅部分解决了开放性问题：填充和掩蔽方法引入了人为边界，而最近的基于图或超图的方法处理了某一维度的开放性，但仍依赖于限制性假设。在本文中，我们提出了面向智能体和任务开放性的指针学习器（PLATO），这是一种基于指针网络的执行者与集中式图神经网络（GNN）评论者的结合，采用集中式训练和分散式执行范式下的多智能体近端策略优化进行训练。我们的基于指针的执行者直接在当前任务集上输出分布，这直接支持了无需掩蔽或重新训练即可改变的动作空间。我们的GNN评论者将智能体-任务交互编码为一个随任务和智能体组合而改变形状的图。这些组件共同考虑了AO和TO，而无需现有方法中的有界性。我们在任务-智能体开放马尔可夫博弈（TaAgO-MG）中形式化了PLATO，扩展了之前的任务开放性公式，并证明其在产生的无界状态和动作空间上是定义良好的。我们使用开放智能体系统评估方法倡议（MOASEI）的野火抑制领域评估了PLATO，这是一个为开放多智能体系统评估而设计的环境，我们展示了与OASYS中最先进的基线相比更强的性能和更一致的零样本泛化能力。

## Abstract
Open agent systems (OASYS) are increasingly prevalent in real-world domains where the sets of agents and tasks change unpredictably over time. Such openness, including agent openness (AO) and task openness (TO), poses a fundamental challenge to multi-agent reinforcement learning (MARL), which typically assumes fixed state and action spaces. Existing methods address openness only partially: padding and masking approaches introduce artificial bounds, while recent graph-based or hypergraph methods handle one dimension of openness but still depend on restrictive assumptions. In this paper, we introduce Pointer Learner for Agent and Task Openness (PLATO), a pointer-network-based actor combined with a centralized graph neural network (GNN) critic, trained with multi-agent proximal policy optimization under a centralized training and decentralized execution paradigm. Our pointer-based actor outputs distributions directly over the current task set. This directly supports changing action spaces without masking or retraining. Our GNN critic encodes agent-task interactions as a graph that changes shape with task and agent composition. Together, these components consider AO and TO without the boundedness of existing approaches. We formalize PLATO in a Task-and-Agent-Open Markov Game (TaAgO-MG), extending prior task-open formulations, and prove it is well-defined over the resulting unbounded state and action spaces. We evaluate PLATO with the Methods for Open Agent Systems Evaluation Initiative (MOASEI) wildfire suppression domain, an environment designed for open multi-agent system evaluation, and we demonstrate strong performance and more consistent zero-shot generalization than state-of-the-art baselines in OASYS.

## 论文总结

### 1. 论文的核心问题与整体含义（研究动机和背景）

- **核心问题**：开放智能体系统（OASYS）中，智能体集合和任务集合会随时间动态变化（智能体开放性 AO 和任务开放性 TO），而传统多智能体强化学习（MARL）方法通常假设固定的状态和动作空间，难以应对这种无界的、动态的变化。
- **研究动机**：现有处理方法（如填充/掩蔽、图/超图方法）要么引入人为边界，要么只处理单一维度的开放性，无法同时适应 AO 和 TO。需要一种无需重训练、无需固定边界的统一方法。
- **整体含义**：本文旨在设计一种能够同时处理 AO 和 TO 的 MARL 算法，使得智能体在任务和队友动态变化的环境中仍能进行有效、可泛化的决策。

### 2. 论文提出的方法论

- **核心思想**：基于指针网络（Pointer Network）的演员（Actor）直接输出当前任务集上的动作分布，无需掩码或重训练；同时使用图神经网络（GNN）评论家（Critic）编码智能体-任务交互图，支持无界的智能体和任务数量。
- **关键技术细节**：
  - **演员**：采用内容指向（content-based pointing）机制。每个智能体由其当前观测因子分解为智能体特征矩阵和任务特征矩阵，通过聚合统计量（均值、方差、最小、最大）得到固定维度的查询向量，再为每个任务生成键，通过加性注意力计算得分，最终经 softmax 得到动作分布。
  - **评论家**：将全局状态构建为二部图（智能体节点和任务节点），使用图卷积网络（GCN）进行消息传递，然后通过平均池化和 MLP 输出状态值估计。
  - **训练框架**：采用集中式训练分散式执行（CTDE）范式，使用 MAPPO 算法优化；所有组件（MLP、注意力、GCN）联合端到端训练。
  - **形式化模型**：扩展了任务开放马尔可夫博弈（TaO-MG），提出任务-智能体开放马尔可夫博弈（TaAgO-MG），明确考虑智能体集合和任务集合的共同变化；并证明 PLATO 在此无界状态和动作空间上定义良好且置换不变。

### 3. 实验设计

- **场景/数据集**：使用 MOASEI 野火抑制域（grid-based），智能体为消防员，任务是扑灭火灾。火灾可通过内源性（火灾蔓延）和外源性（随机点火）产生，智能体因抑制剂量耗尽而退出/重新进入，实现 AO 和 TO。
- **Benchmark**：定义了四个设置（S0–S3）：S0 封闭（无开放性），S1 仅内源性 TO，S2 外源性 TO + 随机补给（含 AO），S3 内源性+外源性 TO + 低补给成功率（最大开放性）。
- **对比方法**：
  - 三种智能基线：DGN、DICG、MOHITO（专门针对 TO）。
  - 四种启发式基线：NOOP、Random、Weakest、Strongest。
- **指标**：回合回报（episode return）、每次灭火动作的奖励（reward per fight）、NOOP 率等。使用 Shapiro-Wilk 自适应双侧检验及 Bonferroni 校正进行显著性检验。

### 4. 资源与算力

- **计算资源**：实验在高性能计算集群上进行，每个节点配备双 Intel Xeon Gold 6348 CPU（共 56 核心），仅使用 CPU（无 GPU），基于 free-range-zoo 库。
- **训练时长**：单个方法（一个网格、一个设置）需约 3–5 天 CPU 时间；整个实验套件（所有方法、网格、设置及 Optuna 调优）总计约 6,000–10,000 CPU 天。

### 5. 实验数量与充分性

- **实验数量**：
  - 原生评估（训练和测试在同一网格）：三种网格尺寸（2×3、3×3、4×4），每个网格四种设置（S0–S3）。
  - 零样本泛化评估：将 2×3 训练的策略测试于 3×3 和 4×4，将 3×3 训练的策略测试于 4×4 和 5×5。
  - 消融实验：在 MLP 与 LSTM 编码器、加性与点积注意力之间进行 2×2 因子消融，评估回合回报及多项指标。
- **充分性与公平性**：
  - 每个方法均通过 Optuna 超参数调优（50 轮），使用相同种子协议确保可控方差。
  - 使用 150 个评估回合（50 种子 × 3 检查点）并采用配对统计检验，显著性检验合理。
  - 消融实验比较了多种变体，但仅在一个最开放设置（S3）下出现显著差异，提示方法对各种组件的敏感性有限。整体实验设计较为充分，主流基线覆盖全面。

### 6. 论文的主要结论与发现

- PLATO 在原生评估（尤其是 S2、S3）中显著优于所有基线，在 3×3 和 4×4 网格上表现突出；在零样本泛化中，PLATO 在多数设置下表现最强且最一致，特别是从 3×3 迁移到 5×5 时优势明显。
- 消融实验表明：在 S3 零样本时，LSTM 编码器加加性注意力组合（lstm+add）最佳；在 S0 零样本时，MLP 加点积注意力（mlp+dot）更好；但在原生评估中无显著差异，说明组件选择对泛化影响大于对原生性能影响。
- 方法成功实现了无人工上界、无需重训练的 AO+TO 处理，并证明了算法在无界状态/动作空间上的定义良好性。

### 7. 优点

- **方法创新**：首次将指针网络用于同时处理智能体开放性和任务开放性，避免固定边界和重训练，具有很强的可扩展性。
- **理论完备**：形式化定义了 TaAgO-MG，并证明演员和评论家是置换不变且定义良好的。
- **实验设计扎实**：涵盖多种开放性设置、多种网格规模、零样本迁移评估和充分的消融研究，统计分析严谨。
- **实用性**：在野火抑制这一具有代表性的 OASYS 领域验证，展示了真实开放环境下的鲁棒性。

### 8. 不足与局限

- **任务限制**：目前 TaAgO-MG 假设每个任务只有一个动作（如 “扑灭该火灾”），不支持多动作任务（如不同灭火方法），存在一定限制。
- **假设条件**：演员假设完全可观测（观测包含所有相关任务和智能体），未探索部分可观测或信念状态扩展。
- **计算开销**：尽管复杂度为 O(|N|^2 + |N||X|)，但在智能体或任务数量较大时仍可能是瓶颈；实验仅在 CPU 上进行，GPU 加速未被探索。
- **框架开放性局限**：未涉及帧开放性（如智能体内部目标、能力改变），作者承认 AO 和 TO 是重点而非 FO。
- **泛化范围有限**：零样本实验仅测试网格尺寸变化，未验证到其他类型环境或任务分布变化；实验仅基于野火域，未在 Eck 等人列出的其他 OASYS 域上验证。
- **消融结果解释**：消融中部分差异性不显著，可能因统计效度或信噪比低，需更多评估或更大样本量。
