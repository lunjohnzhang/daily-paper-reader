## 摘要
群体中的每个机器人能否仅凭局部观测和带宽受限的消息预测相同的未来集体状态？我们将此问题形式化为去中心化共享状态预测，并引入集体状态JEPA（CS-JEPA），这是一种循环联合嵌入预测架构，其在每个机器人上的输出代表一个共同的未来令牌字段。在部署时，每个机器人使用16帧的局部历史记录和每条有向边一个64浮点的循环消息；没有全局池化、目标编码器、回合时钟或记录的未来动作。在没有下游集体标签的情况下预训练后，冻结表示通过岭回归探针进行评估，探针在6、12或24个全局标记的回合上拟合。与具有相同接收端锚点和部署容量但多出9,607个仅用于训练的参数的原始未来重建相比，一项前瞻性注册的五种子后续研究在分布内、环形、相互kNN以及未见规模（最多108个机器人）的系列上提高了预测误差和机器人间一致性的标签预算AUC。所有效果在5/5个外部种子中均有利于CS-JEPA。在另一项独立的封存八种子后续研究中，匹配的动作条件预测器在生成接收端局部预测表示之前接收每个候选的四步计划。CS-JEPA将分支值均方误差降低了45.5%，并将上下文内候选分数皮尔逊相关性提高了0.1291，这两种效果在8/8个种子中均有利，包括未见过的N=32。这些结果支持将共同未来JEPA目标作为在拓扑和规模变化下进行去中心化群体预测的标签高效基元，并提供了规划相关价值估计的额外证据。

## Abstract
Can every robot in a swarm predict the same future collective state from only local observations and bandwidth-limited messages? We formulate this as decentralized shared-state prediction and introduce Collective-State JEPA (CS-JEPA), a recurrent joint-embedding predictive architecture whose output at every robot represents one common future token field. At deployment, each robot uses a 16-frame local history and one 64-float recurrent message per directed edge; there is no global pooling, target encoder, episode clock, or recorded future action. After pretraining without downstream collective labels, frozen representations are evaluated with ridge probes fitted on 6, 12, or 24 globally labeled episodes. Against raw-future reconstruction with the same receiver anchor and deployment capacity but 9,607 additional training-only parameters, a prospectively registered five-seed follow-up improves prediction-error and inter-robot-agreement label-budget AUC on in-distribution, ring, mutual-kNN, and unseen-size families up to 108 robots. Every effect favors CS-JEPA in 5/5 outer seeds. In a separate sealed eight-seed follow-up, matched action-conditioned predictors receive each candidate four-step plan before producing receiver-local predictive representations. CS-JEPA reduces branch-value MSE by 45.5% and improves within-context candidate-score Pearson correlation by 0.1291, with both effects favorable in 8/8 seeds, including at unseen N=32. These results support common-future JEPA targets as a label-efficient primitive for decentralized swarm prediction under topology and size shift, with additional evidence of planning-relevant value estimation.

### 一、论文的核心问题与整体含义（研究动机和背景）

- **核心问题**：机器人集群中的每个个体仅凭自身的局部观测（16帧历史）和来自邻居的带宽受限循环消息（每条有向边64个浮点数），能否预测出**同一个**未来集体状态？
- **问题定位**：这不是传统的单智能体轨迹预测、集中式批评家状态估计或对当前状态的共识估计，而是一个"多接收者、单一共享未来目标"的推理任务。集群整体可能表现出一致的全局状态（如聚集、分裂、旋转、失连），但没有任何单个成员能直接观测到该状态。
- **研究空白**：已有工作分别探讨了置换不变编码器、全局状态预测（GSP）、多智能体世界模型和JEPA架构，但没有人系统研究**JEPA目标能否以集合形式表示未来群体状态、能否通过固定局部消息接口在每个机器人上独立预测、能否迁移到新拓扑和新规模、能否减少下游全局标注需求**，论文将此四者的结合作为研究目标。
- **整体含义**：如果每个机器人都能预测相同的未来集体状态，那么小样本标注即可训练下游解码器读取诸如极化强度、连通性、任务分数等集体变量，从而大幅降低集中式感知和标注负担，同时保持推理时的完全去中心化。

### 二、论文提出的方法论

#### 1. 核心思想

- 提出**Collective-State JEPA（CS-JEPA）**，一种循环联合嵌入预测架构。核心思路是：让每个机器人独立地预测一个**共同的、置换不变的未来目标**（一个固定大小的"全局+空间令牌场"），而不是重建原始未来观测。
- 关键设计哲学：**预测共享未来的潜在表示**（而非原始未来状态）作为自监督目标，从而让不同局部视角的机器人输出相互兼容且对标签高效的表征。

#### 2. 技术细节

- **信息约束**：机器人 i 在时刻 t 的允许信息为自身16帧局部观测、邻居的循环记忆消息（每条有向边每步256字节），不包含全局池化、回合时钟、未来动作、原始邻居特征或目标编码器。
- **接收端局部循环传输**：本地编码器将自观测映射为64维嵌入，通过同步GRU更新隐状态，其中邻居消息通过**均值聚合**（degree-independent）实现尺度不变：
  \[
  \bar{h}_i^{t-1} = \frac{1}{|N_t(i)|} \sum_{j \in N_t(i)} h_j^{t-1}, \quad h_i^t = \text{GRU}([e_i^t, \bar{h}_i^{t-1}], h_i^{t-1})
  \]
- **固定大小未来目标**：冻结的目标编码器嵌入所有未来活跃机器人，通过置换不变的集合分词器形成 **1个全局令牌 + 4×4空间字段（共17个65维令牌 = 1105维）**，与群体规模 N 无关。空间字段使用高斯核加权聚合，全局令牌使用平均嵌入+存在质量。
- **角色条件预测器**：递归预测 t+2 再预测 t+4，对第一次预测停止梯度。
- **共同目标损失**：
  \[
  L_{CS} = \frac{1}{M_Z} \sum_{b,i,h} \frac{\| \hat{Z}_{t+h}^{b,i} - \text{sg}(Z_{t+h}^b) \|_2^2}{D_Z}
  \]
  注意**没有显式的"一致性"损失项**（一致性损失权重为零），这是刻意设计。
- **接收端锚点（receiver anchor）**：一个仅训练用的MLP，预测该机器人自身的冻结未来嵌入，损失权重 λ=2，用于防止预测集合目标时丢失自我动态信息；部署时删除。
- **训练-部署分离**：预训练时目标分支使用特权未来状态提供共享目标，但绝不注入推断输入；部署时仅保留被冻结的本地编码器和循环预测器，外加一个小型岭回归探针。

### 六、论文的主要结论与发现

1. **主假设成立**：在所有4个注册分拆（ID、环、mutual-kNN、未见规模）上，CS-JEPA的预测误差AUC和机器人间一致性AUC均优于锚定匹配的Future-Recon，所有效果在5/5外部种子中为正，95%置信下限均为正。
2. **标签效率**：CS-JEPA的绝对优势分布在完整6–24标签范围内，而非由单一标签预算驱动（图2每条曲线在所有预算下均低于基线）。
3. **一致性自发涌现**：由于没有显式一致性损失，机器人间一致性的提升表明共同未来目标能自发地将不同局部证据组织为相互兼容的预测，且同时伴随准确率提升排除了"全部坍塌到相同无意义输出"的可能。
4. **动作条件价值估计**：封存八种子后续中，CS-JEPA将分支值MSE相对降低45.5%（从0.02847降至0.01553），上下文内候选分数皮尔逊相关提升0.1291，在8/8种子及N=32上均有利。

6. **失败斜坡警告迁移**：冻结表示可迁移至50%智能体故障渐增的预警任务，平均精度AUC增益0.006495。

### 七、优点

- **严谨的实验方法论**：前瞻性注册协议+封存数据+5/8种子外部分析+回合级重采样+精确配对比较，是对自监督机器人学习研究中常见的"事后选优"偏差的有力回应。
- **精心设计的隔离变量**：通过匹配冻结编码器、共享初始化、相同锚点、相同部署容量，将观察到的优势精确归因于"预测共同JEPA潜在目标 vs 重建原始未来场"这一唯一差异；同时给予基线更多训练参数，使胜果更保守。
- **规模与拓扑不变性**：均值聚合和集合分词器使模型参数与N无关，17令牌目标布局保证了推理时对任意规模的兼容，并在实验中验证到108机器人。
- **目标端点的精确性与透明度**："集体状态"定义为可审计的全局+空间潜在场（10个物理量的可解码目标），而非模糊的深层特征；同时存在零触发的一致性检查（无显式一致性损失），从机制上排除了捷径。
- **部署契约明确**：每步每有向边256字节、16帧历史、无时钟、无未来动作、无全局张量，明确陈述了系统边界，便于工程落地和后续对比。

### 八、不足与局限

- **纯模拟器验证**：无真实机器人硬件实验，假设共享归一化坐标帧且无观测噪声，与现实部署仍有距离。
- **训练依赖特权未来状态**：预训练需要完整未来集体状态的访问权限，虽然部署时不需要，但在某些实际场景中可能无法获得真实的未来状态用于预训练。
- **未复现既有系统**：未在原生任务中重新实现GSP/GSP-N或多智能体世界模型系统，与这些方法的对比仍是"任务抽象层面"的，可能在高保真控制任务上表现不同。
- **统计功效有限**：5个外部种子虽然所有效应方向一致，但两侧精确检验p=0.0625未达常规显著性；真实世界变异性大时结论可能略有松动。
- **价值估计未转化为性能**：动作条件CS-JEPA在价值MSE和相关性上更好，但选计划后悔和闭环连通性无显著优势，规划相关价值提升的实际用途尚未闭合。

- **缺乏算力披露**：未报告GPU型号/数量/训练时间，影响复现和计算成本评估。
- **多模态不确定性未刻画**：目标确定性（非概率性）意味着无法量化预测不确定性，可能限制高风险场景中的可用性。
