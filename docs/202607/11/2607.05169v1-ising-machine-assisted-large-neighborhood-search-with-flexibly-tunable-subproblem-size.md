## 摘要
Ising机是组合优化的启发式求解器，但当直接求解大规模约束问题时，其解质量可能下降。Ising机辅助的大邻域搜索（LNS）通过求解较小的子问题来反复更新可行的当前解。现有的针对车辆路径问题（VRP）的可行性保持方法会重新优化所选车辆的整个路径，因此无法精细调整子问题规模。我们提出了LNS-VT，它引入了每辆车重新优化的连续步数作为参数，以在保持可行性的同时精细控制子问题规模。对于一个300站点、5车辆的VRP，其最佳设置经过100次迭代后，相较于现有方法使目标值降低了约10%，且合适的设置会随当前解质量变化。将相同原理应用于二次多背包问题，我们确认了也存在合适的子问题规模，这表明子问题规模控制在Ising机辅助的LNS中很重要。

## Abstract
Ising machines are heuristic solvers for combinatorial optimization, but their solution quality can degrade when large-scale constrained problems are solved directly. Ising-machine-assisted large neighborhood search (LNS) instead repeatedly updates a feasible current solution by solving smaller subproblems. An existing feasibility-preserving method for the vehicle routing problem (VRP) re-optimizes the entire routes of selected vehicles and thus cannot adjust the subproblem size finely. We propose LNS-VT, which introduces the number of consecutive steps re-optimized per vehicle as a parameter to control the subproblem size finely while preserving feasibility. For a 300-site, 5-vehicle VRP, its best setting reduced the objective value by approximately 10\% relative to the existing method after 100 iterations, and the appropriate setting changed with the current solution quality. Applying the same principle to the quadratic multiple knapsack problem, we confirmed that an appropriate subproblem size also exists, indicating that subproblem-size control is important in Ising-machine-assisted LNS.

## 1. 核心问题与整体含义（研究动机和背景）
- **研究动机**：Ising机（一种启发式组合优化求解器）直接求解大规模约束优化问题时，会面临两个困难：一是变量数量可能超出硬件容量，即使可输入，搜索空间过大会导致解质量下降；二是约束通常以惩罚项形式加入，低能态可能不是原问题的可行解。
- **问题定义**：如何设计一种Ising机辅助的大邻域搜索（LNS）框架，在保持可行性的同时，能够灵活控制子问题的规模，从而提升求解质量。
- **现有方法局限**：针对车辆路径问题（VRP）的现有LNS方法（LNS-V）通过选择若干车辆并重新优化其整条路径来生成子问题，但子问题规模仅由车辆数控制，当每个车辆访问站点很多时，单次增减车辆会导致变量数剧烈变化，无法实现精细调整。

## 2. 方法论：核心思想、关键技术细节
- **核心思想**：在LNS-V基础上引入一个新的控制参数——每个被选车辆重新优化的连续步数（即路径片段长度），记为T′，从而更灵活地控制子问题规模，同时保持可行性。
- **关键步骤（LNS-VT算法）**：
  1. 从当前解中随机选择V′个车辆（V′≥2）。
  2. 计算每个被选车辆当前访问非站点数量的实际连续步数T(v)_valid。
  3. 取Tseg = min(T′, min_v T(v)_valid)，确保不超过任何车辆的有效步数。
  4. 对每个被选车辆，随机选择起始步，提取Tseg个连续步骤（这些步骤均为非站点访问）。
  5. 子问题只包含这些被选车辆在提取步内的变量，以及这些步所访问的非站点集合；其他所有变量固定为当前解。
  6. 构建子问题的QUBO能量函数：包括目标函数（只依赖于子问题变量，含与前后固定站点的连接距离）和两个惩罚项：确保每个提取的非站点被恰好访问一次；每个被选车辆在提取步内恰好访问一个非站点。注意不需要惩罚约束C（车辆返站后不再离开），因为提取区间不包含站点停留步。
  7. 子问题由Ising机求解，得到的子问题可行解被“重新插入”回固定部分，产生一个新的候选解；若新解可行且目标值下降，则更新当前解。
- **可行性保持证明**：由于子问题中每个非站点只出现在一个提取步且被恰好访问一次，未提取的非站点不变，全局约束A满足；每个提取步内车辆恰好访问一个非站点，且固定部分满足其他约束，因此重新插入后整个解可行。
- **与LNS-V对比**：LNS-V中变量数 ≈ (V′)²(T-2)²；LNS-VT中变量数 = (V′Tseg)²。通过调节T′（而非仅V′）可实现更细粒度控制，且与原始问题步骤数T脱钩。

## 3. 实验设计
- **主要问题**：单仓库、无容量限制的对称VRP（车辆从仓库出发并返回，每个非站点恰好被访问一次）。
- **数据集/场景**：
  - VRP：300个非站点，5辆车，步数T = ⌈N/V⌉ + 2 = 62，站点和仓库在单位正方形内均匀随机分布。
  - QMKP：200个物品，5个背包；物品价值、相关值、重量取自QKP基准实例“jeu 200 75 1”；背包容量设为 0.8 × (总重量 / 背包数)。
- **对比方法**：
  - **Naive method**：直接求解原问题的完整QUBO（一次求解，计算时间300秒）。
  - **LNS-V**：V′=2（参考前人研究中最佳设置），100次迭代，每次子问题求解10秒。
  - **LNS-VT**：多种V′和T′组合（V′=2时T′={10,20,30,40,50}；V′=3时T′={10,20,30,40}；V′=4时T′={10,15,20,25,30}；V′=5时T′={12,16,20,24}），100次迭代，每次子问题求解10秒。
- **初始解**：所有LNS运行使用同一个由Naive method获得的可行解作为共同起点。
- **评价指标**：VRP取平均目标值（总行驶距离），QMKP取平均总利润（最大化问题），均基于10次独立运行的平均值±标准差。

## 6. 主要结论与发现
- LNS-VT能够灵活控制子问题规模，且保持可行性。
- 在300站点/5车辆VRP上，最佳LNS-VT设置（V′=2, T′=40）经过100次迭代后，平均目标值比LNS-V降低约10%；并且仅用约30%的迭代次数（约30次）即达到LNS-V最终解质量。
- **子问题规模存在最优区间**：VRP中约6000~10000个变量时效果最好；QMKP中约100~150个变量时总利润最高。过大或过小都会导致解质量下降。
- **子问题规模应随搜索阶段动态调整**：早期（当前解质量较差）使用较大子问题能更快降低目标值；后期（当前解接近局部最优）使用较小子问题更有效。
- **相同变量数下，V′和T′组合影响解质量**：较小V′（较长片段）有利于同车顺序调整；较大V′（更多车参与）有利于站车间交换。这解释了为何不同组合表现不同。
- QMKP上的定性规律与VRP相似，表明子问题规模控制是Ising机辅助LNS的关键设计因素。

## 7. 优点
- **方法设计**：
  - 引入T′作为独立控制参数，打破了子问题规模与原始问题步数T的强耦合，实现了细粒度调整。
  - 严格证明了可行性保持，理论可靠。
  - 设计原则可推广到其他约束优化问题（如QMKP），展示了框架的通用性。
- **实验分析**：
  - 不仅比较了最终解质量，还分析了迭代过程中的变化规律（如不同目标值区间的最优规模）以及V′/T′组合的影响，提供了深入的理解。
  - 通过统计“车辆改变”与“顺序改变”的次数，解释了相同变量数下不同表现的机制。
- **实用性**：通过调整子问题规模，使Ising机在有限计算时间（10秒/子问题）内能获得高质量解，提升了整个LNS框架的效率。
