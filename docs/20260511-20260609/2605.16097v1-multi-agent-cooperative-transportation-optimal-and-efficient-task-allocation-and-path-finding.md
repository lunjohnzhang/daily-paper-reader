## 摘要
多机器人系统是现代物流的核心组成部分，但其能力通常局限于单个智能体可执行的任务。本文针对现有框架（如多智能体路径规划（MAPF）和任务分配与路径规划（TAPF））中的关键空白——缺乏对需要多个智能体协同运输大型物品的真正协作——进行探讨。为此，我们形式化了协同运输任务分配与路径规划（CT-TAPF）问题，该问题整合了团队组建、任务分配和无碰撞路径规划。我们提出了一种最优求解器——协同运输任务冲突搜索（CT-TCBS），该求解器采用一种新颖的增量扩展策略，以应对团队组建中固有的组合爆炸问题。考虑到最优求解的计算成本，我们还开发了一系列次优求解器，这些求解器采用全局、以任务为中心的视角，基于全局难度指标（最佳任务或最差任务）选择下一个待分配任务。我们的综合实证评估有三个关键发现：（1）增量扩展策略通过成功剪枝主导任务分配搜索空间，显著优于朴素的组合方法；（2）我们识别出一个任务冲突扩展困境，即对于大规模智能体路径规划子问题有效的复杂冲突解决器，在集成的CT-TAPF设置中可能产生负面影响；（3）与“nn-”以智能体为中心的基线相比，我们提出的次优求解器在解质量-运行时间谱上建立了更高效的新边界。这项工作为一种新型、实用的协同多智能体问题提供了基础框架和一组有效算法。

## Abstract
Multi-robot systems are integral to modern logistics, but their capabilities are often limited to tasks executable by individual agents. This paper addresses a critical gap in existing frameworks like Multi-Agent Path Finding (MAPF) and Task Allocation and Path Finding (TAPF), which lack true cooperation for transporting large items that require multiple agents. To this end, we formalise the Cooperative Transportation Task Allocation and Path Finding (CT-TAPF) problem, which integrates team formation, task assignment, and collision-free pathfinding. We present an optimal solver, Cooperative Transportation Task Conflict-Based Search (CT-TCBS), which features a novel Incremental Expansion strategy to tackle the combinatorial explosion inherent in team formation. Recognising the computational cost of optimality, we also develop a family of sub-optimal solvers that employ a global, task-centric perspective, selecting the next task to assign based on a global difficulty metric (Best Task or Worst Task). Our comprehensive empirical evaluation demonstrates three key findings: (1) the incremental expansion strategy significantly outperforms the naive combinatorial approach by successfully pruning the dominant task-allocation search space; (2) we identify a task-conflict expansion dilemma, where sophisticated conflict resolvers effective for large-agent pathfinding subproblems can be detrimental in the integrated CT-TAPF setting; and (3) our proposed sub-optimal solvers establish a new, more efficient frontier on the solution quality-runtime spectrum compared to "nn-" agent-centric baselines. This work provides a foundational framework and a set of effective algorithms for a new, practical class of cooperative multi-agent problems.

## 2. 提出的方法论

### 2.1 核心思想

- **问题形式化**：给定无向图环境、一组智能体（起始位置）和一组协作任务（每个任务需要k个智能体，定义有起始配置和目标配置），需为每个智能体分配任务槽并规划无碰撞路径，最小化所有智能体完成时间的总和（Sum of Costs, SoC）。
- **CT-TCBS（最优求解器）**：基于冲突搜索（CBS）的两层搜索框架，高层在约束树上以A*搜索探索任务分配和路径约束的组合空间；低层通过统一A*规划个体路径或多智能体护航（Convoy）的路径。
- **核心创新**：增量扩展策略（Incremental Expansion）替代朴素组合扩展，逐槽分配，避免团队组合爆炸。

### 2.2 关键技术细节

- **低层路径规划**：
  - 对完全分配的任务：先规划个体到装配槽的路径，确定同步时间\(t_{sync} = \max(t^{\text{arr}}_j)\)，然后从\(t_{sync}\)开始将整个团队作为单一Convoy规划路径。
  - 对部分分配的任务：只计算个体到装配槽的路径代价作为下界。
- **冲突扩展**：
  - 采用MC-CBS框架处理涉及Convoy的几何冲突，实现三种策略：ASYM（不对称分裂）、SYM（对称分裂）、MAX-d（基于MDD的加权策略）。
  - 冲突扩展优先级高于任务扩展，以保证节点成本完整性。
- **任务扩展**：
  - **增量扩展**：优先完成部分分配的任务（逐槽添加智能体），所有任务完全分配后才启动新任务分配。
  - 对比：组合扩展一次性为任务生成所有可能的团队（组合爆炸）；混合变体Incremental-LR在起始时考虑所有k个槽。
- **启发式函数**：
  - 复合启发式\(H = H1 + H2\)，其中\(H1\)估计已分配任务未来的运输代价（曼哈顿距离下界），\(H2\)估计未分配任务槽的最小填充代价（考虑直接分配和链式分配）。由于\(H3\)（同步等待时间）的计算等价于NP难的广义分配问题，故排除，保证启发的可容许性。
- **次优求解器**（CT-TCBS-BT/WT）：
  - 在任务选择层使用全局视角，基于任务难度度量（通过匈牙利算法求解最小成本指派问题）选择下一个任务。
  - **最佳任务（BT）**：优先选择难度最小的任务（贪心）；**最差任务（WT）**：优先选择难度最大的任务（失败优先策略）。

### 2.3 算法流程（文字说明）

1. **初始化**：创建根节点（空任务分配、空约束），计算启发式。
2. **主循环**（最佳优先A*）：
   - 从OPEN表中弹出f值最小的节点。
   - **目标测试**：若所有任务完全分配且无冲突，返回最优解。
   - **扩展**：
     - 若存在冲突 → 执行冲突扩展（按MC-CBS策略生成两个子节点，分别添加约束集）。
     - 若无冲突但未完成任务 → 执行任务扩展（增量策略：优先完成部分分配任务，否则选新任务的首个槽分配）。
   - 对每个子节点：调用低层规划器计算路径、实际代价\(g\)和冲突信息；若路径可行，再计算启发式\(h\)后加入OPEN表；避免重复状态（CLOSED表）。

## 6. 主要结论与发现

1. **增量扩展策略显著优于朴素组合方法**：在碰撞丰富场景中，Incremental的成功率显著高于Incremental-LR和Combinatorial（Cochran's Q检验 \(p \approx 10^{-5}\)）。原因是任务分配搜索空间（中位数扩展比为9.54）是主要瓶颈，增量策略有效剪枝。
2. **任务冲突扩展困境**：复杂的冲突解算器（MAX-d变体）在CT-TAPF集成环境中反而导致更多节点扩展（Friedman检验显著）。其故意增加g值的策略促使高层A*过早探索替代任务分配，对冲了路径冲突的收益。
3. **次优求解器建立新的效率前沿**：
   - WT的解质量显著优于BT（配对Wilcoxon检验 \(p \approx 10^{-11}\)），因为WT优先分配多智能体任务，避免后期高协调成本。
   - 成功率依场景而异：随机场景下WT更高，空间偏置场景下BT更高。
   - 综合对比中，WT在运行时间和解质量之间取得比-agent-centric基线更好的平衡，Greedy-PP最快但解质量最差。
