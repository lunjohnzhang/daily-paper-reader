## 摘要
自动化仓库面临在最大化存储密度和实现高检索吞吐量之间的基本权衡。虽然基于谜题的存储（PBS）架构通过消除通道来增加容量，但由于潜在的死锁问题，在这些高密度空间中协调多台机器人在计算上具有挑战性。本文针对“最大容量下的有序存储与检索问题”提出了一种新颖的多机器人建模。研究重点是可从单一边界进入的矩形网格，其中负载需要首先存储至满载容量，然后根据预定的出发序列高效检索。这项工作通过利用免重排布局的性质，弥合了几何可行性与执行效率之间的差距。这些性质指导了一种在线的、优先级的多智能体路径规划算法，这也是本文的主要贡献。与通用的集中式规划器不同，该方法利用存储布局的特定不变量来保证完备性并防止死锁，从而实现可扩展性。实验表明，该方法在完工时间方面相对于机器人数量实现了近线性改进，直到 $m = C$，其中 $C$ 是网格宽度。关键的是，支持鲁棒性的算法开销可以忽略不计；该系统使用鲁棒的存储布局来处理出发序列的不确定性，与非鲁棒基线相比，在执行速度上没有显著损失。

## Abstract
Automated warehouses face a fundamental trade-off between maximizing storage density and achieving high retrieval throughput. While puzzle-based storage (PBS) architectures increase capacity by eliminating aisles, coordinating multiple robots in these high-density spaces is computationally challenging due to the potential for deadlocks. This paper introduces a novel multi-robot formulation for the ``ordered storage and retrieval problem at maximum capacity''. The focus is on rectangular grids accessible from a single boundary, where loads need to be first stored up to full capacity and then efficiently retrieved, given a planned departure sequence. This work bridges the gap between geometric feasibility and execution efficiency by leveraging the properties of relocation-free arrangements. These properties guide an online, prioritized multi-agent path-finding algorithm, which is the main contribution of this work. Unlike general centralized planners, the approach exploits the specific invariants of the storage arrangement to guarantee completeness and prevent deadlocks, enabling scalability. Experiments demonstrate that the method achieves near-linear improvement in makespan with respect to the number of robots, up to $m = C$, where $C$ is the grid width. Crucially, the algorithmic overhead of supporting robustness is negligible; the system handles uncertainty in departure sequences using robust storage arrangements with no significant penalty in execution speed compared to the non-robust baseline.

## 2. 方法论：核心思想、关键技术细节、算法流程

- **核心思想**：采用“先布局、后规划”的两层框架。首先依赖已有的顺序规划结果——免重排存储布局（满足到达序列和出发序列），然后在这种布局的几何不变量指导下，运行**在线、异步、优先级多智能体路径规划**，将顺序可行性转化为并行执行效率。
- **系统建模与关键定义**：
  - 环境为 R 行 × C 列网格，底部有 I/O 行和传送带行；机器人可载一负载，采用双层高度模型（空机器人可从静止负载下方穿过）。
  - 避免碰撞分为位置冲突（同类型实体同格）和方向冲突（禁止交错/交换，允许同向“列车式”移动）。
  - 免重排布局：负载在顺序存取时无需移动其他负载即可完成全部存取；k-鲁棒性定义允许出发序列中任意逆序的距离不超过 k。
- **存储阶段算法（Algorithm 1）**：
  - 机器人空闲时，按到达序列 A 依次认领下一个负载；若多个机器人空闲，选择距离取货点最近的机器人。
  - 用**空间-时间 A\* 搜索**规划从当前位置 → I/O 行取货点 → 目标存储格的路径。
  - 全局预留表以 `(位置, 时间, 禁止进入方向)` 记录轨迹；负载层和机器人层分开管理，拾取/放下时动态更新负载障碍。
  - 若路径规划失败，则不认领负载，等待并重试；传送带根据计划的取货时间预留在前一步把负载推上 I/O 行。
- **检索阶段算法（Algorithm 2）**：
  - 机器人先移动到下一个待出发负载处（空闲时），声明负载后将其送往 I/O 行，再回到仓库内某个负载下等待，或去最远行的空单元。
  - 严格维护出发顺序：只有当前负载 j-1 已排队路径到 I/O 行，才允许为负载 j 规划路径；I/O 行槽位按序预留，防止乱序占用。
  - 备选逻辑：若机器人无法规划到下一个负载，则放下当前负载后，选择最近的可达未声明负载下方等待；若无，则移动到最后一行的空位（证明存在且不阻塞后续路径）。
- **完备性理论**：通过归纳证明，存储和检索算法在输入布局满足对应序列时均完备：归纳假设之前的负载已存储/检索，利用布局保证的免重排路径（机器人仅作为可移动障碍），总可找到无碰撞规划，从而杜绝死锁。

## 6. 主要结论与发现

- **效率与可扩展性**：算法在机器人数量 \(m\) 接近网格宽度 \(C\) 时，makespan 实现近线性加速（如 20×20 网格、20 机器人时加速比约 15 倍）；即使机器人数量增加，总行驶距离的增长不超过 5%，协调开销很小。
- **鲁棒性代价可忽略**：使用 R-StoRMR（k=0.4C）鲁棒布局与标准 StoRMR（k=0）布局的 makespan 曲线基本重合，说明处理出发顺序不确定性几乎不牺牲执行速度。
- **在线实时能力**：每负载平均规划时间随网格与机器人数量增大而增加，但在所有测试实例中均低于 1.31 秒，可满足在线条件下机器人无需等待规划。
- **次优性可控**：在可求解的小规模对比中，相对于最优耦合规划器，makespan 次优性比率为 1.09–1.21，部分差距来源于最优求解器允许利用传送带机制进行轻微乱序操作。
