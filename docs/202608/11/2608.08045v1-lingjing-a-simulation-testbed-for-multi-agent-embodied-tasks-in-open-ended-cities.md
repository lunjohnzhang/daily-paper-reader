## 摘要
城市具身智能要求异构智能体（如无人机、地面机器人和自动驾驶车辆）在动态城市中进行协同。因此，仿真器为开发和评估此类协同提供了可扩展的基础。然而，现有平台将不同的具身形态相互隔离，并将其与任务设计和评估相脱离。我们提出了Lingjing，一个面向开放式城市环境中异构多智能体具身智能的仿真平台。Lingjing从地理数据中重建并渲染不断演化的城市，同步多个物理引擎，并向智能体暴露共享的物理和结构化城市状态。其类Gym接口支持用户自定义的ReAct智能体，以及单或多智能体的自然语言任务，并具有可配置的星型或广播通信和资源约束。每一回合都成为可归因的重放，将智能体轨迹与通信关联到关系图变化、资源消耗和基于引擎的评估上，以进行系统性诊断。我们在共享引擎在环协议下，评估了十二个视觉-语言模型在九个城市任务上的表现。受控研究进一步考察了通信、可扩展性、鲁棒性和失败归因。结果揭示了在实体锚定和长周期执行方面持续存在的瓶颈。它还显示了依赖任务的协同权衡以及增加能力的收益递减，而更重的工作负载会进一步降低成功率。Lingjing提供了一个统一测试平台，能够在城市多智能体具身智能中实现可复现的端到端评估和系统性失效诊断。

## Abstract
Urban embodied intelligence requires coordination among heterogeneous agents (e.g., UAVs, ground robots, and autonomous vehicles) in dynamic cities. Simulators therefore provide a scalable foundation for developing and evaluating such coordination. Existing platforms nevertheless isolate different embodiments and decouple them from task design and evaluation. We present \textbf{Lingjing}, a simulation platform for heterogeneous multi-agent embodied intelligence in open-ended urban environments. Lingjing reconstructs and renders evolving cities from geographic data, synchronizes multiple physics engines, and exposes shared physical and structured urban state to agents. Its Gym-like interface supports user-defined ReAct agents and single- or multi-agent natural-language missions with configurable star or broadcast communication and resource constraints. Each episode becomes an attribution-ready replay that links agent trajectories and communication to relation-graph changes, resource consumption, and engine-based evaluations for systematic diagnosis. We evaluate twelve vision-language models on nine urban tasks under a shared engine-in-the-loop protocol. Controlled studies further examine communication, scalability, robustness, and failure provenance. Results expose persistent bottlenecks in grounding and long-horizon execution. They also show task-dependent coordination trade-offs and diminishing returns from added capacity, while heavier workloads further reduce success. Lingjing provides a unified testbed that enables reproducible end-to-end evaluation and systematic failure diagnosis in urban multi-agent embodied intelligence.

   - 同步多个物理引擎，分别适配不同智能体的动力学模型（无人机空域动力学、地面机器人运动学、车辆动力学）。

   - 类 Gym API 提供统一的观测（observation）、动作（action）、奖励（reward）接口，降低智能体接入成本。

4. **自然语言任务与多智能体协作机制**
   - 支持单智能体和多智能体自然语言任务定义。

   - 每一回合（episode）都生成为**可归因的重放（attribution-ready replay）**。

### 2.3 评估协议

- 采用 **engine-in-the-loop（引擎在环）** 的共享评估协议：所有被测模型在同一个仿真引擎控制回路中执行任务，保证跨模型比较的公平性和可复现性。

## 六、论文的主要结论与发现

1. **持久瓶颈：实体锚定（Grounding）与长周期执行（Long-horizon Execution）**
   - 所有 12 个 VLM 模型在城市任务中均暴露出感知层面的实体锚定困难（难以将语言描述与场景中具体物体/位置稳定关联），以及长任务序列中执行稳定性的下降。
2. **异构协同存在任务依赖的权衡**
   - 多智能体协同并非总是优于单智能体：某些任务中通信和协调带来收益，另一些任务中协作开销反而降低效率，呈现出**任务依赖（task-dependent）** 的特性。
3. **能力增加的收益递减**
   - 模型能力的提升带来任务成功率的提升，但边际收益逐渐递减；即从弱模型到中等模型的提升显著，从中等到强模型的增益有限。
4. **重负载显著降低成功率**
   - 更重的任务负载（更多智能体、更复杂的通信拓扑、更严格的资源约束）会进一步降低任务成功率，揭示了当前 VLM 智能体在复杂协同场景中的脆弱性。
5. **统一测试平台的价值**
   - Lingjing 提供了可复现的端到端评估和系统化失败诊断能力，是推动城市多智能体具身智能研究的重要基础设施。

## 七、优点

- **统一的异构多智能体环境**：首次在同一城市仿真中同步多物理引擎，支持空中/地面/车载多载体协同，突破现有平台载体隔离的局限。
- **端到端一体化设计**：将任务定义、智能体接入、物理仿真、评估与诊断统一在同一协议（engine-in-the-loop）中，避免了任务与评估脱节问题。
- **自然语言驱动的任务接口**：Gym 风格接口 + 自然语言任务 + ReAct 智能体支持，有效对接大模型时代的智能体开发范式。
- **可归因的失败诊断**：归因回放机制将轨迹、通信与关系图变化和资源消耗关联起来，实现了系统化的失败溯源分析，这是多数仿真平台不具备的能力。
- **受控实验设计严谨**：对通信拓扑、扩展性和鲁棒性进行了变量隔离研究，揭示了协同权衡和规模效应的非平凡结论。
- **真实地理数据重建**：利用地理数据构建开放城市环境，比人工设计的合成场景更具生态效度。

## 八、不足与局限

- **基准对比不足**：缺乏与现有主流仿真平台（如 Habitat、MuJoCo、AirSim、MetaUrban 等）的直接定量对比，无法定位 Lingjing 的绝对优势边界。
- **模型覆盖面有限**：仅评估了 VLM 智能体，未覆盖经典规划算法、强化学习基线，也无法判断 Lingjing 对非学习方法的支持程度。
- **算力披露缺失**：未说明模型推理所需的 GPU 资源和耗时，影响实验可复现性和成本评估。
- **统计严谨性不足**：缺少多次随机种子的方差报告、显著性检验等统计学细节。
- **地理数据泛化性未验证**：城市重建依赖地理数据源，不同城市、不同数据质量下的表现是否稳定未见消融分析。
- **物理仿真的精度上限**：多物理引擎同步方案虽实现了载体统一，但每个引擎的物理保真度可能存在上限，对于高精度操作类任务的支撑力有待验证。
- **任务复杂度仍需扩展**：9 个任务虽然覆盖多种能力，但相比真实城市任务的无限开放性，任务类型仍相对有限。
