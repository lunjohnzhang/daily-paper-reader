## 摘要
自动化高密度存储系统（仓库、机器人停车场、工厂物流等）需要由多智能体组成的车队在稀缺的关键任务资源之间穿梭，然后停放，且不影响未来操作。我们提出了一种名为“枢轴与站点多智能体路径搜索”(PS-MAPF)的MAPF变体，其中一部分被分配任务的智能体必须各自访问一组可互换枢轴中的某一个（例如，工作站），然后整个车队终止于匿名站点，每个站点停放一个智能体。我们完整刻画了可解性：在2-边连通图上的每个实例都是可解的，而在任意连通图上，相对于未占据顶点数量的结构性有效距离度量给出了一个充要条件。我们证明了即使只有一个枢轴，最小化站点完工时间或站点流经时间也是NP困难的。我们提出了三种算法：一个完整的基线算法、一个基于SAT的最优求解器，以及枢轴优先规划（PPP），后者在74-89%的基准实例上求解，且完工时间和流经时间比基线低数个数量级。

## Abstract
Automated high-density storage systems (warehouses, robotic parking, plant logistics, etc.) require fleets of agents to move through scarce task-critical resources and then park without obstructing future operations. We introduce Pivot-and-Station Multi-Agent Path Finding (PS-MAPF), a MAPF variant in which a subset of tasked agents must each visit one of a set of interchangeable pivots (e.g., workstations) before the entire fleet terminates at anonymous stations, one agent per station. We characterize solvability completely: every instance on a 2-edge-connected graph is solvable, and, on arbitrary connected graphs, a structural effective-distance measure relative to the number of unoccupied vertices gives a necessary and sufficient condition. We prove that minimizing station-makespan or station-flowtime is NP-hard already with a single pivot. We present three algorithms, a complete baseline, a SAT-based optimal solver, and Pivot-Prioritized Planning (PPP), the last solving 74-89% of benchmark instances with makespan and flowtime orders of magnitude below the baseline.

## 1. 核心问题与整体含义（研究动机）

- **背景**：在自动化高密度存储系统（Ocado、Amazon Sequoia 等）中，大量智能体需要在固定轨道/网格拓扑上移动，一部分"任务型智能体"必须访问某个关键资源（称为 **pivot**，如工作站、取货点、充电桩），之后与其余"非任务型智能体"一起停到若干匿名 **站点**（每个站点停一个智能体）。
- **问题**：现有 MAPF 变体（Anonymous MAPF、TAPF、MCPF 等）没有同时兼顾"访问可互换中间资源"与"匿名终点"以及"任务/非任务智能体"的区分，因此不能直接刻画此类仓储协调问题。
- **论文贡献**：提出 **PS-MAPF** 新问题；给出可解性的完整刻画；证明最优求解的 NP-hard 性；提出三种算法（完备基线、SAT 最优求解器、快速启发式 PPP），并通过实验验证。

## 2. 方法论

### 2.1 问题形式化
- 输入为一个无向连通图 \(G=(V,E)\)、枢轴集 \(P\)、站点集 \(S\)、任务型智能体 \(A_t\)、非任务型智能体 \(A_u\) 及初始位置 \(o\)。
- 任务型智能体必须先访问任一 pivot，再到达站点；非任务型智能体可直接去站点；所有路径需无顶点冲突和交换冲突。
- 优化目标为 **station-makespan**（最晚停站时间）和 **station-flowtime**（所有智能体停站时间之和）。

### 2.2 可解性刻画
- **2-边连通图充分性**：若每个任务型智能体与其某个 pivot 之间存在两条边不相交路径（即 2-边连通），则该实例必有解（Theorem 1）。
- **一般连通图的充要条件**（Theorem 2）：
  - 引入"p-adapted configuration"：把所有未占据顶点集中成一个包含 pivot 的连通区域。
  - 对每个任务型智能体 \(i\)，定义 **有效距离** \(d^p_{eff}(o(i))\)，它由 2-边连通分量压缩树中非平凡/分支分量之间的最大距离再加上修正项得到。
  - 智能体 \(i\) 能在可行运动中到达 pivot \(p\)，当且仅当 \(d^p_{eff}(o(i)) \le |V|-|A|\)（即未占据顶点数足够）。
  - 实例可解，当且仅当每个任务型智能体都存在某个 pivot 及可达的 p-adapted 配置满足该条件；该条件可在多项式时间内检查。
- **良构（well-formed）充分条件**：每个任务型智能体有一条到 pivot 的路径，路径上除自身起点外不被其他智能体占据，则该实例必可解。

### 2.3 复杂度
- 通过从 3SAT 构造单 pivot 实例（变量智能体对应上/下路径，子句智能体连接相应字面量路径），证明：
  - 最小化 **station-makespan** 是 NP-hard（Theorem 3）；
  - 最小化 **station-flowtime** 也是 NP-hard（Theorem 4）；
  - 对比：无 pivot 的 PS-MAPF 退化为 Anonymous MAPF，是多项式可解的，因此"一个 pivot 访问约束"即可导致问题难度跃升。

### 2.4 算法
- **BA（基线算法，完备）**：来自可解性证明的构造性过程。按顺序对每个任务智能体做 pivot 路由（利用 2-边连通分量、holes 移动、反转运动回卷），完成所有 pivot 访问后，用匿名 MAPF 流方法分配站点。时间复杂度 \(O(|A_t| n^3) \le O(n^4)\)，但解质量很差。
- **PPP（Pivot-Prioritized Planning，不完备但快）**：
  - Phase 1：按优先级顺序用 Space-Time A* 为任务型智能体规划到 pivot 的路径，并通过时空预约表避免冲突。
  - Phase 2：将剩余匿名问题建模为时间扩展图上的最大流，把所有智能体送往站点。
  - 复杂度 \(O(n^4 m)\)，返回解一定可行；可能因 Phase 2 流失败而整体失败。
- **SAT 最优求解器**：
  - 采用"匿名化"编码：用"面向 pivot 状态 (P)"与"面向站点状态 (S)"两类布尔变量表示任意智能体，避免依赖智能体数量。
  - 约束包括顶点唯一、边交换约束、流量守恒、状态转换、初始/终止条件；公式 \(\Phi(T)\) 可满足当且仅当存在 station-makespan ≤ T 的解。
  - 配合 CP-SAT 求解器，并用 Theorem 6 的 **下界**（按 pivot 距离排序 + pivot 容量瓶颈）减少 UNSAT 搜索轮次。

- **大规模 benchmark（PPP vs BA）**：

  - 每张地图生成 200 个良构实例，pivot 数量 ∈ {1,5,10,20,30}，任务型比例 ∈ {10%,25%,50%,75%,100%}，智能体数量从 1% 到上限（150/170/340）。

- **实验数量较丰富**：小规模最优实验覆盖智能体密度、任务比例、pivot 密度、障碍物、站点密度、网格尺寸等多个参数；每个配置生成 10–20 个实例；大规模 benchmark 每张地图 200 个实例。

- **不足之处**：缺少更系统的消融实验（如对 BA 内部子步骤的单独验证）；未报告标准方差或统计显著性；对于失败实例的分析较定性；PPP 与 SAT 在不同实例集上的严格公平性（如 SAT 只跑小规模、PPP 只跑大规模）仍可进一步加强。

## 6. 主要结论与发现

- **可解性**：2-边连通图上的 PS-MAPF 一定可解；一般连通图上可由基于有效距离的充要条件在多项式时间内判定。
- **复杂度**：单 pivot 下最小化 station-makespan 与 station-flowtime 均 NP-hard。
- **算法表现**：
  - BA 完整但在大规模实例上极慢且解质量差（仓库实例平均运行 282 秒，makespan 高达 23933）。
  - PPP 在 74–89% 的基准实例上成功，比 BA 快 2 倍以上（仓库实例约 138 秒），makespan 和 flowtime 低 **数个数量级**（如 makespan 从 23933 降到约 90）。
  - 优先级排序中 **MC（冲突最多优先）** 综合最强，在密集地图和成功率上表现最好。
  - SAT 最优求解器在 16×16 小网格上效率高，但随规模增大（如 28×28 以上）成功率下降；下界整体较紧，但实例子集间差异较大。

## 7. 优点

- **理论贡献完整**：同时给出可解性的充分条件（2-边连通）、一般图充要条件及多项式时间检查方法，并刻画了复杂度跃升的临界点（单 pivot 导致 NP-hard）。
- **问题建模贴近实际**：明确区分任务型/非任务型智能体，并将 pivot 与站点均设为匿名、可互换，符合作业型仓储场景。
- **算法组合有层次**：完备基线、最优 SAT、快速启发式 PPP 相互补充，体现"理论构造 — 最优求解 — 实用近似"的完整研究路线。
- **匿名化编码有亮点**：用"pivot-oriented/station-oriented"状态变量消除对智能体数量的依赖，使 SAT 编码适合高密度场景。
- **实验覆盖了多参数和多 benchmark**，并公开代码与数据生成脚本，可复现性强。

## 8. 不足与局限

- **PPP 不完备**：在极端瓶颈场景（pivot 数 1–5、任务型比例 75–100%）会因 Phase 2 流量分配失败而失败，缺少失败时的回退机制。
- **SAT 可扩展性有限**：最优求解主要限于 16×16 至 28×28 网格；更大仓库或更高密度场景难以在 60 秒内求解。
- **一般图可解性判定的"非完全显式"**：需要先构造 p-adapted 配置，再检查有效性，虽然多项式算法可实现，但表达上不如单一条件直观。
- **实验偏差风险**：大规模实例只使用 well-formed 实例，可能回避了可解但非良构的难例；随机实例生成的种子、参数选择可能存在隐性偏差。
- **实际应用限制**：未考虑 typed pivots（多类 pivot）、智能体异构性、动态任务到达、通道容量（lift/conveyor）等更复杂约束；也未讨论在线/终身调度问题。
- **个性化目标不足**：当前目标只考虑站点的 makespan/flowtime，未直接优化等待时间、能耗或枢轴排队长度。
