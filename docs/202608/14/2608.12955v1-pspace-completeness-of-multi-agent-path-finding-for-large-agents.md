## 摘要
面向大型智能体的多智能体路径查找（LA-MAPF）是MAPF的一种几何变体，其中智能体被建模为圆盘，冲突由底层欧几里得工作空间中的物理重叠决定。LA-MAPF的目标是判断是否存在从起始配置到目标配置的无冲突转移序列。Agafonov和Yakovlev证明了LA-MAPF是NP难的。在本文中，我们通过从受限滑动令牌（Restricted Sliding Tokens）进行多项式时间归约，证明了LA-MAPF是PSPACE完备的，从而加强了他们的结果。

## Abstract
Multi-Agent Path Finding for Large Agents (LA-MAPF) is a geometric variant of MAPF in which agents are modeled as disks and conflicts are determined by physical overlap in the underlying Euclidean workspace. The goal of LA-MAPF is to decide whether there exists a sequence of conflict-free transitions from a start configuration to a goal configuration. Agafonov and Yakovlev proved that LA-MAPF is NP-hard. In this paper, we strengthen their result by proving that LA-MAPF is PSPACE-complete via a polynomial-time reduction from Restricted Sliding Tokens.

## 1. 核心问题与整体含义（研究动机和背景）
- **背景**：经典多智能体路径查找（MAPF）将智能体抽象为无体积的点，冲突是组合式的。但在真实机器人应用中，智能体具有物理体积，因此需要更贴近实际的几何模型。
- **研究对象**：LA-MAPF（MAPF for Large Agents）将智能体建模为半径为 r 的圆盘，冲突判定基于欧几里得空间中圆盘扫掠出的连续区域是否重叠。当智能体沿边移动时，其扫掠区域可能威胁到位于其他顶点上的静止智能体，这种连续空间冲突是 LA-MAPF 的核心计算难点。
- **已知结果**：Agafonov 和 Yakovlev 通过从 3-SAT 归约证明了 LA-MAPF 是 NP-hard，但精确复杂度（是否属于 PSPACE）此前未定。
- **本文贡献**：通过从已知 PSPACE-complete 的 **Restricted Sliding Tokens（受限滑动令牌）** 问题进行多项式时间归约，证明 **LA-MAPF 是 PSPACE-complete**，从而彻底解决了其计算复杂度问题。此外还证明更强的版本：即使底层图为平面图且所有智能体仅沿水平和垂直方向移动，LA-MAPF 依然是 PSPACE-complete。

## 2. 方法论：核心思想、关键技术细节、算法流程（文字说明）
- **整体思路**：将任意 Restricted Sliding Tokens 实例转换为等价的 LA-MAPF 实例，使得前者存在合法滑动序列当且仅当后者存在无冲突规划。
- **核心思想**：利用 LA-MAPF 的几何重叠约束来模拟独立集约束。参考晶格路径、正交图绘制等概念，设计“单孔”导线（wire）机制，以极少的智能体在稀疏导线中传递冲突约束。
- **关键步骤与技术细节**：
  1. **构造宏图 H**：将原图中的“令牌三角形”（token triangles）收缩为宏顶点（macro-vertex），令牌边（token edges）保留为两个端口顶点（port vertices）间的边，链接边（link edges）不变。
  2. **正交嵌入**：利用 Biedl–Kant 的正交图绘制算法将 H 嵌入到 |V_H| × |V_H| 网格中，每条边最多有两个折点；再将网格按 Λ = 100r 均匀缩放，确保不同组件之间距离足够大。
  3. **令牌三角形装置（token triangle gadget）**：将原三角形的三个端口映射到四个局部顶点（pX,1、pX,2、pX,3、pX,t），并放置三个外部阻塞顶点（B X,ℓ）。通过精心调整距离（如 1.75r、2.5r 等），使得 v-agent 在某一端口时能“物理屏蔽”对应的阻塞顶点，从而模拟令牌三角形内一个令牌只能占据一个端口且端口之间互斥的约束。
  4. **令牌边装置（token edge gadget）**：令牌边的正交电线包含不超过四个顶点（两个端口和至多两个折点），放置恰好少一个的 v-agent，从而整个电线始终存在一个“空位”（hole）。通过空位的级联移动来模拟令牌在两端点之间的滑动。
  5. **链接边导线（link edge wire）**：每条链接边对应一条由阻塞顶点、中间折点和另一阻塞顶点组成的电线，同样安置少一个的 b-agent，保证一个空位。关键不变量是：如果一端端口被 v-agent 占据，则该端的阻塞点必须是空位，从而强制另一端阻塞点被 b-agent 占据，进而阻止另一端口被 v-agent 占据，实现独立集约束。
  6. **映射与反向模拟**：给定 LA-MAPF 无冲突规划，通过端口占用状态映射回 Restricted Sliding Tokens 的令牌配置；反之，将令牌滑动分解为导线上的 agent 逐步移动序列，提供无冲突规划。
