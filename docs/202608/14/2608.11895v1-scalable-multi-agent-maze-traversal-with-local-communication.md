## 摘要
洞穴网络、管道系统以及类似的迷宫环境对未知环境下通信受限的多智能体导航构成了重大挑战。我们提出了一种分布式算法，使智能体能够集体遍历一个未知的、可能循环的图。智能体在指定的起始节点依次进入，任务是在避免碰撞的同时定位并到达一个未公开的目标。它们通过局部通信，利用领导者-跟随者关系和领导者切换进行协调。在任何时刻，仅由一个智能体执行探索，该智能体运行单智能体迷宫求解器。我们证明了该算法的完备性，其最大完工时间（以智能体数量计）渐近等价于最优全知识策略，并推导了其时间和空间复杂度。使用多达625个智能体的仿真表明，随着智能体数量的增加，平均总燃料消耗呈下降趋势，并证明所提方法优于所有智能体独立执行单智能体求解器的简单基线方法。

## Abstract
Cave networks, pipe systems, and similar maze-like environments pose significant challenges for multi-agent navigation in unknown settings with limited communication. We propose a distributed algorithm that enables agents to collectively traverse an unknown, possibly cyclic graph. Agents enter sequentially at a designated start node and are tasked to localize and reach an undisclosed goal while avoiding collisions. They coordinate via local communication using leader-follower relationships and leader switching. At any moment in time, exploration is performed by only one of the agents, which runs a single-agent maze solver. We prove that the algorithm is complete, that its makespan is asymptotically equivalent (in the number of agents) to that of an optimal full-knowledge strategy, and derive its time and space complexity. Simulations with up to $625$ agents show a decreasing average sum-of-fuels as the number of agents increases and demonstrate that the proposed approach outperforms a naïve baseline in which all agents independently execute the single-agent solver.

### 2. 方法论：核心思想与关键技术细节

- **核心思想**：
  - 任一时刻仅有一个“头”智能体（head）执行单智能体迷宫求解器进行探索，其他智能体作为“跟随者”（followers）沿领导者链间接跟随头。
  - 通过局部消息（两跳通信、消息不可穿过被占节点）协调移动，使用**领导者-跟随者关系**和**领导者切换**来保持 swarm 连通性并避免碰撞。
- **算法流程（Algorithm 1）**：
  1. **初始化**：所有智能体在起点 s 依固定顺序激活；首个激活者成为头，后续激活者收到前一个离开起点的智能体的状态消息，将其设为领导者。
  2. **每时间步循环**：
     - **决策**：
       - 头智能体：若目标相邻则直接移向目标；否则调用单智能体迷宫求解器得到候选节点；若该节点被占用，则占用者成为新头；若空闲则广播方向性消息并移动。
       - 非头智能体：调用 `ResolveConflict` 决定移动目标或更新领导者；可能在无冲突时竞争移动至领导者上一步所在节点；竞争通过确定性 Selector 选出唯一胜者，败者转为跟随胜者。
     - **同步移动**：所有活跃智能体同步移动到各自目标节点。
     - **移动后感知与通信**：智能体发送方向性消息（告知上一位置）和状态消息，更新通信范围。
- **关键机制**：
  - 三种广播消息：状态消息、竞争消息、头消息。
  - 定向投递（directed cast）沿单条边传播，用于通知后续智能体领导者的“上一步位置”。
  - 领导者切换发生在头发现目标节点被其他智能体占用时，或竞争失败者选择胜者为新领导者。
- **理论结果**：
  - **完备性**：若底层单智能体求解器完备，则所有智能体必定在有限时间内到达目标（Theorem 1）。
  - **渐进最优性**：在智能体数量 n 趋于无穷时，算法的 makespan 与“全知最优策略”的比趋近于 1（Theorem 2）。
  - **无碰撞**：算法保证不会出现顶点冲突和跟随冲突（Corollary 1）。
  - **复杂度**：
    - 空间复杂度：`O(d·min(n, d²))` 加上单智能体求解器的额外开销（如 Trémaux 为 `O(E)`，BFS 为 `O(V)`）。
    - 时间复杂度：使用 Trémaux 算法时 `O((E + n)·min(n, d²))`；使用 BFS 时 `O(((V+E)² + n)·min(n, d²))`；随机游走期望 `O((V³ + n)·min(n, d²))`；其中 d 为图最大度。
