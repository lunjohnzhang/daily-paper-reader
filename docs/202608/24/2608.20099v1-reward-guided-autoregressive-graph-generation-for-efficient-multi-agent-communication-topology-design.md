## 摘要
基于LLM的多智能体系统（MAS）通过协调多个智能体在复杂推理任务上取得了强劲的性能，但代价是大量的token消耗。最近关于自动拓扑设计的工作ARG-Designer将这个问题重新定义为自回归图生成。然而，其训练目标并没有为模型生成稀疏且高效的拓扑提供明确的激励。我们通过引入受人类反馈强化学习（RLHF）启发的奖励引导自回归图生成（RGA-Designer）来解决这一限制。我们训练了一个奖励模型，同时捕捉任务正确性和结构紧凑性，然后使用奖励模型作为反馈对预训练的图生成器进行微调。我们的方法在保持ARG-Designer级别的任务准确性的同时，平均减少了20.5%的token消耗。

## Abstract
LLM-based Multi-Agent Systems (MAS) achieve strong performance on complex reasoning tasks by coordinating multiple agents, but at the cost of substantial token consumption. Recent work on automatic topology design, ARG-Designer, has reframed this problem as autoregressive graph generation. However, its training objective provides no explicit incentive for the model to generate sparse and efficient topologies. We address this limitation by introducing a Reward-Guided Autoregressive Graph Generation (RGA-Designer) inspired by Reinforcement Learning from Human Feedback (RLHF). We train a reward model that jointly captures task correctness and structural compactness, and then fine-tune the pretrained graph generator using the reward model as feedback. Our method preserves task accuracy at the level of ARG-Designer while reducing token consumption by an average of 20.5%.

### 2.1 核心思想

- 借鉴 RLHF / RLVR（Reinforcement Learning with Verifiable Rewards）框架，训练一个**图级奖励模型**，同时衡量任务正确性和结构紧凑性；再用该奖励模型作为反馈信号，通过策略优化微调预训练的 ARG-Designer 图生成器，引导其生成稀疏且有效的拓扑。

### 2.2 总体流程（三个阶段，外加预训练阶段）

1. **预训练生成器（阶段 0）**：继承 ARG-Designer 的预训练自回归图生成模型 πθ，作为策略优化的初始化。
2. **数据集收集（阶段 1）**：
   - 使用预训练的 ARG-Designer 以不同采样温度生成多个候选图，并在 MAS 上执行，记录是否完成任务（正确/失败）。
   - 同时整合 ARG-Designer 训练阶段已有的（query, graph）对，零额外成本扩充数据。
   - 每条样本表示为 `(G, q, r)`，其中 r 由式 (8) 计算：
     \[
     r = \lambda_c c + \lambda_V \max(0, \frac{V_{max} - |V|}{V_{max}-1}) + \lambda_E \text{clip}(0,1, \frac{E_{max} - |E|}{E_{max} - E_{min}})
     \]
   - 权重设置为 λc=0.6（任务完成优先），λV=0.3（智能体数），λE=0.1（边数），保证正确性优先于稀疏性。
   - 据此构建偏好对，条件：至少一个样本成功完成任务，且奖励差 > δ（0.05）。
3. **奖励模型训练（阶段 2）**：
   - 奖励模型 rθ 为图神经网络（GraphSAGE），对图结构 + 任务语义进行编码。
   - 节点特征由三部分拼接（式 10）：角色嵌入 z_ri（384 维）、查询嵌入 z_q（384 维）、结构特征 φi（5 维：图大小、边数、生成顺序位置、入度、出度）。
   - 经 2 层 GraphSAGE + 残差 + LayerNorm，全局平均池化后由 MLP 输出标量奖励。
   - 使用 **Bradley-Terry 成对排序损失**训练，并对 pass/pass 对降权（λp,p=0.1），因为这类对只含结构大小信息，约占数据的 80–90%。
4. **策略优化（阶段 3）**：
   - 采用 **GRPO**（在线策略，组相对策略优化）。对每个查询采样一组 G 个图，按式 (14) 计算组内相对优势：
     \[
     \hat{A}_i = \frac{\hat{r}_i - \mu_r}{\max(\sigma_r, \sigma_{min})}
     \]
   - 优化目标（式 15）为最大化优势 + KL 正则（控制与参考模型 π_ref 的偏离），β=0.2。因每次更新时重新采样，GRPO 的剪枝项可省略（重要性比 ρ=1）。

## 6. 论文的主要结论与发现

本节详细阐述了论文的主要结论与发现。

- **RGA-Designer 在保持任务精度的同时显著降低 token 消耗**：6 个基准上平均减少 **20.5%** 的 token 使用量（vs. ARG-Designer），其中 5 个基准达到统计显著（MultiArith 例外）。
- **精度无显著退化**：多数基准上精度有微幅提升（如 GSM8K、HumanEval、MMLU），且 t 检验显示所有精度差异均不显著，说明稀疏化没有以牺牲正确性为代价。
- **MultiArith 唯一不显著的原因**：该数据集由模板生成、语言变化小，简单拓扑即可解决，几乎没有冗余可压缩。
- **额外益处**：奖励模型在嵌入空间中评分，可跨数据集复用训练数据。不同于 ARG-Designer 需要为新增角色扩展分类头并重训，RGA-Designer 的奖励模型可以接受未见过的角色，无需修改架构。

## 7. 优点

- **方法创新**：首次将 RLHF/RLVR 范式系统性地应用于自回归图生成领域，为 MAS 拓扑设计提供了一种显式的"正确性 + 紧凑性"联合优化机制。
- **奖励设计合理**：层次化权重（0.6/0.3/0.1）确保正确性优先于稀疏性，避免为省 token 而牺牲任务完成度；基于可验证规则而非人工标注，成本低、可扩展。
- **奖励模型的跨数据集泛化能力**：由于编码的是语义 + 结构空间而非离散角色 ID，训练数据可跨基准复用，有新角色时可零成本适应，比 ARG-Designer 更灵活。
- **实验验证严谨**：10 次重复 + Welch t 检验 + 消融实验，统计证据充分；与 5 种基线（含 4 种 MAS 方法）系统对比，覆盖面良好。
- **实际价值明确**：平均 token 减少 20.5%，对大规模部署 LLM-MAS 的推理成本优化有直接、可量化的收益。

## 8. 不足与局限

- **LLM 骨干单一**：仅使用 Qwen3-4B；换用其他 LLM 后，由于候选图的成功/失败标签依赖于特定底层模型，需要**重建整个训练数据集**，成本较高。异构 MAS（不同智能体用不同 LLM）也不受支持。
- **依赖可验证的 ground-truth 标签**：方法仅适用于有明确可验证答案的任务（如代码、多选题、数学题），对开放式、无客观答案的任务不适用。
- **全局奖励模型的潜在偏差**：统一奖励模型虽便于复用，但不同数据集的任务性质差异大（数学 vs. 代码 vs. 常识），单一模型可能对某些任务类型的结构偏好建模不佳。
- **MultiArith 不显著**：说明方法的收益依赖于任务的数据多样性，对于模板化、低冗余任务增益有限。
- **Best-of-N 的额外开销**：推理时需要采样 N=5 个候选图并让奖励模型打分，虽然论文认为相对 LLM 调用开销可忽略，但实际延迟仍有增加（尤其高吞吐场景）。
- **未报告计算资源细节**：未明确给出训练时长、GPU 数量等，难以精确评估方法的训练成本。

## 9. 文中未明确提及、但值得关注的问题

- **n 值（Best-of-N）的灵敏度**：论文固定 N=5，未报告不同 N 下精度和 token 消耗的权衡曲线；N 增大可提升精度但增加开销。
- **奖励模型评估的可靠性**：奖励模型为 learned surrogate，其评分与真实执行结果的吻合度未单独评估；若高估某些稀疏结构，可能造成策略偏差。
- **数据偏差风险**：偏好对中的"成功"样本受到采样温度影响，若采样策略覆盖不足，可能使奖励模型对图结构空间的某些区域缺乏区分能力。
