## 摘要
我们提出了一种结构化的大语言模型（LLM）架构，用于在具有私有目标视图的合作构建任务中实现零样本人机协调。在Dec-POMDP公式的指导下，该架构将决策分解为（i）基于动作的条件化心智理论（ToM）推理，（ii）分层规划，（iii）对话解释，（iv）动作验证，以及（v）基于反馈的重新规划。我们将所提方法与无ToM推理的消融实验以及离线在多个目标对上训练的多智能体强化学习策略进行了比较。在人类参与者实验中，所提方法相比两种基线方法需要更少的交互步骤，并产生更高的交互后信任评级。这些结果表明，系统地分解团队决策问题，使用LLM作为难以处理的推理和规划计算的易处理替代品，并保留传统验证以确保物理可行性，可以改善任务协调和人类体验。

## Abstract
We present a structured large-language-model (LLM) architecture for zero-shot human--robot coordination in a cooperative construction task with private goal views. Guided by a Dec-POMDP formulation, the architecture decomposes decision-making into (i) action-conditioned Theory-of-Mind (ToM) inference, (ii) hierarchical planning, (iii) conversation interpretation, (iv) action verification, and (v) feedback-based replanning. We compare the proposed method with an ablation without ToM inference and a multi-agent reinforcement-learning policy trained offline over many goal pairs. In human-participant experiments, the proposed method required fewer interaction steps and yielded higher post-interaction trust ratings than both baselines. These results suggest that systematically decomposing the team decision problem, using LLMs as tractable surrogates for otherwise intractable inference and planning computations, and retaining conventional verification for physical feasibility can improve both task coordination and the human experience.

### 研究动机
- **核心问题**：在人机协作场景中，人类和机器人各自持有**私有目标视图**（private goal views），双方无法直接获取对方的任务目标，导致零样本协调（zero-shot coordination）困难。
- **背景**：这类问题可形式化为**去中心化部分可观测马尔可夫决策过程（Dec-POMDP）**，但精确的推理与规划计算在计算上不可解。
- **关键契机**：大语言模型（LLM）具备日益强大的推理能力，可作为不可解计算的高效替代品，同时保留传统规则化机制处理需要精确验证的部分。

### 整体含义
- 本文主张一种**混合架构**思路：用 LLM 做语义推理、高层规划、意图推断；用传统规则验证器确保物理可行性。二者结合，既能提升任务协调效率，也能改善人类对机器人的信任体验。
- 该研究的意义在于：**系统性地将团队决策问题分解**，使 LLM 在复杂人机协作任务中发挥作用，而非仅作为端到端黑箱。

## 2. 论文提出的方法论

### 任务建模：La Boca 构建任务
- 工作空间为离散三维网格 W = {1,2,3,4}³，团队有 9 块不同形状与颜色的积木。
- 人类与机器人各持有一张**私有二维目标投影图**，二者视角不同。最终结构须同时满足两个视角的投影，且用完所有积木。
- 动作定义：放置/移除/等待，包含积木选择、锚点坐标与朝向。动作须满足边界、碰撞、支撑等物理可行性约束。
- 交互为**轮流制**，双方可发送自然语言消息。

### Dec-POMDP 公式化
- 状态包含：物理构建状态、人类私有目标、机器人私有目标、当前行动方。
- 团队目标为最大化期望累积奖励（完成任务奖励 + 交互步数惩罚 + 无效动作惩罚）。
- 机器人维护对候选人类目标的后验信念 bᴴₜ(g)，通过贝叶斯更新。

### 核心架构：结构化 LLM 协调框架

**五大核心模块**：

1. **分层 LLM 规划器（Hierarchical LLM Planner）**
   - **高层规划器**：根据当前状态、机器人目标、人类目标信念、交互历史，选择中间子目标（subgoal），输出意图、子目标描述与理由。
   - **低层规划器**：将子目标转化为具体候选动作（操作类型、积木、占用的网格单元）。

2. **规则化动作验证器（Rule-Based Action Verifier）**
   - 以 Python 函数检查物理可行性：积木可用性、边界、碰撞、支撑等。
   - 返回 `(valid, ∅)` 或 `(invalid, failure_reason)`，拒绝不可行动作并给出结构化失败解释。

3. **基于反馈的重规划器（Feedback-Based Replanner）**
   - 当候选动作被验证器拒绝后，根据失败原因修订动作，保留高层子目标，重新提交验证，直至通过。

4. **基于动作的条件化心智理论模块（LLM-Based ToM Module）**
   - 对每个候选人类目标，LLM 生成该目标下的人类行为预测，再与观测到的人类动作历史进行一致性比较，得到兼容度评分，进而更新信念分布。
   - 该方法提供了**人类行为的近似前向模型**，无需为每个候选目标单独求解最优策略。
   - 信念随人类动作与消息持续更新，同时影响规划器与对话模块。

5. **对话模块（Conversation Module）**
   - 语音 → 文本（gpt-4o-mini-transcribe）→ 信息提取（gpt-4.1-nano）→ 结构化任务信息 → 机器人生成回复（文本 → TTS 语音）。
   - 支持澄清请求、解释、子目标沟通、应答提问、协商冲突提案等。
   - 对话中提取的信息可触发计划更新或新动作提案；人类的具体放置建议经评估后可被接受、修改或拒绝，且最终动作仍须经过规则验证器。

- **参与者**：5 名研究生（25–30 岁），每人完成 3 种条件下的任务。

### 仿真实验
- 额外进行 3 种配置的仿真：RL/RL、LLM/RL、LLM/LLM，各 10 个 episode，上限 15 步。

## 6. 论文的主要结论与发现

1. **LLM+ToM 交互效率最高**：平均交互步数 5.2，优于 LLM 消融（6.4）和 RL（10.2）。
2. **LLM+ToM 信任评分最高**：平均 84.9（交互后），高于 LLM 消融的 81.1，且远高于 RL 的 57.1（比交互前基线 68.6 还低）。
3. **ToM 推理有效**：正确目标的平均信念概率随 ToM 更新而递增，表明模块能逐步推断人类真实目标。
4. **RL 面临可解释性与信任挑战**：尽管 RL 使用了动作掩码保证可行性，但行为仍让参与者难以理解，导致多数人中途放弃。
5. **结构化分离有效**：将语义推理与物理验证分离，让 LLM 专注于高层推理，规则验证器保障底层可行性，是架构成功的关键。
6. **仿真结果对比鲜明**：LLM/LLM 成功率达到 60%（12 步），LLM/RL 为 0%（15 步超限失败），RL/RL 为 100%（平均 5 步）——说明 LLM 与 RL 策略之间的行为不匹配问题是严重的，在 LLM/RL 混合配置中几乎完全失效。

## 7. 优点

### 方法论亮点
- **理论指导明确**：以 Dec-POMDP 为理论基础，将难以处理的贝叶斯信念更新与规划问题映射为 LLM 可执行的近似计算，理论动机清晰。
- **模块化解耦设计**：将 ToM 推理、分层规划、对话处理、验证、重规划五种能力整合于统一框架，各模块职责清晰、可替换、可解释。
- **人机交互友好性**：显式维护人类目标信念、当前子目标和验证反馈，使得系统行为可解释、可事后分析，也便于人类参与对话协商。
- **安全性保障**：规则化验证器作为物理可行性底线，不依赖 LLM 对精确动作集合的表征能力，避免了 LLM 幻觉导致的不可行动作。
- **创新性评估**：同时对比了缺少 ToM 的 LLM 基线和多智能体 RL，能够相对清楚地将 ToM 贡献与 LLM 基础能力分离。

### 实验设计亮点
- 主客观指标兼顾，信任问卷采用标准化量表。
- ToM 改进过程有直接可视化评估（信念随观测更新的曲线），验证机制层面的有效性。

## 8. 不足与局限

### 实验覆盖不足
- **样本量过小**：仅 5 名参与者，属于试点（pilot）研究的规模，个体差异可能主导结果。
- **任务单一**：仅在单一三维网格构建任务中验证，无法判断方法在更大规模、更复杂任务上的表现。
- **RL 数据不完整**：4/5 的 RL 轨迹为参与者主动终止，意味着 RL 的“平均步数”并非完成任务的步数，与 LLM 条件的比较不够公平。

### 偏差风险
- **RL 条件比较劣势**：RL 是离线训练并在新任务上直接部署，本质上可能不是最优的 RL 基准。选择训练不足或任务分布不匹配的 RL 策略作对比，可能低估 RL 方法的潜力。
- **LLM 模型选择**：使用了较便宜的 GPT-5.4 nano 模型，更强的模型可能提升所有 LLM 条件的效果，但也可能缩小或放大条件间差异。
- **报告偏差**：未报告方差分析与统计显著性检验，结论强度有限。

### 应用限制
- 零样本协调的前提假设是人类的行为模式在 LLM 的隐式先验范围内；遇到非常规合作策略时，ToM 推理可能失效。
- 该方法严重依赖外部 LLM API，存在延迟、成本、隐私方面的实际工程限制。
- 当前验证规模下的结果不宜直接推广到大规模或安全关键场景。
