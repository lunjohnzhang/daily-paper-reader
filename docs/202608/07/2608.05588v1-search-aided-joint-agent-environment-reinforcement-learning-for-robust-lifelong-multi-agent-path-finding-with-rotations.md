## 摘要
终身多智能体路径搜索（LMAPF）要求在智能体到达当前目标后不断接收新目标时，反复为其规划无碰撞路径。尽管已有许多基于学习的规划器被提出用于LMAPF，但大多数依赖过于简化的运动学假设，可能忽视对现实世界性能至关重要的运动约束。在本工作中，我们研究了一个更现实的LMAPF模型，该模型源自许多现实世界的自动化仓库系统，称为LMAPF-R2，它结合了鲁棒安全约束和原地旋转约束。这些约束显著增加了协调难度，尤其是在高度受限的空间中。为了应对这些挑战，我们提出了搜索辅助联合强化学习（SJRL）。我们首先使用Causal PIBT增强神经策略，这是一种基于单步搜索的规划器，用于解决智能体的碰撞并传播其意图。然后我们引入了一个统一的强化学习公式，联合优化智能体和环境策略，其中环境策略学习图边代价，通过反向Dijkstra搜索提供全局运动指导。实验表明，SJRL在多个高密度地图上相对于强大的基于搜索的规划器Causal-PIBT取得了显著改进。我们进一步在具有8个物理机器人和248个虚拟机器人的具有挑战性的混合现实仓库环境中验证了SJRL。

## Abstract
Lifelong Multi-Agent Path Finding (LMAPF) requires repeatedly planning collision-free paths for agents that continuously receive new goals upon reaching their current ones. While many learning-based planners have been proposed for LMAPF, most rely on oversimplified kinematic assumptions that may overlook motion constraints critical to real-world performance. In this work, we study a more realistic LMAPF model derived from many real-world automated warehouse systems, termed LMAPF-R2, which incorporates robust safety constraints and in-place rotation constraints. These constraints substantially increase coordination difficulty, particularly in highly constrained spaces. To address these challenges, we propose Search-Aided Joint Reinforcement Learning (SJRL). We first augment neural policies with Causal PIBT, a single-step search-based planner that resolves agents' collisions and propagates their intentions. We then introduce a unified RL formulation that jointly optimizes agent and environment policies, where the environment policy learns graph edge costs to provide global movement guidance via backward Dijkstra search. Experiments demonstrate that SJRL achieves significant improvements over the strong search-based planner, Causal-PIBT, across multiple high-density maps. We further validate SJRL in a challenging mixed-reality warehouse environment with 8 physical robots and 248 virtual robots.

## 1. 论文的核心问题与整体含义

- **研究背景**：终身多智能体路径搜索（Lifelong MAPF, LMAPF）要求智能体在到达目标后持续接收新目标，并不断规划无碰撞路径，是智能仓储、自动化实验室等场景的核心技术。
- **现有缺陷**：主流学习型 LMAPF 规划器（如 PRIMAL、SILLM、MAPF-GPT、HMAGAT 等）大多采用标准 MAPF 模型，假设智能体每步可直接移动到相邻顶点，忽略了实际机器人必须面对的**鲁棒安全约束**（禁止跟车碰撞、保证安全距离）和**原地旋转约束**（差分驱动机器人转向需要时间）。
- **核心问题**：如何在上述更现实、更接近真实仓库运作的约束下，让学习型规划器在**高密度、窄通道、长时程**场景中仍保持可扩展的高吞吐量。
- **论文意义**：首次系统性地为学习型 LMAPF 引入“LMAPF-R2”模型，并提出**搜索增强的联合智能体-环境强化学习（SJRL）**，证明将搜索算法与分层 RL、全局引导相结合，能够显著提升现实约束下的协调性能，有助于推动学习型 MAPF 规划器走向真实部署。

## 2. 论文提出的方法论

### 2.1 总体框架：SJRL

- **核心思想**：同时利用搜索算法与学习策略的互补优势，并“双管齐下”地优化协调——既训练智能体的局部反应式策略，也训练环境的全局引导策略（即引导图/边代价）。
- MDP 视角：环境策略首先为每条边生成代价，并通过反向 Dijkstra 计算全局启发式距离；智能体策略基于局部观测和启发式信息选择子目标（subgoal），随后采用贪心动作执行。

### 2.2 智能体策略（Agent Policy）

- **动作空间分层**：不直接输出原始动作，而是预测“下一顶点”作为子目标，再通过贪心动作（旋转、等待、前进）执行到子目标。
  - 这样做可以缓解多智能体联合探索的指数级困难。
- **搜索辅助**：采用 **Causal PIBT** 的同步变体对神经策略的输出进行碰撞消解。
  - 只让空闲（free）智能体参与决策；
  - 忙碌（busy）智能体当前顶点和子目标均被视为障碍；
  - 禁止循环移动；
  - 通过优先继承机制传播智能体意图，形成链式协调。
- **网络结构**：基于 SILLM 的 CNN + 通信模块 + MLP，并增加两条**跳跃连接**，将启发式距离直接拼接到 CNN 和通信模块输出中，强化环境指导对决策的影响。

### 2.3 环境策略（Environment Policy）

- 使用 CNN 输出每条边代价的高斯分布（均值和方差）；
- 输入包括静态障碍图以及预测的顶点访问频率、边通行频率等统计特征；
- 代价经 arctan + 线性变换映射到 \( [1, 10] \)，初始化均值可调；
- 生成的边代价配合反向 Dijkstra，为智能体提供全局运动启发；
- 可将每个边看作一个虚拟智能体，采用 MAPPO 训练，共享同一奖励。

### 2.4 联合训练流程

1. **预热阶段**：先用均匀边代价（5.5）单独训练智能体策略，减少环境策略训练的方差；
2. **联合训练阶段**：在同一仿真环境中同时更新智能体策略（PPO）与环境策略（MAPPO）；
3. 推理时环境边代价可预计算一次，每步仅执行智能体策略，推理开销低。

### 3.2 对比方法

- **NORL**：无学习的纯搜索基线 Causal-PIBT；
- **SARL**：仅训练智能体策略，统一边代价；
- **SERL**：仅训练环境策略，智能体用 Causal-PIBT；
- **CMA-ES**：原始引导图优化（GGO）方法，用 CMA-ES 优化图边代价；
- **SILLM、MAGAT+、HMAGAT**：当前 SOTA 学习型 LMAPF 方法，按 SILLM 的实践适配到 LMAPF，并用 ADG 执行框架适配差分驱动机器人。

### 3.3 消融/附加实验

- **决策空间与碰撞屏蔽策略消融**：NACS（原始动作 + 朴素屏蔽）、NVCS（顶点 + 朴素屏蔽）、Causal PIBT 对比；

- **引导图初始化的影响**：在仓库和分拣图使用专家单向通道代价初始化；
- **物理机器人验证**：8 个物理机器人 + 248 个虚拟机器人的混合现实仓库场景，使用 OptiTrack 定位与 P3GASUS 错误恢复框架。

## 6. 主要结论与发现

1. **SJRL 显著超越强搜索基线**：在高密度、窄通道地图上，SJRL 的吞吐量明显优于 Causal-PIBT，并且随智能体数量增加优势更明显。
2. **联合学习优于单独学习**：SARL 和 SERL 均弱于 SJRL，说明智能体局部协调与全局引导存在互补性；联合优化可以相互促进。
3. **环境策略通过 RL 优化引导图可行**：SERL 性能与 CMA-ES 相当，并在部分地图上更优，验证了用强化学习替换进化算法的潜力。
4. **子目标分层 + Causal PIBT 的意图传播是成功关键**：直接预测原始动作或朴素屏蔽都远差于 Causal PIBT，特别是在长走廊和随机地图中；意图传播有效缓解了随机探索的指数级困难。
5. **更现实模型的重要性**：直接采用 LMAPF-R2 的 SJRL 优于通过 ADG 适配的标准模型 SOTA 方法，说明在真实执行场景中，规划模型不应过度简化运动学约束。
6. **实际部署可行性**：在 8 实体 + 248 虚拟机器人的混合现实仓库中，SJRL 吞吐量达到 1.01，显著高于其他变体。

## 7. 优点

1. **问题建模贴近现实**：首次将鲁棒安全与原地旋转约束有机融入学习型 LMAPF，具有工程实用价值。
2. **方法设计巧妙**：搜索（Causal PIBT）只负责单步碰撞消解和意图传播，神经策略负责高层决策，降低 RL 探索难度。
3. **“环境-智能体”联合优化视角新颖**：将引导图优化转化为环境策略的 RL 问题，与智能体策略联合训练，实现全局与局部结合的协调。
4. **代码与细节披露充分**：附录提供完整伪代码、训练超参数、热力图可视化等，利于复现。
5. **实验验证全面**：多地图、多密度、多消融、SOTA 对比，并包含真实物理机器人验证，结论可信度高。

## 8. 不足与局限

1. **模型仍有简化**：仅考虑 4 邻居网格、离散时间、原地旋转 90°，没有覆盖连续运动、更复杂车辆运动学（如阿克曼转向、自动驾驶等）。
2. **泛化能力有限**：训练和评估基于同一地图，未实现跨地图泛化；实际新场景可能仍需重新训练。
3. **对比公平性风险**：与 SILLM、MAGAT+、HMAGAT 的对比中，这些方法并未真正在 LMAPF-R2 下训练，可能导致对比优势部分来自“更好的模型假设”本身，而非方法全面占优。
4. **训练成本不低**：每张地图约 9 小时训练，且依赖 4 张 GPU；若扩展到新地图或更大规模，训练开销可观。
5. **联合训练可能陷入局部最优**：论文指出 SJRL 从零训练仍不如专家初始化版本，说明当前 PPO/联合训练范式存在优化瓶颈。
6. **环境策略输入依赖预计算统计特征**：需要先运行已有规划器获得顶点/边使用频率，且这些特征训练和推理时固定，不能在线自适应（论文也提到动态更新边代价留作未来工作）。
7. **物理机器人验证规模相对有限**：实体机器人仅 8 台，虚拟部分虽多，但真实感知和通信挑战可能尚未完全暴露。
