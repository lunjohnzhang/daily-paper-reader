## 摘要
多机器人系统在危险环境中的探索具有得天独厚的优势，但有效部署不仅需要决定机器人应在何处收集信息，还需要决定风险如何在异构团队成员之间分配。本文基于生态学启发的利他行为，开发了一个用于协作风险感知探索的博弈论框架。每个机器人选择有限时域轨迹以最大化信息增益，同时惩罚冗余探索和预期危险暴露。通过特定于智能体的价值参数引入异质性，用于编码利他耦合，该耦合通过受Hamilton规则启发的关联权重进行建模。我们引入了一种用于轨迹规划的博弈论结构，定义了社会纳什均衡，该均衡根据智能体关联性修改智能体行为的效用。这种效用塑造使智能体内化其轨迹选择对队友的影响，鼓励价值较低的机器人在有益于高价值智能体并提升团队绩效时接受风险。我们为智能体定义了一种探索效用，奖励区域覆盖和不确定性减少，同时惩罚冗余和风险，从而在滚动时域规划器中实现基于投影梯度的航点优化。仿真表明，利他规划减少了冗余探索，改善了机器人间距离，并根据智能体价值重新分配风险，同时保持可比较的地图覆盖率。我们还在硬件实验中展示了该方法，其中规划航点由轮式机器人使用单积分控制器和屏障证书进行跟踪。

## Abstract
Multi-robot systems are well-positioned for exploration in hazardous environments, but effective deployment requires deciding not only where robots should gather information, but also how risk should be distributed across heterogeneous team members. This paper develops a game-theoretic framework for cooperative risk-aware exploration based on ecologically inspired altruistic behavior. Each robot selects a finite-horizon trajectory to maximize information gain while penalizing redundant exploration and expected hazard exposure. Heterogeneity is introduced through agent-specific value parameters for encoding altruistic coupling, which is modeled through relatedness weights inspired by Hamilton's rule. We introduce a game-theoretic structure for trajectory planning that defines a Social Nash Equilibrium, which modifies the utility of agent actions according to agent relatedness. This utility shaping causes agents to internalize the effect of their trajectory choices on teammates, encouraging lower-valued robots to accept risk when doing so benefits higher-valued agents and improves team performance. We define an exploration utility for agents that rewards area coverage and uncertainty reduction, while also penalizing redundancy and risk, enabling projected gradient-based waypoint optimization in a receding-horizon planner. Simulations show that altruistic planning reduces redundant exploration, improves inter-robot separation, and reallocates risk according to agent value while maintaining comparable map coverage. We further demonstrate the approach in hardware experiments, where planned waypoints are tracked by wheeled robots using single-integrator controllers and barrier certificates.

## 1. 核心问题与整体含义

论文关注的是**异构多机器人在危险环境中的协作探索问题**。多机器人系统凭借分布式特性对单点故障具有天然鲁棒性，因此在搜索救援、危险环境勘测等任务中具有重要潜力。然而，现有研究大多只关注“机器人应该在哪些区域收集信息”，而较少回答一个关键问题：**风险应如何在价值不同的异构团队成员之间分配**。

论文的核心动机是：在存在空间变化危险的环境中，为了提高整体任务成功率，某些机器人（例如价值较低、风险敏感度低的机器人）应该“心甘情愿”地承担更高风险，以保护价值更高、更脆弱的队友。这种“个体承担成本、团队获得收益”的行为在进化生物学中被称为**利他行为**，其经典数学模型是 **Hamilton 规则**。本文将该规则移植到多机器人轨迹规划中，提出一种基于“算法利他主义”的博弈论框架，使机器人通过效用塑形实现协作风险分配，最终收敛到帕累托最优的探索轨迹。

## 2. 方法论

### 2.1 核心思想

论文将多机器人轨迹规划建模为**博弈论问题**。每个机器人选择有限时域轨迹，其原始效用函数由三部分构成：

\[
u_i(x) = I_i(x) - \alpha R_i(x) - L_i(x)
\]

- \(I_i\)：信息效用（不确定性减少/覆盖率提升）；
- \(R_i\)：与其他机器人轨迹的空间重叠冗余惩罚；
- \(L_i = \lambda_i \sum p_i\)：期望风险损失，\(\lambda_i\) 为机器人的“价值”或风险敏感度。

由于冗余项耦合了所有机器人的轨迹，纯粹的利己决策会导致效率低下或过度冗余探索。为此，论文引入生态学中的 Hamilton 规则：

> 当个体承受的成本 \(C_i\) 小于其对同伴产生的加权收益 \(\sum_j \gamma_{ij} B_{ij}\) 时，利他行为是被鼓励的。

由此定义**社会效用**：

\[
v_i(x) = u_i(x) + \sum_{j\neq i} \gamma_{ij} u_j(x)
\]

其中 \(\gamma_{ij}\) 为机器人 \(i\) 对 \(j\) 的“亲缘权重”，论文将其设置为：

\[
\gamma_{ij} = \frac{\lambda_j}{\lambda_i}
\]

即**低价值机器人更重视高价值机器人的效用**，而高价值机器人相对不太受低价值机器人影响。这种不对称相关权重正是“利他”的量化表达。

### 2.2 关键技术：加权势博弈与均衡

将相关权重矩阵 \(\Gamma\) 代入社会效用向量 \(v(x) = \Gamma u(x)\) 后，论文证明该博弈是一个**加权势博弈**，其势函数为：

\[
\Phi(x) = \sum_{i=1}^n \lambda_i u_i(x)
\]

即“价值加权的社会福利函数”。在此基础上定义了**社会纳什均衡（SNE）**：没有任何机器人能通过单方面改变轨迹提高其社会效用。论文进一步证明：

- **任意全局势函数最大化点都是 SNE**；
- 在轨迹参数化有限维、势函数连续可微且**联合严格凹**的假设下，SNE 等价于势函数的**唯一全局最大化点**，并且对应的轨迹组合是**帕累托最优**的。

### 2.3 算法流程

论文提出**利他虚拟博弈（Altruistic Fictitious Play）**：

1. 初始化各机器人可行轨迹；
2. 每轮迭代中，机器人依次（顺序更新）计算自己的最优社会效用轨迹：
   \[
   \theta_i^{k+1} = \arg\max_{\theta_i} v_i(x_i(\cdot;\theta_i), x_{-i}(\cdot;\theta_k))
   \]
3. 广播更新后的轨迹；
4. 重复直至收敛。

在具体实现中，轨迹被参数化为**航点序列**，并施加工作空间边界约束和相邻航点最大距离约束。由于信息、冗余、风险模型均设计为平滑函数，机器人可以使用**投影梯度上升**来近似求解最佳响应，通过数值积分和空间梯度完成航点更新。

### 2.4 探索模型

- 已知风险：由多个高斯危险源叠加表示；
- 未知风险：由覆盖密度 \(\rho(q)\) 导出的不确定性 \(\xi(q)=e^{-\rho(q)}\) 表示；
- 信息收益：定义为熵的边际减少量，并通过一阶泰勒展开近似为线性可加形式，便于计算梯度。

## 6. 主要结论与发现

- 利他规划能够在不牺牲地图覆盖性能的前提下，**显著减少冗余探索并增大机器人之间的最小距离**。
- 在异构价值配置下，利他机制会**将高风险区域探索任务从高价值机器人转移到低价值机器人**，从而降低价值加权风险，即“保护关键资产”。
- 与自私基线相比，利他策略并非让团队整体更保守，而是改变了**风险承担者的分配结构**，提高团队层面的协作效率。
