## Abstract
This work proposes a hierarchical Model Predictive Supervisory Control (MPSC) framework for multi-agent systems with shared resources. MPSC integrates receding-horizon cost-optimal control with Supervisory control theory (SCT) based supervision that enforces safety, nonblockingness, and resource exclusivity. Scalability arises from hierarchical and scalable supervisor and automaton templates, enabling distributed execution without monolithic synthesis. Using this framework, this work develops an urban Unmanned aircraft system Traffic Management (UTM) model. The model supports pickup-and-delivery missions under time-varying demand efficiently.

### 2. 方法论

**核心思想**：将监督控制理论（SCT）的形式化安全保障能力与模型预测控制（MPC）的滚动时域成本优化能力相结合。UTM层通过SCT监督器定义“可容许行为”集合，UAV层在该集合内进行局部成本最优的滚动决策，从而实现安全性由监督层保证、经济性由优化层保证的分层架构。

**关键技术与流程**：

- **自动机的矩阵代数表示**：将确定性有限自动机（DFA）编码为三个二元矩阵——邻接矩阵A（状态可达性）、事件可达矩阵B（事件到状态关系）、事件可用矩阵C（状态到事件关系）。状态转移用Hadamard积表示为：
  \[
  x_{t+1} = (A x_t) \odot (B u_t)
  \]
  其中 \(x_t\)、\(u_t\) 分别为状态和事件的one-hot编码。正确性条件为 \((A \cdot B^\top) \odot C = C\)。
- **分层可扩展监督架构**：
  - **UAV层**：每个UAV建模为多权重自动机，包含移动、方向性边使用、运行模式、通信、活性、电池等子自动机，以及地图导航、工作流、电池、位置—任务等规格。
  - **UTM层**：利用事件重标注（relabeling）技术，将单一通用监督器模板实例化到每架UAV，避免整体合成；UTM模型包含地图自动机、边独占植物、地理围栏植物及顶点互斥规格。
  - **UTM监督器计算禁止事件集P**，广播给所有UAV；各UAV的MPSC优化仅在P允许的事件子集内进行。
- **MILP优化问题**：在滚动时域H内求解混合整数线性规划，目标函数为：
  \[
  \min \; \alpha_S \sum_{t=0}^{H-1} w^\top x_t - \beta_I \sum_{i \in I} \sum_{t=0}^{H-1} (H-t) u_{t,i}
  \]
  约束包括：初始状态固定（5）、自动机动力学（6）、状态/事件one-hot编码（7）（8）、事件可行性（9）、监督禁止约束（10）。每个控制周期通过BFS提取当前状态的深度H子自动机，求解MILP后仅执行第一个最优事件，再滚动重复。

- 层次化DES公式在R1中比集中式监督器减少约**780倍**的状态数（570 vs 444,816）和约**2300倍**的转移数（1,676 vs 3,828,328），显著降低内存需求。
