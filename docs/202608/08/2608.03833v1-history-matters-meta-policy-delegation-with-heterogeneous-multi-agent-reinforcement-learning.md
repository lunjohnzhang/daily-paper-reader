## 摘要
人工智能代理预计将在未来的决策系统中扮演越来越重要的角色。在本文中，我们考虑了由异构多智能体系统（MAS）组成的协作系统，其中成员具有不同的能力和运营成本。我们研究了代理如何相互委派任务，以便在资源受限的情况下有效完成某些研究任务。我们首先开发了一种基于多智能体强化学习（MARL）的委派训练方法，使代理能够在最小化总执行成本的同时做出顺序委派决策。然后，我们将这种方法扩展到具有指定委派拓扑的MARL。此外，我们引入了两个新的多智能体系统协作与委派框架。第一个框架提出，代理的策略不仅依赖于底层马尔可夫决策过程的当前状态，还依赖于交互历史，包括先前的联合行动。这种基于历史的表述即使在完全可观察的环境中也能改善协调，而传统的MARL方法通常限制策略仅依赖于当前状态。第二个框架提出了一种新颖的、可能多维的货币机制，以促进MAS的协作与委派。

## Abstract
AI agents are expected to play an increasingly important role in future decision-making systems. In this paper, we consider collaborative systems composed of heterogeneous multi-agent systems (MAS), where their members have different capabilities and operating costs. We study how agents can delegate tasks to one another so that certain research tasks can be completed effectively under resource-constrained scenarios. We first develop a multi-agent reinforcement learning-based (MARL) delegation training that enables agents to make sequential delegation decisions while minimizing the total execution cost. We then extend this approach to MARL with prescribed delegation topologies. Furthermore, we introduce two new frameworks for collaboration and delegation in multi-agent systems. The first framework proposes that an agent's policy depends not only on the current state of the underlying Markov decision process but also on the interaction history, including previous joint actions. This history-dependent formulation can improve coordination even in fully observable environments, where conventional MARL methods typically restrict policies to depend only on the current state. The second framework proposes a novel, potentially multi-dimensional monetary mechanism to facilitate the collaboration and delegation for MAS.

### 2. 论文提出的方法论：核心思想、关键技术细节、公式或算法流程

#### 2.1 问题建模框架

- 论文将协作式马尔可夫博弈（Markov Game）定义为 `M = {N, S, A, P, R, γ, {μᵢ}, T, K}`，其中每个智能体 i 都预先训练好自己的任务执行策略 `μᵢ`（如 LLM 的语言生成策略）。
- 在此基础上学习一个**委派元策略** `π: S × A → [0,1]`，它独立于预训练策略，决定将任务委派给哪个智能体执行。
- 群体目标是最大化带折扣的联合期望回报：`J(π) = E[Σ γ^{t-1} Σ Rᵢ(sₜ, aₜ)]`。

#### 2.2 三种委派结构

1. **管理约束（Management Constraints）**：层级控制关系（如 A→B→C），上级可以强制向下级委派任务。每个智能体的动作空间扩展为 `A'ᵢ = Aᵢ ∪ Dᵢ ∪ {no-op}`，其中 Dᵢ 是委派动作集合。每一步只有一个智能体实际执行，遵循层级执行规则。单步奖励为 `Rᵢ(s,a) = αR̄(s,a_exec) − βCᵢ(aᵢ)`，其中环境奖励和个体执行/委派成本以缩放因子 α、β 结合。

2. **委派约束（Delegation Constraints）**：通过有向图表示任意两智能体间的委派关系，去除了严格的层级限制。任意智能体可以委派给任意其他智能体；网络化执行规则下，多个智能体可以同时执行——只有当某个智能体收到其他智能体的委派且自身不再委派他人时才执行。

3. **可转移货币机制（Transferable Money Framework）**：每个智能体拥有货币余额 `wᵢₜ ≥ 0`，其增强状态为 `s̃ᵢₜ = (sₜ, wᵢₜ)`。每步每个智能体选择物理动作 `aᵢₜ`（来自环境策略 `π_env`）和货币转移动作 `pᵢₜ`（来自转移策略 `π_tr`）。转移金额通过合约 `Crᵢ: A → R^{n-1}` 决定，即当智能体 j 执行了某个联合动作时，智能体 i 向 j 支付约定金额。货币**不直接进入环境奖励函数**，仅作为促进合作的内部媒介，简洁地编码过去的交互历史。

#### 2.3 历史依赖策略与算法

- **历史依赖策略**：定义公共历史 `hₜ = (x₁, a₁, x₂, a₂, ..., xₜ₋₁, aₜ₋₁, xₜ)`，策略 `πᵢₜ: Hₜ → Aᵢ` 可以依赖整个历史而不仅是当前状态。Markov 策略是历史依赖策略的特例。
- **两阶段有说服力的实例**：论文构造了一个 2 智能体、2 时间步的博弈例子，说明历史依赖策略可以支持 Markov 策略无法表达的互惠机制——智能体 B 的阶段 2 行为可以条件于智能体 A 在阶段 1 是否选择了昂贵但对 B 有利的动作，从而激励 A 在阶段 1 付出成本，最终实现更高的均衡回报（A 的回报从 0 提升到 8.9）。
- **算法——两步 Nash 值迭代（Algorithm 1）**：
  - 枚举所有可能的两步历史 h₂。
  - 对每个 h₂，计算第二步博弈的纯策略 Nash 均衡集合 E₂(h₂)。
  - 枚举所有满足 σ₂(h₂) ∈ E₂(h₂) 的确定性格续选择器 σ₂。
  - 对每个选择器 σ₂ 和每个第一步联合动作 a₁，计算续值 W^{σ₂}ᵢ(x₁, a₁)，得到诱导的一步博弈效用。
  - 找到第一步博弈的纯策略 Nash 均衡集合 E₁(σ₂)。
  - 构造候选均衡策略并选择最有利于指定智能体（如 B）的策略。
- **定理 1（已证）**：在两步动态博弈中，若两步续博弈和诱导的一步博弈均存在纯策略 Nash 均衡，Algorithm 1 输出一个纯策略子博弈完美 Nash 均衡策略。
- **扩展到 n 步**：通过反向归纳将算法推广到有限 n 步博弈。

### 3. 实验设计：数据集、场景、Benchmark 与对比方法

#### 3.1 管理约束实验（GSM8K）

- **数据集**：GSM8K（公开的小学数学应用题基准，含参考答案），1000 个官方训练题作为固定能力图（ability map），6473 个训练题用于训练委派协调器，官方测试集（1319 题）留出。
- **求解器**：三个冻结的 LLM 求解器——Nemotron 3 Ultra（A，最强最贵）、Llama 3.2 3B（B）、Llama 3.2 1B（C，最弱最便宜）。仅训练集中式 DQN 协调器 π，A/B/C 保持冻结。
- **委派方式**：限制为链式层级 A→B→C，允许三种路线：A 独自回答；A 委派给 B 回答；A→B→C 传递、C 回答。不允许 A 直接跳到 C。
- **奖励设置**：`r = R_corr − λ·C_solve(a_exec) − λ·C_edge(n_e, a_exec) + R_fail`，其中正确回答得 1、错误为 0，成本权重 λ=100，手续费率 α=0.05，三次失败后罚 −1。
- **对比方法**：always-Ultra 基线（所有问题都发送给较贵的求解器 A）。
- **结果**：MARL 协调器得分为 27.56 ± 0.32，准确率 0.982 ± 0.002，成本 $0.033/轮次；始终选择 Ultra 的基线得分为 23.90 ± 0.30，成本 $0.063/轮次；累计成本约 $31.1 vs $60.8（1000 轮次），收益约 +3.7 且成本约减半。

#### 3.2 委派约束实验（GSM8K）

- **委派方式**：更自由的图式委派。协调器首先从 7 种非空启动组合（{A}、{B}、{C}、{A,B}、{A,C}、{B,C}、{A,B,C}）中选择；然后每个智能体可选择回答、传递给第一个其他智能体或传递给第二个其他智能体，共 `7×3³ = 189` 个联合离散动作，允许多个智能体同时回答。
- **对比方法**：(a) always-Ultra 基线；(b) 3.1 节中已经冻结的管理协调器（在相同数据包上回放）。
- **结果**：图协调器得分为 25.20 ± 0.42，准确率 0.961 ± 0.005，成本 $0.043/轮次，累计成本降至约 $45.5（vs always-Ultra 的 $66.7）。管理协调器仍更强（得分 28.70 ± 0.18，准确率 0.986 ± 0.001，成本 $0.024/轮次），说明自由委派带来灵活性，但也带来了更高的协调开销和略低的准确率。

#### 3.3 货币交易机制实验（分布式智能体交互）

- **场景**：两个智能体 A 和 B 交替作为主动智能体（主动者每 20 步交替，共 5000 轮次），只由主动智能体的动作影响物理奖励。当主动方选择帮助（Yes）时，自身承担小成本（-1），但给对方带来大收益（+100）。
- **对比方法**：(a) 独立 Q-learning（IQL，无货币机制）；(b) IQL + 货币转移机制（每次帮助可由对方提供 1 单位固定报酬，在主动方选择物理动作前决定，要求拥有足够余额）。
- **结果**：无货币机制时，双方演化为互不合作的策略（每轮次 0 环境回报）；有货币机制时，双方在所有主动阶段都选择帮助对方，获得 990 的环境回报，实现了完全合作的结果。

#### 3.4 统计检验

- 对 20 个种子的管理/委派委派实验使用**配对 Wilcoxon 符号秩检验**，在 20 个种子上均发现比 always-Ultra 更高的回报和更低的成本（双尾 p = 2⁻¹⁹）。

2. **三种委派结构层层递进**：从层级管理约束 → 图状委派约束 → 可转移货币机制，覆盖了从组织固定到自由协商的实际协作谱系，具有较强的实际背景。
3. **历史依赖策略的理论深度**：不仅提出了概念，还构造了博弈论实例，给出了定理和完整证明（Algorithm 1 输出子博弈完美 Nash 均衡），并提供了 n 步扩展归纳方案，理论扎实。
4. **货币机制设计巧妙**：将货币构建为**增强状态变量**（而非奖励塑形信号），与环境奖励分离，解决了传统奖励塑形方法中"奖励不可转移"的应用

4. **货币机制设计巧妙（续）**：货币作为可转移的“内部媒介”，使得一个智能体对另一个智能体的帮助可以通过货币支付得到补偿，从而绕过了物理奖励不可转移的根本限制。同时，货币余额被设计为增强状态变量而非额外奖励项，既避免了奖励塑形中可能出现的博弈失衡问题，又天然充当了过去交互历史的紧凑摘要——智能体无需记忆完整的历史轨迹，只需读取余额即可推断合作关系的当前状态。这种设计在理论上与历史依赖策略形成互补：货币提供了一种机制化、可学习的方式来实现历史依赖所能表达的互惠行为。

5. **统计严谨性与可复现性**：报告了 20 个种子的均值、方差和配对非参数检验（Wilcoxon 符号秩检验），并给出了完整的超参数表（附录 D）、求解器配置和离线预处理流程，为后续研究者提供了可复现的基线协议。

6. **实际应用价值明确**：实验结果表明，在管理约束下 MARL 协调器相比“永远使用最强模型”的成本约减半（$31.1 vs $60.8），同时准确率还有提升（0.982 vs 0.971），直接回应了 LLM 部署中成本不可预测的核心痛点，具有较强的工程落地指导意义。

### 8. 缺点与局限性

1. **任务泛化性不足**：委派实验仅使用了 GSM8K 这一小学数学推理基准，未在代码生成（如 HumanEval）、多跳问答（如 HotpotQA）、复杂推理（如 MATH）等任务上验证方法的迁移性。对于需要更细致能力区分度的任务（如代码调试、工具调用），结论是否成立尚不明确。

2. **“灵活性 vs 性能”权衡缺乏深入分析**：委派约束（图状结构）实验显示，更自由的委派图带来了更高的协调成本（$0.043/轮 vs $0.024/轮）和更低的准确率（0.961 vs 0.986），但论文对这一反直觉结果仅给出了“协调开销更高”的表面解释，未深入分析是状态空间过大导致探索困难、还是智能体间重复传递导致决策噪声累积，抑或是评估指标本身对层级结构有利。这一分析缺口影响了对方法适用边界的判断。

3. **货币机制实验规模与算法复杂度有限**：货币交易实验仅使用两个智能体、单一动作（Yes/No）、固定报酬（1 单位）和独立 Q-learning 算法，未测试多智能体（≥3）、动态定价、可违约或可借贷等更符合真实场景的设置，也未与 MAGRPO、CoLLM 等更先进的 MARL 算法对比，结论的普适性较为有限。

4. **潜在标签偏差**：离线正确性标签由 Ultra 自身标注（虽手工抽查 200 项一致），这意味着实验中所有求解器的“正确率”本质上衡量的是“与 Ultra 输出的一致性”，而非客观真值。若 Ultra 本身存在系统性错误（如对某些题型有顽固偏差），则协调器可能学会过度依赖 Ultra，从而放大其偏差。

5. **理论结果的条件限制**：定理 1 和 Algorithm 1 仅适用于有限步（两步及有限 n 步）动态博弈，且要求各子博弈存在纯策略 Nash 均衡。对于多智能体强化学习实际操作中的无限时域、随机环境、部分可观测等情况，理论保证尚不清晰。此外，算法通过“枚举所有纯策略 Nash 均衡”再选择最有利均衡的方式，在均衡数量指数增长的场景下计算代价可能过高。

6. **真实环境鲁棒性未被验证**：实验中的求解器均为冻结模型、任务类型固定、成本函数为人设常数。实际系统中模型可能在线更新、任务分布可能漂移、API 价格可能波动，论文未涉及这些动态变化下的适应性研究。

### 9. 改进方向与未来工作

1. **多基准与跨任务验证**：在代码生成、多语言推理、工具使用等更广泛的基准上重复管理/委派实验，检验方法的任务泛化能力，并探索不同任务类型下最优委派结构的异同。

2. **与现有 LLM-MARL 方法集成**：论文明确指出其方法独立于智能体内部策略的学习，因此可以将外部委派层与 MAGRPO、CoLLM 等联合策略优化方法结合，验证双层学习（委派层 + 执行层）是否带来叠加收益。

3. **强化货币机制的设计空间**：引入动态定价（报酬随任务难度协商）、货币贷款与债务、余额上限/税制等机制，研究其对合作稳定性和效率的影响；同时将货币实验扩展到更多智能体（≥3）以检验机制在多边合作中的稳健性。

4. **对“自由委派性能下降”进行机制分析**：通过控制变量实验（如限制传递跳数、增大回放缓冲区、引入分层探索）定位图式委派性能下降的具体原因，为实际系统设计提供“何种程度的约束最合适”的量化指导。

5. **理论扩展**：将历史依赖策略与货币机制的等价性形式化——已证明历史依赖能扩大可达均衡集合，而货币被主张为历史的紧凑摘要，但两者是否在任意博弈中都能保持均衡等价、货币能否完全替代历史记忆，值得给出严格的定理刻画。

6. **动态环境适应性**：研究当求解器性能漂移（如模型升级、降级）或成本函数变化时，委派策略是否能在少量更新下快速适配，或将价格变化直接纳入状态观测实现在线自适应。

### 10. 总体评价与启示

- **总体评价**：这是一篇问题意识明确、方法论扎实、理论与实验兼备的工作。它将 LLM 多智能体系统中的“任务委派”从工程启发式提升为形式化的 MARL 问题，并给出了三种渐进复杂的委派范式，其中历史依赖策略提供了理论上的博弈论洞见，可转移货币机制则弥合了理论与实践之间的距离。虽然实验结果在任务覆盖和算法对比上仍有拓展空间，但论文在成本-能力权衡建模、基于货币的协作机制设计方面具有较高的原创性和应用潜力。

- **核心启示**：
  1. **委派是值得学习的元决策层**：与其手动设计路由规则或依赖集中式调度器，将委派建模为多智能体学习问题可以让系统自动发现成本-准确率的最佳平衡点；且这一元决策层与底层智能体策略解耦，可以即插即用地叠加在已有系统之上。
  2. **结构约束不总是坏事**：管理约束（固定层级）在实验中表现优于自由委派，说明适度限制委派拓扑空间可以减少协调开销，降低探索难度。设计多智能体系统时，“有原则的约束”可能比“完全自由”更有效。
  3. **货币机制是促进合作的有效内部媒介**：当环境奖励无法跨智能体转移时，引入独立的内部货币体系可以形成激励相容的合作均衡——这为 LLM 多智能体系统的社会性设计提供了新思路。
