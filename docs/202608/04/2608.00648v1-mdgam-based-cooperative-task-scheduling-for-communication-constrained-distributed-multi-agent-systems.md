## 摘要
在通信受限的分布式多智能体系统中，协同任务调度具有挑战性，因为每个智能体必须在满足复杂实际约束的同时，根据部分且动态的观测做出决策。现有启发式方法依赖手工设计的投标规则和重复共识，而许多基于学习的方法假设全局观测，且缺乏基于显式通信的协调。为解决这些局限性，本文提出了一种用于分布式多机器人任务分配(MRTA)的神经调度框架，包括多解码器图注意力模型(MDGAM)策略模型和无评论家的组相对多智能体策略梯度(GRMAPG)训练算法。MDGAM使用扩展的图注意力机制联合更新节点和边特征，并采用多个解码器生成任务选择决策和通信消息。GRMAPG从等效任务规划实例中构造组相对优势，以替代传统MARL算法中使用的评论家网络，从而降低训练难度并提高收敛性能。在不同问题规模和通信范围下的实验表明，所提方法在任务完成性能上优于现有启发式和基于学习的方法，同时消融、复杂性和泛化测试进一步验证了所提出的创新点。

## Abstract
Cooperative task scheduling in communication-constrained distributed multi-agent systems is challenging because each agent must make decisions from partial and dynamic observations while satisfying complex practical constraints. Existing heuristics rely on handcrafted bidding rules and repeated consensus, whereas many learning-based methods assume global observations and lack explicit communication-based coordination. To address these limitations, this paper proposes a neural scheduling framework for distributed multi-robot task allocation (MRTA), consisting of a multi-decoder graph attention model (MDGAM) policy model and a critic-free group relative multi-agent policy gradient (GRMAPG) training algorithm. MDGAM uses an extended graph attention mechanism to jointly update node and edge features, and employs multiple decoders to generate task-selection decisions and communication messages. GRMAPG constructs group-relative advantages from equivalent task-planning instances to replace the critic network used in conventional MARL algorithms, thereby reducing training difficulty and improving convergence performance. Experiments under different problem scales and communication ranges show that the proposed method improves task-completion performance over existing heuristic and learning-based methods, while ablation, complexity, and generalization tests further validate the proposed innovations.

### 1. 核心问题与整体含义

- **研究背景**：分布式多智能体系统（如智能交通、物联网、应急响应中的机器人、车辆或无人机）需要在有限通信条件下协同完成空间分布的任务。多机器人任务分配（MRTA）是一个组合优化问题，一般属于 NP-hard，且实际场景中还存在时间窗、异构能力等约束。
- **核心挑战**：在通信受限的分布式设定下，每个智能体只能基于局部且时变的观测做决策，无法获得全局信息；同时通信拓扑随时间变化，甚至可能分裂为多个不连通的组件，这给协同任务规划带来了显著困难。
- **现有方法的不足**：
  - 启发式方法（如 CBBA、PI-maxAss、EEPI）依赖手工设计的投标函数或性能影响指标，且需要反复共识与重规划，通信和计算开销大。
  - 多数基于学习的方法（如 CAM）假设全局可观测，或采用集中式训练/决策结构（如 DL-DRL），未显式建模通信拓扑约束与智能体间通信协调。
- **研究意义**：论文旨在提出一种能同时处理任务规划与通信协调的分布式神经调度框架，在部分可观测、通信受限的条件下提升任务完成数量，具有理论价值和实际应用潜力。

### 2. 方法论

#### 问题建模
- 将通信受限的分布式任务规划过程建模为**Dec-POMDP**。
- 全局优化目标为最大化完成的任务总数，约束包括时间窗、智能体能力匹配、任务冲突避免和返回时间限制。
- 每个智能体在事件触发的决策时刻，基于局部观测（自身状态、任务静态信息、通信连通组件内其他智能体的状态与消息）做出任务选择，并生成通信消息。

#### MDGAM 策略模型
- **编码器**：采用扩展图注意力机制，将局部观测构建为图结构（节点为当前智能体、 depot、候选任务、邻居智能体；边为成对距离等关系）。
- **扩展图注意力三大操作**：
  - Node-Node Attention：聚合节点上下文信息；
  - Edge-Node Attention：利用端节点表示更新边表示，方向感知采用轻量级 Positional Encoding（起点拼接 −1、终点拼接 +1）；
  - Node-Edge Attention：将边信息传回节点表示。
- **多解码器结构**：
  - **任务解码器**：基于注意力层输出候选任务/返回 depot 的选择概率分布，训练时采样、测试时贪心解码；不可行动作通过掩码屏蔽。
  - **通信解码器**：输出连续的通信消息向量（维度 dcom = 128），供后续通信可达的智能体使用。
- 编码器堆叠 4 层，嵌入维度 dm = 128，8 头注意力（每头 16 维），FFN 隐藏维度 256，带残差连接与层归一化。

#### 训练算法
- **基线设置**：设计了基于扩展图注意力的集中式 critic（支持 MAA2C 和 MAPPO）。
- **GRMAPG 核心思想**：不引入 critic 网络，改为从**等价变换**构造的实例组中计算 leave-one-out 基线，构造组相对优势 Âk = Rk − bk，其中 bk 为同组其他实例的奖励均值。
- **等价变换**包括坐标旋转、任务类型与智能体能力交换、时间参数与速度的联动缩放等，保持理论最优目标不变。
- **无偏性保证**：由于组内其他轨迹与当前轨迹条件独立，基线满足 E[bk∇θ log Pθ(σk|gk)] = 0。
- **优化目标**：直接优化终端任务完成数量的期望，避免手工 stepwise 奖励分解与 critic 估计误差。
