## 摘要
多智能体规划问题出现在各种工程应用中，如多机器人灭火和工厂中的无人机巡检。一个特别的挑战是时空约束（即智能体应在何时和/或何地做什么）和拓扑约束（即智能体应如何交互）的存在，这些通常通过图的概念来形式化。在过去几年中，已经提出了各种框架，可以通过时空逻辑来捕获此类约束。我们在此关注带有图算子的时空逻辑（STL-GO），这是一种最近的形式化方法，支持对多个智能体及其拓扑结构（如感知、通信和任务拓扑）进行推理。在本文中，我们考虑规划满足STL-GO中编写约束的多智能体路径的问题。由于需要通过STL-GO固有的图算子对多个可能随时间变化的图进行编码，该问题特别具有挑战性。我们提出了该问题的两种编码方法，一种基于混合整数规划（MIP），另一种基于可满足性模理论（SMT），并具有可靠性保证。我们提供了一个统一接口来指定智能体约束、其图拓扑和STL-GO规范，使得两种方法可以无缝使用，并便于它们之间的直接比较。我们在一个多无人机搜索与救援基准上评估了这两种编码，针对团队规模和图复杂度进行了消融实验，突出了所提出编码在动态多图交互下的表达能力。

## Abstract
Multi-agent planning problems arise in a variety of engineering applications, such as multi-robot wildfire fighting and unmanned aerial inspection in factories. A particular challenge is the existence of spatio-temporal (i.e., when and/or where an agent should do what) and topological constraints (i.e., how agents should interact), as typically formalized via the notion of graphs. Over the last years, various frameworks have been proposed that can capture such constraints via spatio-temporal logics. We focus here on spatio-temporal logic with graph operators (STL-GO), a recent formalism that supports reasoning about multiple agents and their topologies, such as sensing, communication, and task topologies. In this paper, we consider the problem of planning multi-agent paths that satisfy constraints written in STL-GO. This problem is particularly challenging due to the need of encoding multiple, potentially time-varying graphs via the graph operators inherent to STL-GO. We present two encodings of this problem, one based on mixed-integer programming (MIP) and another based on satisfiability modulo theory (SMT), with soundness guarantees. We provide a unified interface for specifying agent constraints, their graph topologies, and the STL-GO specification, enabling seamless use of both methods and facilitating direct comparison between them. We evaluate both encodings on a multi-UAV search-and-rescue benchmark, ablating over team size and graph complexity, highlighting the expressiveness of the proposed encodings under dynamic multi- graph interactions.

- **研究背景**：多智能体系统（MAS）的规划问题通常需要同时满足**时空约束**（何时/何地执行什么动作）与**拓扑约束**（智能体之间如何交互）。现有形式化方法如 LSTL、SSTL、SaSTL、STREL、Census STL 等虽然能表达某些时空或群体属性，但难以统一处理**多个动态交互图**（感知图、通信图、任务图）上的量化与基数约束。
- **STL-GO 的定位**：STL-GO 是近期提出的时空逻辑，支持对多个智能体及其多种交互拓扑进行推理，特别适合描述“感知→通信→任务分配→救援”等复杂协同过程。然而，此前 STL-GO 仅被用于**运行时监控**，并未解决“如何从规范自动合成控制序列”的规划问题。
- **核心研究问题**：给定多智能体系统模型、环境轨迹、STL-GO 规范和有界时域，如何合成开环控制序列，使执行轨迹满足规范，并给出可计算的编码与正确性保证。

## 论文提出的方法论

1. **系统建模与问题定义**
   - 智能体状态 `xit` 在同一状态空间 `X`，环境状态 `wt` 按确定性动力学演化。
   - 智能体动力学限制为离散时间**仿射动力学**：`xit+1 = A xit + B uit + E wt + c`。
   - 交互图通过**图构造器函数** `Γtype(Xt, wt)` 生成，边存在性与权重由联合状态决定；要求边谓词可 MIP/SMT 编码，权重为分片仿射或 LRA 表达式。

2. **MIP 编码（基于 Gurobi）**
   - 动力学等式、状态/输入超矩形约束直接加入。
   - 原子谓词用 Big-M 编码为二进制变量。
   - 逻辑、时序算子（∧、∨、¬、U、F、G）采用标准有限时域展开。
   - **图算子编码**是核心创新：
     - 对每条入边 `(j,i)` 引入二元变量表示“边存在且权重在 W 内”；
     - 引入“边满足 φ 且权重合格”的辅助变量；
     - 用整数计数变量和上下界违例二元变量实现基数区间 `[e1,e2]`；
     - 通过析取/合取编码实现对图类型集合的 ∃/∀ 量化。
   - 多智能体量词 `EX`、`FA` 分别编码为 agent 变量的或/与。
   - 给出了健全性引理与定理：MIP 可行 ⇒ 所得轨迹满足 STL-GO。

3. **SMT 编码（基于 Z3）**
   - 使用无量词 LRA+LIA 理论。
   - 原子谓词直接写为线性不等式等价；逻辑与时序算子用布尔连接词和有限展开的析取/合取表示。
   - 图算子编码：
     - 布尔变量 `b` 表示“边存在且权重在区间内”；
     - 用 `ite` 计数合格邻居数 `c`；
     - 基数约束写成 `e1 ≤ c ≤ e2` 的等价；
     - 图类型量化由析取/合取直接表达。
   - 同样给出健全性证明。

4. **统一接口与情景树规划**
   - 实现统一接口：输入智能体集合、交互图拓扑、STL-GO 公式和目标函数，可编译为 MIP 或 SMT 求解。
   - 对搜索救援场景，枚举所有可能应急激活情景 Ω，对每个情景建立状态/控制序列，并加入“不可区分情景共享相同控制前缀”的一致性约束，从而生成**有限情景树**式条件规划。

## 论文的主要结论与发现

1. **两种编码均正确且可行**：MIP 与 SMT 都能在动态、多图、有基数约束的 STL-GO 规范下成功合成多智能体轨迹。
2. **SMT 更紧凑、更快**：在搜索救援场景中，SMT 的变量数、约束数和求解时间通常显著优于 MIP；MIP 的优势在于支持目标函数优化。
3. **图复杂度显著影响求解难度**：感知图、通信图、任务图依次增加求解时间与模型规模，任务图带来的决策-依赖耦合最难求解。
4. **STL-GO 优于 HyperLTL 表达**：在网格对比中，HyperLTL 因需枚举单元对（通信距离约束）导致约束数随 `O(T·N^4)` 增长，STL-GO 的图算子编码仅为线性增长，且求解时间更短。
