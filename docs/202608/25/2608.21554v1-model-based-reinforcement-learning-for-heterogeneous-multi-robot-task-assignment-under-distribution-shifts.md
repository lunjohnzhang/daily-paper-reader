## 摘要
异构多机器人服务系统必须将请求分配给兼容的机器人，构建可行的调度方案，并随着新任务在线到达而进行调整。历史数据有助于预测未来需求，但过度依赖不准确的预测在分布偏移下会降低性能。我们开发了一种预测感知的自适应滚动框架，用于处理具有预定和实时请求的异构多机器人任务分配。该问题被建模为有限时域随机动态规划，包含机器人-任务兼容性、有序服务需求、路径约束、服务时间窗以及时域末端返回要求。所提出的策略在采样未来请求场景的同时，将当前分配限制在已观察到的请求上，从而评估当前分配。为支持在线使用，该框架结合了剪枝候选控制、等待操作以及一种交互感知的基础策略，用于高效估计未来成本。通过根据近期预测失配自适应地重新加权预测请求，并选择性地重新优化已分配但未开始的请求，实现了对预测误差的鲁棒性。我们还引入了一种基于历史数据驱动的程序，用于在部署前选择异构车队构成。在一项使用医院住院楼层真实护理任务请求的案例研究中，所提出的方法实现了接近完整的服务，并相对于反应式、令牌传递、预测定位和短视贪心基线减少了已服务请求的等待时间，其中尾部延迟指标的改进最大。

## Abstract
Heterogeneous multi-robot service systems must assign requests to compatible robots, construct feasible schedules, and adapt as new tasks arrive online. Historical data can help anticipate future demand, but relying too heavily on inaccurate predictions can degrade performance under distribution shifts. We develop a prediction-aware adaptive rollout framework for heterogeneous multi-robot task assignment with scheduled and real-time requests. The problem is formulated as a finite-horizon stochastic dynamic program incorporating robot-task compatibility, ordered service requirements, routing constraints, service windows, and end-of-horizon return requirements. The proposed policy evaluates current assignments using sampled future request scenarios while restricting immediate commitments to requests already observed. To enable online use, the framework combines pruned candidate controls, wait actions, and an interaction-aware base policy for efficient future-cost estimation. Robustness to forecast error is provided by adaptively reweighting predicted requests based on recent prediction mismatch and selectively re-optimizing assigned but unstarted requests. We also introduce a historical-data-driven procedure for selecting the heterogeneous fleet composition before deployment. In a case study using real nursing-task requests from hospital inpatient floors, the proposed approach achieves near-complete service and reduces serviced-request wait times relative to reactive, token-passing, prediction-positioning, and myopic greedy baselines, with the largest improvements in tail-delay metrics.

## 1. 核心问题与整体含义（研究动机和背景）

- **研究背景**：异构多机器人服务系统需要将在线到达的任务请求分配给具备不同能力的机器人，并构建可行、可调度的方案。在真实场景（如医院住院楼层）中，请求往往既有预定的，也有实时出现的，这要求系统在动态环境中持续决策。
- **核心问题**：现有方法常依赖历史数据对未来需求进行预测，但在**分布偏移（distribution shift）** 下，历史分布与真实分布不一致，预测会失准；如果过度依赖这类不准确的预测，任务分配性能会显著退化（如机器人空跑、服务延误、部分请求未被服务）。
- **研究含义**：论文希望设计一种**对预测误差鲁棒（prediction-aware robust）** 的在线决策框架，使异构多机器人系统在分布偏移环境下依然能保持高服务率、低等待时间，特别是降低尾部延迟，为实际部署提供可靠方案。

## 2. 论文提出的方法论

### 2.1 核心思想

- 将问题建模为**有限时域随机动态规划（finite-horizon stochastic dynamic program）**，约束包括：机器人-任务兼容性、有序服务需求、路径约束、服务时间窗、时域末端返回要求。
- 核心策略是：**在采样未来请求场景的同时，只对当前已观察到的请求做出即时分配承诺**。即用“对未来场景的模拟评估”来指导“当前实际动作”，避免对未来预测请求过早承诺、从而降低预测错误带来的风险。

### 2.2 关键技术细节

- **采样式未来成本估计**：通过采样未来的请求场景，评估每个候选分配动作的期望未来成本，使当前分配决策能“看到”全局而非局部。
- **剪枝候选控制（pruned candidate controls）**：为满足在线计算需求，对候选控制集合进行剪枝，减少需要评估的动作数量，提升效率。
- **等待操作（wait actions）**：允许机器人暂时不分配任务，等待更优的请求出现，以增强决策的灵活性和鲁棒性。
- **交互感知基策略（interaction-aware base policy）**：在 rollout 或 Monte Carlo 树搜索类框架中，使用一个考虑机器人之间相互影响的基策略来快速估计未来成本，避免低估或高估剩余请求的服务难度。
- **自适应预测重加权**：通过跟踪近期的预测误差（预测失配程度），动态调整未来预测请求在决策中的权重；预测越不准，决策中越不依赖预测。
- **选择性重新优化**：对已分配但尚未开始执行的请求，允许在必要时重新优化分配方案，从而吸收新信息、修正旧决策。
- **部署前车队构成选择**：提出一个基于历史数据驱动的程序，在部署前确定异构车队（不同机器人类型、数量）的组成，使车队能力分布与预期需求更匹配。

### 2.3 算法流程（文字说明）

1. 初始化车队状态与已观察到的请求集合。
2. 在每个决策时刻：
   - 根据近期预测误差调整未来请求预测的权重；
   - 采样多组未来请求场景；
   - 枚举候选分配控制（经剪枝），结合等待操作；
   - 使用交互感知基策略对每个候选控制评估期望未来成本；
   - 选择期望成本最小的控制执行（仅对已观察到请求做承诺）；
   - 更新状态，选择性触发对未开始任务的重优化。
3. 周期性地或当分布偏移检测到一定程度时，更新预测权重与车队状态配置。
