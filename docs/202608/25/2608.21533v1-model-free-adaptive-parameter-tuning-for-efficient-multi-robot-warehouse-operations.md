## 摘要
机器人履行中心（FCs）将库存存储在密集排列的货架（即货舱）上。取回深埋在货舱块中的目标货舱需要移开阻碍的货舱（即挖掘）。多机器人规划器使用参数化成本函数来控制挖掘行为，产生一系列策略：在一种极端情况下，阻碍货舱被送往其他货舱块（在行驶通道中占用更多机器人）；在另一种极端情况下，货舱在块内重新排列（避免通道拥堵但增加提取时间）。这一系列中的每个点对地面拥堵和吞吐量都有不同的下游影响。最优操作点取决于具体的设施配置，并随操作条件（如变化的站点需求和拥堵模式）而变化，使得离线调优不切实际。我们提出了一种基于极值搜索控制（ESC）的自适应参数调优框架，该框架根据测量的吞吐量持续调整规划器参数。ESC通过使用正弦抖动信号扰动参数并将扰动与性能变化相关联来估计梯度，实现无模型优化，使其对大型FC运营中固有的多分钟延迟效应和信用分配挑战具有鲁棒性。仿真研究表明，自适应策略在多种条件下优于固定策略。我们观察到，在地图和机器人车队规模变化时，吞吐量平均提高了5.0%，在动态操作条件下提高了8.4%。这项工作消除了手动参数配置，实现了实时自适应，为FC存储运营提供了一种自调优范式。

## Abstract
Robotic Fulfillment Centers (FCs) store inventory on shelves (pods) arranged in dense blocks. Retrieving a target pod that is buried deep in a block requires moving obstructing pods out of the way (i.e., digout). Multi-robot planners use parameterized cost functions to control digout behavior, producing a spectrum of strategies: at one extreme, obstructing pods are sent to other blocks (using more robots in travel lanes); at the other, pods are shuffled within the block (avoiding lane congestion but increasing extraction time). Each point on this spectrum has different downstream consequences for floor congestion and throughput. The optimal operating point depends on the specific facility configuration and shifts with operational conditions such as varying station demand and congestion patterns, making offline tuning impractical. We present an adaptive parameter tuning framework based on Extremum Seeking Control (ESC) that continuously adjusts planner parameters in response to measured throughput. ESC performs model-free optimization by perturbing parameters with sinusoidal dither signals and correlating perturbations with performance changes to estimate gradients, making it robust to the multi-minute delayed effects and credit assignment challenges inherent in large FC operations. Simulation studies demonstrate that the adaptive policy improves upon fixed policies across several conditions. We observe an improvement in throughput by an average of 5.0% across map and robot fleet size variations, and by 8.4% under dynamic operating conditions. This work eliminates manual parameter provisioning and enables real-time adaptation, providing a self-tuning paradigm for FC storage operations.

### 2. 方法论：核心思想、关键技术细节与算法流程

- **核心思想**：采用**极值搜索控制（Extremum Seeking Control, ESC）** 作为无模型自适应优化工具。通过对规划器参数施加正弦抖动信号，将参数扰动与吞吐量响应进行相关分析，从而估计性能函数梯度，并沿梯度方向迭代更新参数，最终收敛至局部最优。
- **技术路线概览**（以标量参数 γ 为例）：
  1. **参数扰动**：`θ(t) = θ̂(t) + a·sin(ωt)`，以振幅 a 和频率 ω 对参数估计值 θ̂ 施加正弦抖动。
  2. **高通滤波**：对测量的吞吐量 `y(t) = J(θ(t))` 通过高通滤波器 `ẏ_hp = -ω_h·y_hp + ẏ`，去除信号中的直流（DC）成分，保留抖动频率附近的波动。
  3. **解调**：将滤波后信号乘以抖动信号 `sin(ωt)`，实现梯度信息的解调提取。
  4. **低通滤波**：通过低通滤波器 `ξ̇_lp = -ω_l·ξ_lp + ω_l·y_hp·sin(ωt)` 平滑解调信号，提取梯度估计。
  5. **积分更新**：`θ̂ = k̄·ξ_lp`，沿梯度上升方向更新参数估计值，并通过投影保证参数约束在可行集 Θ 内。
- **离散化实现**：由于实际系统只能周期性更新参数（更新周期 Δt），论文给出离散化版本：
  - 高通滤波采用后向欧拉：`y_hp^k = h·(y_hp^{k-1} + y_k - y_{k-1})`，其中 `h = 1/(1+ω_h·Δt)`；
  - 低通滤波采用指数平滑：`ξ_lp^k = α_l·ξ_k + (1-α_l)·ξ_lp^{k-1}`，其中 `α_l = ω_l·Δt/(1+ω_l·Δt)`；
  - 参数更新：`θ̂_{k+1} = θ̂_k + k̄·ξ_lp^k·Δt`。
- **相位延迟补偿**：通过互相关分析测得参数变化到吞吐量响应间的延迟 τ ≈ 4 分钟，解调信号中加入相位补偿 `sin(ω(t_k - τ))`，以解决信用分配问题。
- **多参数扩展**：对 d 维参数 θ ∈ R^d 使用相互正交（频率充分分离）的抖动信号，分别解调各维梯度，交叉耦合在时间平均下趋于零。论文实际调优参数 θ = {γ, ρ}，其中 ρ 为站点队列大小参数。
- **收敛性保证**：在光滑性、有界性、局部强凸性（凹性）等标准假设下，引用已有理论成果（Lemma 1）保证 ESC 对局部最优的实用收敛性，且投影操作不影响收敛。

### 6. 主要结论与发现

- **RQ1**：dig cost 的抖动确实在吞吐量信号中产生同频率可观测振荡（≥15 dB 高于噪声底），验证了 ESC 可用的梯度信息存在性。
- **RQ2**：参数变化到吞吐量响应之间的相位延迟约为 **4 分钟**，据此设置 Δt = 5 分钟的更新周期可避免梯度估计被瞬态效应污染。
- **RQ3**：
  - 名义条件下，ESC 在稳态期（最后 2 小时）比固定策略平均提升 **11.16%** 的吞吐量；
  - 无论初始 ρ ∈ {1, 2, 3}，ESC 自动将 ρ 收敛到约 1.6–2.0 的狭窄最优区间，且收敛值与初始化无关，显示自动参数发现能力；
  - ρ = 1 等远离最优的初始条件下提升最显著（24–42%）；初始接近最优时仅小幅提升，甚至可能因抖动扰动出现轻微下降；
  - 跨配置转移场景中，固定策略平均损失 5.0% 吞吐量（95% CI: [2.6%, 7.4%]），ESC 在线自适应可消除该转移代价，最坏情形下 ESC 损失仅 −3.0%，最好情形增益达 +17.3%。
- **RQ4**：50% 站点登出后，ESC 自动将 ρ 从约 3.3 调至 4.3，扰动前提升 +3.5%，扰动后提升 **+14.3%**，全程提升 **+8.4%**，显著优于维持固定参数的策略。

### 8. 不足与局限

- **参数覆盖有限**：仅对 γ（dig cost）和 ρ（队列大小）两个参数进行自适应调优，α 和 β 保持固定；规划器可能还有其他影响性能的参数未被纳入，多维度同时优化的可扩展性仍需进一步验证。
- **缺乏真实世界验证**：全部实验基于离散事件仿真，未在真实 FC 或实物机器人系统上部署验证；仿真与真实系统在机器人动力学、拥堵模式、通信延迟等方面的差距可能影响结论的可迁移性。
- **延迟估计的静态假设**：4 分钟相位延迟通过固定的互相关分析获得，但实际延迟可能随拥堵程度、地图布局等条件动态变化；固定延迟补偿在极端波动条件下的鲁棒性有待考察。
- **ESC 超参数依赖人工整定**：抖动频率、滤波器时间常数、积分增益等 ESC 超参数仍需人工选择并满足时标分离要求；不同规模的 FC 可能需要重新整定这些超参数。
- **局部收敛本质**：ESC 本质上是局部优化方法，可能收敛到局部最优而非全局最优；在高度非凸的参数-性能景观上，初始点选择对最终性能有影响。
- **抖动代价**：抖动信号在收敛后的持续扰动会带来小幅性能损失（论文中初始 ρ=2 情形下观察到轻微下降），虽然可接受，但缺少自适应振幅衰减等改进策略的探讨。
- **转移实验样本量有限**：不同地图不同机器人数量条件下的 95% 置信区间较宽且包含零（[−1.4%, +9.3%]），该场景下结论的统计显著性偏弱。
