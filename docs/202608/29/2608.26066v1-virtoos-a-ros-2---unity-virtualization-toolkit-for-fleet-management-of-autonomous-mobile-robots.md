## 摘要
在本文中，我们介绍了VirTooS，一个旨在为自主移动机器人（AMR）团队实施车队管理任务的Python/C#工具包。VirTooS利用机器人操作系统（ROS）2和Unity游戏引擎，在混合现实环境中提供逼真、可扩展的虚拟实验。该工具箱允许用户轻松生成和定制虚拟场景，以进行逼真的仿真。可以利用虚拟和真实传感器（例如LiDAR）在混合现实环境中进行地图构建和安全导航。为了实现分布式机器人实验，我们提出了一套利用ChoiRbot框架的定制例程。作为一个激励性示例，我们展示了在虚拟环境中解决任务分配问题的一组实验，允许真实机器人与虚拟机器人之间无缝交互。此外，该软件包附带一套容器化套件，便于在不同机器上部署。源代码将在GitHub上公开提供。

## Abstract
In this paper, we present VirTooS, a Python/C# toolkit designed to implement fleet-management tasks on teams of Autonomous Mobile Robots (AMRs). VirTooS leverages the Robot Operating System (ROS) 2 and Unity game engine to provide realistic, scalable virtual experiments in a mixed-reality environment. The toolbox allows users to easily generate and customize virtual scenarios for realistic simulations. Virtual and real sensors as, e.g., LiDARs, can be exploited to map and safely navigate in the mixed-reality environment. To enable distributed robotics experiments, we propose a set of tailored routines leveraging the ChoiRbot framework. As a motivating example, we show a set of experiments for task assignment problems in a virtual environment, allowing seamless interaction among real and virtual robots. Moreover, the package comes with a containerized suite to easily deploy it on different machines. The source code will be made publicly available on GitHub.

## 2. 方法论：核心思想、关键技术细节与算法流程

- **核心思想**：VirTooS 采用三层模块化架构，将高层决策、单机控制与虚拟化仿真解耦，并使用 ROS 2 作为中间件，Unity 作为可视化/虚拟化前端，Gazebo 作为物理引擎。

  1. **优化-based 车队管理系统**：基于 ChoiRbot 框架，每个机器人被视为独立智能体，通过分布式优化算法（如动态任务分配 DTA）完成决策，并与邻居通信、本地计算，得到任务分配结果。
  2. **单机器人控制、导航与规划系统**：基于 ROS 2 的 Nav2 和 SLAM Toolbox，接收高层决策后生成控制指令，执行全局/局部路径规划、避障和同步建图；该层提供了针对多机器人场景适配的插件式功能。
  3. **Unity–Gazebo 虚拟化接口**：Unity 负责环境渲染和虚拟传感器模拟（如 LiDAR），Gazebo 提供机器人动力学；通过 ROS-TCP-Connector / ROS-TCP-Endpoint 实现了 Unity 与 ROS 2 的实时双向 TCP/IP 通信。
- **关键技术细节**：
  - 动态生成参数化虚拟环境：用户可配置房间大小、货架布局（All Rows、Two Corridors、Random）和机器人数量，环境对象按 ROS 2 坐标系网格放置。
  - 机器人模型通过 URDF 导入 Unity，并处理坐标系差异（Unity 用 RUF，Gazebo 用 FLU），保证状态和传感器数据一致性。
  - 虚拟传感器（如激光扫描）可由 Unity 配置界面设置参数，并将数据转发给 ROS 2 侧导航/建图模块。
  - 利用容器化（Docker）实现跨平台、多机器快速部署；混合现实中真实机器人位姿由 Vicon MoCap 系统提供，通过 ros2-vicon-receiver 传入 ROS 2，再经 TCP 连接同步至虚拟环境。
