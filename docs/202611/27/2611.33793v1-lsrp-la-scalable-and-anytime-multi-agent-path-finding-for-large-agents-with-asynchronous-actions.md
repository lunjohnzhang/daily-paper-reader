## 摘要
多智能体路径规划（MAPF）旨在为多个智能体寻找从起始位置到目标位置的无碰撞路径，同时最小化路径成本。大多数 MAPF 算法假设每个智能体占据单个顶点，且所有智能体的动作是同步的。这些假设可能限制 MAPF 规划器在实际中的应用。现有摆脱这两个假设的规划器要么只能处理少量智能体，要么无法改进其解。最近提出了一种名为 LSRP* 的规划器，它可扩展、支持任意时间且具有异步动作，但仍受限于每个智能体占据单个顶点。本文提出了一种新的规划器 LSRP*-LA，用于具有异步动作的大型智能体的 MAPF（LA-MAPF-AA），其中智能体可以占据多个单元格。LSRP*-LA 可扩展且完备，并且在获得初始解后持续改进解的质量，直到运行时间预算耗尽。我们分析了 LSRP*-LA 的性质，并在各种地图上使用多达 800 个智能体将其与多个基线方法进行测试。LSRP*-LA 可处理的智能体数量是基线方法的两倍，其解成本约为近期面向大型智能体的同步规划器的一半。

## Abstract
Multi-Agent Path Finding (MAPF) seeks collision-free paths for multiple agents from their start locations to their goal locations while minimizing path costs. Most MAPF algorithms assume that each agent occupies a single vertex and that the actions of all agents are synchronized. These assumptions may limit the use of MAPF planners in practice. Existing planners that get rid of both assumptions either handle only a few agents or cannot improve their solutions. Recently, a planner called LSRP* was proposed, which is scalable and anytime with asynchronous actions, but still limited by that each agent occupies a single vertex. This paper develops a new planner called LSRP*-LA for MAPF for large agents with asynchronous actions (LA-MAPF-AA), where an agent can occupy several cells. LSRP*-LA is scalable and complete, and it keeps improving solution quality after the initial solution is obtained until the runtime budget depletes. We analyze the properties of LSRP*-LA and test it against several baselines with up to 800 agents on various maps. LSRP*-LA can handle twice as many agents as baseline methods and its solution cost is about half that of recent synchronous planners for large agents.

  - 完备（有解实例必能找到解）；
  - anytime（获得初始解后持续优化直到时间预算耗尽）。

## 2. 方法论

### 2.1 问题建模

- 工作空间划分为单位格子，智能体 \(i\) 位于顶点 \(v\) 时占据格子集合 \(F_i(v)\)，称为 **footprint（足迹）**；从 \(u\) 移动到 \(v\) 时占据 **swept area（扫掠区域）** \(F_i^{sw}(u,v)\)，满足 \(F_i(u)\cup F_i(v)\subseteq F_i^{sw}(u,v)\)。
- 每个智能体有各自允许的顶点/边子图 \(G_i=(V_i,E_i)\)，移动时长 \(D(i,u,v)\) 可因智能体、边而异；时间为连续量。
- 动作为四元组 \(a_i=(p,v,t_p,t_v)\)：从 \(p\) 在 \(t_p\) 出发，于 \(t_v\) 到达 \(v\)；等待可任意正时长，移动时长固定为 \(D(i,p,v)\)。
- **冲突定义**：两个动作的扫掠区域相交，且时间区间 \([t_p,t_v)\) 重叠，即
  \[
  F_i^{sw}(p(a_i),v(a_i))\cap F_j^{sw}(p(a_j),v(a_j))\neq\emptyset
  \ \wedge\ [t_p(a_i),t_v(a_i))\cap[t_p(a_j),t_v(a_j))\neq\emptyset
  \]
- **目标**：最小化所有智能体路径成本之和（SOC），其中智能体到达目标后的等待成本被“冻结”，不再累计。
- 该模型可退化为 MAPF-AA（单格、顶点冲突）和 LA-MAPF（单位时长、同步动作）。

### 2.2 核心思想

LSRP*-LA 在 LSRP* 框架上扩展，由两部分组成：

1. **搜索算法**：类似 LaCAM* 的联合动作搜索，负责完备性与 anytime 优化；
2. **规则式过程**：快速为搜索未分配的 idle 智能体规划动作，负责快速获得初始解。

大智能体主要改变搜索中的 **动作树子节点生成**，其余变化集中在规则式过程。

### 2.3 关键技术细节

- **联合动作与事件**：
  - 联合动作 \(a=(a_i)_{i\in I}\) 包含每个智能体当前正在执行的动作；
  - 当前事件 \(\tau(a)=\min_i t_v(a_i)\) 为最早到达时刻；
  - 在 \(\tau\) 时刻到达的智能体为 idle，其余为 busy；
  - 后继联合动作让所有 idle 智能体从 \(\tau\) 开始新动作，busy 智能体保持原动作。
- **动作树 \(AT(a)\)**：
  - 逐个为 idle 智能体分配动作（等待或移动）；
  - 移动 \(v_i\to u\) 仅当 \((F_i^{sw}(v_i,u)\setminus F_i(v_i))\cap R_{tree}(\theta)=\emptyset\)，即新扫掠区域不与已分配动作、busy 智能体动作及未分配智能体足迹冲突；
  - 叶子节点即所有合法后继；子节点数量可能随 idle 智能体数指数增长，因此按需逐个展开。
- **搜索树**：
  - 搜索节点 \(n=(a,n_{parent},T,\lambda)\) 保存联合动作、父节点、动作树前沿 \(T\)、规则式状态 \(\lambda=(\epsilon,\Phi)\)；
  - 成本 \(g(n)=\sum_i g(a_i(n))\)，下界 \(f(n)=g(n)+\sum_i h_i(v_i)\)，其中 \(h_i\) 为到目标的最快路径时长；
  - Open 为栈结构，深度优先扩展；找到首个目标节点后，剪枝 \(f(n)\ge g(n^*)\) 的节点；
  - 当 Open 为空或时间耗尽时返回当前最优解 \(n^*\)。
- **Push Tree（推树）与 Ban Chain（禁入链）**：
  - 大智能体移动时可能同时挡住多个未规划智能体，形成推树；
  - 被推智能体必须离开推者的扫掠区域，且不能停在祖先推者的目标扫掠区域内；
  - **禁入链** \(\beta=\langle(k_1,u_1),\dots,(k_r,u_r)\rangle\) 记录祖先及其延迟移动目的地，被推智能体只能停在足迹不与 \(S(\beta)=\bigcup_q F_{k_q}^{sw}(v_{k_q},u_q)\) 冲突的顶点；
  - 推者在其“释放时间” \(t_{rel}\)（所有被推者离开其扫掠区域后）执行 **deferred move（延迟移动）**。
- **Evacuation（疏散）**：解决“大推者一次推动需要被推者多步让路”的问题，按顺序尝试三种方式：
  1. **严格疏散**：最多 \(d_s\) 步，终点同时离开 \(S(\beta)\) 和推者未来 \(\ell\) 步的“lane” \(L(\beta)\)，避免很快再次被推；
  2. **单步移动**：一步离开 \(S(\beta)\)，但可能仍位于 lane 上；
  3. **宽松疏散**：最多 \(d_l\) 步，仅要求离开 \(S(\beta)\)，作为最后手段。
  - 疏散路径不得推其他智能体，且不得与已规划智能体的扫掠区域或未规划智能体足迹冲突。
- **Action Queue 与 Pre-execution Check**：
  - 疏散的后续动作及推者的延迟移动按执行顺序存入各智能体的动作队列 \(\Phi_i\)；
  - 动作真正开始前执行 **预执行检查**：其扫掠区域不得与任何其他智能体的足迹或扫掠区域冲突；
  - 若检查失败或开始时刻已过，则清空队列并重新规划该智能体；
  - 该检查对大智能体尤其必要：等待期间其他智能体可能进入其未来扫掠区域中当前未被占据的格子。
- **规则式过程流程**：
  - 更新优先级 \(\epsilon_i\)（每次后继加一，到达目标后重置）；
  - 仅根节点读取动作队列，非根节点丢弃队列；
  - 按优先级降序处理未规划 idle 智能体，调用 `ASY_PUSH-LA`；
  - `ASY_PUSH-LA` 依次尝试严格疏散、单步移动、宽松疏散；单步移动若遇到阻挡则递归推动阻挡者，形成推树；全部失败则返回失败并尝试下一顶点。
- **理论保证**：
  - **定理 1**：LSRP*-LA 终止且对可解实例返回解；若运行至 Open 为空，则返回最优解；
  - 证明要点：动作树叶子恰为合法后继；规则式过程因只推动未规划智能体而递归深度不超过 \(N\)，且每个 idle 智能体都能获得动作；
  - **命题 1（疏散深度）**：方形智能体在无障碍情况下，横向离开宽度为 \(s_i\) 的条带最多需 \(\lfloor(s_i+s_j)/2\rfloor\) 步；若向前离开则至少需 \(\ell+1\) 步。据此取 \(\ell=6,d_s=4,d_l=3\)，可支持边长不超过 3 的方形智能体。

- **可扩展性最强**：在四张地图上 LSRP*-LA 的成功率均最高。`den520d` 上可扩展到 **800 个智能体**，而 LSRP-LA 为 400、PP-SIPP-LA 为 200、CBS-AA-LA 仅约 30；搜索使规则式方法可处理的智能体数翻倍。迷宫和空地图分别扩展到 250 和 300 个智能体。
- **解质量高**：
  - 相比 LSRP-LA，最终 SOC 最多降低约 **25%**；
  - 在 CBS-AA-LA 能求解的小规模实例上，SOC 最多仅高约 **2%**，接近最优；
  - 相比 PP-SIPP-LA，小规模接近 100%，大规模约 112%，总体可比。
- **异步规划收益显著**：与动作时长设为 5 的同步规划器（MD-PIBT、Layered LA-MAPF）相比，LSRP*-LA 的 SOC 约为其 **一半（25%–78%）**；即便将所有时长设为 1、回到同步 LA-MAPF 设定，LSRP*-LA 仍不更差（对 MD-PIBT 为 65%–99%，对 Layered LA-MAPF 为 38%–100%），说明其优势不仅来自异步动作，也来自更优的路径规划。
- **疏散机制关键**：无 evacuation 时，被推智能体反复被推，初始解成本高出 1.3–9.0 倍；60 秒后仍为有 evacuation 初始解的 110%–900%，而有 evacuation 时可降至 50%–95%。
- **理论性质**：LSRP*-LA 完备；若运行到搜索耗尽则返回最优解；实际 60 秒预算下表现为 anytime 持续改进。

  - 推树 + 禁入链解决“一个推者同时阻挡多个智能体”；
  - evacuation 解决“大推者需要被推者多步让路”的耦合问题；
  - 预执行检查解决异步动作下“未来扫掠区域被他人提前占用”的隐患。
- **理论保证较完整**：给出完备性、最优性定理及疏散深度命题，并为参数选择（\(\ell,d_s,d_l\)）提供依据。
- **兼顾可扩展性与解质量**：规则式过程保证快速

- **兼顾可扩展性与解质量**：规则式过程保证快速获得初始解，搜索负责在时间预算内持续改进，二者形成互补；因此在 800 个智能体规模仍能求解，同时在小规模实例上接近 CBS-AA-LA 的最优成本。
- **工程细节考虑较周全**：动作队列、预执行检查、延迟移动与释放时间等机制，针对异步动作下“未来扫掠区域可能被提前占用”的隐患作了防护，提升了规则式过程在真实执行语义下的安全性。
- **建模具有一定通用性**：通过 footprint 与 swept area 统一表达大智能体冲突，模型可退化为 MAPF-AA 与 LA-MAPF，便于与已有问题设定衔接。
- **实验比较口径较谨慎**：解质量比值仅在双方均成功的实例上计算，并补充“所有时长设为 1”的同步设定比较，部分缓解了异步时长带来的不公平性。

## 8. 局限与不足

- **最优性保证的实际意义有限**：理论最优性仅在搜索耗尽（Open 为空）时成立；60 秒预算下多数大规模实例只能获得 anytime 次优解，论文未系统报告最优性间隙随规模的变化。
- **模型仍偏理想化**：智能体以方格/足迹和固定移动时长描述，未显式考虑加速度、转向半径、运动学约束、动态障碍、通信延迟与执行误差；实际车队部署时可能需要更复杂的运动规划层。
- **冲突判定可能偏保守**：以扫掠区域相交且时间区间重叠作为冲突条件，安全性较好，但可能限制可并行的动作组合，尤其在狭窄通道中会放大拥堵与规划难度。
- **疏散参数依赖特定智能体尺寸**：\(\ell=6,d_s=4,d_l=3\) 的依据主要针对边长不超过 3 的方形智能体；更大尺寸、非方形或非完整约束智能体的适用性未充分验证。
- **目标函数单一**：仅优化 SOC 且冻结到达后的等待成本，未讨论 makespan、能耗、公平性或截止时间等工业指标；不同目标下的方法表现可能不同。
- **统计与复现信息不足**：每个配置 20 个实例，未报告置信区间、显著性检验、随机种子影响及参数敏感性；算力信息仅给出 MacBook Air 配置与 60 秒时限，缺少 CPU 核心数、并行方式和总运行时长等细节。
- **真实场景验证缺失**：实验均基于 MAPF 基准地图与离散仿真，未在真实机器人平台或高保真物理仿真中验证，实际执行中的时序抖动、定位误差与通信限制可能影响预执行检查与动作队列的可靠性。

## 9. 启示与可迁移点

- **“规则式快速构造 + 搜索 anytime 改进”的混合范式**对大规模多机器人规划具有较强参考价值：规则式方法负责可扩展性，搜索负责解质量，二者通过统一状态表示衔接。
- **预执行检查 + 动作队列**的思想可迁移到其他异步多智能体系统：在动作真正开始前重新验证冲突，可缓解规划与执行之间的时序偏差。
- **推树、禁入链与疏散机制**为“大智能体推动多个小智能体”的耦合问题提供了可操作的分解思路，可推广到异构尺寸机器人、移动障碍物或人机共融场景。
- **问题建模的退化能力**便于将新方法嵌入已有 MAPF/LA-MAPF 基准体系，也提示后续工作可在同一框架下逐步加入运动学、动态障碍与不确定性。

## 10. 总体评价

LSRP*-LA 的主要贡献在于将“大智能体”和“异步动作”两个现实假设同时纳入可扩展的 MAPF 框架，并通过规则式过程与搜索的结合，在数百至 800 个智能体规模上保持较高成功率，同时在小规模实例上接近最优。其理论分析、疏散机制与预执行检查具有较好的方法完整性，实验也覆盖了多种地图结构、智能体尺寸与速度以及多类基线。总体而言，这是一篇工程实现与理论保证结合较好的工作，适合仓储物流、自动化工厂等异构车队场景；但其最优性保证在大规模下较弱，模型仍偏理想化，统计显著性与真实机器人验证不足。未来可重点关注更大/非方形智能体、运动学约束、多目标优化、参数自适应以及真实平台部署。
