## 摘要
在无信号交叉口协同网联自动驾驶车辆时，必须联合决定通行顺序和车辆轨迹。对于固定的通行顺序，该问题可以方便地表述为双层形式：每辆车求解自身的最优控制问题，其最优值是车辆进入和驶出时间的函数；协调器则在先后顺序约束下优化这些时间。我们利用实时软件包 acados 通过算法微分计算下层问题的一阶和二阶灵敏度，这些灵敏度是求解上层问题所需的。该实现利用定制算法，获得了最优协同算法的高计算效率实现。我们在数值仿真中验证了该实现，结果表明我们的算法兼具实时可行性和有效性。

## Abstract
When coordinating connected and automated vehicles at an unsignalized intersection, the crossing order and the vehicle trajectories must be decided jointly. For a fixed crossing order, the problem can be formulated conveniently in a bi-level form where each vehicle solves its own optimal control problem, whose optimal value is a function of its entry and exit times, and a coordinator optimizes these times subject to precedence constraints. We compute the first and second order sensitivities of lower-level problems, which are required to solve the upper-level problem, by means of algorithmic differentiation using the real-time software package \texttt{acados}. This implementation exploits tailored algorithms to obtain a computationally efficient implementation of the optimal coordination algorithm. We validate our implementation in numerical simulations that demonstrate both real-time feasibility and effectiveness of our algorithm.
