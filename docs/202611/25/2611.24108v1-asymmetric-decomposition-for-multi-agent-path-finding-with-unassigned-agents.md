## 摘要
未分配任务的机器人可能会阻碍正在执行任务的机器人，而将其引导至指定停车位置又会造成不必要的行驶。本文提出流预言机冲突搜索（FOCBS）用于含未分配智能体的多智能体路径规划（MAPF-UA）。FOCBS 使用基于冲突的搜索（CBS）在已分配智能体路径上进行搜索，并通过最小费用流预言机为无目标未分配智能体规划路径。当所选的已分配智能体路径使未分配智能体不存在无碰撞路径时，流冲突分支将最小割阻塞者转化为已分配智能体约束，从而在不排除最优解的情况下引导搜索。批量零成本热启动加速预言机，避免起点的平局打破策略减少未分配智能体移动。对于有限图上的可行实例，我们证明算法终止，并证明以最后到达时间度量的已分配智能体服务时间总和全局最小。未分配智能体移动在所选已分配智能体路径条件下最小化，但不提供全局字典序最优性保证。基准实验表明，FOCBS 随未分配智能体数量增加具有良好的可扩展性；消融研究表明，与丢弃无法完成的已分配智能体路径相比，流冲突分支在保持最优性的同时能求解显著更多实例。仿真和实体机器人实验验证了计划的可执行性，实验室测试相对于基于停车的协调基线将车队行驶距离减少 40.8%。源代码及相关资源见 https://github.com/Chin-hsi/focbs。

## Abstract
Robots without assigned tasks may obstruct active robots, while routing them to designated parking locations can cause unnecessary travel. This article proposes flow-oracle conflict-based search (FOCBS) for Multi-Agent Path Finding with unassigned agents (MAPF-UA). FOCBS searches over assigned-agent paths using conflict-based search (CBS) and routes targetless unassigned agents through a min-cost flow oracle. When the selected assigned-agent paths leave unassigned agents no collision-free paths, flow-conflict branching converts min-cut blockers into assigned-agent constraints, which guide the search without excluding optimal solutions. A batched zero-cost warm start accelerates the oracle, and start-avoiding tie-breaking reduces unassigned-agent movement. For feasible instances on finite graphs, we prove termination and global minimization of assigned-agent sum of service time, measured by last-arrival times. Unassigned-agent movement is minimized conditional on the selected assigned-agent paths, without a global lexicographic optimality guarantee. Benchmark experiments show that FOCBS scales well with the number of unassigned agents, and ablation studies show that, compared with discarding non-completable assigned-agent paths, flow-conflict branching solves substantially more instances while retaining optimality. Simulation and physical-robot experiments demonstrate plan executability, with laboratory tests reducing fleet travel by 40.8% relative to the parking-based coordination baseline. The source code and related resources are available at https://github.com/Chin-hsi/focbs

## 1. 核心问题与研究动机

- **应用背景**：自动化仓库、履约中心、制造物流与自动驾驶实验室中的多机器人系统依赖 MAPF 计算无碰撞路径。滚动时域方法把终身 MAPF 分解为连续的规划片段，但在许多实际系统中，**并非每个机器人在每个规划片段中都分配了任务**。
- **问题痛点**：
  - 把空闲（未分配）机器人当作**静态障碍**，会堵塞狭窄通道，迫使活跃机器人绕远路甚至不可达；
  - 把空闲机器人**送往指定停车点**，虽能清空通道，却造成大量不必要的行驶，并占用宝贵的工作空间（图 2 的三方案对比：(SST, SMU) 分别为 (4,0)、(2,3)、(2,1)）。
- **形式化对象**：MAPF-UA（Multi-Agent Path Finding with unassigned agents）。已分配智能体 $A$ 有起点 $s_i$ 与目标 $g_i$；未分配智能体 $U$ 只有起点 $\hat s_j$、**无目标，可终止于任意顶点**；所有智能体须无顶点冲突、无对向边冲突。
- **优化目标（顺序/字典序式）**：
  - 先最小化已分配智能体的**服务时间总和 SST**（以“最后到达时间” $t_i^{last}$ 度量，即到达目标后必须一直停留）；
  - 再在**选定 A-paths 条件下**最小化未分配智能体的**移动总和 SMU**。
  - 注意：这不同于“全局字典序最优”（后者还要在全部 SST 最优 A-paths 中再最小化 SMU）。
- **核心难点**：
  1. 未分配智能体的**终点是决策变量**，且在同一组顶点上置换等价，状态空间冗余；
  2. SST 最优的 A-paths 可能恰好占用了未分配智能体“让路”所需的时空资源，导致其无解（Remark 1：$C_A \le C^*$，但 $C_A$ 对应的 A-paths 可能不可完成）；
  3. 直接对两类智能体联合跑 CBS，会因未分配智能体相关冲突的分支而爆炸，可扩展性差。

## 2. 方法论：FOCBS（Flow-Oracle Conflict-Based Search）

### 2.1 核心思想：非对称分解

- **Proposition 1（非对称结构）**：
  - (a) 寻找 SST 最优且**可完成**的 A-path 集是 **NP-hard**（$m=0$ 时退化为经典最优 MAPF）；
  - (b) 固定 $\pi_A$ 后，为无目标的未分配智能体找最优 U-paths（或判定 $R(\pi_A)=\varnothing$）可在 **TEN 规模的多项式时间**内完成（单商品最小费用流）。
- 因此：**高层只对已分配智能体做 CBS 搜索，未分配智能体交给流 oracle**；oracle 失败时把失败信息（最小割阻塞者）反馈为已分配智能体的 CBS 约束。

### 2.2 算法流程（Algorithm 1）

- CT 节点 $N$ 只存约束与 A-paths $\pi_N^A$，OPEN 按 SST 排序；
- 若 A-paths 之间存在冲突 → 标准 CBS 分裂（对冲突双方各建子节点）；
- 若 A-paths 相互无冲突 → 调用 `FLOWORACLE`：
  - 成功：返回完整计划 $(\pi_N^A,\pi_U)$；
  - 失败：构造诊断 TEN、求最大流，由残量网络源可达集得到**最小 $s^+$–$s^-$ 割**，割中带标签的零容量弧即 **blocker**；每个可分支 blocker 生成一个子节点（禁止 $(a_i,v,t)$ 顶点占用或 $(a_i,v,w,t)$ 边穿越），重规划该智能体；
- 无任何可分支 blocker → 该节点无可行完成，剪除；
- 返回 `INSTANCE_INFEASIBLE` 表示实例无解。

### 2.3 时间扩展网络（TEN）构造（图 4）

- 顶点-时间分裂节点 $v_t^{in}\to v_t^{out}$（容量 1、成本 0）实现顶点容量；
- 等待弧 $v_t^{out}\to v_{t+1}^{in}$（容量 1、成本 0）；
- **merge–split 边 gadget**：每条边每个时间区间 5 条单位容量弧，中央弧 $e_t^{in}\to e_t^{out}$ 成本 1（计一次移动），对向移动共享该弧从而互斥；
- 源弧 $s^+\to(\hat s_j)_0^{in}$；汇弧 $v_{T_N}^{out}\to s^-$ 对**所有顶点**开放（体现“任意终点”）；
- A-paths 的每个时空占用被“删除”或（诊断 TEN 中）容量置 0 并打标签；对向移动弧亦置 0；
- 关键性质：固定 horizon 下不同 A-paths **只改变弧容量**，故同一割的容量可跨 A-paths 比较。

### 2.4 流冲突分支的正确性（Lemma 2，核心理论贡献）

- 设当前 A-paths 下最大流割 $\delta^+(S)$ 容量 $<m$。若存在某个可行完成计划**保留所有可分支 blocker**，则其限制到 $0..T_N$ 会诱导一个价值 $m$ 的流，要求 $\bar c(\delta^+(S))\ge m$；但只有“释放某个带标签保留弧”才能让割弧增容，于是 $\bar c \le c_N < m$，矛盾。
- 结论：**对全部可分支 blocker 的分支构成一个覆盖所有可行完成的析取**（含更长 horizon 的完成），因此不会丢失最优解；等价于一条 nogood 约束 $\sum_{b\in B} x_b \le |B|-1$（类似逻辑型/组合 Benders 反馈）。

### 2.5 加速与降本技巧

- **BZ-SSP（批量零成本热启动，Algorithm 2）**：对在 $[0,T_N]$ 全程未被保留的起点，先批量插入零成本原地等待流（$k_0$ 条），再对剩余 $m-k_0$ 单位在完整残量网络上跑 SSP（允许改道），保持最小费用（Proposition 3）。
- **起点规避平局打破（start-avoiding tie-breaking）**：
  - 低层 LexA* 键 $\langle f, c, p, h\rangle$，$p$ 为部分路径访问未分配起点的次数；
  - 高层同 SST 节点按 $(d,q)$ 排序，$q$ 统计访问未分配起点的次数；
  - 仅在等价代价间打破平局，**不改变 SST 最优性**，但减少“迫使未分配智能体移动”的路径。

### 2.6 理论保证

- **Lemma 1**：oracle 返回 $R^*(\pi_A)$ 或正确报告 $R(\pi_A)=\varnothing$（含 canonical flow 论证：turnback 可替换为等待弧降本）。
- **Proposition 2**：沿 CT 分支，各智能体最后到达时间、SST、$T_N$ 单调不减，且 $T_N \le SST(\pi_N^A)$。
- **Theorem 1**：有限图上**可行实例**中 FOCBS 终止并返回顺序最优解（SST 全局最优 $C^*$，SMU $=Q(\hat\pi^A)$）；但**不保证全局字典序最优**；**不可行实例不保证终止**。
