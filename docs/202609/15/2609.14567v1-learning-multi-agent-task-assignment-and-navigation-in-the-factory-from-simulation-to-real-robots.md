## 摘要
强化学习（RL）在机器人决策中已展现出相当大的潜力，但将多智能体强化学习（MARL）部署到工业环境中的实体多机器人系统上仍然具有挑战性。本文研究了去中心化MARL在多机器人多机床看护中的实际适用性。我们提出了特征融合多智能体近端策略优化（FMAPPO），该方法将2D LiDAR测量值与任务特定状态信息相融合，以实现安全的去中心化多机器人任务分配与导航。我们使用高保真机器人仿真和ROS2开发了一套完整的从仿真到现实的流程，并将其部署在真实世界条件下运行的实体移动机械臂平台上，实验中机械臂处于禁用状态。我们进一步研究了学习策略对指令更新频率的敏感性，这是实际部署中的一个重要考量。仿真中的对比评估表明，FMAPPO以较大的效应量显著优于最先进的基线方法：在零件配送方面，相较于MAPPO和SMAPPO分别提升106%和21%；在零件收集方面，分别提升48%和11%。与MAPPO和SMAPPO相比，FMAPPO还将机器利用率分别提高了31和10个百分点，同时使碰撞分别减少18%和15%，并使安全分数分别提高14和6个百分点。此外，真实世界实验表明，学习到的去中心化策略能够协调多个机器人服务多台机器，同时在实际传感与控制约束下保持安全运行。真实世界实验视频可在线获取：https://anonymouspapers123.github.io/FMAPPO/。

## Abstract
Reinforcement learning (RL) has shown considerable promise for robotic decision-making, yet deploying multi-agent RL (MARL) on physical multi-robot systems in industrial environments remains challenging. This paper investigates the real-world applicability of decentralized MARL for multi-robot multi-machine tending. We propose Feature-fusion Multi-Agent Proximal Policy Optimization (FMAPPO), which fuses 2D LiDAR measurements with task-specific state information to enable safe decentralized multi-robot task assignment and navigation. A complete simulation-to-reality pipeline was developed using high-fidelity robotic simulation and ROS2 and deployed on physical mobile-manipulator platforms operating under realistic real-world conditions, with the robotic arms disabled during the experiments. We further investigate the sensitivity of the learned policy to command update frequency, an important consideration for real-world deployment. Comparative evaluation in simulation demonstrated that FMAPPO significantly outperformed state-of-the-art baselines with a large effect size, achieving improvements of 106\% and 21\% in parts delivery and 48\% and 11\% in parts collection over MAPPO and SMAPPO, respectively. FMAPPO also increased machine utilization by 31 and 10 percentage points, respectively, while reducing collisions by 18\% and 15\% and increasing the safety score by 14 and 6 percentage points compared with MAPPO and SMAPPO, respectively. Furthermore, real-world experiments demonstrated that the learned decentralized policies can coordinate multiple robots to service multiple machines while maintaining safe operation under real-world sensing and control constraints. Videos of the real-world experiment are available online https://anonymouspapers123.github.io/FMAPPO/.

## 2. 方法论

### 2.1 核心思想

- 以 **MAPPO** 为骨干，遵循 **CTDE**（集中训练、分散执行）范式：Actor 仅用局部观测执行，Critic 训练时可见全局状态。
- 核心洞察：任务语义状态与高维 LiDAR 几何信息**角色不同**，若直接拼成一个同质观测向量会掩盖差异。因此提出**特征融合编码器（Feature-fusion Encoder）**，让几何分支与语义分支独立编码后再融合。

### 2.2 观测编码器关键技术细节

- **LiDAR 分支**：
  - 降采样后的距离向量（归一化到 [0,1]）单独处理；
  - 3 个一维卷积块（Conv1d + ReLU + MaxPool1d）逐步提取局部空间特征；
  - 再经全连接层 + ReLU + LayerNorm，得到紧凑的 LiDAR 嵌入（8 维）。
- **实体语义分支**：机器人位置/速度、机器、存储区、邻近机器人分别由独立的 FC + ReLU + LayerNorm 编码（Actor 中均为 16 维），学习各类实体的专门表示。
- **融合与注意力聚合**：
  - LiDAR 嵌入先与自身位置、速度拼接，送入 agent encoder 得到 agent embedding；
  - 对**每一类实体**分别施加独立的多头注意力模块，以 agent embedding 为 Query，以该类实体嵌入为 Key/Value，得到机器、存储区、邻近机器人三个 context vector；
  - agent embedding 与三个 context vector 拼接构成最终观测嵌入。

### 2.3 Actor / Critic 结构

- **Actor**：观测编码器 → 3 个 FC 块（Linear + ReLU + LayerNorm）→ 线性层输出连续动作分布的均值；动作标准差的对数为可学习参数。训练时从高斯分布采样以鼓励探索，评估时直接取均值。
- **Critic**：对所有智能体并行应用观测编码器，再用带**可学习 Query** 的多头注意力将各 agent 嵌入聚合为定长全局状态表示，经 LayerNorm 与 3 个 FC 块后由线性层估计状态价值。

### 2.4 观测、奖励与动作

- **观测**（在前序工作基础上扩充）：
  - 机器人全局位置 + 是否携带零件的二值标志；
  - 所有机器的相对位置 + 零件可用状态；
  - 指定投放区（drop-off）的相对位置；
  - 其余机器人的相对位置 + 是否携带零件；
  - **新增**：机器人 z 轴朝向与线速度、两台 LiDAR 的处理后距离点、其他机器人的相对朝向与线速度。
  - LiDAR 预处理：降采样 → 超出最大探测距离的点重置为最大值 → 归一化到 [0,1]。
- **奖励函数**：沿用前序工作的收集奖励 $R_{pi}$、配送奖励 $R_{pl}$、距离塑形奖励 $R_{pm}$/$R_{ps}$、时间惩罚 $R_t$，并做两处改进：
  - **碰撞惩罚分解**：新碰撞惩罚 $R_{nc}$（首次发生碰撞时施加）与碰撞持续惩罚 $R_{dc}$（碰撞存续的每个时间步施加），且设计为 $R_{nc} > R_{dc}$，强烈抑制碰撞的"发生"而非仅仅惩罚"持续"，理由是真实部署中预防碰撞比事后恢复更关键。
  - **未收集零件惩罚精化**：只惩罚当前未携带零件的机器人，避免惩罚正在运输中的机器人：
    $$R_u = \begin{cases} s_u \cdot p_{un}/M & \text{若机器人未携带零件} \\ 0 & \text{否则} \end{cases}$$
    其中 $s_u$ 为缩放系数，$p_{un}$ 为未收集零件总数，$M$ 为机器数。
  - 总奖励：$R_T = R_{pi} + R_{pl} + R_{nc} + R_{dc} + R_{pm} + R_{ps} + R_u + R_t$。
- **动作空间**：连续的机器人 x、y 轴线速度指令（全向底盘）。不含角速度，但朝向保留在观测中，以应对运动中的航向漂移、仿真碰撞引起的朝向改变，以及某些移动操作平台对朝向的要求。

### 2.5 仿真与真实部署流程

- **仿真**：NVIDIA Isaac Sim（高保真 GPU 加速物理）+ Isaac Lab（多智能体 RL 支持）。6×6 m 场地，2 机器人 / 2 机器 / 1 存储区，实体随机初始化且任意两实体最小间距 2.1 m，位置限制在中心 4.2×4.2 m 区域。**操作动作被抽象**：到达机器即视为成功收集，到达投放区即视为成功配送。机器人模型为 Rangen（AgileX Ranger Mini 全向底盘 + Kinova Gen3 机械臂，本工作不使用机械臂）。
- **真机平台**：两台 Rangen；两个 Hokuyo UAM-05LP 2D 安全 LiDAR 对角安装实现 360° 覆盖；NVIDIA Jetson AGX + Intel NUC 提供机载算力；另配 Phidgets IMU、RoboSense Helios 16P 3D LiDAR、OAK-D Pro Wide RGB-D 相机。
- **真机部署架构（完全去中心化）**：
  - 定位：EKF 融合轮式里程计与 IMU；两台 2D LiDAR 的扫描合并后经 SLAM Toolbox 做 SLAM 估计世界坐标系位姿并更新 TF 树；Odom Publisher 节点融合位姿与速度生成最终 odometry。
  - 通信：每台机器人运行在独立 ROS Domain ID 内，**Zenoh** 作为机器人内部及机器-机器人之间的中间件（低开销、灵活发布订阅），每个机器人与机器各托管一个 Zenoh Router；ROS Domain Bridge 只选择性导入必要话题（其他机器人 odometry 与 has_part、与机器交互的 is_collected/set_collected）。
  - **FMAPPO Wrapper**：加载训练好的策略、从 ROS 话题采集观测、构造观测向量、执行推理、发布速度指令到底层控制器。
  - 实验中两台机器在单台地面站笔记本上仿真，移动机械臂为实体平台。

## 3. 实验设计

### 3.1 仿真主对比实验

- **基线**：MAPPO、SMAPPO（用 SKRL 库中同一 MAPPO 实现复现其观测编码器）。
- **训练设置**：三者同条件训练 **500K 环境交互步**、**256 个并行环境**；每 episode 300 步，固定 150 步的零件处理延迟，两台机器每 episode 最多产出 4 个零件；每个环境步对应 6 个物理仿真步（相同指令重复执行）。
- **评估**：取训练最后 200 个 episode 作为收敛阶段，**7 个不同随机种子**，报告均值（标准差）。
- **指标**：零件收集数、配送数、碰撞数、安全分数 $S_T = \frac{1}{1 + C_T/(P_c+P_d)}$、机器利用率 $MU = P_c/P_{max}$。
- **统计方法**：Shapiro–Wilk 正态性检验 → 配对样本 t 检验 + Holm–Bonferroni 多重比较校正（α=0.05）→ Cohen's 标准化均值差衡量效应量。
