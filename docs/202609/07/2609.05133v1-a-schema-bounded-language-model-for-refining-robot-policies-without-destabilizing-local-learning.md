## 摘要
本文研究了在分散式系统中，当策略推理和本地控制在不同更新级别运行时，复合异构机器人的导航问题。在一个NetLogo--Python实现中，三个机器人共享运动动力学但使用不同的LLM后端。每个机器人独立地结合了一个大语言模型（LLM）策略代理、一个置信上界（UCB）老虎机和一个双重深度Q网络（Double DQN）控制器；没有中央LLM生成团队动作。LLM推理被限制在轮次级的策略生成和细化，而不是tick级的动作选择。机器人通过包含策略、结果和学习反馈的共享轮次摘要进行跨LLM通信。UCB执行细化模式选择，而策略条件化的Double DQN从导航变量、活动策略参数和LLM动作先验中执行tick级动作选择。四种配置中的每一种均在30轮中进行了评估。在固定仿真中，完整配置在所有90个关联的机器人-轮次记录中均到达目标，并实现了最低的中位完成时间（42 ticks）和P90（73.2 ticks）；其中位数比其他配置低25.0--39.1%。这些观察结果提供了来自所评估配置的描述性、配置级证据。

## Abstract
This paper addresses navigation by composite heterogeneous robots in a decentralized system when policy reasoning and local control operate at different update levels. In a NetLogo--Python implementation, three robots share motion dynamics but use different LLM backends. Each robot independently combines a large language model (LLM) policy agent, an Upper Confidence Bound (UCB) bandit, and a Double Deep Q-Network (Double DQN) controller; no central LLM generates team actions. LLM inference is confined to round-level policy generation and refinement rather than tick-level action selection. The robots perform cross-LLM communication through a shared round summary containing policies, outcomes, and learning feedback. UCB performs refinement-mode selection, and the policy-conditioned Double DQN performs tick-level action selection from navigation variables, active policy parameters, and the LLM action prior. Each of the four configurations was evaluated over 30 rounds. In the fixed simulation, the complete configuration reached the goal in all 90 correlated robot--round records and achieved the lowest median completion time (42 ticks) and P90 (73.2 ticks); its median was 25.0--39.1\% lower than those of the other configurations. These observations provide descriptive, configuration-level evidence from the evaluated configurations.

# 详细总结

## 1. 核心问题与整体含义

- 研究背景：异构多机器人系统需要将不同物理/决策能力的智能体组合起来完成共享任务；大语言模型（LLM）为此类系统带来了语言介导的任务分解、通信和政策自适应能力。
- 核心矛盾：在持续导航任务中，**策略推理**（policy reasoning）与**运动控制**（motion control）运行在不同更新层级——LLM适合在任务边界生成/细化策略，而本地控制器需要在每个仿真时间步（tick）选择动作。若每一步都调用 LLM，等于把策略推理放进了本地控制环路内部，容易造成决策延迟和局部学习不稳定。
- 具体研究问题：如何让**机器人特有的、持续存在的 LLM 策略**能从共享的"已完成回合"信息中持续细化，同时又让本地强化学习提供每个运动动作？这需要显式区分：策略所有权、跨 LLM 通信、回合级策略细化、tick 级动作选择四者的职责边界。
- 整体思路：提出一种"模式受限（schema bounded）"的分散式双层架构——每台机器人拥有自己的 LLM 策略体、UCB bandit 和 Double DQN；LLM 只在回合边界生成/细化策略，不参与逐 tick 动作决策；UCB 决定细化的"模式"，Double DQN 在该策略条件下执行 tick 级动作。这样既保留 LLM 的高层推理能力，又避免其破坏局部学习的稳定性。

## 2. 方法论

### 2.1 系统架构

- 复合机器人模型：每台机器人由四部分组成：
  - `Ti`：NetLogo turtle（底层运动仿真体）
  - `Mi`：专用 LLM 策略体（负责回合级策略生成与细化）
  - `Ui`：UCB1 bandit（负责选择细化模式）
  - `Di`：Double DQN 控制器（负责 tick 级动作选择）
- 去中心化：决策权和持久控制状态均在机器人本地，**不存在中央 LLM** 生成团队策略或选择机器人动作。
- 三种 LLM 后端分别配给三台机器人：Llama-3.3-70B-Instruct（量化）、Phi-4、Meta-Llama-3.1-70B-Instruct（量化）。
- 共享文本板（shared board, `Bk`）：用于交换已完成回合的策略、结果、理由说明、DQN 反馈与 UCB 建议；各 LLM 读同一块板但只生成自己机器人的下一条策略。

### 2.2 双层时序解耦

- LLM 推理只发生在**回合边界**：每台机器人在每轮之前恰好调用 LLM 一次（初始化 1 次 + K−1 次细化），总计 K 次/机器人；LLM **不会**被用于 tick 级动作选择。
- UCB 在回合结束后评估上一轮策略效果，并为下一轮选择一种"细化模式"。
- 模式集合：
  - KEEP_CURRENT（保留当前策略）
  - ADOPT_BEST_SHARED（采纳最佳共享策略）
  - SMALL_MUTATION（小幅变异）
  - EXPLORE_NEW（大幅探索）
  - HYBRID_WITH_BEST（本地稳定组件与共享最优组件混合）
- UCB 更新与选择公式：
  - 更新：`n_{i,z} ← n_{i,z} + 1`，`R_{i,z} ← R_{i,z} + (R_i^k − R_{i,z})/n_{i,z}`
  - 选择：`z^{k+1}_i = argmax_z [ R_{i,z} + c√(ln(n_i+1)/n_{i,z}) ]`，其中 c=1.4
  - UCB 信用奖励：成功并到达目标时 `R_i^k = min(1, L_i / max(T_i^k, 1))`，其中 `L_i = ⌈d_i^0/3⌉`（乐观移动下界）；失败为 0。

### 2.3 LLM 策略格式与消毒机制

- 一条回合策略由数值运动向量与四个区域动作偏好组成：
  - 数值字段：标准前进步 `δ`、近目标步 `δ_near`、最大转向角 `ω`、对齐阈值 `α`、近目标距离阈值 `d_near`
  - 区域偏好：far/misaligned、far/aligned、near/misaligned、near/aligned，分别从五动作集合 `A` 中挑选（FORWARD、FORWARD_SMALL、TURN_ONLY、TURN_AND_FORWARD、TURN_AND_FORWARD_SMALL）
- LLM 推荐动作 `a_LLM(d,e)` 是一个**软先验**，而非强制动作。
- 模式受限/消毒：LLM 输出先解析为 JSON/dict，再按合法范围进行清洗，缺省或非法字段沿用当前默认值；初始化失败加载完整默认策略，后期细化失败则保留上一轮可用策略。这一机制避免了 LLM 的格式错误或超界输出"污染"已稳定运行的控制器。

### 2.4 策略条件化 Double DQN

- 输入为 15 维状态（每块 5 维）：
  - 导航状态：当前距离、归一化角度误差、是否在近区、是否对齐、距离历史通道
  - 活动策略参数：前进步/最大转角/对齐阈值等归一化后的数值
  - LLM 动作先验：根据当前策略与状态计算的区域动作 one-hot 编码
- 网络结构：R¹⁵ → 64 ReLU → 64 ReLU → R⁵
- 动作选择：概率 ε 下均匀随机探索；否则在 Q 值上加上 LLM 先验偏置 `β p`（C4 中 β=0.05）：`argmax_a [Q(s,a) + β p(s,a)]`
- 目标计算（Double DQN）：用在线网络选动作，用目标网络求 Q 值；γ=0.99
