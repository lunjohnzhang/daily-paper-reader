## 摘要
我们研究图上的无碰撞移动问题，其中任务是协调一组机器人，使其在最小化总移动距离的同时，到达满足某种期望性质的目标队形。该框架扩展了两类经典模型：(a) 最小化移动 [Demaine et al., TALG '09, '14]，其不强制避免碰撞；(b) 协调运动规划或多智能体路径规划 [Eiben et al., SoCG '23, Deligkas et al., ICALP '24, 以及许多其他工作]，其中每个机器人被分配一个明确的目标位置。我们关注机器人的目标队形应当连通的情形。我们分析该问题关于（主要）机器人数量和总移动长度在网格图及其两种自然推广——平面图和单位圆图——上的参数化复杂度。

## Abstract
We study collision-free movement problems on graphs, where the task is to coordinate a set of robots so that they reach a target formation satisfying a desired property while minimizing the total travel distance. This framework extends two classical models: (a) minimizing movement [Demaine et al., TALG '09, '14], which does not enforce collision avoidance, and (b) coordinated motion planning or multi-agent path finding [Eiben et al., SoCG '23, Deligkas et al., ICALP '24, among many others], where each robot is assigned an explicit target position.   We focus on the setting where the target formation of the robots should be connected. We analyze the parameterized complexity of the problem with respect to the number of (main) robots and the total travel length on grid graphs and two natural generalizations thereof: planar graphs and unit disk graphs.

## 2. 方法论：核心思想与关键技术细节

- **问题形式化**：给定图 `G=(V,E)`、主机器人起始位置集 `R`、恶意机器人集 `O`（`R∩O=∅`）及整数 `c`，询问是否存在长度 ≤ `c` 的无碰撞运动计划，使得终态主机器人诱导子图满足性质 `Π`。运动 `M_r` 是顶点序列，每一步可停留或移到相邻顶点；两运动"无碰撞"要求任一步不占同一顶点、任一步不交换使用同一条边（反向冲突）。

- **难度结果（第4节）**：
  - **定理1**：从 **Multicolored Clique** 参数化归约证明 *Collision-Free Movement to Connectivity* 关于 `k+c` 是 **W[1]-hard**。归约使用"边选择 gadget"（每条边对应一个恶意机器人）与"验证 gadget"（编码颜色/端点一致性）。
  - **定理2**：从 **Linked Planar 3-SAT** 归约证明即使 `k=2` 且输入为**网格图**也是 **NP-hard**。构造分两步：先构造平面实例（变量 gadget + 子句 gadget + 等长子路径），再通过"展开"嵌入为网格（引入子句 gadget、等长"蛇形"路径、足够大的间隙区）。

- **核化算法（第5节）**：
  - **Reduction Rule 1**：若顶点 `v` 到所有主机器人起始位置的距离 > `c`，则删除 `v`（及其上的恶意机器人）。安全性证明基于"移动恶意机器人需要消耗主机器人邻近路径上的步数"。
  - **Reduction Rule 2**（仅连通性）：若存在主机器人 `r` 使 `dist(v,r) > c+k`，则删除 `v`。
  - 网格中半径 `c` 的球含 `O(c²)` 个顶点，故**定理3**给出 `O(k·c²)` 多项式核；**定理4**通过两条规则给出 `O(min{k·c², k²+c²})` 核。

- **核化下界（第5节）**：
  - 使用 **OR-cross-composition** 与 **weak cross-composition** 框架（基于 Linked Planar 3-SAT 与定理2的构造），证明在 `coNP ⊆ NP/poly` 假设下无多项式核（定理5、6、7）。

- **平面图 FPT（第6节）**：
  - 核心思想：将问题表达为 **MSO（单子二阶逻辑）**，再调用 **Courcelle 定理**（MSO 模型检测关于 `tw(A)+|φ|` 是 FPT）。
  - 构造关系结构 `A`，universe 含 `V, E, [c], Sv=V×[c], Se=E×[c]`，8个关系符号（main、robot、inc、vertex、edge、step_v、step_e、nextstep）。
  - 树宽界：`tw(A) ∈ O(c·tw(G)²)`；公式 `φ` 大小 `O(c²)+f(k)`；先用 Reduction Rule 1 限制直径 `O(k·c)`，再由平面图得 `tw(G) ∈ O(k·c)`，从而证明**定理8**（关于 `k+c` 是 FPT，且该算法实际对"`k+c`+树宽"亦成立）。

- **单位圆盘图 FPT 近似（第7节）**：
  - 利用单位圆盘图是 **clique grid**（每个网格单元内为团，附加边仅在距离 ≤2 的单元间）的性质。
  - 算法流程：猜测最优 `c` → 应用 Reduction Rule 1 → 猜测 `k` 顶点连通树 `T` 及主机器人到 `T` 的映射 → 计算 **continuation type**（编码每步可达的团-类型对）→ 猜测类型向量作为运动模板 → 校验运动合法性/无碰撞/子图嵌入（调用 Demaine et al. 的子图嵌入算法）→ 构造运动计划。
  - 因"只能保证进入正确类型而非正确顶点"，每个团可能多花一步，导致**近似因子2**；最后归位每主机器人最多再花3步，故能量 ≤ `2·OPT + 3k`（**定理9**）。
