## 摘要
在一组机器人移动之前，必须检查每个提议步骤是否与其他机器人及障碍物发生碰撞。我们提出 CollisionGAT，一种图注意力网络，它读取移动智能体的当前状态和提议状态，以及局部相关的静态障碍物，并为每个移动智能体返回一个碰撞风险分数。任何控制器都可以利用这些分数来接受、修复、重新规划或推迟某个提议步骤。我们将 CollisionGAT 部署在连续路径跟随控制器上，以及部署在 GATeD 上；GATeD 是一种对障碍物无感知的 D* Lite 规划器，它使用类型化否决来更新其规划图。精确几何检查提供训练标签，并独立审计每个执行步骤。

## Abstract
Before a team of robots moves, each proposed step must be checked for collisions with other robots and with obstacles. We present CollisionGAT, a graph-attention network that reads the current and proposed states of moving agents together with locally relevant stationary obstacles and returns one collision-risk score per moving agent. Any controller can use these scores to accept, repair, replan, or postpone a proposed step. We mount CollisionGAT on a continuous path-following controller and on GATeD, an obstacle-blind D* Lite planner that uses typed vetoes to update its planning graphs. Exact geometric checks supply the training labels and independently audit every executed step.

## 1. 核心问题与研究动机

- **背景**：多机器人团队在执行动作前，必须逐步检查每个提议步是否与其他机器人或障碍物发生碰撞。这一决策本质上是**关系型**的——单独看对某机器人安全的步，可能落到另一机器人的目标位置、撞入障碍物，或使两个机器人争夺同一格。
- **难点**：有意义的邻居数量每个时间戳都在变化，检查器必须处理**可变数量的智能体与障碍物**。
- **现有方案的问题**：精确几何谓词虽精确，但穷举筛查需评估约 `n² + nm` 个智能体–智能体、智能体–障碍物对，计算昂贵，且难以与任意控制器/规划器灵活解耦。
- **定位**：论文刻意让 CollisionGAT “做得更少”——外部控制器提供动作，网络只负责**分类**该动作是否危险；控制合成与形式化认证保持为互补角色。
- **核心含义**：提出一种**控制器无关（controller-agnostic）**的一步碰撞筛查层，介于“提议”与“执行”之间，返回每智能体一个风险分数，供控制器接受、修复、重规划或推迟。

## 2. 方法论

### 2.1 核心思想
- 用**四头成对注意力图神经网络**读取每个智能体的当前状态与提议状态，以及局部相关的静止障碍物，为每个活跃智能体输出一个碰撞风险分数。
- 接口极简：控制器送入当前与提议状态（每个节点带“智能体/障碍物”类型标签），网络返回每智能体一个风险分数；控制器据此决策。
- **不接收**相对位移、距离或碰撞裕度等工程化特征，完全依赖原始状态与注意力机制学习关系。

### 2.2 问题形式化
- 世界 `W` 含活跃智能体集 `A_t` 与静止障碍物集 `O`；智能体 `i` 当前占据 `p_i`，控制器提议一步状态 `q_i`，到达为吸收态。
- **连续运动**：`W = [0,L]²`，智能体占据闭球 `B(z, r_i)`，障碍物占据闭方块 `Q(c_o, a_o)`。
- **离散运动**：`W = Λ_N`（N×N 网格），合法提议为原地或四邻域移动，起点两两不同。

### 2.3 精确标签定义（作为教师与审计）
- **网格标签**：进入障碍格（`y^obs`）；两智能体同格或头对头交换（`y^agt`）；合并为 `y^all`。
- **连续扫掠标签**：沿直线中心轨迹 `γ_i(λ)`，用最小距离判定智能体–智能体（`y^sw,agt`）与智能体–障碍物（`y^sw,obs`）碰撞。

### 2.4 交互图与特征
- **边过滤** `χ_t(u,i)`：仅保留在提议步中可能与 `i` 碰撞的发送者。连续情形先用轴对齐包围盒（按智能体半径扩张）粗筛，仅保留包围盒可能重叠的发送者对。
- **连续特征（7 维）**：以活跃智能体质心 `c_t` 为中心的当前位置、提议位置、步长 `ℓ_i`、半径 `r_i`、障碍物指示位。
- **网格特征（5 维）**：以网格中心归一化的当前位置、提议位置、障碍物指示位。
- 障碍物位置重复、步长为零；中心化用于去除全局平移。

### 2.5 四头成对注意力分类器
- 成对表示 `z_ui = [x_u ‖ x_i]`；每个注意力头 `h` 有一个标量注意力 logit MLP 与一个 16 维消息 MLP。
- 三种发送者视图：`all`（全部）、`agt`（仅智能体）、`obs`（仅障碍物）；各自做注意力加权平均后拼接为 64 维消息 `M^μ_i`。
- 更新：自编码器 `φ_x` → 与消息拼接 → 更新映射 `φ_u` → 残差 + LayerNorm → 线性层 + Sigmoid 得风险分数 `ŷ^μ_i`。
- 隐藏层宽度 64，每头 16 维消息，dropout 0.10；**连续模型 29,381 参数，网格模型 27,205 参数**。
- 阈值化决策：`ĉ_i = 1{ŷ^agt ≥ τ_agt ∨ ŷ^obs ≥ τ_obs}`（网格版含 `y^all`）；视图共享同一权重，分数是调优风险而非校准概率。

### 2.6 训练流程
- **网格模型**：先学 40,000 个基础碰撞原语场景 → 在 2,100 个大世界联合转移场景上微调。
- **连续模型**：2,800 个原语图起步 → 任务适配用 4,410 个目标导向图 + 1,102 个原语回放图 → 再用 13,200 个部署匹配/困难/控制器生成图精炼冻结模型。

### 2.7 两个控制器挂载（算法流程）
- **算法 1（连续 CollisionGAT-Guard）**：各智能体独立跑 A* 得路径，贪心缩短为路点序列；按 `ℓ_i,t ~ U[0.4,1.2]` 采样步长朝当前路点推进（最后一步截断以免越过路点）；对提议做 GAT 评估 → 最多 5 次修复（降低被警告智能体速度）→ 其余被警告智能体保持等待，逐个恢复直到无移动警告 → 仍警告则原地不动；同步提交并退休到达者。
- **算法 2（离散 GATeD）**：各智能体持有完整四连通网格图，规划器**对真实障碍物无感知**；D* Lite 增量修复返回下一最小代价格。
  - **类型化否决**：障碍物归因警告 → 将格加入共享“已发现墙”集合 `b̂`，并**永久**从所有规划器删除该格关联边；其他移动警告或优先级失败 → 仅临时移除 `(p_i, q_i)` 边至下一时间戳。
  - **决策**：先由确定性优先级解决重复目的地、交换、移入等待者格（静止者胜，否则最低 ID 胜）；重规划直至接受或无修复预算，否则全等待。
  - 精确网格谓词仅审计已提交步，**从不修改动作**。

## 3. 实验设计

### 3.1 数据集 / 场景
- **两个独立的 100 世界测试套件**（连续与离散分开评估）。
- **连续套件**：50 个生成的 25×25 方形障碍世界 + 50 张来自最低复杂度带的 50×50 PNG 地图；每回合 7–13 个智能体，分配到 1–3 个目标。
- **离散套件**：34 张最低复杂度带 + 33 张中带 + 33 张最高复杂度带地图；49 张 50×50 与 51 张 100×100；每回合 7–13 个智能体，共享目标与多目标各半。
- **复杂度度量**：占用四叉树节点数，三个连续带：15,000–26,999 / 27,000–38,999 / 39,000–50,999。

### 3.2 Benchmark 与对比
- **基准本质上是精确几何谓词**：既提供训练标签，也独立审计每一个已执行步骤。
- 论文**未与其他学习型方法或传统几何方法做性能/精度对比**；表 I 仅并列两种挂载的到达与碰撞结果，且作者明确指出这**不是精度比较**（控制器与测试套件不同）。
