## 摘要
预训练机器人策略提供了强大的操作技能，但通常局限于单智能体场景，即机器人孤立地行动。在这项工作中，我们研究如何利用极少的协作数据，将预训练的单智能体扩散策略适配到多智能体场景，并协同优化两个关键目标：高协调性能与单智能体技能保持。为此，我们提出 ALTER，一种面向按需协调的适配方法：适配后的策略在团队部署时能与其他机器人协调，同时在单独运行时仍能独立行动。执行是去中心化的：每个机器人仅根据自身的视觉观测行动，无需智能体间的显式通信。我们的方法训练一个协调头，用于预测残差去噪器，在必要时将单智能体行为转化为协调的多智能体行为，同时保留单智能体能力。为保留单智能体能力，我们在训练残差去噪器期间，用基础策略生成的自蒸馏数据来增广少量协作演示。在仿真中，ALTER 相比我们的基线实现了更高的协调成功率，同时保持了更高的源技能保留率。在我们的硬件实验中，我们发现了类似趋势：与基线相比，ALTER 能更好地协同优化协调成功率与单智能体技能保留。

## Abstract
Pretrained robot policies offer strong manipulation skills but are typically limited to single-agent settings, where a robot acts in isolation. In this work, we study how to adapt pretrained single-agent diffusion policies to multi-agent settings using minimal collaborative data, co-optimizing for two key objectives: high coordination performance and single-agent skill retention. To this end, we introduce ALTER, an adaptation method for coordination on demand: the adapted policy coordinates with other robots when deployed in a team while remaining capable of acting independently when operating alone. Execution is decentralized: each robot acts only on its own visual observations, without explicit inter-agent communication. Our method trains a coordination head that predicts a residual denoiser to transform single-agent behavior into coordinated multi-agent behavior when necessary while also preserving single-agent capabilities. To preserve single-agent capabilities, we augment a small number of collaborative demonstrations with self-distilled data generated by the base policy during training of the residual denoiser. In simulation,ALTER achieves higher coordination success over our baselines while retaining much higher source-skill retention. In our hardware experiments, we find similar trends where ALTER better co-optimizes for coordination success and single-agent skill retention than the baselines

## 1. 核心问题与整体含义（研究动机与背景）

- **背景**：基于扩散/流匹配的生成式策略（如 Diffusion Policy、DP3）已能让单个机器人从示范中学会复杂操作技能，但绝大多数成果局限于**单智能体**设定，即机器人在孤立环境中行动。让多台机器人去中心化协作是提升生产力的低成本途径。
- **核心瓶颈**：把模仿学习（IL）扩展到多智能体场景面临**数据瓶颈**——同时操作多台机器人采集协作示范代价极高，无法大规模获取。
- **本文的切入点**：与其从零学习协作行为，不如把它视为**适配问题**：从已有的、开箱即用的单智能体扩散策略（称为 base policy）出发，做多智能体适配。
- **关键约束（使问题更难）**：
  - 协作示范数量极少（低数据 regime）；
  - **无法访问 base policy 的原始专家训练数据**（策略通常以 checkpoint 形式发布），因此不能像持续学习那样做标准「排练（rehearsal）」来对抗灾难性遗忘。
- **核心研究问题**：*如何用有限的多智能体数据，把单智能体扩散策略适配到与他人协作，同时保留其单智能体能力？*
- **目标定义——"按需协调"（coordination on demand）**：适配后的策略在团队部署时能协调，单独运行时仍能独立作业；**部署时不给任何标签指示当前是否需要协作**。执行必须**去中心化**：每个机器人只看自己的视觉观测，无显式智能体间通信。

## 2. 方法论：ALTER

### 2.1 核心思想
- 将 base 去噪器 `D_base` **完全冻结**，在其上叠加一个小型**残差协调适配器 Δφ**（第二套小型去噪网络），只训练该适配器。
- 用 **policy-distilled replay**（基策略在源环境中的自蒸馏 rollout）替代缺失的源数据集，与少量协作示范**联合训练**，使同一组参数同时服务于源任务与目标任务。

### 2.2 残差去噪器（Residual Coordination Adapter）
- 适配后去噪器为加性形式：
  `D_φ(x_σ, σ, o) = D_base(x_σ, σ, o) + Δφ(x_σ, σ, o, D_base(x_σ, σ, o))`
  - Δφ 接收与 base 相同的输入（加噪动作块、噪声水平、观测），并额外接收 **base 的预测本身**（因为它要学的正是对 base 预测的修正量）。
  - Δφ **只使用智能体 i 自己的局部观测 o^i**，因此天然保持去中心化执行。
- **Remark 1（加性性质）**：由于 `D ↦ (D − x_σ)/σ²` 是仿射的，故
  `s_{D_φ}(x_σ, σ, o) = s_{D_base}(x_σ, σ, o) + σ⁻² Δφ(x_σ, σ, o)`
  即采样概率流 ODE 相当于在 base 上增加漂移项 `−Δφ/σ`。**当 Δφ ≡ 0 时，π_φ = π_base**。
- **零初始化**：适配器输出通路按 ControlNet 惯例零初始化，使训练起点**精确等于** π_base。
- **与残差策略学习（RPL）的区别**：修正作用在**向量场（score field）**而非采样出的动作上，因此可以改变 π_base 的**分布**，而不只是给动作加偏置。

### 2.3 混合域训练（Mixed-Domain Training）
- **Policy-Distilled Replay（策略蒸馏回放）**：在源环境中以滚动时域方式执行冻结的 π_base，记录观测与执行动作，得到 `D_S = {τ^S_j}`，扮演持续学习中 rehearsal 的角色，且**无需任何专家成本**。
- **协调损失**（在多智能体示范 D_C 上）：
  `L_coord(φ) = L_den(φ; D_C)`，即 EDM 去噪回归损失，梯度只流入 φ；所有智能体共享策略，故把 N 个智能体的 (o^i_t, a^i_{t:t+H}) 元组**混合池化**训练，任何样本都不含其他智能体的观测。
- **回放损失**（关键设计）：**不**把 D_φ 回归到回放动作，而是直接惩罚残差本身：
  `L_replay(φ) = E_{D_S, σ, ϵ}[ w(σ) ‖Δφ(x + σϵ, σ, o)‖²₂ ]`
  因为由 Remark 1，**残差为零即精确恢复 π_base**，故只需在源任务输入上把残差压向零。
- **总目标**：`L(φ) = L_coord(φ) + λ_ret · L_replay(φ)`，λ_ret > 0 权衡协作增益与源技能保持。
- **隐式路由**：当观测像源任务时残差趋于零，当观测中出现伙伴时残差产生修正——**无需显式切换机制**。

### 2.4 部署与实现
- 所有智能体共享同一组权重，各部署一份 `D_base + Δφ`，仅使用各自肩部 RGB 相机的图像，按 base 的滚动时域循环运行。
- **Base 去噪器**：DiT 风格 Transformer，输入加噪动作块、噪声水平与图像编码器产生的视觉 token；ALTER 只通过前向传播接触该网络。
- **Δφ**：小型 DiT 风格解码器，采用 EDM 预条件；条件来源有二：(1) 通过可学习投影接入 base 编码器的 token 特征（side-tuning 思路）；(2) 原始观测经轻量 CNN 处理（使适配器能关注冻结编码器可能丢弃的伙伴线索）。
- 适配器比主干小，推理开销增加有限。

## 3. 实验设计

### 3.1 仿真场景与 Benchmark
- **TwoArmPlaceWipe（双臂任务）**：两机器人仅凭局部视觉观测在共享空间操作。
  - 任务序列：Robot 1 抬起带柄托盘、放到两个等待区之一并归还；Robot 2 拿起海绵擦拭托盘下方脏污并归还。
  - 需**时空协调**：Robot 1 须先清空脏污网格，且须等到 Robot 2 擦完才归还托盘；序列一旦断裂即可能碰撞失败。
  - 冻结的单臂策略提供「放置并返回」与「擦拭并返回」两个源技能。
  - 随机化物体、垫子、脏污初始位置，评估对示范中未出现配置的泛化。
- **成功判据**：托盘在 x、y 两轴距归位点 < 1.5 cm；海绵相对目标偏移 x ≤ 8 cm、y ≤ 6 cm；擦拭覆盖率 ≥ 60%。

### 3.2 硬件场景
- 两台 7 自由度 **xArm7** 机器人 + 带盖盒子 + 毛绒小鸟。
- 流程：Robot 1 揭开盖子 → Robot 2 把鸟放进盒子 → Robot 1 重新盖回。
- 成功判据：鸟在盒内，且盖子覆盖 > 50% 并在无机器人支撑下保持不动。

### 3.3 对比基线
- **FS（From Scratch）**：用同样的多智能体示范 + 蒸馏单臂 rollout 从零训练，参数总量与「冻结单臂策略 + 协调头」匹配。
- **FT-MIXED**：用多智能体 + 单智能体数据直接微调预训练策略的全部 17,446,215 个参数。
- **FT-MULTI**：只用多智能体数据微调预训练策略（检验源回放的必要性）。
- 所有方法测试时均为去中心化，仅用自身肩部 RGB 观测。

### 3.4 训练与评估协议
- AdamW，恒定学习率 2×10⁻⁴，权重衰减 1×10⁻⁴，900k 优化步，每 100k 步保存 EMA 滤波 checkpoint。
- 数据预算：多智能体示范 20/40/60 条，分别配 20/40/60 条策略蒸馏单臂示范；混合训练每个 batch 512 样本，多/单智能体各半；纯多智能体训练每 batch 256 样本。
- 评估：先在 40 个 episode 上选协调成功率最高的 checkpoint，再在 200 个全新多智能体 episode 上评估；源任务保留在 100 个 episode 上评估（对 ALTER 保持协调头激活）。每 15 环境步重采样一次，episode 上限 1800 步。
- 硬件：69 条双臂示范 + 68 条策略蒸馏单臂示范；单臂策略在 332 条示范（揭盖、盖回、抓放鸟三个源任务）上预训练；训练 25k 梯度步；规划与执行时域均为 20 步；每次试验 900 步上限。

### 3.5 消融实验
