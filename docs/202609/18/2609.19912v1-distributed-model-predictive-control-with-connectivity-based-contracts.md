## 摘要
移动机器人团队依赖与其邻居的持续通信来进行协调，然而大多数分布式模型预测控制（DMPC）方案假设通信网络保持连通，而不是主动保证其连通性。增加这样的保证很困难，因为通常的连通性数学条件是非凸的，并且将每个智能体与其他所有智能体都联系起来，这与可扩展的分布式实时控制器不兼容。我们提出了一种DMPC框架，其中为每个智能体分配一个连通性契约：一个局部区域，规定其预测位置在预测时域内可以位于何处。这些契约的设计使得，只要每个智能体都保持在自己的契约内，整个团队就保证保持连通。在给定所维护的契约图的情况下，智能体通过与其直接邻居的一次交换来构建其契约，之后每个智能体独立求解自己的优化问题。我们证明，所得的闭环系统保持连通性、避免碰撞，并满足局部状态和输入约束。在微型自主类车机器人上的仿真与硬件实验验证了该方法。

## Abstract
Teams of mobile robots rely on continuous communication with their neighbors for coordination, yet most distributed model predictive control (DMPC) schemes assume the communication network stays connected rather than actively enforcing it. Adding such a guarantee is hard since the usual mathematical condition for connectivity is nonconvex and links every agent to every other, which is incompatible with a scalable distributed real-time controller. We propose a DMPC framework in which each agent is assigned a connectivity contract: a local region prescribing where its predicted positions may lie over the prediction horizon. The contracts are designed so that, as long as every agent stays within its own contract, the team is guaranteed to remain connected. Given the maintained contract graph, an agent builds its contract from a single exchange with its immediate neighbors, after which every agent solves its own optimization problem independently. We prove that the resulting closed-loop system maintains connectivity, avoids collisions, and respects local state and input constraints. Simulation and hardware experiments on miniature autonomous car-like robots demonstrate the approach.

## 1. 核心问题与整体含义

- **背景**：多机器人系统被广泛用于搜索救援、协同运输、环境监测与探索等单机器人难以胜任的任务。模型预测控制（MPC）能在显式处理状态/输入约束的同时优化任务目标，但集中式 MPC 扩展性差且存在单点故障，因此分布式 MPC（DMPC）成为主流选择——各智能体求解局部优化问题，仅与邻近智能体交换信息。
- **核心矛盾**：DMPC 依赖可靠（可能多跳）的通信网络，但**绝大多数 DMPC 方案只是"假设"网络保持连通，而非"主动保证"连通**。一旦连通性丢失，信息无法在网络中传播，会危及安全性、协调性与控制器性能。
- **为何困难**：连通性的标准数学条件——图拉普拉斯矩阵第二小特征值（Fiedler 值）λ₂(L(p(t))) > 0——具有两个致命性质：(1) **非凸**；(2) **全局耦合**，把每个智能体与其他所有智能体绑在一起。这与可扩展、可实时求解的分布式控制器不兼容。
- **整体含义**：本文提出"连通性契约"范式，用**凸的、邻居局部的、预测时域上的区域约束**替代非凸全局 Fiedler 特征值约束，使连通性保障首次被无缝嵌入到带任务目标与约束优化的 DMPC 框架中，并保留递归可行性与闭环约束满足的理论保证。

## 2. 方法论

### 核心思想
- 为每个智能体 i 在每个预测步 k 分配一个**连通性契约** C_{i,k|t} ⊆ R^{n_p}（其预测位置必须落入的局部凸区域），使得只要所有智能体都遵守各自契约，团队通信图必然保持连通。
- 同时沿用 [24] 的**碰撞契约** D_{i,k|t}，把耦合的碰撞约束也解耦为局部集合约束。
- 契约建立在一个"提议轨迹"之上，通过一次一跳邻居交换即可构造，之后各智能体**完全独立**求解各自 FHOCP，无需任何迭代协调或多跳共识。

### 关键技术细节
1. **契约图 T_t**：选一个通信图的连通生成子图（最简单情形是生成树），仅需维护其边即可保证全局连通；T_t 可随时间更新，但必须始终是连通生成子图且与提议轨迹相容。
2. **兼容提议轨迹（Definition 1）**：提议位置轨迹需满足动力学、状态/输入约束、落入碰撞契约、且每条维护边两端在每一步距离 ≤ r_com。
3. **成对球构造（式 23–24）**：对每条维护边 (i,j) 与预测步 k，构造半径 r_com/2、球心位于两点提议位置中点的球 B_{ij,k|t}；智能体 i 的契约定义为其所有关联边的球的**交集** C_{i,k|t} = ⋂_{j∈N_i^T(t)} B_{ij,k|t}。
   - 由于契约 C_i 与 C_j 都是同一半径 r_com/2 球的子集，其直径 ≤ r_com，故任意两个契约内位置的距离必然 ≤ r_com，维护边得以保留。
   - 交集是凸集的交，故契约**凸**；实际实现中用**多边形内近似**（正 8 边形）转化为线性位置约束。
4. **局部 FHOCP（式 28）**：目标为可加性分解的局部代价 + 终端代价；约束含局部动力学、状态/输入约束、碰撞契约 (28f)、连通性契约 (28g)，以及**终端等式约束**到优化器自选的可行稳态 (28h)–(28j)。由"位置不变性"假设，终端平衡点可平移位置而不改变所需稳态输入，因此终端位置可与终端契约相容。
5. **递归可行性证明（Theorem 1）**：用标准 MPC 移位构造候选轨迹，终端稳态保持；碰撞契约按 [24] 递归更新以包含移位后位置；由于契约有效性（Proposition 1），T_t 的每条边在移位后仍被保留，故可取 T_{t+1}=T_t，从而局部 FHOCP 递归可行，闭环满足局部约束、避碰与连通性。
6. **分布式计算（Algorithm 1）**：每个控制周期内——与契约图中的一跳邻居交换提议位置轨迹 → 用 (23)–(24) 构造连通性契约 → 按 [24] 构造碰撞契约 → 求解局部 FHOCP → 施加首个输入 → 移位并令 T_{t+1}=T_t。
7. **鲁棒性处理**：契约构造时把通信半径从 r_com 收紧为 r_com − δ（δ = r_buffer），作为对通信延迟、状态估计误差与模型失配的缓冲。

## 6. 主要结论与发现

- **理论结论**：契约的有效性条件（含提议位置 + 边两端距离约束）可被球交集构造满足；在契约内规划即可保证维护子图 T_t 是通信图的子图，从而 λ₂ > 0；结合标准 MPC 移位与碰撞契约递归更新，闭环系统**递归可行**，并始终满足局部状态/输入约束、避碰约束与连通性约束。
- **仿真结果**：无连通性契约时 **31/31 次运行都出现连通性违规**（min λ₂ = 0.0）；本文方法 **0 次违规**，min λ₂ = 0.1981，最小碰撞距离 0.1175 m（安全），求解时间中位数 2.31 ms、95 百分位 4.29 ms，与仅含碰撞契约的基线（2.02 / 3.77 ms）几乎相当。
- **[23] 的对比结论**：迭代至收敛的 SQP 也能保持连通（min λ₂ = 0.1981），但计算代价极高（中位数 219 ms，95 百分位 7.66 s），无法实时；单次实时迭代的 SQP-RTI 虽把时间降到 19/50 ms，却**失去保证**——4 次运行连通性违规、6 次违反安全距离（最小碰撞距离 0.0806 m）。
- **硬件结果**：不使用契约时 λ₂ 降为 0（网络断开）；使用连通性契约时 λ₂ 稳定在约 0.198，最小碰撞距离 0.132 m，求解时间中位数 3.04 ms、95 百分位 5.00 ms，验证了方法的实时可实现性。
- **总体发现**：把非凸全局连通约束转化为局部凸契约，可在几乎不增加计算负担的前提下同时获得可扩展性、实时性与理论保证。

## 7. 优点

- **方法层面**：
  - 用**凸的、一跳局部的球交集契约**替代非凸且全局耦合的 Fiedler 特征值约束，思路简洁且几何直观（中点球 + 直径约束）。
  - 局部 FHOCP **完全解耦**：契约一旦算出，不再出现其他智能体的优化变量，无需迭代协商、无需多跳共识，天然适配实时分布式实现。
  - 统一框架：**任务目标、局部约束、避碰与连通性**在同一约束优化问题中处理，优于势场法/图论法的"纯连通

处理方式。”  
  - **理论自洽性较强**：从契约有效性（Proposition 1）到递归可行性（Theorem 1），再到闭环约束满足，形成了一条较完整的证明链，而不是仅给出经验性规则。  
  - **保守性与可实现性有明确折中手段**：通过正多边形内近似把凸集约束线性化，通过缓冲半径 \(\delta\) 吸收延迟与估计误差，使方法可直接嵌入现有 MPC 求解器，而非停留在集合论层面的抽象表述。  
  - **分布式实现路径清晰**：契约构造只需一跳邻居的提议轨迹，契约图维护也仅涉及连通生成子图/最小生成树的局部更新，避免了多跳共识或全局协调，符合多机器人实时控制的实际通信架构。  

## 8. 局限与可改进方向

- **对初始连通性与通信可靠性的隐含依赖**：方法保证“只要契约被遵守，连通性就保持”，但其契约构造本身仍要求智能体能够与契约图中的一跳邻居交换提议轨迹。若初始网络已不连通，或控制周期内消息严重丢包/异步，契约构造与更新可能失效；论文主要通过 \(\delta\) 缓冲间接增强鲁棒性，未对随机丢包、异步时钟、通信中断给出严格闭环保证。  
- **保守性可能限制任务性能**：球交集契约、多边形内近似以及通信半径收紧都会缩小可行位置集合。在窄通道、密集障碍或高密度编队中，这种保守性可能导致跟踪误差增大、速度降低，甚至局部 FHOCP 不可行；论文未系统量化“连通性保证”与“任务性能损失”之间的权衡。  
- **连通性模型较为理想化**：采用固定通信半径 \(r_{\mathrm{com}}\) 的距离图模型，未显式处理视距遮挡、天线方向性、异构通信半径、信道质量与带宽限制。实际机器人网络中，几何距离小于 \(r_{\mathrm{com}}\) 并不必然意味着可靠通信。  
- **系统与任务类型有限**：理论部分依赖“位置不变性”等假设，使终端平衡点可平移而不改变稳态输入；该性质对某些非线性、非完整或欠驱动系统未必成立。实验也集中在类车机器人参考跟踪任务，未覆盖无人机、三维空间、机械臂或异构团队。  
- **规模与场景泛化证据不足**：仿真与硬件均为 7 个智能体、室内动捕环境，缺少数十至上百智能体、大范围室外、动态障碍、通信拓扑频繁切换等压力测试。硬件重复次数较少，统计显著性有限。  
- **超参数与消融不充分**：契约图更新频率、多边形顶点数 \(R\)、缓冲 \(\delta\)、预测时域 \(N\)、通信周期 \(T_{\mathrm{com}}\) 等关键参数对性能与保守性的影响未做系统消融；分布式最小生成树重构的通信开销与最坏情况计算时间也未充分报告。  
- **与全局最优/集中式基准的差距未刻画**：论文主要对比无连通性约束的 DMPC 与特征值约束 MPC，未给出集中式 MPC 或离线最优轨迹作为性能上界，因此难以判断局部契约式 DMPC 在任务代价上距离理想解有多远。  

## 9. 启示与未来方向

- **方法论启示**：将非凸、全局耦合的约束转化为“局部凸契约 + 邻居间一致性条件”是一种有潜力的通用思路。类似思想可推广到覆盖控制、编队保持、安全区域约束、通信质量约束等多机器人协同问题。  
- **工程启示**：契约式 DMPC 的实时性优势来自“先构造约束、后完全解耦求解”的两阶段结构。对于嵌入式多机器人系统，这种结构比每步迭代求解耦合 NLP 更易满足毫秒级控制周期。  
- **可能的研究延伸**：  
  1. 在随机丢包、异步通信与延迟下建立契约构造的概率或鲁棒保证；  
  2. 设计自适应契约尺寸/缓冲，以在连通性保障与任务性能之间动态折中；  
  3. 扩展到异构通信半径、三维运动与动态拓扑；  
  4. 将契约图维护与任务层规划结合，减少每步重构最小生成树的开销；  
  5. 在大规模仿真与室外平台上验证可扩展性，并与集中式或分布式耦合优化方法进行更全面的代价对比。  

## 10. 总体评价

本文的核心贡献在于提出了一种**可实时求解、理论上可保证连通性的分布式 MPC 框架**。它没有直接处理非凸且全局耦合的 Fiedler 特征值约束，而是通过“连通性契约”把全局连通要求分解为每个智能体预测时域上的局部凸位置约束，从而在几乎不增加单机求解负担的情况下，同时获得避碰、约束满足与通信连通性保证。理论证明较为完整，仿真与硬件实验也清楚展示了相对无连通性约束基线和实时化特征值约束方法的优势。

不过，其实验规模、通信模型与系统类型仍偏窄，鲁棒性保证主要依赖缓冲而非严格的随机/异步分析，契约带来的保守性也缺少系统量化。因此，该工作更适合被视为一种**有前景的范式性方法**：它打开了“用局部契约保障全局网络性质”的方向，但距离在复杂、大规模、真实通信条件下的普适部署仍有进一步研究空间。
