## 摘要
大语言模型（LLMs）为机器人中的规划与导航引入了一个令人兴奋的新范式，但随着团队规模增大，它们在即便简单的多机器人任务上也会失败。我们提出 COMPASS，一种可扩展的去中心化多机器人架构，用于通过推理空间反馈控制来操控大规模的智能体机器人集群。反馈由每个机器人本地生成，其方式是通过一个空间 Transformer 将整个机器人集群中的多跳消息聚合为一个学习到的反馈 token。我们的实验发现，语言模型集群能从输入指令的结构化多样性中获得性能提升，这种多样性可以抵消偏差；这一优势在不同规模下均得以保持。与集中式前沿 LLM 策略和仅语言通信的消融相比，我们发现 COMPASS 的耦合设计能够决定性地产生具有凝聚力的集群编队，并准确实现所指令的意图。我们表明，推理反馈在与紧凑的学习 token 组合时效果最佳。我们的消融实验表明，若原始状态出现在语言通道中，手工设计的反馈会彻底破坏凝聚力。COMPASS 能够零样本泛化到含义模糊的未见指令，同时指挥规模最高达其训练规模 16 倍的集群，在自然语言指令下让多达 1024 个机器人飞行。

## Abstract
Large Language Models (LLMs) introduce an exciting new paradigm for planning and navigation in robotics, but fail on even simple multi-robot tasks as team sizes grow. We propose COMPASS, a scalable, decentralized multi-robot architecture for controlling large collectives of agentic robots with reasoning space feedback control. Feedback is generated locally on each robot by a spatial transformer which aggregates multi-hop messages across the fleet into a learned feedback token. Our experiments find that collectives of language models demonstrate performance gains from structured diversity of the input command, which can cancel biases; an advantage that is held across scale. Compared against a centralized frontier LLM policy and a language-only communication ablation, we find that the coupled design of COMPASS decisively produces cohesive flocking formations that accurately fly the commanded intent. We show that reasoning feedback works best when composed with a compact learned token. Our ablations show that hand engineered feedback with raw state appearing in the language channel obliterates cohesion. COMPASS generalizes zero-shot to unseen instructions of ambiguous meaning while commanding flocks up to 16 times its training scale, flying up to 1024 robots under natural language commands.

## 二、方法论

### 1. 核心思想

- 将**物理动力学系统**与**潜在推理动力学**耦合：快速物理控制由空间 Transformer（MAST）完成，慢速推理由每个机器人本地的 LM 完成。
- 每个机器人携带一个持久程序：`PROG_i(t) = [P_i ‖ T_i ‖ f_i(t) ‖ g]`，包含操作员提示 P、思维轨迹 T、学习到的反馈 token f、学习到的目标 token g，全部位于 LM 的嵌入空间。
- **关键设计**：LM 本身**冻结权重**，仅训练反馈 token f、目标 token g 与 MAST；语言模型无需进行空间推理，空间信息通过 MAST 聚合后以紧凑 token 形式注入推理循环。

### 2. 推理循环（Reasoning in the Loop）

- **推理状态更新**（式 2）：
  `z_i(t+1) = φ_{1:ℓ}( P_i ‖ T_i ‖ ψ(π_i(t)) ‖ g )`
  - φ_{1:ℓ}：LM 前 ℓ 层；
  - ψ：学习到的适配器，将下游控制器输出 π_i(t) 嵌入为反馈 token f_i(t)。
- **思维生成**（式 3）：`T_i(τ+1) = T_i(τ) ‖ φ_gen(P_i ‖ T_i(τ))`，每个机器人独立采样生成自己的思维轨迹，N 个机器人产生 N 种对同一指令的不同解读；轨迹完成后冻结并 KV 缓存。
- **潜在推理**：z_i(t) 是程序前向传播后目标 token 位置的隐藏状态。由于因果掩码与终端位置，反馈 token 与目标 token 可查询整个程序，而语言 token 不会关注它们——简化了学习，使 f 与 g 无需位于语言流形上。提取深度 ℓ 为设计参数，模糊指令需更深提取，但性能并非单调提升。

### 3. 空间 Transformer（MAST）

- 输入构造：`h^(0)_i = MLP([z_i ‖ x_i])`，融合推理状态与观测状态。
- **几何编码**：采用 2D 旋转位置编码（RoPE），将 query/key 分成 2ζ 个通道对，按坐标旋转，使注意力 logit 仅依赖位移 `p_j − p_i`，从而保证平移不变性且不破坏置换等变性；编码周期 λ 上界决定可分辨几何范围。
- **通信约束**：注意力仅限通信图内邻居（`d_ij ≤ r_c`），每个注意力层等价于一轮 1 跳消息交换，L_MAST 层提供 L_MAST 跳感受野，信息通过重叠邻域逐步扩散至全集群。
- **输出双解码**：最终 token π_i 经两个 MLP 头分别解码为动作 u_i 与反馈 token f_i，闭环回到式 (2)。
- 超参数：L_MAST = 4 层、隐藏维度 256、8 头（d_h = 32）、λ = 96 m、r_c = 4 m。
- **训练集中式、执行去中心化**：每个机器人只需评估自己的注意力行，利用网络接收的 token 即可本地执行。

### 4. 训练方法

- **行为克隆**：以集中式势场控制器为专家（对齐项 + 目标速度跟踪 + 群质心凝聚 + 避碰斥力），从邻居信息模仿该行为。
- 辅以 **DAgger 重标注**与**截断时间反向传播（TBPTT）**处理循环反馈。
- 语言模型权重冻结，仅优化 f、g 与 MAST；LM 本身微调留作未来方向。

## 六、主要结论与发现

1. **可扩展性**：COMPASS 在 N = [32, 64] 上训练，可零样本泛化至 N = 1024；航向误差随规模**下降**（N = 8 时 2.79° → N = 1024 时 0.34°），体现"集体推理的智慧"。
2. **语言通道的局限**：纯语言通信在 N = 64 时导致集群碎裂为 15 组、速度降至目标一半（2.5 m/s），甚至**劣于完全无通信**；原因是邻居空间信息淹没了模型的思维轨迹。
3. **集中式 LLM 的失败**：Claude Opus 4.8 能正确解码语义指令，但随 N 增大无法为所有机器人生成一致加速度，且频繁生成错误数量的动作，需重试。
4. **结构化多样性**：将同一意图的多种措辞（尤其是混入 1/4 更易解码的措辞）分布在集群中，可抵消偏差、提升航向精度与速度，且优势跨规模保持；但"同等难度的多样措辞"并不带来增益。
5. **反馈设计**：推理反馈在与**紧凑学习 token** 组合时效果最佳；手工设计的反馈若将原始状态放入语言通道，会彻底破坏凝聚力。
6. **零样本泛化**：
   - 模糊概念指令（如 "where Santa Claus lives"）中位航向误差：in-training 1.0°、held-out 模板 1.9°、概念类 5.7°；
   - 16 点罗盘零样本平均误差 7.96° ± 4.41°，24 次试验中 18 次落入扇区；
   - 数值方位角零样本误差 2.2° ± 1.6°，且训练数值方位角**未**提升二级中间方位性能，说明语言方向接地与数值方位角相互独立。
7. **LM 规模权衡**：更大模型（0.6B → 4B）提升模糊指令解码精度（误差比 1.00 → 0.80 → 0.65），但延迟与显存上升；Qwen3-1.7B 为边缘部署与泛化的折中选择。

## 七、优点与亮点

- **架构解耦清晰**：语言通道负责"去哪里"（语义意图），MAST 负责"如何凝聚地到达"（运动控制），推理状态作为二者的下游接口，LM 完全无需空间推理。
- **可扩展性设计巧妙**：MAST 利用旋转位置编码 + 图掩码注意力，保证平移不变性与置换等变性，训练集中式、执行去中心化，参数量与 N 无关。
- **反馈 token 设计**：以学习到的紧凑 token 注入 LM 输入，而非原始状态文本，避免了语言通道被淹没；LM 冻结使训练成本可控。
- **结构化

- **结构化多样性作为隐式纠偏机制**：论文揭示了一个反直觉但实用的结论——多样性并非"越多越好"，而是"异质越好"。将同一意图的多种表述（尤其是掺入少量更易解码的简单表述）分布在集群中，等价于在群体层面做了一次隐式的多数投票与偏差抵消，使个体解码错误不再沿局部邻域同向累积。这一发现把"提示工程"从单体层面提升到了群体层面。
- **闭环而非开环的推理观**：反馈 token 使 LM 的推理状态被下游执行结果持续"校正"，避免了纯开环规划中误差沿时间与空间双重放大，这一范式对任何"LM + 控制器"的具身系统都有借鉴意义。
- **工程可落地性**：默认仅用 Qwen3-1.7B 这类可在边缘设备运行的模型，配合冻结权重与仅训练少量 token/适配器，使方案在真实机器人集群上具备部署可行性。
- **评测维度较完整**：同时报告航向误差（任务）、碎片数（连通性）、速度方差（一致性）、NN 距离 CV（均匀性/安全）与延迟、重试次数（系统开销），避免了"只报任务指标、掩盖系统代价"的常见问题。

## 八、局限与不足

### 方法层面

1. **单任务验证**：核心结论几乎全部建立在"语言指挥集群飞行"这一场景上。该任务虽然具备语义可评分、需避碰、需涌现一致性三大特性，但动力学相对低维、目标单一。方法能否迁移到需要异构分工、抓取操作、动态障碍或长时序任务（如多机器人搜索-救援）尚不明确。
2. **对专家控制器的依赖**：MAST 通过行为克隆集中式势场控制器学习，因此其性能上界受限于该专家。论文未说明当专家次优或任务无法用简单势场表达时，MAST 是否仍能收敛到合理策略。
3. **语言模型完全冻结的代价**：冻结 LM 降低了训练成本，但也意味着系统对"LM 本身语义理解错误"没有任何纠错通路——概念类指令 5.7° 的中位误差本质上就是 LM 解码能力的天花板，而非控制器的瓶颈。
4. **反馈与目标 token 的可解释性弱**：f 与 g 是学习得到的嵌入向量，不位于语言流形上，虽提升了性能，却使系统行为难以被人类审计；对安全攸关的集群应用而言，缺乏可解释性是一个实质性缺口。
5. **训练规模与部署规模的巨大跨度**：在 N = [32, 64] 训练后直接推到 N = 1024（16 倍），论文将其归功于几何编码的平移不变性与局部注意力，但未给出严格的分布外泛化保证，也未测试极端密度（如 r_c 固定而 N 继续增大导致邻域过载）下的退化行为。
6. **超参数敏感**：提取深度 ℓ 影响性能且非单调，编码周期 λ 决定可分辨几何范围，r_c 决定感受野——这些参数与任务尺度、机器人密度强耦合，论文未提供系统的调参指南或自适应机制。

### 实验与报告层面

7. **关键消融规模偏小**：LM 规模权衡实验仅在 N = 1 的简化探针上完成，无法反映大规模集群中不同 LM 规模对涌现行为的影响；停止指令实验仅 10 次试验，统计功效有限。
8. **基线不完全对等**：集中式 LLM 基线通过 Claude Opus 4.8 的远程 API 调用，其延迟、重试与算力特征与本地 SLM 不可直接比较，"集中式 LLM 失败"的结论中混杂了接口与工程因素，而非纯粹的能力因素。
9. **训练成本信息缺失**：仅报告 GPU 型号、数量与 200 epoch，未给出训练时长、能耗或总 GPU 小时，削弱了复现与成本评估的可行性。
10. **统计呈现不统一**：部分实验给出误差棒，部分仅给中位数，跨实验的方差来源（种子、初始条件、措辞）未被统一分解。
11. **缺乏真实硬件验证**：全部结果来自仿真，未讨论通信延迟、丢包、定位噪声、算力受限等真实集群的关键扰动。

## 九、启发与可拓展方向

- **将"推理空间反馈控制"推广为通用范式**：把 LM 的隐藏状态视为被控量，控制器输出经适配器回注形成闭环，这一结构原则上可移植到任意"慢推理 + 快控制"的分层具身系统中（如机械臂操作、自动驾驶车队、多无人机编队）。
- **群体级提示工程**：结构化多样性表明，多智能体系统中"给不同个体不同表述"是一种低成本的鲁棒性增强手段。未来可研究多样性的最优配比、自适应分配（如按个体能力或位置分配不同难度表述）以及多样性与其他去中心化机制（如共识协议）的交互。
- **可解释的反馈 token**：可将 f 约束在可读语义空间（如"接近目标/偏离/拥堵"的离散概念），在保留紧凑性的同时换取可审计性，这对安全认证尤为关键。
- **跨任务与异构集群**：将 MAST 的几何编码扩展到时变通信图、异构动力学与任务分工场景，是自然且必要的下一步。
- **真实系统落地**：通信丢包、延迟抖动、定位误差下的闭环稳定性分析，以及 LM 推理与 MAST 控制在不同频率下的稳定性边界，都是工程化的关键课题。
- **与集中式 LLM 的混合架构**：既然集中式 LLM 在语义层面表现良好而空间一致性差，可考虑"集中式 LM 负责全局意图分解 + 去中心化 COMPASS 负责局部执行"的混合方案，以兼顾语义全局性与控制可扩展性。

## 十、总体评价

本文的核心贡献不在于提出某个更强的控制器，而在于**重新划分了多机器人系统中语言与空间的职责边界**：语言模型只处理"去哪里"，空间 Transformer 只处理"如何凝聚地到达"，二者通过推理状态与学习到的紧凑 token 在闭环中耦合。这一设计使得系统在训练规模 16 倍以上仍能零样本泛化，并首次系统性地量化了"把邻居状态塞进语言通道"这一常见做法的危害——它甚至劣于完全无通信。结构化多样性与反馈 token 的实验进一步提供了可直接复用的工程经验。

同时，论文的结论边界清晰但相对狭窄：单一任务、仿真环境、专家依赖、LM 冻结导致的语义天花板，以及部分小规模消融，都提示读者应将其视为一个**强有力的架构范式与概念验证**，而非即插即用的通用方案。其最大价值或许在于提出了一个可被广泛借鉴的问题框架——**如何在推理空间中对集体行为施加反馈控制**——而非某一具体数值结果。
