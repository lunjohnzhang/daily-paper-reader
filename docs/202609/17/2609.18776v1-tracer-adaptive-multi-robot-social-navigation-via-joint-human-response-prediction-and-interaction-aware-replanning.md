## 摘要
在人类共享空间中，多机器人导航本质上是交互式的：协调的机器人运动会影响附近实体如何响应，而这些响应又为后续机器人决策提供了有价值的信息。然而，现有方法通常分别处理以动作为条件的预测、多机器人规划或在线自适应，因此缺乏一种统一机制来建模机器人—实体联合交互，并根据已执行的交互结果调整未来决策。为弥补这一空白，我们提出TRACER，一种双向滚动时域框架，闭合了预测与自适应之间的环路。TRACER使用逐实体的概率响应模型评估候选轨迹（即机器人团队的替代可行未来运动规划），该模型将单个机器人效应与非可加性的成对交互分离开来；在执行所选轨迹前缀后，它利用同步观测到的响应，更新关于潜在响应模式的持续身份绑定信念。这些更新后的信念随后在概率安全性和响应感知代价准则下指导后续候选评估。实验表明：(i) 与容量匹配的加性预测器相比，TRACER能更准确地捕捉非加性多机器人交互效应；(ii) 持续的身份一致证据可改善响应预测和下游重规划；以及 (iii) 在SocialGym2多机器人社交导航基准上，完整的TRACER框架相比独立机器人基线提高了无碰撞完成率。

## Abstract
Multi-robot navigation in human-shared spaces is inherently interactive: coordinated robot motions influence how nearby entities respond, while those responses provide valuable information for subsequent robot decisions. However, existing methods typically address action-conditioned prediction, multi-robot planning, or online adaptation separately, and therefore lack a unified mechanism for modeling joint robot-entity interactions and adapting future decisions from executed interaction outcomes. To address this gap, we propose TRACER, a bi-directional receding-horizon framework that closes the loop between prediction and adaptation. TRACER evaluates candidate (i.e., alternative feasible future motion plans for the robot team) trajectories using a per-entity probabilistic response model that separates individual-robot effects from non-additive pairwise interactions; after executing the selected trajectory prefix, it updates persistent identity-bound beliefs over latent response modes using the synchronized observed responses. These updated beliefs then guide subsequent candidate evaluation under probabilistic safety and response-aware cost criteria. Experiments show that (i) TRACER more accurately captures non-additive multi-robot interaction effects than a capacity-matched additive predictor, (ii) persistent identity-consistent evidence improves response prediction and downstream replanning, and (iii) the complete TRACER framework improves collision-free completion over an independent-robot baseline on the SocialGym2 multi-robot social-navigation benchmark.

## 2. 方法论：核心思想、关键技术与算法流程

### 2.1 总体思想

- **双向滚动时域（receding-horizon）框架**，每个决策窗口分三步：
  1. **评估并选择**候选联合轨迹（CJT）；
  2. **执行并观测**所选轨迹的前缀及实体的同步响应；
  3. **更新身份绑定后验信念**，带入下一窗口。
- **前向耦合**：CJT → 逐实体响应分布（回答 RQ1）。
- **后向耦合**：已执行交互 → 更新身份绑定后验，引导下一窗口的候选评估（回答 RQ2）。

### 2.2 问题形式化要点

- **联合轨迹（JT）/候选联合轨迹（CJT）**：对活跃机器人集合 $R_t$，JT 为同步元组 $U_t=(\tau_{r,t})_{r\in R_t}$；上游候选生成器返回 $M$ 条 CJT，仅 $U_t^\star$ 被执行。另有固定参考 JT $U_t^0$ 作为响应偏差基线。
- **评估实体子集 $E_t^{(\text{eval})}$**：在预测时域内至少一条 CJT 下可能进入机器人—实体安全距离的实体。
- **执行前缀与未执行后缀**：执行前 $L$ 步（$1\le L<T$），其余为后缀。
- **变机器人数量处理**：CJT 放入 $R^{(\max)}$ 个固定输入槽，用 $\gamma_{r,t}\in\{0,1\}$ 指示活跃性，非活跃槽填充并掩码；槽索引仅为占位符，**置换活跃机器人不改变表示与预测**（排列不变性）。
- **机器人侧确定性可行集**：$C_t^{(\text{feas})}=\{U_t^m \mid \text{Dyn}\wedge\text{Obs}\wedge\text{RR}\}$，即动力学、静态避障、机器人间时空不重叠检查。机器人—实体安全因未来运动不确定，只能作为逐实体概率约束。

### 2.3 响应模式与证据

- 实体 $e$ 在窗口 $t$ 的响应为未来 $T$ 步的 2D 速度序列 $Y_{e,t}\in\mathbb{R}^{T\times2}$；存在潜在响应模式 $z_e\in Z=\{1,\dots,|Z|\}$，测试时潜在、从已执行交互推断。
- **执行证据**：$\xi_{e,t'}=(H_{e,t'},\,U^{(\text{exec})}_{t',1:L},\,Y^{(\text{obs})}_{e,t',1:L})$；证据集 $D_{e,<t}=\{\xi_{e,t'}:t'<t\}$。**未执行 CJT 与已选 CJT 未执行后缀的预测属于反事实，不进入 $D_{e,<t}$**。
- **身份绑定后验**：$b_{e,t}(z)=\Pr(z_e=z\mid D_{e,<t})$。
- **预测分布**（模式混合）：$p_\phi(Y_{e,t}\mid H_{e,t},U_t^m,b_{e,t})=\sum_{z}b_{e,t}(z)\,p_\phi(Y_{e,t}\mid H_{e,t},U_t^m,z)$。改变 $U_t^m$ 改变模式条件分布，执行证据改变混合权重。

### 2.4 导航目标

- 优化问题：在 $C_t^{(\text{feas})}$ 上最小化 $J_t$，约束为逐实体机会约束 $q^{(\text{viol})}_{e,t}(U\mid H_{e,t},b_{e,t})\le\alpha$。
- 代价由三部分加权构成：目标进度 $J^{(\text{goal})}$、残余交互风险 $J^{(\text{risk})}$、响应负担 $J^{(\text{brdn})}$。

### 2.5 前向耦合：前向响应模型（FRM）

- **异质交互图** $G_{e,t}$：以目标实体 $e$ 为目标节点，附近实体与活跃机器人为其他节点；边类型含 R&R、R&E、E&E。
- **编码器**：共享 LSTM 编码各节点历史；两层**异质图 Transformer（HGT）**按边类型传播消息，得到场景表示 $h_{e,t}$；轨迹编码器 $\psi^{(\text{traj})}$ 编码每条候选轨迹，得到 $a^m_{e,r,t}$。
- **聚合**：对候选轨迹编码做**掩码均值**得到联合运动表示 $\bar{a}^m_{e,t}$（对机器人排序不变）；上下文向量 $q^z_{e,t}=[h_{e,t};u(z);u(|R_t|)]$ 融合模式嵌入与机器人数量嵌入。
- **输出分布**：模式条件对角高斯 $p_\phi(y_{e,t}\mid H_{e,t},U_t^m,z)=\mathcal{N}(y_{e,t};\mu^{m,z}_{e,t},\text{diag}[(\sigma^{m,z}_{e,t})^2])$，协方差由 softplus 输出。
- **条件均值的效应分解（关键创新）**：
  $$\mu^{m,z}_{e,t}=\mu^{0,z}_{e,t}+\sum_r \gamma_{r,t}\delta^{m,z}_{e,r,t}+\sum_{r<s}\gamma_{r,t}\gamma_{s,t}\delta^{m,z}_{e,(r,s),t}$$
  - **单机器人效应**：$\delta^{m,z}_{e,r,t}=f_1(q^z_{e,t},a^m_{e,r,t})-f_1(q^z_{e,t},a^0_{e,r,t})$，当机器人遵循参考轨迹时为 0。
  - **成对残差**：用对称构造 $\rho(a,b)=[a+b;|a-b|;a\odot b]$ 与 MLP $g$，通过**容斥（inclusion–exclusion）** 构造 $\delta^{m,z}_{e,(r,s),t}=G(a^m_r,a^m_s)-G(a^m_r,a^0_s)-G(a^0_r,a^m_s)+G(a^0_r,a^0_s)$，任一机器人遵循参考轨迹时残差为 0，从而隔离**联合偏离**产生的额外响应。
  - 高于二阶的交互被省略。

### 2.6 候选选择：安全过滤 + 代价排序

- **安全过滤**：由采样速度积分（零阶保持）得实体位置序列，定义机器人—实体距离；违规事件为任一机器人任一预测步进入硬距离 $d^{(\text{hard})}$；违规概率按后验模式加权 $q^{(\text{viol})}_{e,t}(U_t^m)=\sum_z b_{e,t}(z)\Pr[\min_{r,\ell} d^{m,\ell}_{r,e,t}<d^{(\text{hard})}]$；安全集 $C_t^{(\text{safe})}=\{U\in C_t^{(\text{feas})}:q^{(\text{viol})}_{e,t}(U)\le\alpha,\forall e\}$。无评估实体时安全集等于可行集；安全集为空则使用**制动回退**。
- **代价排序**：
  - **目标进度** $J^{(\text{goal})}$：候选终端位置到目标的距离，用参考终端距离归一化（含 $\varepsilon$ 防除零）。
  - **残余交互风险** $J^{(\text{risk})}$：对软距离 $d^{(\text{soft})}>d^{(\text{hard})}$ 的最大亏缺取平方正部，**取最大值**以免关键近距遭遇被平均掩盖。
  - **响应负担** $J^{(\text{brdn})}$：候选诱导的实体速度与加速度相对参考的偏差加权平方和。
  - **总代价** $J_t$：风险与负担项对潜在模式与模式条件预测响应双重期望后，与目标进度项加权求和；在 $C_t^{(\text{safe})}$ 中选代价最小者 $U_t^\star$。

### 2.7 后向耦合：证据驱动贝叶斯更新（EBU）

- **证据采集**：执行 $U_t^\star$ 前 $L$ 步（低层控制器执行，因扰动实际运动可能偏离计划），记录实际执行的机器人状态 $U^{(\text{exec})}_{t,1:L}$ 与同步实体速度响应 $Y^{(\text{obs})}_{e,t,1:L}$，与局部上下文共同构成 $\xi_{e,t}$。
- **后验更新**：对每个模式计算已执行前缀的对数似然 $\eta^{(L)}_{e,t}(z)=\log p^{(L)}_\phi(Y^{(\text{obs})}_{e,t,1:L}\mid H_{e,t},U^{(\text{exec})}_{t,1:L},z)$（与全时域预测共享同一 FRM 参数），再用贝叶斯规则更新：
  $$b_{e,t+1}(z)=\frac{b_{e,t}(z)\exp(\eta^{(L)}_{e,t}(z))}{\sum_{k}b_{e,t}(k)\exp(\eta^{(L)}_{e,t}(k))}$$
- 新实体用 $b_{e,0}(z)$ 初始化；某窗口无同步观测则后验原样传递；身份轨迹终止后丢弃。

### 2.8 离线训练

- FRM 需同时支持**全时域预测**与**短前缀似然**，二者用同一套参数联合训练。
- 训练样本由配对的三条分支（参考、单机器人改变、联合改变）在匹配上下文、场景初始状态、外生随机性与响应模式标签下生成。
- 前缀长度 $\tilde{L}\sim P^{(\text{pref})}$，$\tilde{L}\in\{1,\dots,T\}$；定义归一化全时域对数似然 $\ell^{(T)}_n$ 与前缀对数似然 $\ell^{(\text{pref})}_n$（按 2 个速度坐标与时间步归一化）。
- 总损失 $L^{(\text{resp})}=-\frac{1}{|B|}\sum_{n\in B}[\ell^{(T)}_n+\lambda^{(\text{pref})}\ell^{(\text{pref})}_n]$，端到端梯度下降优化全部 FRM 参数。

## 3. 实验设计：数据集/场景、Benchmark 与对比方法

### 3.1 评估协议（合成）

- **因果响应协议（causal-response protocol）**：用于评估**前向模型**。生成匹配场景，在四种机器人运动干预下（无、仅一个、另一个、两个机器人轨迹改变）保持初始状态与外生随机性固定，直接测量非加性联合效应。
  - 每场景 2 机器人、12 实体；none / additive / nonlinear 三种响应机制各 4,096 / 256 / 256（训练/验证/测试）场景。
- **持续模式协议（persistent-mode protocol）**：用于评估**后向更新**。响应模式在多个重规划窗口内固定。
  - 每 episode 3 机器人、10 实体（每窗口观测 3 个）；8,192 训练 episode，256 同分布（ID）与 256 分布外（OOD）测试 episode；团队动作相关，8 窗口内模式固定。
- **通用设置**：5 个随机种子、8 步历史、12 步预测时域、$\Delta=0.4$ s、3 步执行前缀、模型宽度 96。
- **指标**：负对数似然（NLL）、平均位移误差（ADE）、最终位移误差（FDE）、配对效应 RMSE（pair RMSE）。

### 3.2 前向耦合对比方法

- 消融：HistoryOnly（无机器人动作输入）、NearestRobot（最近机器人条件）、Additive（无成对残差）、
