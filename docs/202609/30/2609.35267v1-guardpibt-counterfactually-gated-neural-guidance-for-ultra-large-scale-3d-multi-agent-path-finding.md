## 摘要
在密集交通下，大规模 3D 多智能体路径规划变得愈发困难。带回溯的优先级继承（PIBT）具有良好可扩展性，但在密集交互和大规模拥塞下，其单步目标导向排序可能变得不够充分。我们提出 GuardPIBT，它增强而非替代 PIBT 执行器：神经预测仅对 PIBT 原生候选提出残差重排序，而最终动作仍由 PIBT 决定。首先，局部图注意力对邻近交互建模，而全局源—目标传输特征为候选重排序提供群体级协调上下文。其次，反事实组门控过滤那些其闭环效应可能损害协调的重排序。第三，对于超大规模群体，群体自适应分组保持决策粒度，异步缓存推理摊薄神经计算开销，选择性修复解决长尾智能体。PIBT 始终保留有效性检查、优先级继承和回溯。在多达 100,000 个智能体的实验中，在 2D 和 3D 环境中均展示出可靠完成，包括全部三次 100,000 智能体仓库运行，且经审计的图违规为零。项目网站见：{\color{magenta}\texttt{https://guardpibt.github.io/GuardPIBT/}}。

## Abstract
Large-scale 3D multi-agent path finding becomes increasingly difficult under dense traffic. Priority Inheritance with Backtracking (PIBT) scales well, but its one-step goal-directed ordering may become insufficient under dense interactions and large-scale congestion. We present GuardPIBT, which augments rather than replaces the PIBT executor: neural predictions only propose residual reorderings of PIBT's native candidates, while final actions remain determined by PIBT. First, local graph attention models nearby interactions, while global source--goal transport features provide population-level coordination context for candidate reordering. Second, a counterfactual group gate filters reorderings whose closed-loop effects may degrade coordination. Third, for ultra-large populations, population-adaptive grouping preserves decision granularity, asynchronous cached inference amortizes neural computation, and selective repair resolves long-tail agents. PIBT retains validity checking, priority inheritance, and backtracking throughout. Experiments with up to 100,000 agents demonstrate reliable completion across 2D and 3D environments, including all three 100,000-agent warehouse runs with zero audited graph violations. The project website is available at {\color{magenta}\texttt{https://guardpibt.github.io/GuardPIBT/}}.

  - 经典最优/有界次优求解器（CBS、ECBS）有解质量保证，但对智能体数、地图尺寸、冲突密度扩展性差。

  1. PIBT 主要依赖局部交互与目标导向代价，**难以捕捉大量智能体汇聚到共享区域所产生的长程拥堵**；

## 2. 方法论

### 2.1 核心思想
- 保留 PIBT 作为离散执行器，只学习其候选排序上的**残差修正**；将全部候选 bonus 置零即可**精确退化**为所选 PIBT 基线。
- 两阶段训练：先学候选打分器（提案），再用真实 PIBT 闭环 rollout 学反事实组门控（提案准入），避免门控监督期间提案分布漂移。

### 2.2 轻量 3D PIBT 骨干
- 为控制内存，不做完整 3D 距离场（否则为 O(N·W·H·D)），而是使用**松弛但避障感知的下界**：
  - 投影 2D 障碍 `O2D(x,y)=∏_z O3D(x,y,z)`（整列被占才视为阻塞）；
  - 同一目标列的智能体共享一个 8 连通 BFS 场；
  - 自由空间 26 邻域下界 `h_open = √3·d1 + √2·(d2−d1) + (d3−d2)`，投影下界 `h_proj = √2·min(d_xy,d_z) + |d_xy−d_z|`，取二者最大。
- 候选代价用定点整数表示（轴向 100、面对角 141、空间对角 173），默认键 `K_i^t(a) = c(a) + h_i(x_i^t+a)`。
- 智能体优先级由累积延迟与非目标等待构成：`δ = [q + h(x) − h(s)]₊`，`p = δ + λ_w·w + ε_i`。
- PIBT 内核本身不变：按优先级处理、暂占目标、递归移动低优先级占位者、释放失败声明、回溯。

### 2.3 全局–局部候选打分
- **局部交互分支**：13 维智能体特征（归一化位置、目标位移、无穷范数距离、归一化时间、上一时刻运动、是否在目标、度数），半径图连接至多 k_n 个邻居；边特征被加入 key 与 value，形成消息感知注意力（式 12–13）。
- **全局源–目标运输分支**：
  - 定义直连路径 `ξ_τ = (1−τ)x̄ + τḡ`，`u = ḡ − x̄`，实现中 τ=0，即按当前位置分配宏单元、目标速度为归一化的当前→目标位移；
  - 工作空间划分为固定 `Bx×By×Bz` 网格，每个活跃 token 存中心、当前/目标密度、裁剪密度失衡、平均剩余位移、平均近期速度；
  - token 间做稠密自注意力，速度头以 **rectified flow matching** 损失 `L_FM` 监督；
  - 每个智能体用学习到的距离、相对方向、目标对齐偏置查询所有 token，得到 `z_flow`；
  - 门控残差融合：`γ = σ(W_g[z_loc; z_flow])`，`z = LN(z_loc + γ⊙z_flow)`。
  - **关键区别**：全局上下文在线从当前群体重建，而非存储为地图特定的 guidance graph，因此可跨地图、跨规模迁移。
- **PIBT 感知的候选打分**：对每个位移构造候选特征 `ψ = [a_x,a_y,a_z, 目标占用, 竞争默认需求, 单步反向边风险, 是否默认候选]`，共享网络输出 27 维 logit，并加入候选特定分数与运输速度对齐项（式 18）。
- 编译执行器键：`K̃ = 10³(K_fix − β_fix) + κ`，其中 κ 为确定性次级 tie-breaking 与显式启用的治理项。**学习到的 bonus 只改变 PIBT 测试合法候选的顺序**；障碍过滤在排序前，目标占用声明、父单元/反向边拒绝、优先级继承、占位者驱逐、声明释放与回溯全部留在 PIBT 内核内。

### 2.4 执行器对齐的反事实组门控
- **反事实监督**：冻结打分器在 on-policy 帧上生成合法 top-k 提案，将活跃提案智能体做**空间分组**；对每组 g，从同一构型、同一逐步优先级噪声出发，分别跑基线（默认 PIBT 顺序）与干预（前 K 步激活该组重排序）的真实 PIBT 内核 H 步。
  - 代价 `J(τ) = C_exec + H_rem − λ_s N_solved + λ_w W + λ_m L_motion + λ_c C_column`；
  - 反事实优势 `A_g = J(τ_base) − J(τ_int)`，标签 `y_g = 1[A_g > 0]`。
- **门控网络**：`ℓ_cf = ℓ_base + w_cf^⊤ tanh(W_cf z_i + φ_c(ψ_ia))`，同一状态可对一个候选接受、对另一个拒绝；训练时组内提案 logit 聚合为 `ℓ_cf,g`，用带优势加权的 BCE 加一致性正则（式 23）优化。
- **在线执行**：每个活跃提案得到 `p_cf = σ(ℓ_cf)`，组内取平均，**只有组均值超过阈值 τ_cf 才激活该组重排序**——从而避免同一拥堵区域内互相矛盾的干预。

### 2.5 两阶段训练
- **Stage 1**：on-policy PIBT rollout 提供状态、默认代价向量、执行有效目标候选与未来运动统计；优化 `L1 = λ_rank L_rank + λ_def L_default + λ_FM L_FM + λ_aux L_aux`。
- **Stage 2**：冻结运输编码器、局部 GAT 与候选打分器，用式 (20) 生成组标签，只优化反事实头；部署阈值在留出组上结合校准与实测配对优势选取。

### 2.6 超大规模部署扩展（仅用于 10 万级完成实验）
- **种群自适应分组**：`B_d(N) = max(1, round(B_d^ref·(N/N_ref)^{1/3}))`，参考 6×4×2（N_ref=1000）在 N=100,000 时变为 28×19×9，使组内期望人数近似恒定；组概率只用活跃提案智能体，避免已完成/被过滤智能体稀释决策。
- **稀疏异步刷新**：全局 token 始终从全群体聚合；局部图、候选张量与输出头可只对已知活跃目标构建，否则按固定 chunk 评估全体；single-flight 异步 worker 在 PIBT 复用上一有效 bonus 的同时计算下一快照，快照完成后才安装，并有固定 TTL 过期，从而把神经推理摊薄到多个编译 PIBT 步之外。
- **选择性长尾完成**：批量协调由重复的分组 GuardPIBT 阶段完成；停滞时重启优先级噪声、提升未解决/被接受提案的智能体、逐步放松门控、用 frontier holding 防止已完成目标层重新占用接近区域；**只有最终残余集合进入时间索引 SIPP 修复**（已完成智能体成为保留资源，少数阻塞目标的智能体可被临时释放再返回），最后用短 PIBT 阶段把修复路径接回在线执行。
- **复杂度**：单次刷新 `O(N·k_n·d + M²d + N_t·M·d + 27·N_t·d)`；全局 token 聚合对 N 线性，目标注意力与候选打分依赖 `N_t ≪ N`。共享目标列把下界存储从 `O(NWHD)` 降到 `O(|U|WH)`。
- **参考配置**：隐藏宽度 64、4 头、2 层局部 GAT、1 层 token 注意力、12×8×4 宏网格、最多 16 个图邻居；反事实标签 H=32 步 rollout、K=8 步干预；标准打分器 top-k=3，10 万级冻结配置可用 top-k=1。
