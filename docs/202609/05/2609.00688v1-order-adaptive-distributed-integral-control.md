## 摘要
我们处理分布式动态协调中的一个结构性权衡：当目标复杂度未知时，低控制器阶数可以节省状态，但可能留下持续的跟踪误差；而高阶数则改善跟踪，但可能给每个智能体带来不必要的动力学负担。为了消除这种选择，而不诉诸于计算更复杂的非线性反馈或易于抖动的非光滑反馈，我们开发了一种阶数自适应的分布式积分控制器（OADIC）。具体来说，我们从比例反馈开始，并且仅在局部可测的相对误差表明当前阶数不足时，才添加积分状态。同时，我们将候选控制器组织成嵌套形式，从而在阶数切换期间保留现有状态和增益，并保持控制输入的连续性。为了给这一设计提供理论基础，我们首先刻画增强的智能体-目标图上规定相对位移的一致性。接下来，我们构造增益以稳定所有可容许的固定阶子系统，并为变维闭环建立统一的输入-状态稳定性界。此外，我们证明了OADIC在有限个决策间隔后拒绝每个不充分的阶数，并明确给出了关键阶数拒绝时间的界限。

## Abstract
We address a structural tradeoff in distributed dynamic coordination: when the target complexity is unknown, a low controller order saves states but may leave a persistent tracking error, whereas a high order improves tracking but may burden every agent with unnecessary dynamics. To remove this choice without resorting to computationally more involved nonlinear feedback or chattering-prone nonsmooth feedback, we develop an order-adaptive distributed integral controller (OADIC). Specifically, we start with proportional feedback and add integral states only when locally measurable relative errors show that the current order is inadequate. Meanwhile, we organize the candidate controllers in a nested form, thereby preserving the existing states and gains and maintaining continuous control inputs during order transitions. To provide a theoretical basis for this design, we first characterize the consistency of prescribed relative displacements on the augmented agent--target graph. Next, we construct gains that stabilize all admissible fixed-order subsystems and establish a uniform input-to-state stability bound for the variable-dimension closed loop. Furthermore, we prove that OADIC rejects every insufficient order after finitely many decision intervals and explicitly bound the rejection time of the critical order.

# 阶数自适应的分布式积分控制（OADIC）论文总结

## 1. 论文的核心问题与整体含义

**研究动机与背景：**
- 分布式多智能体协同中，控制器应携带多少内部动态是一个核心设计问题。内部模型原理要求控制器复现被跟踪/被抑制信号的动力学，但该原理并未说明当信号复杂度未知时如何选择内部模型的阶数。
- 这导致一个结构性权衡：
  - **阶数过低**：留下未建模的动力学，造成持续的协调误差；
  - **阶数过高**：网络中每个智能体都必须携带不必要的积分状态，产生随智能体数量增长的存储、计算与初始化开销。
- 现有方法的主要不足：
  - 基于内部模型的分布式控制器需要在运行前指定参考信号模型及其维度；
  - 非线性/非光滑（如固定时间、滑模）控制虽然增强暂态性能，但仍保留预先设定的控制器维度，并引入额外实现复杂度；
  - 没有任何方法能在运行中依据观测到的跟踪表现来决定是否需要增加积分状态。
- **论文目标**：在纯线性分布式架构中，实现控制器阶数的在线自适应调节，消除"低阶有误差、高阶有负担"的预先阶数选择矛盾。

## 2. 论文提出的方法论

**核心思想：**
- 提出**阶数自适应分布式积分控制器（Order-Adaptive Distributed Integral Control, OADIC）**：
  - 从最简单的比例反馈出发；
  - 仅当局部可测的相对误差表明当前阶数不足时，才增加一个积分状态；
  - 控制器采用**嵌套结构**，阶数切换时保留已有状态和增益，保持控制输入连续（无扰切换）。

**系统模型：**
- n 个单积分器智能体：ẋᵢ = uᵢ；
- 无向通信图 G，部分智能体可访问动态目标 x₀(t)；
- 目标是通过局部相对测量，使所有智能体达到给定相对位移约束（一致性位形跟踪）。

**关键技术细节：**

1. **一致性条件**：用增强图（agent–target）的关联矩阵刻画给定相对位移的一致性——即沿增强图每个回路的带符号位移和为零，等价于包含位移向量属于关联矩阵的行空间。在此条件下，可将问题转化为每个智能体跟踪目标轨迹加固定偏移。

2. **监视器设计**：每个智能体从局部相对误差构造局部监管量 ρᵢ(t)，通过网络最大一致算法得到网络级指标 J(t) = maxᵢ ρᵢ(t)；该指标与全局跟踪误差 ∥e∥ 等价（双向不等式）。

3. **切换规则**：在每个决策区间 [tₖ, tₖ₊₁] 计算相对误差缩减率 rₖ = [J(tₖ) − J(tₖ₊₁)]/J(tₖ)。若 rₖ 不超过递减阈值 εₖ（εₖ = ε∞ + ε₀/(k+1)^α），则激活一个额外积分状态。

4. **嵌套增益设计**：采用统一的嵌套增益序列（满足递推不等式），使得所有固定阶子系统同时稳定。增益条件为 κ₀ > 0, κ₁ < λ₁κ₀²/4, κₗ₊₁ < κₗ²/(4κₗ₋₁) 等，保证特征多项式所有根为负实数。

5. **控制器状态转移规则**：切换时保留所有已有积分状态，仅初始化新状态为零，从而保证切换前后控制输入连续。

6. **稳定性理论**：
   - 将闭环写成变维导数状态 η 的动态方程（含目标导数作为外部输入）；
   - 证明每个固定阶 Aᵠ 均是 Hurwitz 矩阵；
   - 建立**统一输入-状态稳定性（ISS）界**，同时涵盖连续动力学、目标强迫与阶数切换引起的重置项；
   - 证明最终阶数 q∞ 存在，且若 q∞ < qmax 则在决策时刻误差按收缩因子收缩；若饱和到 qmax，误差极限正比于未建模导数 x₀^(qmax) 的极限幅值与子系统增益的乘积。

7. **不足阶数的有限时间检测**：
   - 对目标为 d 阶多项式的情形，证明任何非饱和的阶数 q ≤ d 都会在有限决策间隔后被拒绝；
   - 对最难检测的临界阶数 q = d（误差有界收敛到非零残差），给出显式的拒绝时间上界。

## 6. 论文的主要结论与发现

1. **OADIC 在保持纯线性、分布式控制结构的前提下，实现了控制器阶数的在线自适应**——从比例反馈起步，按需逐步增加积分状态，避免提前指定内部模型维度。
2. **所有固定阶子系统可同时稳定**：嵌套增益构造条件使得每个阶数的闭环状态矩阵均为 Hurwitz。
3. **变维闭环满足一致的输入-状态稳定性界**：即使发生阶数切换（伴随状态向量维数增加），目标导数有界时误差状态保持一致有界。
4. **不足阶数可在有限决策间隔后被检测并拒绝**：即使固定阶子系统本身稳定但留下非零稳态误差，OADIC 仍能识别内部模型不足并继续增加阶数；临界阶数（最难检测）的拒绝时间有显式上界。
5. **精度-复杂度权衡的有效性**：
   - 相比固定 q = 3 控制器，OADIC 的积分状态时间平均减少 23.3%，同时接近其三阶跟踪精度；
   - 相比固定 q = 2 控制器，OADIC 的尾部 RMS 误差降低约 95.8%；
   - NFOIC 尽管尾部误差最小，但全程保留两个积分状态且引入符号幂次反馈，复杂度更高。

## 7. 优点

- **问题定位精准**：针对分布式控制中普遍存在但被忽视的"内部模型阶数在线选择"问题，介于线性低阶与复杂非线性方法之间填补了一个清晰缺口。
- **纯线性架构**：所有激活阶数下的控制律都是线性组合，不引入非线性反馈或非光滑项，避免了抖振与特殊解定义问题，便于实际工程实现。
- **无扰切换**：嵌套结构配合新的积分状态置零的重置规则，使切换前后控制输入连续（bumpless transfer），且有严格的线性重置映射 Lemma 5 支撑。
- **理论深度扎实**：
  - 一致性条件有清晰的图论/代数刻画（关联矩阵行空间条件）；
  - 增益构造条件利用 Kurtz 多项式判据，保证闭环特征根全为负实根；
  - 对变维混杂系统给出一致的 ISS 界，明确处理状态维数变化的切换与重置；
  - 对不足阶数有限时间拒绝的证明中，对 q < d（误差多项式增长）和 q = d（误差收敛到非零常数）两种情况分别给出严谨分析，并给出显式拒绝时间界限。
- **监视器设计精巧**：使用局部边误差的平方和构造指标，并通过最大一致算法计算网络级指标，与全局误差等价且完全分布式可实现。
- **对比实验的信息量较好**：通过三类对比方法（低阶、满阶、非线性增强）清楚展示了准确性-复杂性之间的权衡，特别是以平均积分状态时间为量化指标的思路值得借鉴。

## 8. 不足与局限

- **实验覆盖范围窄**：
  - 仅仿真了一组网络拓扑（10 节点环+两条链路）和一种目标轨迹（二次多项式）；
  - 未验证更高维状态空间、有向图、切换拓扑、时延、测量噪声、异构智能体动力学等更复杂实际场景；
  - 虽然论文理论分析可推广到更高维（通过 Kronecker 积），但数值验证没有体现。
- **无统计分析与敏感性研究**：单次确定性仿真，没有对阈值参数（ε₀、ε∞、α）、决策间隔 Td、增益 κ 的扰动开展敏感性实验，无法说明这些参数选择对鲁棒性的影响。
- **"拒绝时间上界"依赖的量在分布式场景下不直接可获得**：定理 3 中的 τd 依赖于 η(t_kd)、η⋆等集中式量（如 λn/Md/βd 等全局量），主要用于理论分析而非实际分布式估计。
- **OADIC 的延迟自适应导致暂态精度不及全程满阶控制器**：论文自己承认——OADIC 换取的是状态省却，而非暂态加速；在时间紧迫或跟踪误差需要快速收敛的场景中，它的价值有限。

- **未涉及实际多机器人系统的物理约束**：未考虑输入饱和、执行器限制、通信丢包等真实装置问题；
- **潜在的偏差风险**：NFOIC 非线性增益幅度被作者"有意设定为有利于 NFOIC"（原文如此），这虽然展现了结构对比，但并非一个公平的性能极限对照基准；此外对固定阶 q = 3 的评价没有计及其数值实现时线性增益的调参成本。
