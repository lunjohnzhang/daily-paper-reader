## 摘要
多智能体组合优化问题因其NP-hard特性而极具挑战性。近年来的并行自回归神经求解器通过允许智能体同时决策来提高推理效率，但其性能在大规模实例上往往会下降。这主要归因于对局部几何结构的建模较弱，以及冲突任务选择仅在动作生成后才被处理。为解决这些局限性，我们提出了GeoPAR，一种面向可扩展多智能体组合优化的几何引导并行自回归强化学习框架。GeoPAR集成了三个关键组件：（1）投影窗口稀疏几何机制，通过多方向投影构建轻量级局部候选邻域；（2）稀疏边偏置注意力，将这些几何关系注入节点表示；（3）缓存引导的冲突感知分配，在解码过程中重用几何缓存以抑制独占任务的重复选择。在异构车辆路径问题和开放式多车场取送货问题上的实验表明，GeoPAR在减少路径展开步数并保持高效推理的同时，提升了大规模零样本泛化能力。

## Abstract
Multi-agent combinatorial optimization problems are notoriously challenging due to their NP-hard nature. Recent parallel autoregressive neural solvers improve inference efficiency by allowing agents to make decisions simultaneously, but their performance often degrades on large-scale instances. This is largely attributable to weak modeling of local geometric structures and the fact that conflicting task selections are handled only after action generation. To address these limitations, we propose GeoPAR, a geometry-guided parallel autoregressive reinforcement learning framework for scalable multi-agent combinatorial optimization. GeoPAR integrates three key components: (1) a projection-window sparse geometry mechanism that builds lightweight local candidate neighborhoods through multi-directional projections, (2) sparse edge-biased attention that injects these geometric relations into node representations, and (3) cache-guided conflict-aware assignment that reuses the geometric cache during decoding to suppress duplicate selections of exclusive tasks. Experiments on heterogeneous vehicle routing and open multi-depot pickup-and-delivery problems show that GeoPAR improves large-scale zero-shot generalization while substantially reducing rollout steps and maintaining efficient inference.

## 2. 方法论：核心思想、技术细节与算法要点

- **总体框架**：GeoPAR 是一套几何引导的并行自回归策略，由三部分构成：投影窗口稀疏编码器、动态并行指针解码器、缓存引导的冲突感知分配模块。

### 2.1 投影窗口稀疏几何机制（Projection-Window Cache，PWin）
- 目标：避免构建稠密的节点间关系图，同时保留与任务相关的局部几何邻域。
- 具体做法：
  - 将任务节点用低维几何描述符 \( z_i \) 表示（如归一化坐标）；
  - 沿 \( q \) 个单位投影方向 \( u_\ell \) 对节点进行排序，得到多个一维排序；
  - 对每个方向取滑动窗口半径 \( w \) 内的“排名邻居”，合并多方向候选后利用 TopK 截断为每个节点保留最多 \( K \) 个候选，构成稀疏几何缓存 \( \mathcal{N}_\mathrm{pw} \)。
- 作用：局部候选邻域的构造为廉价近似，避免完整距离矩阵计算的 \( O(N^2) \) 开销。

### 2.2 稀疏边偏置注意力（Sparse Edge-Biased Attention）
- 在编码器中，将投影窗口邻域作为注意力可见范围。
- 对每个缓存边对 \( (i,j) \) 构造边描述符 \( \psi_{ij} \)、候选来源类型 \( c_{ij} \)、归一化排名距离 \( \rho_{ij} \)。
- 注意力分数公式为：
  \[
  e_{ij}^{(r)} = a_{ij}^{(r)} + b_\psi^{(r)}(\psi_{ij}) + b_c^{(r)}(c_{ij}) + b_\rho^{(r)}(\rho_{ij})
  \]
  其中 \( a_{ij}^{(r)} \) 为注意力点积项，其余为偏置项，将几何信息注入局部节点表示。
- 同时节点还额外关注 agent 嵌入获取条件信息，并通过可学习残差门控得到更新后的节点表示。

### 2.3 动态并行指针解码器
- 每个 active agent 的查询由静态 agent 嵌入、动态 agent 状态、全局环境状态共同构造：
  \[
  q_m^t = W_q[ h_{A_m}; \phi_A(\delta_m^t); \phi_E(s_t) ]
  \]
- 智能体之间先经过一个轻量通信模块，再与可行的 action 嵌入做点积得到指针 logits：
  \[
  L_{m,j}^t = \beta \cdot \tanh\left( \frac{\langle W_Q \bar q_m^t, W_K \bar h_j^t \rangle}{\sqrt d} \right)
  \]
- 输出每个 agent 上的独立动作分布，但原始并行动作可能冲突，需要下一模块处理。

### 2.4 缓存引导的冲突感知分配（Cache-Guided Conflict-Aware Assignment）
- 对每个 agent 构造紧凑候选池：
  \[
  \mathcal{B}_m^t = \mathrm{TopK\_logit}(m) \cup \mathrm{CacheK}(m,\mathcal{N}_\mathrm{pw},s_t) \cup \mathrm{HeurK}(m,s_t)
  \]
  - 分别来自解码器高概率动作、投影窗口缓存中的几何后继候选、轻量任务原生候选（如 savings 启发式候选）；训练时再加入少量随机可行候选。
- 对池内候选打分：
  \[
  S_{m,j}^t = \ell_{m,j}^{\theta,t} + \lambda_\mathrm{geo} B_{m,j}^{\mathrm{geo}} - \Omega_{m,j}^t
  \]
  - 其中 \( \ell \) 为神经解码分数，\( B^{\mathrm{geo}} \) 为缓存几何奖励，\( \Omega \) 为即时软代价（如旅行时间、makespan 估计增量、负载过高等）。
- 关键约束：独占任务不能被多个 agent 在同一并行步重复选择。
  - 训练阶段：采样时排除已被消费的独占动作（Sample X）；
  - 推理阶段：冲突动作只分配给分数最高的 agent（Resolve X）；
  - 无可用任务时通过 Fallback 选择等待类安全动作。
- 算法流程：Pool → Score → TopR → Sample X（训练）/ Resolve X（推理）→ Fallback。

### 2.5 训练目标
- 以强化学习 score-function 估计器进行训练：
  \[
  \nabla_\theta J(\theta) = \mathbb{E}\left[ (R-b) \sum_{t=1}^{T} \nabla_\theta \log \pi_\theta^{\mathrm{train}}(\tilde a_t | s_t) \right]
  \]
- 其中 \( \log \pi_\theta^{\mathrm{train}} \) 基于经过冲突感知采样后的可执行联合动作在候选集上的 softmax/log 概率计算。

## 6. 主要结论与发现

1. **大规模零样本泛化显著改善**：
   - HCVRP 上，在大规模测试（如 1000/20、2000/40、3000/60、5000/200、5000/400）中，GeoPAR 几乎全面取得最低目标值；
   - 对比 PARCO，GeoPAR 在大规模 OMDCPDP 上也稳定获得更好的目标值，说明方法不局限于欧氏车辆路由问题。
2. **Rollout 步数和推理时间大幅减少**：
   - HCVRP 上，例如 1000/20 从 PARCO 的 693 步降至约 215 步；
   - 某些大规模配置下 rollout steps 可降低 70% 以上，推理时间相对 PARCO 和 2D-Ptr 平均加速 7.5× 与 33.8×；
   - 效率提升并非仅来自推理硬件或简单并行化，而在于冲突感知分配避免了重复/浪费的并行动作。
3. **几何缓存与冲突感知机制互补**：
   - 仅加入 CA（不引入 PWin）主要通过减少冲突来缩短 rollout，但目标值不一定改善，甚至大规模下游变差；
   - 仅加入 PWin（不加 CA）可以提高局部候选质量，但无法有效缩短 rollout；
   - 只有两者同时存在时，方法才同时取得目标值优化和步数减少。
4. **CA 内部组件的作用顺序明确**：
   - 仅 logit Top-K 冲突解析已能大幅减少步数但质量不稳定；
   - 几何候选加入池（GeoPool）不一定有效，只有几何奖励进入打分（GeoScore）后才有实际增益；
   - Full CA 在 3000-5000 规模下相比 GeoScore 额外提升目标值但略微牺牲效率，表明质量与效率存在可调节的取舍。
5. **方向数经验选择**：
   - \( q=4 \) 是在解质量和运行成本之间的较优折中：相比 \( q=8 \) 目标值差距小于 0.5%，但运行时间最高节省 17.2%。
6. **极端设置仍是弱点**：
   - 极低 agent 密度（例如 fleet scarcity）的 HCVRP 情况下目标值仍高度敏感，提升不均匀。

- **验证维度丰富**：除最终指标外，还从路径边召回率、rollout steps、train-time dynamics、direction 数量等多个角度验证机制效果，帮助读者理解“为什么有效”和“瓶颈在哪”。
- **对比透明度**：在补充材料中报道了 HAM 在大型 OMDCPDP 上极差的表现，避免选择性展示强基线；同时承认在某些设置中 GeoPAR 目标值不如强启发式（如小规模 HCVRP 的 SISRs），结论相对客观。
- **充分报告时间成本**：不仅报告目标值，而且报告 amortized time/推理时间，能更清楚地判断方法在实际应用中的可负担性。
